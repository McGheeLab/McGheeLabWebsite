Tick Available to put a module in every teacher's picker on the #/teach dashboard — nothing else here changes what teachers see. Use ↗ Open to read the module in a new tab exactly as a student gets it before you make it available. ✎ Details adds the subjects, grade levels and one-line description that help a teacher choose. The module files themselves come from /modules/manifest.json — this tab only curates visibility and metadata.
Loading engagement hub…
Oversight of the public engagement hub (/#/engage): approve teacher listings (nothing is browsable until approved), watch every availability slot, and intervene on any visit request — confirm, decline, or cancel on the teacher's behalf. External researchers get in via the engage:browse / engage:request capabilities on the permissions page; lab members need no grant.
Loading profiles…
Approved profiles appear in the "Teachers Using Our Materials" section of the public People page. Any edit by the teacher automatically pulls the profile back to pending until re-approved.
