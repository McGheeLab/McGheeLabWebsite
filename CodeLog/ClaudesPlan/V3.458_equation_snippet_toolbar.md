# V3.458 — matrix + accent snippet toolbar on every math-field

> Test feedback on Paper Builder III (fix 6 of 7, first half of issue 1): "the equation
> editor needs matrix, and special operator stuff like dot over the variable or double
> dot etc."

## What changed

**rm/js/mathlive-loader.js** gains `window.mathliveSnippetBar(mf)` — a toolbar element
mounted above any `<math-field>`. It lives in the shared loader (not paper-editor.js)
because both the builder AND the library reader's capture modal need it; its CSS
self-injects once (`_injectSnipbarCss`), so no page-specific stylesheet edits.

Groups:
- **Accents** — ẋ `\dot{#@}` · ẍ `\ddot{#@}` · x̂ `\hat{#@}` · x̄ `\bar{#@}` ·
  x⃗ `\vec{#@}` · x̃ `\tilde{#@}` · x′ `{#@}^{\prime}` (`#@` = MathLive's
  wrap-the-selection token; empty selection leaves a placeholder).
- **Structure** — fraction `\frac{#@}{#?}`, √, superscript, subscript.
- **⊞ Matrix ▾** — popover: type (pmatrix/bmatrix/vmatrix/Bmatrix/cases) + rows×cols
  steppers (1–6; cases forces 2 columns — value & condition) → builds the env with
  `\placeholder{}` cells and inserts. Outside-click closes; the doc listener
  self-removes if the bar leaves the DOM.
- **Operators** — ∑ ∏ ∫ (with bound placeholders) ∮ ∂ ∇ ∞ ± ⋅ ×.

Mechanics: every button `preventDefault()`s on mousedown so the field keeps focus AND
selection (that's what makes `#@` wrap); `_snipInsert` uses `mf.insert(latex,
{focus:true})` (falls back to `executeCommand(['insert', …])`), then dispatches a
synthetic `input` on the field — all three mount sites' dirty guards listen for
`input`, and a toolbar insert is a real edit, so the untouched-open/close fidelity
guarantee (E1) is unaffected.

## Mount sites (all guarded `if (window.mathliveSnippetBar)`)

- **rm/js/paper-equations.js** `_mountVisualToggle.openVisual()` — bar inserted above
  the field, removed in `closeVisual()` (covers all three library-row/create-modal
  seams).
- **rm/js/paper-blocks.js** `_openEqVisualOverlay` — bar atop the modal host, above the
  field; inserts enable Apply like hand edits.
- **rm/js/equation-capture.js** `showVisual()` — bar above the capture modal's field
  (reader page).
