# V4.38 — Reading sets: a paper's project by where it belongs; a slim row where each set's box holds its tabs

## Goal
Gabe (19 Nov 2026): "Papers that are not assigned a project get assigned to a project based on the greatest number of appearance in a project out of all of them. The tab space for reading sets is too large, and the reading set color/region must envelop the paper tab space from the same tab. Right now, all papers open in Auto In-Vitro so project assignment is not working properly."

## Why everything went to Auto In-Vitro
A paper read from the Library is shown on its literature note (`READER.litDoc`, 17b), and that note is made in `READER.project()`: the project last chosen in the Library's reader, else **the first project in the notebook**. V4.29 put a paper in the set of the project of the note it came from, so every Library paper — and any paper picked from the reader's + while that set was shown — landed in that one project's set.

## Approach
- **`RSET.auto(d)`:** the reader's own literature note of a Library paper (`type: literature`, `libId`, not a review). Its project was only a default, never an assignment.
- **`RSET.appears(b)`:** a paper's appearances by project:
  - its cards in notes (`RDX.embedsOf`, or the same file);
  - the components that cite it, show its card bridged (`RDX.citedIn`), or quote it.

  The reader's own literature notes and notes outside any project don't count.
- **`RSET.home(b)`:** the project of the note it is a card in, when that note is in a project and is not the reader's own; else the project with the most appearances (Gabe's rule); else none.
- **`RSET.target(b)`, the set a paper goes in:**
  - the set of the project you are in (the note's; from the reader itself, the set shown), when the paper appears in that project — so a paper of two projects is in both;
  - otherwise its home;
  - a paper that appears in no project stays where you are.

  The first move of the flat tabs into sets (V4.29's migration) uses the home too.
- **Once (`RSET.rehome`, `rtabs.home438`):** tabs already filed in a set they don't belong to move to their home set — a tab doesn't appear in that project and has a home elsewhere. This empties the default project's set of the papers that were wrongly there.
- **The row** (`34-readsets.css`, `.rd-tabs.rs-row`):
  - slimmer: 37 px instead of about 41, with tabs 22 px tall and at most 170 px wide;
  - each set is a **rounded box of its colour**, an edge and a light tint, that holds its name and every one of its tabs, like a region of a note;
  - the tab being read is lit inside the box instead of cut out of it;
  - the name is in the app's type at 11 px rather than spaced capitals (up to 17 characters; the whole name is in its tooltip);
  - the chips are the same height as the box;
  - the row's +, ◫ and ✕ are compact.
- **Settings → Reading sets by project:** the description says where a paper goes.
