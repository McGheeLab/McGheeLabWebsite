# V3.531 — My Day R6: pending confirmations + week glance + home tile

Part of the **My Day program** — see `V3.526_my_day_program.md`.

## Goal
The morning loop: yesterday's unresolved plans ask "did this happen?";
the week strip gives 7-day context; the RM home page points at both.

## Approach
- **Pending confirmations** (my-day.js): items from the last 7 days still
  `status:'planned'` render as amber cards — ✓ Did it
  (`DAY_DISTRIBUTE.confirmDone`: work event via
  `ActivitySignals.recordWork`, huddle plan → `completed`, notebook nudge
  toast) · ✗ Skipped · → Today (date edit through the full cascade, so
  booking/huddle/tracker follow).
- **Week glance**: Mon–Sun count dots over the viewed week (one range
  query), tap = jump date.
- **`rm/js/home-feed.js`** gains `tileMyDay` (first tile): "N planned
  today, M awaiting confirmation" → my-day.html. Fail-silent like every
  home-feed tile; hidden when there's nothing to say.

## Deploy
FTP only.

## Verify
- A planned item from yesterday shows the amber card this morning.
- ✓ creates `auto-dayplan-<id>-<date>` work event alongside the schedule
  event; huddle card flips completed.
- → Today moves the booking + huddle + tracker dates.
- Home strip shows the tile only when counts are non-zero.
