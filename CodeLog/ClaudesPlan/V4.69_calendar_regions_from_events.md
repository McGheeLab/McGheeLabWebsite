# V4.69 — Scientia Calendar: what was written during an event becomes a region named after it

## Why
Gabe, 19 Nov: "Actvity logged during an event automatically groups them in a region after the event ends, and if there is a dependency, it bridges that region to the other dependency region if it is in another note, and links them if they are in the same note. The region name is the event name. If nothing is logged into that event time, later in that note, it asks you if you want to log anything from that event, thus creating the region for you to work in. It also appears as a reminder on the Today tab." Asked again on 20 Nov.

## What changed
- **Once an event has ended** (checked each minute and soon after the app starts, for the last two weeks; `CAL.regionSweep`): the components written during it become a region (`REGION.create`) named after it, with `region.event = {id, day}`.
  - Which components: those written during it in its note (one occurrence's note for a repeat), or in any note if it has no note. Their time is `made` or `created`.
  - Done once per occurrence, kept on the event as `ev.rg[day]`. An event made after its time had passed is skipped.
- **Linked events** (`then`), once both have their regions (`CAL.regionLinks`): in one note, a connection between the two regions (a wire, `leads to`); across notes, a bridge recorded on each region (`region.bridges`).
- **The region's tab** (`REGION.render` wrapped) shows a chip for its day, which opens the calendar there, and one per bridge, which opens the other note.
- **Nothing written during it:** its note asks at the top of the canvas (`CAL.askBar`): "Nothing was written during … Log anything from it?", with **Make its region** and **Not this time**.
  - Make its region: a component "From …" in a region named after the event, opened ready to write.
  - **The Today tab** lists the same questions under "From your calendar" (`VIEWS.home.render` wrapped). For an event with no note it offers Make its note; the question then waits in that note.
- The event's card on the calendar shows an icon once its region is made.
- **Settings → Calendar:** "What is written during an event becomes a region" (on by default), in the preview.
