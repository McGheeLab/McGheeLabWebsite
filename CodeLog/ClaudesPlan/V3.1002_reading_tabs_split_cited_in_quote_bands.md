# V3.1002 — Reading tabs, the split reader, Cited in, where a quote is from

## Goal
Gabe (14 Nov 2026), part 2 of the Library overhaul: several papers (and HTML pages) open at once in the reader as tabs with a + button; switching tabs in the beside view brings you to the paper's origin note; the notes citing the paper offered while reading; the beside view split by tabs up to 2×2 like the notes' split; a quote's citation as visible as the bridge's origin band (V3.994); a bridged quote or excerpt carrying both bands; clicking the citation band opens the paper beside.

## Approach
- **One dock, several panes (`13zzb-reader.js`).** `RDOCK` keeps its API (`open`, `close`, `st`, `draw`, `page`, `zoom`, `step`, `count`, `KINDS`, `phone`, `saved`) so 11b, 13zza, 13zze, 13zzm and 23d keep working; `RDOCK.st` is now the pane in focus and `RDOCK.panes` holds up to four. Every pane is filled through `RDOCK.open(b, { pane })` (the hooks other modules wrap around `open` add their buttons to every pane). The dock (`.rd-wrap`) is the tab row over a grid of panes in the reader's column of `#app`.
- **Tabs, kept per device** in `_ls 'rtabs'`; the note's own `rdock:<docId>` record is still written (the reader goes back to it with the feature off; the lab harness reads it).
- **Where it lives:** tabs on — from note to note; on a page that isn't a note it steps aside (`close(true)`) and comes back with the next note (`restore`). Tabs off — one paper, belonging to its note, exactly as before.
- **The Library link** (`17e` `RDX.libOf`): `block.libId` (set from Cited in's "Link it…" or by `embedFor`), else the same media file, the lab paper (`rmPaper`), the page's address (`web.final|url`).
- **Cited in** reads `IX.citations` (built from cite marks), the paper's other embeds and their bridges.
- **The citation band** reuses the bridge band's markup and look (`.origin`, 24-kinds.css) with its own colour (`--cite`, Settings); `DocView.box` (quotes) and `DocView.refCard` (bridges, passages, widget bridges) are wrapped last.
- **Multiple HTML panes** draw in the same moment: `QUOTE.fill` takes the frame's own `_rdSrc` so each page is its own. The panes' PDFs are pinned against `PDFW.trim`; `DOCS.repaint` redraws a pane that isn't in focus too.
- Settings: `rtabs`, `rsplit` (needs rtabs), `citedin`, `citeband` in 20a-features.js with previews; switches guard the code (`RDOCK.tabsOn/splitOn`, `RDOCK.ftOn`) and CSS (`body.f-off-…`, `.rd-notabs`).
