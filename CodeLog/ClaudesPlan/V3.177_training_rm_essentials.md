# V3.177 — Training: RM Essentials (Day-1 Orientation)

> Status: **BUILT (2026-05-11).** See [rm/pages/training-rm-essentials.html](../../rm/pages/training-rm-essentials.html)
> and [rm/js/training-rm-essentials.js](../../rm/js/training-rm-essentials.js).
> CHANGELOG entry: V3.177. First module in the new "Using RM" category.

## Goal

Get a lab member from "I have a sign-in" to "I operate RM like a power
user" — fluent in the workflow paradigm, the cross-page integration,
and the non-obvious moves (brand-dropdown switching, ⊟ Split, save-as-
custom, Cmd+K multi-pick, 📌 PMR badge, drag-to-reorder strip chips).

**V3.177 explicitly avoids "what RM is" / sign-in / Firestore-as-
source-of-truth content** — per the saved feedback memory
`feedback_rm_trainings_power_user.md`, that material is dead weight in
training. Setup belongs in `rm/CLAUDE.md` if anywhere.

## Format

Lecture-style page (V3.163/V3.176 pattern) — sticky TOC + sequential
sections + three interactive widgets:

1. **Nav-map grid** — for when workflows aren't enough; click a group
   to expand its page list with one-line descriptions and direct links.
2. **Power-user quiz** — six questions that separate new users from
   power users (brand-dropdown vs round-tripping the home page;
   auto-pending tracker entries vs manual re-typing; Cmd+K multi-pick
   vs hand-typed citations; 📌 PMR flagging vs pasting into PMR;
   ⊟ Split vs browser tabs; save-as-custom vs browser bookmarks).
3. **Power-user toolkit checklist** — 12-item self-assessment of the
   habits that mark a power user.

## Sections (11)

1. **The workflow paradigm** — workflows, not pages, are the unit of
   work. The top nav is bare on purpose.
2. **The five default workflows** — when to use each.
3. **The workflow strip** — drag-to-reorder, + Add page, × remove,
   save-as-custom, brand-dropdown for in-shell switching.
4. **Split view** — when to reach for it, how to swap panes mid-flow.
5. **Cross-page integration** — RM's secret weapon. Paper writing
   auto-creates pending tracker entries; notebook 📌 auto-creates PMR
   figure cards; admin task assignment auto-materializes Inbox badge.
6. **Custom workflows** — when defaults don't fit, build your own.
7. **The daily / weekly rhythm** — start-of-day / during / end-of-day
   / end-of-week cadence.
8. **Power-user shortcuts** — non-obvious moves catalogued.
9. **Page inventory** — interactive nav-map widget.
10. **Power-user quiz** — interactive widget.
11. **Power-user toolkit checklist** — interactive widget.
