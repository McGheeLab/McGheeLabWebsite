# V3.105 — Citation panel: Google Scholar "Look up" fallback

## Goal

When a parsed reference has neither a DOI nor an arXiv id, the
citation panel previously offered no way to act on it — only a "no
id" chip explaining why. Reported:

> *"when there is no DOI in the references on the paper the
> references don't show the ability to link to it. In this case, we
> should add a button that says look up and it uses the title to
> search for the paper on google scholar."*

Outcome: every parsed reference becomes actionable. If we have a
DOI, the existing `+ Add to library` flow runs. If we have arXiv,
the `+ Add (arXiv)` flow. If we have **neither**, the user gets a
`Look up` button that opens Google Scholar with the parsed title (or
raw entry text) as the query — they verify the paper, grab the DOI
from Scholar's record, and can come back and add via the DOI flow.

## Approach

Tiny additive change in [rm/js/paper-citations.js](../../rm/js/paper-citations.js)'s
sidebar render path:

1. New helper `_scholarUrl(ref)` — returns
   `https://scholar.google.com/scholar?q=<encoded ref.title or ref.raw>`,
   capped at 250 chars to stay under URL limits.
2. New `else if (ref)` branch in the actions block of `_renderPanel`
   that fires when `ref` is parsed but has no DOI and no arXiv id —
   renders a `<a class="btn btn-sm lp-cite-lookup" target="_blank">`
   pointing at the Scholar URL.

The existing `no id` chip is kept — it's still informative
("auto-add isn't available for this entry") — and the `Look up`
button is the manual path alongside it.

## Files changed

- **`rm/js/paper-citations.js`** — `_scholarUrl(ref)` helper
  (above `_renderPanel`); new `else if (ref)` branch in the actions
  block that returns a `Look up` button when no DOI / no arXiv id.
- **`sw.js`** — `CACHE_VERSION` 79 → 80.

## Out of scope

- Auto-fetching the DOI from Scholar (would require server-side
  scraping; Scholar blocks easy automation).
- Other lookup services (Semantic Scholar, OpenAlex, etc.). Scholar
  is the user's preferred starting point for now.
- A click handler that pulls the user back into the `+ Add to library`
  flow once they've found a DOI — currently the user has to copy/paste
  or use the existing library import flow. Add later if it surfaces.

## Verification

1. Hard reload the paper reader (evict SW cache `mcgheelab-shell-v79`).
2. Open a paper whose reference list contains entries without DOIs
   (older papers, conference proceedings, books, web URLs, etc.).
3. In the citation panel, expand a row whose chip says `no id`. The
   actions area should now contain a `Look up` button.
4. Click `Look up` — Google Scholar opens in a new tab with the
   reference's title (or raw entry) as the search query.
5. References with DOIs / arXiv ids still show their existing
   `+ Add to library` / `+ Add (arXiv)` / `Open paper →` actions
   unchanged.
