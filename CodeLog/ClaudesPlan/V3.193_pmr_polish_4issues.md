# V3.190 — PMR polish: 4 user-reported issues

## Issues to fix (from user, 2026-05-12)

1. **Reference links should auto-import** anything the user has created
   (notebook entries, protocols, past PMRs, paper drafts, grant drafts).
2. **All sections should be rearrangeable** — student moves sections up
   or down depending on what they want to discuss.
3. **Every section should have a New + Archive portion.** Items default
   to New. Once admin and student have "discussed" an item (explicit
   check-off), it moves to Archive. Archive is collapsed by default and
   searchable when expanded.
4. **Goals section: each new line is a bullet** — Enter creates a new
   bullet, Tab indents to a sub-bullet, Shift+Tab outdents.

## Approach

### Schema (additive)

- `state.doc.section_order: string[]` — ordered list of section keys.
  Missing keys fall back to the default order, so new sections added in
  future versions surface automatically.
- Every archivable item across all sections gets a `discussed_at: ISO
  string | null` field. Already exists on `discussion[]` cards from
  V3.157 — reuse the field name across all sections so the helper is
  uniform.

### Shared helpers

- `splitArchive(items)` → `{ active, archived }` based on `discussed_at`.
- `buildDiscussedToggle(item, onChange)` — small "✓ discussed" /
  "↶ restore" button paired with every archivable item.
- `renderItemArchive(label, items, renderItemFn)` — collapsed
  `<details>` with a search input that filters by free-text match across
  the item's stringified content.
- `buildReorderControls(sectionKey)` — `▲`/`▼` arrows on each block
  header that swap positions in `state.doc.section_order`.

### Section-by-section archive

Applies to: barriers, reference_links, weekly_entries (per-week),
project_overview, paper_writing, figure_reviews, discussion.

Skipped (data shape doesn't fit):
- Goals — bullet items have no ids; per-horizon archive doesn't make
  sense ("you don't archive a goal, you achieve it"). Skip for V1.
- Open tasks — pulled live from `tasks/buckets.json`, not stored on the
  PMR doc. Bucket archival lives in V3.189.
- Activity / Stats — read-only summaries.
- Past PMRs — already an archive.

### Goals as bullet lists

Switch each horizon card's contentEditable body to a `<ul>` root:

- Empty body starts with `<ul><li><br></li></ul>`.
- Browser default behavior on `Enter` inside a `<li>` already creates a
  new sibling `<li>`.
- Intercept `Tab` → `document.execCommand('indent')` (nested `<ul>`).
- Intercept `Shift+Tab` → `document.execCommand('outdent')`.
- Save HTML as before; load HTML as before.

### Reference auto-import

New `⤓ Auto-fill from my work` button on the Reference links block:

- `notebookIndex` — `userData/{uid}/notebook/_index` (V3.110 indexed by entry)
- `protocols` — `protocols` where `authorUids array-contains uid`
- `papers` — drafts where `authorUids array-contains uid` and `is_library_entry !== true`
- `past PMRs` — `userData/{uid}/pmr/_index` minus current period
- `grants` — `grantDrafts` where `authorUids array-contains uid` (V3.179)

Dedupe by URL/label so re-runs are idempotent.

## Verification

1. Goals: open a horizon, press Enter → new bullet. Tab → indented. Shift+Tab → out.
2. Reference links: click `⤓ Auto-fill` → notebook/protocols/papers/PMRs/grants appear, deduped on re-run.
3. Sections: click `▲`/`▼` on a section header → reorders. Reload preserves order.
4. Archive: on any archivable section, click `✓ discussed` on an item → it slides into the collapsed "Archive (N)" section. Expand → search → filtered to matching items. Click `↶ restore` → item returns to New.
5. Admin cross-user view: all four behaviors are read-only (no reorder, no discuss-toggle, no auto-import).
