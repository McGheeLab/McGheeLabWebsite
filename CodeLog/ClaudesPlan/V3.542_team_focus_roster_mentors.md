# V3.542 — Team Focus: active-member roster, type grouping, on-page mentor assignment

Follow-up to the Weekly Focus program (`V3.536_weekly_focus_program.md`),
Alex test feedback 2026-07-25.

## Goal

The Team Focus rail should show only active members, organized the way
the lab thinks about them, and the mentorship hierarchy itself should be
editable right there — students assigned under other team members —
while the PI keeps full visibility over everyone's focus and tasks.

## Changes

- **`rm/js/focus-areas.js` `listMentees()`** — filters out
  `category === 'alumni'` and `'guest'` on both paths (admin roster +
  mentor query). Admins still get the whole active roster, so the PI
  sees every student's focus/tasks regardless of mentor assignments
  (unchanged from V3.536 — the `focusAreas` rule already grants admin).
- **`rm/js/team-focus.js`** — rail grouped by member type using the
  people.js category set (PI → Postdocs → Grad students → Undergrads →
  High school → Collaborators → Other), self pinned first. New
  **"reports to" mentor row** in the main column when viewing someone:
  chips of the person's current mentors (`users/{uid}.mentor_uids`) +
  admin-only "＋ assign a mentor…" select (arrayUnion) and ✕ per chip
  (arrayRemove). Admin-gated because `users/{uid}` updates are
  admin-only in firestore.rules — non-admin mentors see the chips
  read-only. Assigning a mentor immediately gives that person
  cross-user access to the mentee's focus areas, PMR, and notebook
  (the existing V3.243 `isMentorOf()` gate).
- **`rm/css/team-focus.css`** — rail group headers + mentor-row styles.

## Also in this release (Alex, same feedback round)

- **My Day filed under Activity in All Pages**: `rm/js/page-registry.js`
  now honors an optional `pageGroup` on top-level NAV_ITEMS entries
  (nav placement stays top-level; the All Pages grid groups by
  `pageGroup`). My Day declares `pageGroup: 'Activity'`.
- **All Pages link cleanup** (`rm/js/all-pages.js`): audited every
  NAV_ITEMS href — no dead files or redirect stubs; added the 11 missing
  tile descriptions (task market, lab notebook, protocols,
  grants/biosketch/facilities, training, pcard helper, classifier
  settings, admin teachers/guests) + descriptions/icons for My Day and
  Team Focus; removed the stale `sharing` entry (page folded into the
  task market in V3.317).
