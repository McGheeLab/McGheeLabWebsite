# V3.466 — Grant unification R4: Grant Docs pill page (shell)

> Fourth release. Adds the `📎 Grant Docs` pill/page — visible only on grant papers —
> as the home for R5 (reusable template library) and R6 (submission checklist). This
> release is the shell + type-gated visibility; the panel shows a placeholder until
> R5/R6 fill it.

## Type-gated pill (rm/js/paper-equations.js)

- `TABS` gains `{ id: 'grant-docs', plainLabel: 'Grant Docs', visibleFor: ['grant'] }`.
  `visibleFor` is a new optional field — tabs without it show for every `paper_type`
  (all existing pills unchanged).
- New `_paperType()` (reads `PaperEditor.getPaperMeta().paper_type`, ready by
  `attach()` time since it runs after the paper loads) + `_tabVisibleFor(tab, type)`.
- New `_reflectPillVisibility()` hides pills whose `visibleFor` excludes the current
  type. Called at pill-bar build AND from `_reflectPillState` (every state sync), so a
  paper_type that resolves just after the first build self-corrects. The Write pill is
  always shown.
- `_buildPanel` adds a `#pe-grant-docs-root` tab-content div (same lazy-scaffold
  contract as Guide/Symbols). `_refreshPanel` adds a `grant-docs` branch:
  `window.PaperGrantDocs.buildTabContent(root)` when that module is loaded (R5/R6),
  else a one-time explanatory placeholder so the page never dead-ends.

## Page routing (rm/pages/paper-builder.html)

- Boot allowlist `PAGES` += `'grant-docs'` + a `PAGE_TITLES` entry. The allowlist only
  gates URL recognition + the tab title / anti-flash CSS — it's type-agnostic by
  design, so `?page=grant-docs` is always a valid URL; on a non-grant paper the pill is
  hidden and the panel shows the placeholder.

## CSS (rm/css/paper-editor.css)

- `.pe-grant-docs-placeholder` + hint styling.

## Verification

- `node --check` clean; CSS balanced; harness 252 green (no export/schema logic
  touched).
- Browser (Alex): on a grant paper the `📎 Grant Docs` pill appears and navigates to
  the page (placeholder for now); on a journal paper the pill is absent; deep-linking

  Write pill still returns to the doc.
