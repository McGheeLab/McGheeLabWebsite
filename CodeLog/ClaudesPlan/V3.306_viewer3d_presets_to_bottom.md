# V3.306 — viewer3d.html mobile: move preset quick-links to the bottom

## Problem

After V3.303's mobile pass, the `☰ Controls` toggle button (top-left, z-index 8,
~118px wide) still overlapped the preset pill bar. Measured on a 390px viewport:
the toggle spanned x=12→130 and the presets started at x=64 — a 66px horizontal
overlap on the same row, so the toggle covered the first preset pill(s).

## Fix (user's suggestion: "the quick links should just go to the bottom")

Mobile-only (`max-width:820px`) in `DataIllustrations/viewer3d.html`:

- **Preset pills → bottom row**: `#presets{top:auto; bottom:10px; left:170px;
  right:10px}` (horizontal scroll retained). This clears the top entirely —
  the top-left Controls toggle and top-right gimbal no longer share a row with
  anything.
- **Legend narrowed** so the presets fit beside it (bottom-left): added a
  `.legend-note` class to the long grains caption div and `#legend
  .legend-note{display:none}` on mobile. Legend now ~150px wide (title + bar),
  presets dock to its right (left:170px).
- **Open panel height trimmed**: `#hud` mobile `max-height` `100vh - 130px` →
  `100vh - 175px`. The panel is content-box, so padding+border add ~30px below
  max-height; the old value let the open panel's visual bottom just touch the
  new bottom preset row. The trim leaves a ~40px gap.

Everything else from V3.303 kept: gimbal `scale(0.56)`, gimbal hidden while the
panel is open (the top-anchored panel still overlaps the top-right gimbal when
open), colorbar pinned to a safe left column.

Desktop (no media-query match) is untouched: presets centered at the top, toggle
hidden, grains caption visible.

## Verification

Headless Chrome (puppeteer-core + system Chrome), 2D bounding-box overlap:
- **390×844 and 375×667**: toggle ∩ presets, presets ∩ legend, presets ∩ gimbal
  all zero; opening the panel does not overlap the bottom preset row
  (panel bottom 755 vs presets top 798 on 390; 578 vs 621 on 375).
- **1400×900**: presets back at top-center, toggle hidden, grains caption shown
  — no regression.
