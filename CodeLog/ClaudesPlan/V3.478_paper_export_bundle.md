# V3.478 — Bidirectional import/export E1: portable export

> First release of the paper import/export program (plan:
> `~/.claude/plans/the-papers-page-the-optimized-dongarra.md`). Export any paper draft
> to a portable, re-importable bundle. Client-only — no deploys.

## What shipped

- **NEW `rm/js/paper-export-bundle.js`** (`window.PaperExportBundle`), loaded on
  `paper-export.html` (JSZip + PAPER_FIGURES + the live `state.yConn` all in scope):
  - `serialize(yConn)` — a **faithful** whole-paper snapshot mirroring paper-editor's
    `_snapshotYValue` `{__ytype}` convention (NOT the exporter's lossy `extractAttrs`),
    so table `cells` (Y.Map<Y.Text>), figure `subfigures` (Y.Array<Y.Map>), composed
    panels, etc. round-trip as Y-types that `appendBlockFromTree` rehydrates. Emits
    every section field (incl. `completed_*`/`revision_*`/`uploaded_file`/`style_overrides`),
    every block (with `skeleton_items`), the `equation_library` (incl. `type`), and the
    `figure_unplaced`/`table_unplaced` libraries. **Section + block `id`s are emitted**
    — the linchpin for comments' `blockId` bindings to survive a round-trip.
  - `buildAndDownload(ctx, statusCb)` assembles `<slug>.paperbundle.zip`:
    `paper.json` (authoritative manifest: paper meta + full `paperExports` config incl.
    checklist + tree + equations + unplaced libs + bibliography + asset index),
    `paper.md` (readable prose — headings, paragraphs, figures→`![](assets/…)`,
    lists, `$$eq$$`, References), `refs.bib` (via `PaperExportTex.buildBibtex`),
    `comments.json` (read from `papers/{id}/comments`), and `assets/<hash>.<ext>` (every
    Storage image — placed figures, unplaced libraries, composed panels, graphical
    abstract, section attachments — fetched via a freshly-minted
    `PAPER_FIGURES.downloadUrl`; failures are logged, not fatal).
  - Bibliography projects each `[@key]` (via `PaperExportTex.collectCitationKeys`) to its
    lab-library `meta.library` fields so citations resolve on reimport without the
    lab-wide `items.json`.
- **`rm/js/paper-export.js`** — `📦 Export paper (portable)` button in `.px-actions` →
  `_exportPortable` (ensures `fullCitationByKey` is loaded, then delegates); a status
  line reports progress/asset counts.
- **`rm/pages/paper-export.html`** — the button + `#px-export-status` + the module
  script tag. **`rm/css/paper-export.css`** — `.px-hint`.
