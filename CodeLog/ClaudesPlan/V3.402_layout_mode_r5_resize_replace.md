## What shipped (rm/js/paper-doc-view.js + rm/css/paper-doc-view.css)

1. **Resize handles** — selecting a figure in a layout session grows
   E/W edge handles on its image (`_attachResizeHandles`, managed by
   `_applyLayoutSelection`, so they survive re-renders). Dragging is
   visual-only (mutates the imgwrap width %; the cached aspect-ratio
   reflows height live), zoom-aware (÷ `state.zoomK`), with a status
   chip. Handles `stopPropagation` so they never start a move-drag; a
   no-move click commits nothing; Esc-cancel inherited from R4's chain.
2. **Canonical-size snapping** — `_snapTargets(containerW)` builds the
   snap set from `PaperLayout.getRules(template)`:
   `figure_widths_mm` (mm → px @96 dpi; "89 mm — 1 column") for
   publisher journals, `figure_widths_frac` for preprints/mebp, plus
   the width presets (full/90/80/half column). 8 px snap window; the
   chip names the target. `oneAndHalf`/`double` targets surface in the
   page-span container.
3. **Span crossover** — dragging past the column width (2-col journals)
   flips the intent to `span='page'` (`\textwidth`, size_key 'double');
   shrinking a page-span figure back under the column width returns it
   to `span='column'`. The natural column↔page gesture.
4. **Commit** — ONE transact on pointerup carrying the FULL intent
   (anchor/span/lock + width + size_key — the V3.395 opt-in rule for
   legacy blocks), origin 'fig-width'. Snapped widths emit robust
   fraction specs (`\linewidth`, `0.74\textwidth` …), never raw mm —
   Design A5's emission rule; the mm value lives in the chip label.
5. **Replace image** — the figure popover gained `🖼 Upload image…`
   (file input → `PAPER_FIGURES.uploadImage` — sha-dedup, 15 MB cap,
   png/jpg/gif/webp/svg/pdf) and `📚 From library…` (thumbnails from
   `PaperEditor.getUnplacedFigures()`, live attrs via
   `findUnplacedYMap`). Both funnel into `_applyImageSwap`: **image
   attrs only** (storage_path/download_url/hash/mime) in one
   'figure-upload' transact — the placed figure keeps its caption,
   number, label, and cross-refs; the library entry stays. Old
   aspect-ratio cache entry dropped + session height memo reset (a
   same-length sha URL would alias the key).
6. **Measure-cache aliasing fix (R4 latent bug)** — the session height
   memo keyed on `innerHTML.length` aliased same-length width changes
   (50%→80%). Figures now stamp `dataset.w` (the rendered pct) and the
   key includes it.
