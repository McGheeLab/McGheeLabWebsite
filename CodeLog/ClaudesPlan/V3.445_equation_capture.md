# V3.445 — E3 of Paper Builder III: equation capture in the journal-paper reader

> Alex's redirect: capture SINGLE equations while reading — pick the equation region,
> transcribe to our math type, annotate it like any other comment; the builder's picker
> reuses them (E4 next). A capture is a REGULAR reader annotation with extra fields, so it
> inherits anchoring, the comment field, lab/private visibility, and the type-filter pills
> for free. No Firebase deploys: same `papers/{libPaperId}/annotations` path, snip inlined
> as a data URI.

## Flow

Select the equation region in the reader (the existing geometric selection) → the create
toolbar's new **ƒ** action → the region is SNIPPED from the rendered page canvas → a
transcription modal (snip on top; MathLive `<math-field>` ⇄ LaTeX tabs; name; note) →
saved via `ANNOTATION_SYNC.create` with
`{kind:'equation', annotation_type:'equation', latex, name, snip_data_uri, comment,
target:{pages: anchors}, color_id:'green', visibility: panel default}`.

## Changes

- **NEW `rm/js/equation-capture.js`** (`window.EQUATION_CAPTURE`):
  - `init({paperId, viewer})` — wired on reader tab attach.
  - `open({anchors})` — create flow; `_snipFromAnchors` crops the union rect (+6px pad)
    from `viewer.getPageNode(page).canvas` (backing-store scale = canvas.width / wrap CSS
    width), downscales to ≤600px-wide JPEG data URI (~40–80 KB — inlines in the Firestore
    doc, no Storage rules).
  - `openForAnnotation(ann)` — edit transcription/name/note via `ANNOTATION_SYNC.update`.
  - `renderStatic(latex, el)` — MathLive `convertLatexToMarkup` + one-time injection of
    the vendored `mathlive-static.css`/`mathlive-fonts.css` links.
- **`rm/js/annotation-overlay.js`** — `_showToolbar` gains the teal **ƒ** button (only
  when `onCaptureEquation` is wired); `init` accepts the callback.
- **`rm/js/library-paper.js`** — passes `onCaptureEquation` → `EQUATION_CAPTURE.open` and
  calls `EQUATION_CAPTURE.init({paperId, viewer})` on tab attach.
- **`rm/js/paper-overlay-types.js`** — new `equation` type (teal) in the filter pills.
- **`rm/js/annotation-panel.js`** — `kind==='equation'` rows render a capture block
  (name + static math + snip thumbnail + "✎ Transcription" for the owner) above the
  normal comment/evidence chrome; post-render pass calls `renderStatic`; edit button →
  `openForAnnotation`. Notes editing = the existing comment field, untouched.
- **`rm/pages/library-paper.html`** — loads `mathlive-loader.js` (shared E1 loader) +
  `equation-capture.js` before library-paper.js.
- **CSS (`rm/css/style.css`)** — `.ann-toolbar-eq`, `.eqcap-*` modal, `.ann-eq-*` panel
  block.
