# V3.108 — Paper builder inventory popover: also search chemicals

## Goal

Fix a reported bug: the "+ Reagent / equipment" popover in Methods
sections (Phase C inventory quick-insert,
[paper-editor.js:999-1156](../../rm/js/paper-editor.js)) only finds
*equipment-class* inventory items. Reagents like agarose live in the
**chemicals** collection (Firestore `inventory` collection with
`kind: 'chemical'`) and are not reachable from the popover, even
though they're the most common thing the user wants to insert in a
Methods section.

## Root cause

[paper-editor.js:1016](../../rm/js/paper-editor.js#L1016) loads only
`inventory/items.json` (which is filtered server-side to
`kind: 'item'` per
[api-routes.js:158-163](../../rm/js/api-routes.js#L158-L163)). The
chemicals route at `inventory/chemicals.json` (filtered to
`kind: 'chemical'`) is never loaded, so the in-memory search index
never sees agarose, ethanol, MgCl₂, or any other reagent.

## Fix

In `ensureInventoryList`:

1. Load both `inventory/items.json` and `inventory/chemicals.json` in
   parallel via `Promise.all`.
2. Map each into the same projection shape, tagged with `kind:
   'item' | 'chemical'`.
3. Include CAS number (`safety.cas_number`) in the search haystack for
   chemicals, so a user can search by CAS as well as by name.
4. Render a small kind badge in each popover row so the user can tell
   reagents from equipment at a glance.

The existing `insertInventoryItem` already preserves `attrs.item_ref`
on the inserted paragraph; that pointer continues to round-trip
either kind (the `inventory` Firestore collection is unified — the
discriminator is just the `kind` field).

```bash
# open http://localhost:8000/rm/pages/paper-builder.html?paper=<some-paper>
```

1. Open a Methods section, click `+ Reagent / equipment`.
2. Search "agarose" → reagent appears with a "chemical" badge.
3. Search by CAS, e.g. "9012-36-6" (agarose CAS) → matches.
4. Search "pipette" or another equipment item → still appears with
   an "item" badge.
5. Pick a chemical → paragraph inserts with the chemical name + vendor
   + cat (CAS appended if present).
6. Hard reload to evict `mcgheelab-shell-v81`.
