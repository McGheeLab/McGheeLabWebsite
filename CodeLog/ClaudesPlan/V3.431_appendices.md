# V3.431 — Appendices (A/B numbering) — R2 of the Lists/Appendices/Section-refs program

> R2 of the program. Adds appendix support: a section (and every section after it) numbers
> A, B, C — matching LaTeX's `\appendix` switch. The sibling grant builder had this; the
> paper builder didn't. Builds on the V3.429 section-numbering engine.

## Model

A section-level boolean `appendix`. The **first** section flagged `appendix` (in document
order) opens the appendix zone: it and every later section number as A, B, C (subsections
A.1, A.2; subsubsections A.1.1) — regardless of the base number style. Round-tripped like
`special` so it survives section reorders.

## Changes

- **`rm/js/paper-schemas.js`** — `newSection` opts gains `appendix` (and `ref_label`, used by
  R3); set only when provided.
- **`rm/js/paper-editor.js`** — round-trip `appendix` (+`ref_label`) in the ×4 section
  functions (`sectionMapToTree`, `hydrateSectionFromTree`, `appendSectionFromTree`,
  and the export reader below). Section-header **"§ Appendix"** toggle in `renderSection`'s
  actions row (delete/set on the section map; `secMap.observe` re-renders).
- **`rm/js/paper-export-tex.js`** — `paperTreeFromYDoc` reads `appendix`; `buildBundle`'s
  section loop pushes `\appendix` into the input lines **once**, immediately before the first
  appendix section that produces content (LaTeX then auto-numbers A/B).
- **`rm/js/paper-doc-view.js`** — `inAppendix` state in the numbering walk; the first
  `sec.appendix` resets the counter and flips to alpha. The number formatters
  (`fmtSectionNum`/`fmtSubNum`/`fmtSubsubNum`) gain an optional trailing `appendix` arg →
  `_alphaUpper` letters (A / A.1 / A.1.1), overriding arabic/ieee. `off` still suppresses;
  `on`/`auto` both number appendices.
- **CSS** — `.pe-section-apx-btn`/`-on` (violet section-header pill).
