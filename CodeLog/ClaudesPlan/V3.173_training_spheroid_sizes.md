## Goal

Operational fluency on the lab's spheroid sizing / cell-state
classification pipeline. SpheroidSizes processes confocal images of
spheroids to extract per-spheroid size distributions and per-cell state
classifications across tiered analysis stages. Lighter-weight than Cell
Tracker — no GUI, command-line / script-driven.

## Format

Full interactive notebook (MODULE_TEMPLATE.md pattern). 4 tabs (this is
a more focused tool than Cell Tracker).

## Prerequisites

- V3.164 microscope basics
- V3.168 image analysis basic
- Python + venv comfort (the training shouldn't teach this; point
  students at a one-liner setup)

## Tabs (preliminary — refine when authoring)

### Tab 1 — What SpheroidSizes is, when to use it
- Background: spheroid size distributions as an experimental readout
  (cytotoxicity, growth dynamics, drug response); why a custom tool
  beats hand-measuring in Fiji
- Decision rule: SpheroidSizes vs. Cell Tracker vs. manual Fiji ROI

### Tab 2 — `params.py` + the input ND2 / TIFF
- Background: parameter file structure; what each field does
- Interactive: a parameter playground that previews how each value
  affects the result on a small embedded sample

### Tab 3 — `cell_states.py` classification + tier sweep via `run_tiers.py`
- Background: how cell states are classified (cytometric features,
  thresholds); the tiered sweep that explores parameter sensitivity
- Worked example: run a tier sweep on a small dataset; read the output

### Tab 4 — Output structure + downstream use
- Background: the `output/` folder layout (one subfolder per tier
  according to the current source); HDF5 vs. CSV vs. PNG previews
- Capstone: import outputs into the paper-figure pipeline; the typical
  spheroid-size-distribution box-plot
