# V3.117 — Protocols Builder Phase 2: formulas

## Goal

Land **Phase 2** of the Protocols Builder roadmap (full plan:
`~/.claude/plans/we-want-to-make-idempotent-pixel.md`). Adds the user's
headline ask: formulas with variables that propagate live into prose.

A grad student who needs to scale up "5 mLs of 2% wt agarose:
5 mL × 0.02 = 0.1 g agarose" should be able to:

1. Open the formula block on the Agarose protocol.
2. Change `vol` from `5` to `12`.
3. See every `[!var:agarose_mass]` token in the protocol's steps update
   to `0.240 g` instantly.

No re-doing arithmetic. No copy-paste. The protocol becomes a live
calculator that drives the prose.

### Schema for the `formula` block

```js
{
  id: 'blk-…',
  kind: 'formula',
  status: 'draft',
  body: '',
  attrs: {
    label: 'Compute agarose mass',     // Y.Map.set as plain string
    description: 'mass = volume × wt%',
    expression: 'vol * wt_pct / 100',
    variables: [                        // Y.Array<Y.Map>
      { name: 'vol',    label: 'Final volume',  default: 5, unit: 'mL' },
      { name: 'wt_pct', label: 'Weight percent', default: 2, unit: '%'  },
    ],
    output: {                           // Y.Map (single row)
      name: 'agarose_mass',
      label: 'Agarose mass',
      unit: 'g',
      decimals: 3,
    },
  },
}
```

### Symbol-table semantics

Two-pass build: inputs first (every formula's `variables[]` rows go into
the table), then outputs in document order (each formula's `expression`
is evaluated against the current table; the output is stored under
`output.name`). Last-write wins on duplicate names with a console
warning so authors notice clashing names.

A formula's output is visible to LATER formulas, so chained calculations
work:

```
[Formula 1]   vol=5, wt_pct=2 → agarose_mass = 0.1
[Formula 2]   expression = "agarose_mass * 1000"   output: agarose_mg = 100
```

### Inline token grammar

`[!var:<identifier>]` where identifier matches `[a-zA-Z_][a-zA-Z0-9_]*`.
Mirrors paper-equations.js's `[!eqi:<id>]` / `[!eqr:<label>]` family.
Step / note / safety / figure-caption bodies (anything bound via
`bindYTextWithVars`) substitute these tokens with chip spans on blur.
On focus, the contenteditable swaps back to raw text so the user can
edit the literal token string.

### mathjs choice

Locked in the user-approved Phase 1 plan: mathjs now (~150 KB gz, lazy
ESM, supports unit literals + safe scoped `evaluate`), Pyodide later as
a separate `python` block kind. mathjs covers 100% of arithmetic +
unit conversion in the sample protocols (`5 mL × 0.02 = 0.1 g`).

### Read-only viewers

Variable chips render for non-owners just like for owners — they're
informational. Editing controls (variable rows, expression input,
output row, "+ Add variable") respect `ctx.canEdit` and disable when
the viewer isn't the owner or admin.

## Acceptance test

1. Open the Agarose LLS protocol.
2. Insert a formula block. Set `label = "Agarose mass"`,
   `expression = "vol * wt_pct / 100"`, output name `agarose_mass`,
   unit `g`, decimals 3.
3. Default vars: `vol=5 mL`, `wt_pct=2 %`. Preview shows
   `→ Agarose mass = 0.1 g`.
4. Edit any step body to read `Measure out [!var:agarose_mass] of agarose`.
   On blur the chip renders `0.1 g`.
5. Change `vol` to 12. Without saving / reloading: the chip in the step
   re-renders to `0.24 g`.
6. Open in a second tab — formula edits sync via Yjs; both tabs see
   `0.24 g` within ~500 ms.

## Known limitations (deliberately deferred)

- **mathjs Unit type round-trip.** If the user writes
  `expression = "vol mL * wt_pct / 100"` (mathjs unit syntax), the
  output is a Unit object. Phase 2 stringifies it to display; Phase 3+
  could expose unit-aware comparisons.
- **No formula-block linting.** Bad expressions surface a `⚠` chip with
  the mathjs error message. No syntax highlighting, no autocomplete.
- **No cycle detection.** A formula that references its own output via
  `[!var:result]` in a variable's `default` field would loop on
  rebuild. mathjs throws on undefined symbols, so the practical impact
  is just a `⚠` chip — no infinite loop.
