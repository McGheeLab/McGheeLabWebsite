## 1. A quick note gets its details when it is saved

A quick note stays a plain *Note* titled "Quick note · <day>" outside any project until the person saves it
somewhere. **Save to a project…** (in the note's header while it has no project, on its card in Quick notes, and in
the blank-page bar) opens one form — Gabe's own `modal`, never a browser popup — that asks for everything the note
inherits from where it goes:

| Field | Rule |
|---|---|
| Title | required; empty while the title is still the quick default |
| Type | Gabe's note types (`userProfiles()`), the note's own preselected |
| Project | required; the person's assigned RM projects first, then their own |
| Theme | the project's active themes, or none; only for a type that lives in a theme (`prof(type).scope === 'theme'`) |

Saving sets `title`, `type`, `scope`, `projectId`, `themeId`, clears `quick`, and the note leaves Quick notes for its
project's region (and, in an RM project, its card in RM — V3.880's index). The components stay as written.

## 2. The open-note tabs (`rm/js/notebook-scientia.js`)

The Lab Notebook's Scientia group showed the 20 most recent notes. It becomes the person's **open** notes:

- a note opened anywhere (a tab, the Portfolio, a link) joins the tabs; the list lives in `localStorage`
  (`nbc_sis_open`), seeded with the six most recent notes the first time;
- every tab has an **×**: it closes the tab (the note is untouched); closing the note on screen goes to the next tab,
  or to Today;
- **＋ Quick note** sits after the tabs: it opens Scientia on a new blank quick note (`sisCmd: 'quick'` →
  `SIS_LAB.quickNote()`, which waits for the app to be ready). *All N* stays for every note.

## 3. The canvas pills in a note (`rm/scientia/lab-mode.js` §11)

The Lab Notebook's four movable pills, on every Scientia note, driving Scientia's own tools (nothing copied):

| Pill | First arc | Second arc / actions |
|---|---|---|
| **✎ the hand** (bottom left) | Zoom · Move (pan the paper, drag components) · Pen · Highlighter · Lasso | the mode's options — pen / highlighter: Gabe's ink colours (+ any colour, kept per device), the eraser, three widths, pressure, undo, redo; zoom / move: in, out, 100 %, fit; lasso: back to the pen |
| **＋ Insert** | the most used inserts (a component, a lab paper, a material, an RM protocol, run a protocol, a well plate, *Something I did*, a collection) | *More…* → Gabe's whole Insert list (`INSERT.menu`) |
| **✦ Tools** | the note's timer (start / pause / resume), calculator, equation, Gabe's ink bar, focus mode, put the pills back | |
| **⊕ View** (bottom right) | zoom in · 100 % · zoom out · fit | the zoom % under the pill |

- The hand maps onto Gabe's ink: Pen / Highlighter / Lasso / Eraser = `INK.tool` with `INK.mouse` on (the mouse and
  the pen draw); Move = `INK.mouse` off (Gabe's default: the paper pans, components drag); Zoom = a tap zooms in ×1.5
  at the point (Alt / Shift / right button: out), a drag up or down zooms smoothly. The mode is read back from `INK`
  each time, so Gabe's ink bar and the pill never disagree.
- A pill drags anywhere (its place is a fraction of the note's area, `_ls` `lab:pills`), the fan opens away from the
  nearest edges (RM's ring layout), a tap outside closes it, a double tap on ✎ goes back to the last mode.
- Monochrome icons only (inline SVG paths from the site's Heroicons set; the app has no `ICON`).
- Not ported: RM's phone mode bar and finger drawing (Scientia's finger pans and pinches by Gabe's design; the iPad
  pen draws in any mode), RM's voice recording with the ink (Scientia has its own recordings), regions (each app's
  own, V3.878).
