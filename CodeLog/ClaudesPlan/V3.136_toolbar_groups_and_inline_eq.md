# V3.136 — Paper builder header redesign + `+ Inline Eq` button

## Goal

User report: "we need a button to add inline equations into text as
well, put this on the top header next to the add references to text
buttons. break everything in this header up into sections. Make the
header look good."

Three asks in one:
1. **Add a button to insert inline equations** in the global toolbar
   (today only reachable via right-click → Insert inline equation, a
   hidden affordance new lab members never find).
2. **Break the header into sections** so the toolbar's mental model is
   visible at a glance.
3. **Make the header look good.**

## Approach

### Three labeled groups

The V3.120 toolbar has two unlabeled groups (`B I X₂ X² <>` and
`+ Eq + Fig + Table + Cite`). The Cite + Eq/Fig/Table grouping conflated
two distinct concepts:
- **Inline tokens** (`[@key]`, `[!eqi:<id>]`) cause the editor to render
  the *thing itself* mid-prose: a citation chip with author/year, an
  equation rendered via KaTeX. They drop a chip from a library.
- **Reference tokens** (`[!eqr:<label>]`, `[!fig:<label>]`,
  `[!tab:<label>]`) render as pointers — `Eq. 3` / `Fig. 2 (B)` /
  `Tab. 1` — and rely on the numbered object existing somewhere else in
  the doc.

V3.136 splits them:

| Group | Purpose | Buttons |
|---|---|---|
| **FORMAT** | Markdown-ish styling | `B` `I` `X₂` `X²` `<>` |
| **INLINE** | Chips that render the thing itself | `+ Inline Eq` `+ Cite` |
| **REFERENCE** | Pointers to numbered objects | `+ Eq` `+ Fig` `+ Table` |

Each group renders as
`<div class="pe-gt-group pe-gt-group-{format|inline|reference}">` with a
floating `<span class="pe-gt-group-label">FORMAT</span>` above a
`<div class="pe-gt-group-row">` of buttons, separated by vertical
dividers (`<span class="pe-gt-divider">`).

### `+ Inline Eq` button

Calls new `_toolbarInsertInlineEquation(anchorBtn)` which opens the
existing V3.109 `_openInlinePicker(x, y)` at the button's bottom-left
+ 4 px (mirroring V3.120's pattern for `+ Eq` / `+ Fig` / `+ Table`).
The picker reads from `paperMap.equation_library` filtered to the
inline-typed entries (V3.124 schema field) and inserts an
`[!eqi:<id>]` token at the saved caret. The right-click → Insert
inline equation path is preserved for muscle memory.

### Visual polish

- Toolbar gets a subtle `linear-gradient(to bottom, #fafafa 0%, #f5f5f4
  100%)` background instead of pure white so the bar reads as a
  distinct strip.
- Group sublabels are 9 px `font-weight: 700` uppercase gray
  (`#9ca3af`) with `letter-spacing: 0.08em`.
- Vertical dividers (`width: 1 px`, `background: #e5e7eb`,
  `align-self: stretch`) sit between groups.
- Buttons get white surfaces with soft `#e5e7eb` borders + 5 px radius
  (was transparent), so each button reads as a tap target. Hover
  bumps to `#eff6ff` with blue text. Active press: `transform:
  translateY(1px)`.
- **Inline-group buttons** get a tinted amber background
  (`#fef3c7` / `#fde68a` / `#92400e`) so the chip-insert buttons
  visually echo the chip color in prose.
- **Reference-group hover** is blue-tinted (`#dbeafe` / `#60a5fa` /
  `#1e40af`) so cross-reference buttons echo their picker styling.
- Pillbar polish: pills slightly larger + bolder (font-weight 600);
  active pill picks up a soft blue shadow.

## Verification

1. Open `/rm/pages/paper-builder.html?paper=<id>`. The header now shows
   three labeled groups: FORMAT / INLINE / REFERENCE with vertical
   dividers between them.
2. Place caret in any paragraph. Click `+ Inline Eq` → picker opens
   anchored to the button. Pick an inline equation → token inserts at
   the caret + renders as a KaTeX chip on blur.
3. Picker's empty state directs the user to the Equations panel if no
   inline equations exist yet.
4. `+ Cite` still opens the V3.40 citation popover; `+ Eq` / `+ Fig` /
   `+ Table` still open their reference pickers.
5. Right-click → Insert inline equation still works (back-compat).
6. Format buttons still wrap selection in markdown tokens.
7. Pills: clicking a non-active pill opens the slide-out on that tab;
   clicking the active pill closes it. Active pill carries a soft blue
   shadow.
8. Hard-reload to evict SW cache `mcgheelab-shell-v111` and pick up the
   new toolbar HTML + CSS.

## Out of scope (deferred)

- **Keyboard shortcut for `+ Inline Eq`.** No standard key for inline
  equation insert. Could land later if requested.
- **Group reordering** (e.g. "References before Inline"). Current order
  reads left-to-right by frequency: format actions are most frequent,
  inline tokens are next, cross-references trail.
- **Picker upgrades.** The inline picker is unchanged from V3.109.
