# V3.418 — Magnitude consistency in the equation checker

## Context
Alex, on V3.417's "magnitude conversion is a separate future problem":
"no magnitude is important, we need to keep that consistent." Symbol-
table values are raw numbers, so µL + mL is numerically wrong (×1000)
even though the dimension matches.

## Kernel (`rm/js/protocol-graph.js`)
- `UNIT_SCALES`: every catalog unit (+ ascii spellings) carries a
  multiplicative scale to its category base (µL 1e-6 → L; min 60 → s;
  mg 1e-3 → g; mM 1e-3 → M; …). `UNIT_KINDS` marks families that share
  a category but can NEVER interconvert multiplicatively: molar (pM…M)
  vs moles (nmol…mol) vs mass-concentration (mg/mL, g/L), and °C/K/°F
  (offset scales). `quantityOfUnit(unit)` → `{dim, scale, kinds}`;
  unknown/custom units get `scale: null`.
- `checkTokenDims` upgraded to QUANTITY-valued recursion:
  - `+ − min max`: dims must match (as before), then KINDS must match
    ("molar vs mass-concentration"), then known scales must agree —
    else "values whose magnitudes differ ×1000 — convert one side".
  - `× ÷` multiply/divide scales; `^literal` powers them; `sqrt` takes
    the square root. Composite scales flow into the declared-unit
    comparison.
  - `scale: null` (custom units, or legacy plain-dim callers — the
    old call signature still works) silently disables magnitude checks
    for the affected operands: no false alarms.
  - Ratio units (%, ×, AU, fraction) are all scale 1 — protocols
    conventionally handle percent with explicit /100 (the shipped
    percent recipe stays warning-free).
- Returns `{ok, dim, scale, kinds, warnings}`.

## Editor (`rm/js/protocol-graph-editor.js`)
The pad's declared-unit comparison now runs three tiers: dimension
mismatch (existing) → unit-family mismatch → MAGNITUDE mismatch
("the math computes ×1000 larger than 'µL' — check the operand
units"). Alias quantities come from `quantityOfUnit`.

## Verification
Suite **593 ok / 0 FAIL** — scales/kinds lookups (incl. ascii
spellings), µL+µL clean, µL+mL warns naming ×1000, molar+massconc and
°C+K family warnings, unknown-magnitude silence (m³: dimension known,
no scale entry), scale algebra (µL×mL = 1e-9, L÷mL = 1000, mL² =
1e-6), min() magnitude check, legacy dim-map callers unaffected.
