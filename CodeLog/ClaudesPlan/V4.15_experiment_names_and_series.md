# V4.15 — Experiments are named once and can continue a series

## Goal
Gabe: "+ Experiment asks you to name the experiment with the option to add it to an experiment sequence/iteration from a theme (e.g., […] Run 2 in that theme allows you to name it automatically […] Run 3). That name carries through to all parts of the experiment and do not add — Planning or — Run after the experiment title." — and: "The preset text components for each experiment note type should be stripped and go back to the universal text component any general note would have."

## Approach
- **One name for every note of an experiment** (`13c-chain.js`):
  - `CHAIN.create` and `CHAIN.advance` title each stage note with the experiment's name alone. The stage shows as the note's type chip, the stage strip (`CHAIN.strip`) and the Portfolio's stage label.
  - Renaming one note renames the others: `M.touchDoc` is wrapped (every title edit goes through it — the title bar, `/rename`, the note dialog, the lab's first-block Title), and `CHAIN.renamed(d)` carries the new name to the notes still titled with the old one, and to `chainName`.
  - Once per notebook (`settings().expTitles415`), notes titled exactly "name — Stage" are renamed to the name.
- **Series of runs:**
  - A series is the first experiment's chain id, written as `series` on every note of its runs, with each run's number as `run` (`CHAIN.openSeries`, the first time a run continues it).
  - `CHAIN.seriesIn(projectId, themeId)` lists a theme's experiments as series (a lone experiment is a series of one); `CHAIN.nextRun(s)` names the next run: "… Run 2" → "… Run 3", "…" → "… Run 2" (`CHAIN.RUN_RX`, `baseOf`, `runOf`).
  - `CHAIN.advance` carries `series` and `run` to each next stage.
- **The dialog** (`CHAIN.start`): Project, Theme, **Continue a series** (shown when the theme has experiments), Name, Date. Picking a series fills the name with the next run and says which runs come before; "No: a new experiment" clears a name it filled.
  - The lab's build (`rm/scientia/lab-mode.js`, V3.885) replaced `CHAIN.start` so + Experiment made the note at once. Gabe now asks for the name: on `DOMContentLoaded` (after the lab layer has loaded) `CHAIN.start` is put back and the lab's function kept as `CHAIN.labStart`. The dialog ends through it, so the note is made exactly as the lab makes notes (its first block holds the details); the series rides along as `CHAIN._pending`, read by `CHAIN.create`. `lab-mode.js` is not edited; the v3869 harness check "+ Experiment makes its first stage at once — no dialog" becomes "asks the name first, then makes its first stage at once through the note's first block".
- **Plain text** (`02-schema.js` `STANDARD_TEMPLATES`): Planning, Run, Analysis and Synthesis start with the universal text component a general note has. A notebook's standard template still as it was built in becomes that component (`CHAIN.migrate`, run with `ensureStandardTemplates`); each old preset stays as a template of its own, switched off (`tp_pre415_<type>`, deterministic ids so two devices make one), to switch on in Settings → Templates.
- **Settings → Features → Canvas & notes → Experiment series** (`expseries`, in Simple too): the switch (off: no series to continue; the name is still asked) and a live preview.
