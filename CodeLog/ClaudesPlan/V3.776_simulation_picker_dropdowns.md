# V3.776 — ＋ Simulation: three dropdowns instead of a typed number

Alex: *"I want the simulation number to be a series of three dropdown boxes that have all the
available simulations in it: dropdown 1 the module (with name), dropdown 2 the tab (with name),
dropdown 3 the section (with name)."*

Follows V3.775, where a typed `4.0.1` silently became module 03's simulation. A picker cannot
name a module that is not on the class's list, so the whole class of "typed the wrong thing"
goes away, and the names make the choice legible on a projector.

## Design

- **Module** — `simLessons()`: the class's Learning Modules lessons with the number the resolver
  gives them (`^0*(\d+)[a-z]?[-_.]` on the filename; ordinal only for a class with unnumbered
  files) → `4 — The Cytoskeleton: From Reading to Moving`. Defaults to the module of the page being
  viewed if it is a simulation page, else the newest lesson.
- **Tab** — from the module's own HTML. Tab numbers come from the sections' `data-nav="T.S"` (module
  01 starts at tab 1, 04c at tab 0, so the button index is NOT the number); labels from the module's
  `.tab-btn` text whose leading number matches (`1. The Actin Cytoskeleton`), else `Tab n`. Only tabs
  with at least one eligible section are listed.
- **Section** — `h2[data-nav][data-title]` → `1.2 · Two ends, and a conveyor belt`. Under
  *Simulation only* just sections containing a `<canvas>`; under *Whole section* all of them.
- **Catalogue** — `parseModuleCatalog(html, lesson)` is pure (testable); `moduleCatalog(lesson)`
  fetches once per module (`force-cache`, same origin) into `SIM_CATALOGS` for the page's life. A
  module without `whiteboard-panel.js` shows its "cannot be embedded yet" error inline (01 and 02
  today).
- **Add page** assembles `${module}.${tab}.${sec}` and goes through the unchanged `resolveSimRef`,
  so the picker and the resolver cannot disagree; the page's `sim.ref` stays the same string it
  always was (replay and the generated `simulations/N.T.S.html` wrappers are untouched).
- State is `S.simSel = { module, tab, sec }`; the form re-renders in place on each `change`
  (`renderSimForm()`), so the toolbar is not rebuilt while a select has focus. Status line names all
  three choices; the Add button is disabled until a section is selected.
