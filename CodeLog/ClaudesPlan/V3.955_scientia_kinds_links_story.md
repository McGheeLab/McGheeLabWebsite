## Decisions

- **Links are per kind, both ends read.** `between(A, B)` walks A's links (A → or ← with B) then B's; one entry per relation, the dragged-from end's direction first; the relation last used from that kind (`settings().relDefaults`) goes first. Neither end kinded → `null` → the old popover, every relation.
- **Classes** (`CKINDS.is(b, c)`): a kind id; a structure the component carries (`IX.itemsOf`); `question` also by a `?` in the text; `evidence` = evidence / observation / result structures or an image panel, plate, table, plot, run, recording, canvas or paper; `paper` = rmpaper, pdf or a cite mark; `person` = a person term; `any`.
- **The kinds' relations** (`KREL`: fuels, tests, predicts, refines, answers, produces, illustrates, next) are added to `REL` (the Proxy's target) and `WIRECOL`, not to `RELATIONS` — the standard popover, `/connect` and the 1–9 keys stay nine. `next` has an empty label and `arrow: true`; 12b draws no label for it.
- **The new beat is a story component** (kind `story`, the previous beat's complexity): a plain text component would have no complexity and the arc nothing to plot. Gabe said "a new text component" — it is one, with the kind set.
- **The arc sits left of the first beat** (236 × 150, 24 px off), one per story with no story leading into it; drawn with the wires (`drawWires`), redrawn only when a beat, a link or a complexity changed (`data-key`); `bbox` counts it so Fit shows it; Tidy widens the first beat's node by it.
- **Your own kinds** keep working: a kind made before V3.955 with `targets` reads as links (`related` with each target).
- No lab-layer change (lab-mode.js, cloud-sync.js, scientia-cloud.py untouched). `serve.py` and `pen-button/` are the desktop server's (Gabe's).
