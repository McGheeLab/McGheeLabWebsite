# V3.931 — A hub replaced by a computer's notebook never ends a share

## Goal
Shared Scientia projects kept disappearing. The latest was "Our lab development", shared by Alex and Gabe. Put it back
for both of them, and close the path that removed it.

## Cause (from the code; the production trace is `restore-share.js`)
`FirestoreHub.replace` (`POST /api/snapshot`) is what a desktop does when it connects and "this computer's notebook
wins" (`scientia-cloud.py --prefer local`, and the installed app's choice from V3.928). It wipes `rows` and `ops`, then
writes the computer's records with `seq: 0, dev: null`. Nothing the computer lacks keeps a tombstone, and no commit
reaches the live relay. The hourly `sharePass` then reads the result:

- **Owner's hub replaced.** The root is missing, or present without `shareWith` (an old copy from before it was shared).
  `grantsOf` returns `{}`, so step 4 removes every member's copies and step 5 deletes the index *and its shadows*. Both
  people lose the project, and the only server-side copies are the kept `before-replace` file and the op logs.
- **Collaborator's hub replaced.** Step 1 sends "deleted" for each missing copy. V3.923 lets a deletion through when
  the owner's row was last written by `share:<uid>`, which covers every note the collaborator ever edited. A stale copy
  in their computer's notebook was also taken as their edit.

V3.923 closed only the live-relay case and the root.

## Approach
- `fromReplace(row) = !row || (!row.seq && !row.dev)`. A replace is the only writer that leaves seq 0 with no device.
- `sharePass` step 1 skips those rows. Step 3 already gives the collaborator their copy back.
- `heal(env, old)` runs before the pass reads the owner. If the root came from a replace, it pushes back from the
  members' shadows (edit members first) every record the owner lacks, plus the root with the index's grants merged in.
  It writes as device `share-restore`. A root the owner edited or tombstoned is left alone, so a real unshare or delete
  still works.
- `scripts/scientia-project/restore-share.js`: traces and restores this one, since its index and shadows are already gone.
