# V3.370 — Layout ground-truth fixtures + audit harness (layout coverage R1)

> Plan: robust page-layout segmentation, R1 of 5 (2026-07-14). Same
> evidence-first pattern as the citation coverage expansion — build the
> measuring stick before touching the engine. User symptom: highlight
> drag-selection "bridges into other sections of text oddly" across
> columns / figures / captions / footnotes.

## Changes

- **`scripts/gen_layout_fixtures.py`** (reportlab; added to
  requirements.txt): generates 12 synthetic PDF fixtures modeling real
  journal archetypes (2-col tight/normal, mixed front matter with
  abstract/keywords, figures spanning both/one column, footnote islands +
  header/footer/page numbers, 3-col, sidenotes, single-col preprint,
  ragged 2-col reference list, equation gaps, rotated caption, two-page
  spread) into `rm/test-fixtures/layout/`. Each PDF ships a sibling
  `.truth.json` recording every text run's TOP-DOWN bbox + block
  membership + block type/column/order (reportlab knows exactly where it
  drew everything). Deterministic per-fixture seeds → diff-stable
  regeneration. `index.json` lists the suite.
- **`rm/pages/layout-audit.html` + `rm/js/layout-audit.js`**: offline
  harness (no auth/Firestore for the fixture run — works on a plain
  `python3 -m http.server`, per the plan's local-dev requirement).
  Extracts items with `PDF_VIEWER.extractTextItemsFromPdf`, matches each
  to its GT block by center-point containment, runs segmentation, and
  scores: **column accuracy**, **block purity** (clusters ⊆ one GT block),
  **reading-order violations**, and the headline **bridge rate** —
  random in-block drags that leak into another block, i.e. the user's
  symptom measured directly. JSON export + baseline-diff (Δ per column),
  mirroring the citation-audit R1 pattern.
- Segmentation source: `window.PAGE_LAYOUT.segmentPage` when present
  (R2+); until then a naive (y,x)-order fallback records the honest
  pre-engine baseline.

## Baseline recorded (naive y,x order, this release)

Validated via node over the truth runs (scoring math, independent of
pdf.js): **bridge rate 100%** on every multi-column fixture (01 tight
2-col, 05 footnote, 06 3-col, 12 multipage) and **0%** on 08 single-col —
confirming the metric fires on the symptom and does NOT false-positive on
preprints. Full browser run (with real pdf.js extraction) is the number
Alex records after FTP; that becomes the R2 comparison baseline.
