# V4.77 — Scientia: Start empty replaces "Empty 1×2"; one m×n box with a preview that reshapes as you type

## Why
Gabe, 20 Nov: "For image panels, make sure that image panels have the option to start empty, replacing the Empty 1x2 option. The list of panel options should have all most used ones like it has right now, with one mxn input that allows you to input into them, reshaping the preview widget of what the panel looks like."

The Image panel dialog had ten shape tiles, two number boxes (rows, columns) and a button, "Empty 1×2", that made one fixed empty panel.

## What changed
- **Start empty** (`FIG.insert`, `13x-figure.js`): a two-way switch at the top of the dialog, "Choose images now" | "Start empty". With Start empty on, any tile and the m×n box make the panel at once, with its cells waiting (each empty cell already took a click to add an image; a toast says so). The "Empty 1×2" button is gone. The tiles draw dashed cells while Start empty is on.
- **The ten usual shapes stay** as tiles, as before.
- **One m×n box** replaces the two number boxes. It reads `2x3`, `2×3`, `2 3`, `2,3` (up to 12 each, 36 cells in all). A preview widget beside it (`FIG.shapeWidget` / `FIG.shapeSet`: rows × columns of 4:3 cells, fitted into a fixed box) reshapes on every keystroke; with Start empty on its cells show a +. A non-shape is marked and the button is disabled; Enter makes the panel.
- **Settings → Features → Figures & decks**: description extended; a setting "A new image panel begins" (By asking for images / Empty, waiting for a click) chooses what the dialog opens on (`figures.start`); the preview is the dialog's switch and a 2×3 shape widget, true to that setting.
