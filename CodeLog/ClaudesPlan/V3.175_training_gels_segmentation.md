## Goal

Operational fluency on the lab's GELS image-segmentation pipeline — used
on confocal images of cell-laden hydrogels (GELS = "gels" / hydrogel
mechanics) to extract per-region masks for downstream mechanical and
morphological analysis. Tied to the GELS Paper and Prostate GELS R01
proposal work.

## Format

Full interactive notebook (MODULE_TEMPLATE.md pattern). 4 tabs.

## Prerequisites

- V3.164 microscope basics
- V3.168 image analysis basic
- V3.169 image analysis intermediate (segmentation + thresholding)
- Python comfort

## Tabs (preliminary)

### Tab 1 — What GELS_ImageSegmentation is + the paired training data
- Background: the GELS workflow — confocal Z-stacks of cell-laden
  hydrogels, segment regions of interest (gel boundary, cell positions,
  fracture patterns)
- The repo's paired `TrainingN_raw.png` + `TrainingN_mask.png` data:
  what the masks encode; how to add new training pairs

### Tab 2 — `ND2fileparser.py` — converting AX-R outputs to the model input
- Background: ND2 file structure; the parser's role
- Interactive: walk through what the parser extracts (channels, Z,
  metadata) and how it formats inputs for the segmentation step

### Tab 3 — Running segmentation + interpreting outputs
- Background: the segmentation model (verify against current source —
  may be classical morphology, may be a trained CNN)
- Worked example: run on a single image; inspect the output mask
- Validation: comparing predicted masks against reference masks
  (IoU / Dice) on the training set

### Tab 4 — Adding new training data + retraining
- If the pipeline supports retraining / fine-tuning: how to add new
  paired raw+mask images; what the retrain cycle looks like; how to
  evaluate whether the new model is better
- Capstone: take a fresh AX-R image of a hydrogel through parsing →
  segmentation → output review
