# V3.179 — Grants Workflow Phase 2: Grant Writer + Budget Editor

## Goal

Second slice of the Grant Writing workflow. V3.178 shipped the auto-
generated artifacts (biosketch + facilities doc); V3.179 ships the
**writing tools** — a block-based grant editor and a multi-year budget
editor. With V3.179 a lab member can author a full grant draft end-to-
end from inside RM:

1. **Grant writer** ([`rm/pages/grant-builder.html`](../../rm/pages/grant-builder.html))
   — list + editor shell mirroring `paper-builder.html`. `?grant=<id>`
   switches to editor mode.
2. **Budget editor** — modal mounted from the grant editor's
   `budget-table` block. Y1–Y5 tabs, modular ↔ detailed toggle,
   per-year personnel × effort × fringe + equipment + supplies + travel
   + consultants + subawards + other-direct rows, MTDC / TDC indirect-
   cost engine, live grand-total footer. Per-year data writes to
   `grantDrafts/{id}/budget/{year}`; a denormalized summary writes back
   to `grantDrafts/{id}.budgetSummary`.

The federal grants portal (V3.181), AI matcher (V3.182), and Yjs
collaborative editing (deferred to V3.183+) are out of scope. Per the
user's directive ("do the grants portal + scraper last"), V3.179 +
V3.180 ship together as the writing-tools half of the workflow; V3.181
+ V3.182 ship later as the discovery half.

## Deferred from the original V3.180 plan: Yjs CRDT

The approved plan called for a Yjs-backed collaborative editor mirroring
paper-yjs.js + paper-editor.js (~4400 lines of cloned editor + 390 lines
of cloned Yjs persistence). V3.179 ships a **single-author, non-Yjs
editor** instead — same on-disk data shape, ~700 lines of editor code
rather than ~7000. The data is stored at `grantDrafts/{id}.tree` as a
plain JSON tree matching the paper writer's Y.Doc materialization, so a
future V3.183 Yjs upgrade is additive (hydrate the JSON tree into a
Y.Doc on first connect, then take over).

Trade-off: no real-time collab in V3.179. Grants are typically authored
by one PI, with co-PIs reviewing comments after the fact — V3.183 will
revisit this once usage shows whether real-time collab is needed.

## Firestore schema (grantDrafts)

```
grantDrafts/{grantId}
  title, status: 'draft'|'internal-review'|'submitted'|'awarded'|'declined'
  mechanism, agency, programOfficer
  pi: { uid, name }, coIs: [uid], collaborators: [{name, inst, role}]
  deadlineISO, submittedAt, awardedAt
  fundingId               // populated on submission
  opportunityId           // populated when started from a portal NOFO (V3.181)
  budgetSummary: { directs, indirects, total, years: [{year, directs, indirects, total}] }
  attachments: { biosketchVariantIds: [], facilitiesDocIds: [] }
  tree: {
    meta: { title, templateId },
    sections: [{
      id, kind, label, order, status,
      children: [{
        id, kind, status, body, attrs
      }]
    }]
  }
  createdBy, createdAt, updatedAt

  /budget/{year}             ← Y1..Y5
    year, mode: 'modular'|'detailed', modularAmount,
    fringeRates: { academic, summer, postdoc, student },
    idc: { rate, basis: 'MTDC'|'TDC', excludeEquipmentAbove },
    escalation,
    personnel: [{ name, role, baseSalary, effortAcademicPct, effortSummerPct, effortCalendarPct, fringeKind, notes }],
    equipment, supplies, travel, consultants, subawards, otherDirect (all arrays),
    publications: number,
    computedTotals: { directs, mtdcBase, indirects, total },
    updatedAt
```

## Block kinds (`grant-schemas.js`)

| kind             | Render                                                            |
|------------------|-------------------------------------------------------------------|
| `paragraph`      | Contenteditable rich text                                         |
| `aim-bullets`    | Hypothesis textarea + grid of Aim cards (title + summary), seeded in `specific-aims` sections |
| `budget-table`   | Placement marker that opens the budget modal; renders the current `budgetSummary` totals inline |
| `personnel-table`| Editable name/role/effort/notes table                             |
| `compliance-row` | Yes/No/N/A radio + question prompt; seeded in `vertebrate-animals`, `human-subjects`, `select-agents` sections |
| `letter-card`    | Letter-of-support placeholder (writer/role/institution); upload integration deferred to V3.183 |

## Budget calculation (`grant-budget-model.js`)

Pure functions, no DOM:
- `personnelCost(row, fringeRates, escalation, yearIdx)` → `{salary, fringe, total}` with `salary × effort × (1+esc)^y + fringe`
- `categoryTotals(year, yearIdx)` → per-category direct totals
- `mtdcBase(year, totals)` → `directs − equipment(≥excludeAbove) − subawardDirects(>$25k each) − subawardIndirects`
- `idcAmount(mtdcBase, rate)` → `base × rate`
- `yearSummary(year, yearIdx)` → `{totals, mtdcBase, indirects, total}`
- `aggregateYears(years[])` → `{directs, indirects, total, years[]}` for the parent doc's `budgetSummary`

Default fringe rates: academic 30%, summer 10.5%, postdoc 27%, student 10.5%.
Default IDC: 54.7% MTDC, exclude equipment ≥ $5k.
Default escalation: 3%/yr.

## Cross-page integration

- "**+ Biosketch**" toolbar button — picker reads `biosketches/{uid}/variants/`,
  adds the chosen variantId to `attachments.biosketchVariantIds` and writes
  `grantDraftIds: arrayUnion(grantId)` back onto the variant doc.
- "**+ Facilities**" toolbar button — picker reads `facilitiesDocs/`, adds the
  chosen docId to `attachments.facilitiesDocIds` and writes
  `attachedTo: arrayUnion(grantId)` back onto the facilities doc.
