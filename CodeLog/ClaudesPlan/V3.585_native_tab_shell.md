# Instant tab switching in the Ourlab app — native multi-WebView shell (m-v0.3)

## Context

Alex: "we are still reloading each tab each time we move from one tab to another…
why not silently load everything in the background and then just serve it as if
all tabs are all open." Today each tab tap is a full top-level navigation
(document teardown + 555 KB SDK re-parse + auth re-resolve + refetch). V3.573
tried "all tabs open" with iframes and was retired (V3.574): WKWebView doesn't
propagate Firebase auth into iframes, and cross-frame Firestore writes break.

**Design:** keep every tab a TOP-LEVEL page (the proven configuration) but make
the NATIVE layer own the tabs: one live `CAPBridgeViewController` per tab, kept
warm; a tab tap swaps which WebView is visible. All WebViews share the default
`WKWebsiteDataStore` (verified in Capacitor source — `CAPBridgeViewController.
swift:119-147` never overrides it), so Firebase auth IndexedDB is shared and
each tab restores sign-in once per launch.

**User decisions (locked):** app-only (web navigation untouched); warm DOM with
PAUSED listeners in background tabs (detach Firestore listeners when hidden,
re-attach on focus; small refresh-on-arrival accepted).

**Version bookkeeping:** another session shipped V3.582 (sw→556). Re-check
CHANGELOG head + sw.js immediately before claiming versions (collision memory).
Planned: web releases V3.585+ (sw 559+; renumbered from V3.583 after a parallel-session collision at V3.584, mobile release m-v0.3, TestFlight
build 7+. Docs per convention: plan doc (this), CHANGELOG, ARCHITECTURE, both repos.

## Architecture

```
UIWindow → TabShellViewController (storyboard initial VC)
  ├── TabBridgeViewController(.myday)  → /rm/pages/my-day.html    [eager; PRIMARY: push delegate]
  ├── TabBridgeViewController(.focus)  → /rm/pages/team-focus.html [idle-preload ~3-5s]
  ├── TabBridgeViewController(.chat)   → /rm/pages/chat.html       [idle-preload]
  ├── TabBridgeViewController(.tasks)  → /rm/pages/tasks.html      [idle-preload]
  └── TabBridgeViewController(.misc)   → More-sheet/other pages    [lazy, disposable]
```
No native tab bar — each page's own HTML bar (mobile-shell.js) is the UI; taps
call the new `OurlabTabs` plugin. Web/Android degrade to plain `<a href>`
navigation when the plugin is absent (zero shared-config changes;
capacitor.config.json untouched).

## Plugin/event contract (both sides implement exactly this)

- `OurlabTabs.ping() → {ok}` (availability probe)
- `switchTo({key: myday|focus|chat|tasks}) → {key}` (rejects misc/unknown)
- `open({href: "/rm/…html[?query]"}) → {key, navigated}` — routes by the same
  match rules as TABS (tasks family regex `/tasks[a-z-]*\.html$/`); navigates
  the target webview only if `path?query` differs; then shows it
- `reloadAll()` — reloads every webview EXCEPT the caller to its tab start page
  (hidden misc destroyed instead). Called on sign-in success + sign-out only
- `getActiveTab() → {key}`
- Events into pages (plain DOM on `document`, payload `.key`):
  `ourlab:tab-hidden` / `ourlab:tab-visible` on every switch. **Contract
  addendum (reconciles the two designs):** native ALSO fires `ourlab:tab-hidden`
  once into an idle-preloaded webview after its page finishes loading, so a
  hidden-preloaded chat pauses instead of streaming invisibly. Web side is
  idempotent to double-dispatch and defaults to visible.

## Native implementation (OurlabMobile, m-v0.3) — verified APIs

4 new Swift files in `ios/App/App/` (added to App target in project.pbxproj —
via Xcode or scripted PBXFileReference/PBXBuildFile UUID pairs), full sketches
in the design record:

1. **`TabRoute.swift`** — `TabKey` enum + startPaths + `key(forPath:)` mirroring
   mobile-shell.js TABS matchers (keep tasks-family logic in lockstep;
   `lab-tasks.html` → misc, same as web regex).
2. **`TabBridgeViewController.swift`** (subclass of `CAPBridgeViewController`):
   - `override instanceDescriptor()` → `descriptor.appStartPath =
     "rm/pages/<tab>.html"` (verified: `CAPInstanceDescriptor.h:126`,
     `CAPInstanceConfiguration.swift:11-16`, loaded at
     `CAPBridgeViewController.swift:167-180`). Query-free only —
     `appendingPathComponent` percent-encodes `?`; query deep-links use
     explicit `webView.load()` instead.
   - `descriptor.handleApplicationNotifications = isPrimary` — pins the
     process-global `UNUserNotificationCenter` delegate to the My Day bridge
     (verified `NotificationRouter.swift:4-17`: false never clears another's
     delegate) so push taps always land in My Day's JS, which then calls
     `OurlabTabs.open`. `descriptor.hasInitialFocus = isPrimary` (hidden
     preloads must not steal first responder).
   - `override capacitorDidLoad()` → `bridge?.registerPluginInstance(
     OurlabTabsPlugin(shell:))` (verified `CapacitorBridge.swift:350-367`;
     JS proxy injected `atDocumentStart` so `Capacitor.Plugins.OurlabTabs`
     exists on every page).
   - Helpers: `navigate(toHref:)` (URL relative to `bridge.config.serverURL`),
     `currentHref`, `reloadToStart()`.
3. **`OurlabTabsPlugin.swift`** — `CAPInstancePlugin + CAPBridgedPlugin`
   (identifier/jsName/pluginMethods), one instance per bridge; methods above;
   `reloadAll` captures its own `bridge` to exclude the caller.
4. **`TabShellViewController.swift`** — container. Children full-bleed,
   **frame + autoresizing masks, NOT Auto Layout** (Keyboard plugin's
   `ResizeNative` does raw `setFrame:`, `Keyboard.m:355-360`). `activate(key)`
   flips `isHidden` + fires the two events via
   `bridge.triggerDocumentJSEvent` (verified `CapacitorBridge.swift:683-688` →
   document.dispatchEvent, `native-bridge.js:218-231`). Idle-preload
   focus/chat/tasks at +3-5s (fire the post-load `ourlab:tab-hidden` per
   contract addendum). `open(href:)` routing per contract.
   `reloadAll(except:)`. `didReceiveMemoryWarning` → destroy misc, then LRU
   hidden tab (never active, never myday — it owns push).
   `childForStatusBarStyle/Hidden` → active child.

**Storyboard:** Main.storyboard's single VC node `customClass` →
`TabShellViewController`, `customModule="App"`. Info.plist/AppDelegate/
capacitor.config.json unchanged.

## Web implementation (McGheeLabWebsite rm/, V3.583+)

Implementation order (each step testable before the next):

1. **`rm/js/api-firestore-adapter.js`** — registry gains pause/resume:
   extract `api.subscribe`'s body → `_subscribeAttach(path, callback)`;
   registry entries become `{path, callback, raw, paused, attachedAt}`
   (wrapper-unsub semantics preserved for all ~15 existing callers);
   add `api.pauseAll()` / `api.resumeAll()` (re-attach re-fires snapshots =
   the accepted refresh). `detachAll`/`detachByPath` gain `e.raw &&` guards.
2. **NEW `rm/js/tab-lifecycle.js`** (~60 lines) — listens for the two events;
   `window.__OURLAB_TAB_VISIBLE` flag; fan-out ordering hidden: page hook →
   `api.pauseAll` → `firebridge.pauseProfileSync`; visible: reverse. Per-page
   opt-in hook `window.OURLAB_TAB_LIFECYCLE = {pause, resume}`. Idempotent via
   a `visible` flag; every call try/caught. **Initialize `visible` from
   `document.visibilityState` when available** (hidden-preload case), default
   true. Ship via OurlabMobile sync-rm.mjs inject list (harmless on web —
   events never fire).
3. **`rm/js/firebase-bridge.js`** — expose `pauseProfileSync:
   _detachProfileLiveSync, resumeProfileSync: _attachProfileLiveSync` on the
   public API (attach already self-guards + diff-suppresses).
4. **`rm/js/chat.js`** — `pauseChat()`/`resumeChat()` (full sketch in design
   record). Pause: saveDraft, clear typing + its timer, stop presence
   heartbeat **and remove the visibilitychange listener startPresence added**
   (leak fix), drain `_unsubs`, null all named unsubs. Keep ALL state + DOM.
   Resume: guard `_paused`/`!_user`; `_alertInit=false` (re-baseline, no alert
   storm); `_suppressAutoSelect` when parked on Overview (new guard added to
   the V3.86 auto-select condition at subscribeChannels); if `_activeChannelId`
   → set `_pendingRestore=true` (REUSES the V3.581 validation only — parse-time
   pre-seed never re-runs) + `subscribeMessages(_activeChannelId)` +
   re-`subscribeThread(_threadParentId)` if set; re-run subscribeChannels/
   ReadState/Users/Config, `subscribeUserMeta` only if live at pause,
   `startPresence()`. End-of-init race guard: `if (_paused) { _paused=false;
   pauseChat(); }`. Export `window.OURLAB_TAB_LIFECYCLE = {pause, resume}`.
   Accepted UX (comment in code): resume returns feed to live tail.
5. **`rm/js/mobile-shell.js`** — `tabsPlugin()` helper gated on
   `Capacitor.isNativePlatform()` (keeps `?mobileShell=1` browser preview on
   anchors); anchors gain `data-key`; bar click: `preventDefault` +
   `switchTo({key})`, `.catch` → href fallback; More-sheet links →
   `open({href})` with fallback; sign-out → `reloadAll()` + `location.reload()`
   (reload SELF to own tab page, not my-day — webview identity); sign-in
   success `.then` → `reloadAll()`. Loop invariant (comment both sites):
   reloadAll is called ONLY from these two user-action paths, never from
   onAuth callbacks.
6. **`rm/js/mobile-push.js`** — `routeTo()` prefers `OurlabTabs.open({href})`
   with `window.__OURLAB_TAB_VISIBLE === false → return` guard (multi-receiver
   belt-and-suspenders); keep existing fallbacks byte-identical. Registration
   throttle sessionStorage → localStorage (shared store; token write already
   idempotent).
7. **`rm/js/my-day.js`** — register hook: `resume(){ refresh().catch(()=>{}) }`.
8. **`rm/js/chat-alert-watch.js`** — capture its 2 dropped unsubs; detach on
   hidden, re-attach on visible with `_init=false` re-baseline (no alert storm).

**Reuse:** api adapter listener registry (~489-535), chat's named unsubs +
`_unsubs` + destroy() precedent (~3933), V3.581 `_pendingRestore` validation
block, dormant `rm:app:navigate` stays as an untouched fallback branch.

## Key risks + mitigations (full ranked list in design record)

- **Chat resume correctness** (top): the five failure modes each have a named
  guard (visibilitychange leak / auto-select refire / mid-init pause / alert
  storm / channel-deleted-while-hidden). Soak-test ×10 pause-resume cycles.
- **Hidden-webview throttling/visibility semantics** (flagged, not source-
  verified): explicit shell events are the contract so nothing relies on
  visibilitychange; fallback knob = stack-behind instead of isHidden.
- **Memory** (~250-600 MB worst case, 5 webviews): staggered preload + memory-
  warning eviction (misc → LRU; never myday/active) + lazy rebuild.
- **Firestore persistence conflict**: none — app-side persistence is OFF
  (V3.580 gate); web persistence never runs in the app. Do NOT enable
  persistence on native while 5 webviews exist without multi-tab mode.
- **Degradation**: plugin-absent → anchors navigate (Android/web unchanged);
  every plugin call carries an href/`.catch` fallback.
