# V3.359 — Lab notebook mobile-native layout (FuturePlan 10, Phase 1)

## Goal

Make `rm/pages/lab-notebook.html` phone-native. Camera capture has been
the notebook's flagship bench feature since V3.238, but the page carried
exactly one `@media (max-width:720px)` query. This release standardizes
to the canonical 640/1024 breakpoints and gives the phone a real shell.

## What shipped

- **Rail → left drawer at ≤640px** — `#ln-layout` becomes an
  `.rm-mobile-drawer-host` with the rail as `.rm-mobile-drawer-left`
  (shared `MOBILE_DRAWERS` helper + style.css rules; V3.235 pattern).
  Toolbar gains a phone-only ☰ toggle; picking an entry closes the
  drawer. Classes are applied only when `mobile-drawers.js` actually
  loaded — a missing script degrades to the old stacked-rail layout
  instead of stranding the rail off-screen.
- **Sticky bottom action bar** (`ensureActionBar`, lives on `<body>`
  outside re-render churn): **📷 Capture · 🎙 Voice · ➕ Observe ·
  🏷 Tag**, 48px targets, `env(safe-area-inset-bottom)` padding.
  Buttons self-create today's entry when none is open (`ensureEntryThen`
  → `openTodayEntry`). Observation buttons dim outside `running` phase
  (`refreshActionBar`).
- **Keyboard handling** — `visualViewport` resize/scroll listeners
  translate the bar above the soft keyboard; `.ln-body` gets
  `scroll-margin-bottom` so the caret clears the bar.
- **＋ Today** toolbar button — opens today's most-recent entry or
  creates one. Phone empty state gains a big **“📷 Capture into today's
  entry”** button (create-then-camera in one tap).
- **CSS rewrite** (`rm/css/lab-notebook.css`): 720px query replaced by
  ≤1024 (rail 240px) and ≤640 blocks — sticky toolbar, full-bleed
  editor, 44px touch targets, horizontally-scrolling body toolbar,
  always-visible attachment delete (no hover on touch), near-full-width
  popovers, safe-area-capped modals. Desktop ≥1025px untouched.

## Files

`rm/js/lab-notebook.js`, `rm/css/lab-notebook.css`,
`rm/pages/lab-notebook.html` (+ `mobile-drawers.js` script tag).

## Verification

`node --check` on touched JS. Browser: DevTools iPhone emulation —
drawer open/close/backdrop, action bar above keyboard, ＋Today round
trip, camera input fires; desktop regression (toolbar, editor, run
panel) at ≥1025px.

## Rollback

git revert + re-FTP + CACHE_VERSION bump. Client-only; no schema or
rules changes.
