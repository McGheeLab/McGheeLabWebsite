# V3.774 — Week 4 (cytoskeleton) simulation pages

Alex: *"push all simulations from the learning module into the website repo for me to FTP"*

## What is actually broken

`modules/bme466/04c-the-cytoskeleton.html` is deployed and byte-identical to the
course repo's canonical `local-test/04c-the-cytoskeleton.html`, and it carries the
whiteboard head block — so the module page itself works. But:

1. **`scripts/gen_simulations.py` never sees it.** `MODULE_FILE_RE = ^(\d+)-.*\.html$`
   requires a digit run followed immediately by `-`. `04c-` has a letter between, so
   the file is skipped and **zero** of its 23 simulations were ever generated.
2. **The 16 `4.*.html` pages that do exist are dead.** They were generated from
   `04-the-membrane-that-senses.html`, which no longer exists in `modules/bme466/`
   (Week 4 was reworked from the membrane to the cytoskeleton, V2.74–V2.77). Their
   iframes point at a missing file.
3. **`whiteboard.js:resolveSimRef` has the same blind spot** — it finds a module by
   `^0*<n>[-_.]` against the filename, which `04c-` also fails, so `4.T.S` only
   resolves by lucky ordinal fallback (`lessons[n-1]`) and breaks the moment the
   class lists its modules in another order.

## Fix

- `gen_simulations.py`: `MODULE_FILE_RE → ^(\d+)[a-z]?-.*\.html$`, plus a guard that
  refuses two files claiming the same module number (`04-…` and `04c-…` together
  would silently overwrite each other's refs).
- `whiteboard.js`: prefix match `^0*<n>[a-z]?[-_.]`.
- Regenerate `modules/bme466/simulations/` — 23 new `4.T.S.html`, 16 membrane orphans
  removed, `index.json` rewritten. Generated pages only *iframe* the module
  (`?embed=T.S&sim=1`), so nothing is copied and the module stays the single source.
- `sw.js` CACHE_VERSION 751 → 752.

## Note on the moving target

A parallel session is editing Week 4 right now (the file grew 711,798 → 718,533 bytes
mid-task and the course changelog is at V2.77). The wrappers bake in only the section
number and `data-title`, so content edits need no regeneration; adding, renumbering or
retitling a section does. `python3 scripts/gen_simulations.py bme466 --check` is the
detector and is safe to re-run before the FTP push.
