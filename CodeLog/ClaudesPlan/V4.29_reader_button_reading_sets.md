# V4.29 — The Reader button and reading sets by project

## Goal
Gabe (18 Nov 2026): "Add a button in the top right corner, which is to open the Reader (responsible for PDFs, HTMLs, websites, and more). […] Your tabs are organized by projects, so you may have multiple reading sets opened at once. The current project you are in displays that reading set. Project reading sets overlap tabs from the same project, which act similar to regions. Other projects have their reading set region collapsed, Clicking on a collapsed region collapses the previous one while opening this one. Clicking close on the tab is the only way to close the PDF, HTML, etc… from that reading set. If you are opening the reader outside of a project, your most recent visit gets opened. This applies to projects too: the most recent visit from the project you're currently in is opened. If a paper is cited in multiple projects and is opened from a specific project, it may appear in both."

(The rest of the same message — the maximised view keeps the tabs, the mini library from the left, shelves assigned to projects — is V4.30. One sentence, maximise → close returns beside, is V4.31, another builder's.)

## Approach
- **A new module wraps the reader, so 13zzb stays as it is.** `scientia/src/17i-readsets.js` (`RSET`) + `34-readsets.css` wrap `RDOCK.load / save / open / focus / close / closeTab / follow / tabsRow / layout`, `RDX.goTab` and `DocView.render`. No direct edit to `13zzb-reader.js` or `13zz-maxhl.js` (the beside panes are being changed by another builder at the same time).
- **The state** stays on this device in `_ls 'rtabs'`, extended:
  - `sets { key: { tabs, at, from, show, act } }`: key = the project's id, or `-` for notes outside any project; `at` = when each tab was last read; `from` = the note it was opened from; `show` / `act` = what the panes showed;
  - `cur` = the set shown; `mode` = `sets` | `flat`.
  - `RDOCK.S.tabs` is **the shown set's tabs**, so 13zzb's tabs, panes, ◫ split, + and closing work on it unchanged. `RSET.sync` writes the row back into its set before every save and focus; the zoom of the other sets' tabs is kept (13zzb trims it to the row's tabs).
- **The migration:** the flat tabs kept before V4.29 go once each into the set of its note's project (the embed's note); the set shown is the shown tab's.
- **Which set a paper goes in** (`RSET.target`): opened from a note (the book on a card, ◧ Beside, the citation band, /beside) → the note's project; from the reader itself (a tab, a free pane, + on the row, the empty set's picks — `window.event`'s target inside `.rd-wrap` or a modal) → the set shown. A paper opened from two projects is a tab in both.
- **The row** (`RSET.paintRow`, after 13zzb draws it): the shown set's tabs move into a band (`.rs-set`) named by its project and tinted in its colour (`hashHue(projectId)`; grey for no project), with a top line like a region's border; every other set with tabs becomes a chip (`.rs-chip`: name, count). Sets sit in the Portfolio's order of projects, no project last.
- **Collapse / expand:** a chip clicked → `RSET.use(key)`: the row becomes that set, the panes as it left them (else its most recent tab), the one open before folds. It does switch what is read (the most recent tab of the set opened).
- **Going to a note:** when the project of the note in focus differs from the last one (`RSET.lastCtx`), its set is shown (Settings: on by default). A project with no set yet: the reader steps aside (`close(true)`; `S.open` stays) until you come back to a project with tabs, or press the Reader button. Moving between notes of one project keeps the set you chose with a chip.
- **A tab clicked** takes the note to its paper (Reading tabs → "follow") only when the paper's note is in the set's project; otherwise the note stays (it would leave the project and the set). "Go to its note" in the tab's menu still goes.
- **Only × closes a tab.** `RDOCK.close()` (✕ on the row, /close, the last tab of the only set) closes the reader with `keep`; `S.open = false`; every set keeps its tabs. The last tab of a set closed: the reader closes, and the other sets keep their tabs (the Reader button, or a note of their project, brings them back; the lab harness's "Close: … the note forgets it" holds). Close on a pane in full screen goes back beside (the tab stays). Leaving the note already kept the tabs (13zzb: `close(true)`); closing a maximised card never touched them.
- **The Reader button** `#readerbtn` (RDOCK's book icon, monochrome SVG), appended last to the header row (after the theme toggle; the lab layer's ✦ sits in the note's canvas below the header, so they never meet), hidden on the phone and with the feature off. `.on` while the reader is open.
  - **In a note:** that project's set at its most recent tab; a set with none yet: the empty set — the papers and pages in that project's notes (newest first, up to six), + Open a paper or page…, and the other sets' chips.
  - **Elsewhere:** the project of the page (a project's or theme's page, the Portfolio's selection; the quick notes → no project) if its set has tabs, else the set read most recently; its most recent tab, **beside the note it was opened from** (`from`, else the note it is in). Chosen over the maximised view because the reader beside a note is where the set's row, Cited in and ◫ live, a highlight lands in a note you can see, and "the project you are in shows its set" stays true. Settings can make it full screen there instead (Esc comes back beside). Nothing read yet: the + picker.
  - Clicked while the reader is open: it closes (tabs stay).
- **Settings** (`20a-features.js`, Reading & sources):
  - **Reading sets by project** (`rsets`, needs Reading tabs): the switch (off: one flat row of every set's tabs, the shown set first, then by when last read — as before; on again: the sets as they were, tabs closed meanwhile gone, new ones sorted by their notes' projects); tunes *Going to a note of another project opens its set* and *Each project in its own quiet colour*; preview: a tab row with one open set and two chips — click a chip to open it there.
  - **Reader button** (`rbtn`, needs Reading tabs): the switch (CSS `body.f-off-rbtn`); tune *Outside a note, it opens the last paper* — beside its note / full screen; preview: the header's right end with the book.

## Decisions where the brief was silent
- The tab row's ✕ closes the reader and keeps the tabs ("Close the reader — your tabs stay in their sets").
- The pane bar's "Close ✕" beside the note is unchanged: it is labelled "Close this tab".
- "Tabs kept open" (6/12/24, closing the oldest not showing) now counts per set.
- A lit review (a literature note outside any project, linked to projects) is in the no-project set, like the other notes outside any project.
- A project deleted: its set's tabs join the no-project set.
