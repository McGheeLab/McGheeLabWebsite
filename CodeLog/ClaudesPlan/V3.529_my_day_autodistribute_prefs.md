# V3.529 — My Day R4: auto-distribute prefs (persistent toggle + exclusions)

Part of the **My Day program** — see `V3.526_my_day_program.md`.

## Goal
Program decision 4: a persistent per-user "auto distribute" toggle (ON by
default) with a per-surface never-send list; when off, each entry's
destination chips start unchecked and the student picks manually.

## Approach
- **`userData/{uid}/dayPlans/_prefs`** —
  `{auto_distribute, excluded_surfaces[], schema_version}`; absent doc ⇒
  auto ON (the decided default). Covered by the userData wildcard rule —
  no rules work. Route `my_day/prefs.json` registered in api-routes.js
  for admin-migrate visibility; the engine reads/writes via direct refs.
- **`DAY_DISTRIBUTE.getPrefs/setPrefs`** (cached) +
  `defaultSurfacesFor(item, prefs)` honoring prefs + per-item exclusions.
- **⚙ gear popover** on the My Day date bar: the toggle + per-surface
  checkboxes; changes recompute the composer chips immediately.

## Deploy
FTP only.

## Verify
- Exclude Huddle → new work items skip huddle; chip shows unchecked but
  can be re-toggled per entry.
- Toggle auto OFF → composer chips start unchecked; nothing distributes
  until picked.
- Prefs persist across devices (Firestore doc, not localStorage).
