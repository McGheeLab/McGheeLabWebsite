# V3.432 — Section cross-references ([!sec:label]) — R3 of the Lists/Appendices/Section-refs program

> Final release of the program. Cross-refs existed for figures/tables/equations/citations/
> footnotes but not for sections. Now a `[!sec:label]` token references a section or
> subheading — rendered as the target's number in the doc view + compiled PDF, and as its
> title in the editor. Mirrors the `[!fig:label]` machinery.

## Model

Sections carry an optional top-level `ref_label`; subheadings carry `attrs.ref_label`
(both round-tripped in V3.431). `[!sec:label]` is an atomic chip (like `[!fig:]`). The
editor shows the target **title** (`§ Cell culture`) — the editor has no journal numbering;
the document viewer upgrades the chip to the computed **number** (`Section 3.2`) post-mount;
the exporter emits `\label{label}` after the heading and `\ref`/`\cref` for the token.

## Changes

- **`rm/js/paper-editor.js`**
  - `[!sec:label]` token in `renderParagraphHtml` and `renderChipsOnlyHtml`; the serializer
    round-trips via the generic `data-src` chip attribute (no change needed).
  - `renderSecRefChip(label)` → `.pe-secref-chip[data-secref-label][data-src]` showing the
    target title (unknown → faded `[?§ label]`); `getSectionRefTargets()` walks sections +
    subheading blocks → `{label: {title, id}}`.
  - Section-header **ref-label input** (`🔖 sec:label`) in `renderSection`; sets/deletes
    `ref_label` on the section map on blur.
- **`rm/js/paper-blocks.js`** — subheading toolbar **ref-label input** (`🔖 sub:label`),
  writing `attrs.ref_label`.
- **`rm/js/paper-doc-view.js`**
  - During the numbering walk, record `secRefNums[ref_label] = _refNum(number)` (number
    minus trailing punctuation) for numbered sections + subheadings → `state.secRefNums`.
  - `_resolveSecRefs()` runs after `_mountSheets`: rewrites every
    `.pe-secref-chip[data-secref-label]` whose label is in the map to `Section N` (forward +
    backward refs both resolve because the map is complete before this pass).
  - `.pe-secref-chip` added to `SPLIT_GUARD_SEL` (never split a ref chip mid-page).
- **`rm/js/paper-export-tex.js`**
  - `paragraphTextToTex`: `[!sec:label]` → `Section~\ref{label}` (or `\cref{label}` when the
    cleveref add-on set `_use_cref`).
  - `secLabelTex(sec)` emits `\label{<ref_label>}` after `\section`/`\section*`;
    `subheadingToTex` emits `\label` from `attrs.ref_label`. Absent label = byte-identical.
- **CSS** — `.pe-secref-chip`/`-unknown` + `.pe-section-reflabel`/`.pe-subheading-reflabel`
  inputs (editor); `.pe-secref-chip` added to the doc-view chip-flatten lists so it renders
  as plain "Section N" text.
