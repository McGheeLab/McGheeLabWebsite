# V4.95 — Slash commands made of workflows (Scientia, on V4.89)

## Why

Gabe, 20 Nov 2026: "Slash commands should be tunable with workflows or actions (everything you can think of)."

Before this, `/` in a component listed the built-in commands (11b `CMD`) and every + Insert row. The app already had *macros*
(11b `MACRO`: steps behind one /command, imported from a `.sis-macro.json` file) but no way to make a command in the app,
and the built-ins could not be tuned. This builds on the macro idea (the same registry, the same placeholders' spirit) instead
of making a second system: a workflow step can run any command or macro, and Settings turns a macro into a workflow in one click.

## What changed

- `13zzga-slashwf.js` (new): `SWF`.
  - A command of your own is `{ id, name, desc, aliases, steps: [{ action, opts }] }` in `settings().slashCmds` (synced). `CMD.all()`
    (11b) lists them after the macros, group "Yours", `swf` set, so the slash menu and the command bar both show them.
  - 27 actions, in groups: Text (insert text with `{date} {time} {now} {datelong} {weekday} {selection} {line} {component} {note}
    {project} {theme} {cursor}` and the answers of Ask steps; clear), Structure (make the words a Claim / Result / Question…),
    Component (set the kind, name it, new component below, float, wire to the previous one, fold, flag for synthesis, bridge,
    move through the move panel), Note (tag, flag for the weekly review, log a line in today's day note), Time and tasks
    (task with a due like `+1d`, reminder, the note's timer), Insert (a widget by its INSERTS id, a template's components),
    Go and run (any command-bar command with arguments, a macro, open a note / a tab / today, say something), Ask (prompt).
  - The Ask step is an inline box at the caret (`.swf-ask`), never `prompt()`; the answer is `{name}` for later steps; Esc stops.
  - A step works on the data (the component's body through `M.saveBlockBody`), not on the editor, so steps after a repaint still
    land at the caret. "Which words" for a structure: what the last text step typed, else the sentence before the caret, else
    the line, else the whole component.
  - A run is ONE undo group: `DB.beginGroup('/name')`, the steps' own `beginGroup` calls folded in (as `13p-edit.js` does), the
    canvas' settle (boxes nudged apart) inside the group. Ctrl+Z straight after a run, caret still in the component, undoes the
    run (a capture-phase key handler; the editor would otherwise undo its own typing).
  - Tuning the built-ins: `settings().slashTune = { hidden: [], order: [], aliases: { slash: [alias…] } }`; `13zzg-slash.js`
    `rows()` drops hidden ones, puts pinned ones (in order) and, if asked, mine first, and an alias typed in full ranks first;
    `CMD.get` knows an alias, so the command bar does too.
  - Settings editor (Features → Slash commands): list (Edit, Duplicate, two-tap Delete), `+ New command`, an editor with a row per
    step (action, its options, ↑ ↓, drag the grip, duplicate, remove), `+ Add a step` (the actions by group, on a click),
    examples, a refusal that says which step is wrong, **Try it** (runs the steps on a sample component in memory; the live
    preview shows the sample and what each step did; nothing is written), export / import as JSON (`sis-slash/1`, with the
    tuning), macros → workflows. Below it, the built-ins: show / hide, Pin (with ↑ ↓ order), an alias box.
- `20a-features.js`: the `slash` feature's description, three tunes (my commands first, a bolt on them, say what a run did), the
  editor and the built-ins list as `node` tunes, and a preview that draws the menu as it is now plus the Try it result.
- `13zzg-slash.js`: rows / score / row icon as above. `11b-commands.js`: `CMD.all()` adds mine; Settings → Commands points to the page.
- `48-slashwf.css`: the bolt, the question, the editor.
