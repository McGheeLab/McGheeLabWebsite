# V3.349 — Calendar-picker skeleton: visible hour lines, today marker, hour-only labels

## Goal

Make the calendar grids you pick times on readable at a glance: a clear
hour rhythm (strong line every hour, faint line every half-hour), time
labels only on the hour, a visible "today" column, and paintable cells
that read as slots instead of a black void. Applies to the guest
availability picker (freeform grid, both public + RM render paths) and
RM's My Availability grid.

## Problem

Alex (2026-07-12): "the look and feel of the calendar picker is not
great, we need to see the skeleton of the calendar we are picking from
more clearly." Today: every 30-min row carries a full time label (wall of
text, no rhythm), all gridlines are identical 1px `gap` seams, empty
cells are `rgba(255,255,255,.03)` on a dark surface (structure
invisible), and nothing marks today.

## Approach

**Engine markup (`scheduler.js`)** — same generator serves public + RM:
- New `todayISO()` helper (local date, matches ScheduleUtils' convention).
- `freeformGridHTML` + the guest picker grid in `guestViewHTML`: label
  only rows whose `b.time` ends in `00`; stamp every row's cells
  `ff-hour` / `ff-half`; stamp today's header + cells `ff-today`.

**RM My Availability markup (`rm/js/scheduler.js`)**: cell loop stamps
`ms-cell--hour` (even slot index = top of hour) and `ms-cell--today`.

**CSS — `user-styles.css` (public) + `rm/css/scheduler.css` (RM copy),
kept in sync for the `.ff-*` block; `.ms-*` lives only in RM:**
- `.ff-hour` cells: 2px top border (strong hour line over the 1px gap
  seam); hour time-labels brighter (`--text` vs `--muted`).
- `.ff-block` base: slight lift (`rgba(255,255,255,.04)`) so the
  paintable field reads as cells; crisp accent inset outline on hover
  (the old `brightness(1.2)` did nothing on near-black). Inline heat
  backgrounds in admin view still win (inline > class).
- `.ff-today`: accent underline on the day header, faint accent edges
  down the column (inset box-shadow, so it never fights heat/selected
  backgrounds; declared before `.ff-selected` so selected wins).
- `.ms-cell--hour`: 1px top border at .12 alpha (vs .03 half-row seams);
  day separator bumped .06 → .09; `.ms-cell--today` gets a faint accent
  wash (paint/erase previews have higher specificity and still win).

## Files modified

## Out of scope

Sticky day headers on the public page (fixed site header collision risk);
sessions-mode grid (few labeled rows, skeleton already legible); the
admin session-builder grid (`.sb-dg-*`, already has hour cells).
