## The model

- The user sizes the **figure box**; the image and caption are sub-blocks
  inside it. The image is maximized within (a) the box width and (b) an
  optional **image height cap** — aspect preserved, letterboxed/centered
  when the cap binds. The caption spans the box and is never hand-sized.
- **Attr: `max_h`** — integer mm, the IMAGE max-height (never the box
  total: export must stay deterministic with no DOM — caption height under
  LaTeX is unknowable client-side). Absent = unconstrained = byte-identical
  sentinel. Dragging to/past natural height DELETES the key.
- LaTeX mapping: `\includegraphics[width=…, height=<max_h>mm,
  keepaspectratio]` — graphicx's exact "maximize inside a w×h box".
  **Narrow anchored figures** (box width < full line: fraction < 1 or
  absolute units) wrap image+caption in `\begin{minipage}{<width>}` so the
  PDF caption spans the box like the preview. Legacy blocks (no `anchor`)
  keep the flat verbatim path — byte-identical (harness-guarded).

## What shipped

1. **NEW rm/js/paper-fig-fit.js** — `PaperFigFit.fit({boxWpx, maxHmm,
   aspect, captionPx, gap, mmPx}) → {imgWpx, imgHpx, boxHpx, bound}`.
   Pure, DOM-free, module.exports guard (Node harness requires it
   directly). Loaded in paper-builder.html before paper-doc-view.js.
2. **paper-doc-view.js** — figure DOM restructured: `.pdv-figure` (flow
   item, container width — packer untouched) → `.pdv-fig-box` (pct%,
   centered, carries handles) → `.pdv-fig-imgwrap > img` (explicit px from
   fit()) + `figcaption` INSIDE the box. Stamps `data-h` (cap) + `data-ar`
   (aspect). Measure cacheKey gains `dataset.h` (the V3.402 aliasing bug
   class). Resize module: handles moved to the box; new **S** (height cap)
   + **SE** (both axes) handles; `_snapTargetsV` (journal
   `figure_max_height_mm` + "Natural — no height cap" release target, 8px
   window); pure-height drags do NOT rewrite the width spec; commit = one
   transact `{anchor, span, lock, width?, size_key?, max_h?}` origin
   `fig-size` (added to LAYOUT_ORIGINS); `_cancelResize` on Esc (front of
   the chain); `_writeFigAttrs` now treats `null` as attrs.delete (cap
   release restores the absent sentinel).
3. **paper-layout-rules.js** — `resolveFloat` return gains
   `height: '<mm>mm' | null`; advisory (never clamp) when the cap exceeds
   `render_hints.layout.figure_max_height_mm`; module tail now exposes a
   module.exports guard (Node-requireable).
4. **paper-export-tex.js** — `figureToTex` assembles
   `width=…[, height=…mm, keepaspectratio]` and the minipage wrap for
   narrow anchored figures (gated on having a caption to align).
5. **CSS** — `.pdv-fig-box` (position anchor), `.pdv-resize-s` bottom
   pill (ns-resize), `.pdv-resize-se` corner dot (nwse-resize).
