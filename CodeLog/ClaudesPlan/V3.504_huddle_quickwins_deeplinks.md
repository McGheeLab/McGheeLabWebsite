# V3.504 — Huddle quick wins + notification deep-links (R1 of the Huddle UX redesign)

## Goal

First of five releases addressing why lab members aren't active on the Huddle:
fix the outright-broken discovery surfaces before the structural redesign
(R2, V3.505+) lands. No layout changes in this release.

Program plan: user-approved 5-release redesign — R1 quick wins, R2 IA collapse
to 4 tabs + inline composers + UI-level Plans/Rundown merge, R3 rundown→plans
data migration, R4 per-user seen state + badges, R5 decommission.

## What shipped

1. **Dashboard "The Huddle" card fixed** ([rm/js/dashboard.js](../../rm/js/dashboard.js)).
   The card filtered `p.status === 'active' || 'published'` — statuses that
   have never existed (plans are `planned/completed/cancelled/delayed`) — and
   read `p.userName`/`p.title` (schema is `ownerName`/`text`), so it always
   rendered "No active plans" and linked to `'#'`. Now: queries `huddlePlans`
   by the current ISO `weekId` (math copied verbatim from huddle.js
   `getMonday`/`getWeekId`, including the Sunday→next-Monday quirk), counts
   `planned`/`delayed` plans, shows `ownerName: text` (HTML-escaped), appends
   an open-help-request count, and links to `/rm/pages/huddle.html`.

2. **Notification deep-links** — `?kind=plan|help|rundown&item=<docId>[&tab=<section>]`.
   - [functions/huddle.js](../../functions/huddle.js): all five push URLs now
     carry `kind`+`item` (plan join / watch / status-change → `kind=plan`;
     help create / response → `kind=help`).
   - [rm/js/huddle.js](../../rm/js/huddle.js): new `applyDeepLink()` runs in
     the bootstrap before first render — maps kind→section, fetches the doc,
     jumps `_currentWeekOffset` to the item's week via new `weekIdToOffset()`
     (inverts `getWeekId` by offset scan so the Sunday quirk stays consistent),
     routes own help requests to My Help vs. others' to Help Feed, and opens
     the plan popup (`_popupPlanId`). New `flashDeepLinkTarget()` runs after
     every render: once the target's snapshot lands, `scrollIntoView` + a
     `.hud-flash` pulse (2 cycles), then clears so later renders don't re-scroll.
   - Help cards and rundown cards now carry `data-item-id`; grid blocks
     already had `data-plan-id`.

3. **Empty-state CTAs** — Help Feed, My Help, and Rundown empty states get a
   primary button (`data-goto-section`) jumping straight to the matching
   create form. Wired generically at the end of `wireSection()`.
