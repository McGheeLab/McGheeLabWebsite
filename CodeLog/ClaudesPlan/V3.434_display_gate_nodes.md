# V3.434 — 📊 Cards / 🔗 References display gates (mirror retired from UI)

## Context

Alex's demo-2 feedback, refined through plan-mode Q&A: replace the
constant "Mirror value…" modifier with output-gate node types. Final
model: **📊 Cards** gates which variables render as the document's
result cards (existing hero-card look); **🔗 References** gates which
values the editor's 🔗 picker offers inline — a curated subset, "not a
list of all variables in the node editor", grouped by gate node. Card
variables are automatically referencable. STRICT gating (Alex's
explicit choice): no cards node → no cards; no gate nodes → empty
picker with a how-to hint. Prose `[!var:]` tokens keep resolving — the
gate governs what is OFFERED, not what computes/renders.

## Kernel (`rm/js/protocol-graph.js`)

- `NODE_TYPES` + `'cards'` + `'refs'`; defaults `{label:'Results'}` /
  `{label:'References'}` (the panel/group header). Pure sinks:
  `producedVars` → [], one dynamic `display` slot each,
  `edgeRole(target cards|refs) → 'display'`, `inferScopes` skips
  display edges.
- **`displayGroups(graph)`** (exported): per gate node in node order →
  `{nodeId, type, label, vars:[{name,label,unit}]}` — wire order,
  deduped per group, sourceVars resolved via the global name table
  (pass-through-safe), undeclared units filled from resolveQuantities
  (µL·mol style), per-item producers skipped.
- `validateGraph`: display wires only into gate nodes (error); empty
  gate node warns ("gates nothing"). `compile` warns per-item vars
  wired to a gate ("wire it into a List instead") and attaches
  `displays: displayGroups(graph)`.
- **`designInputsOutputs`**: outputs = cards-gated vars ONLY, group +
  wire order — compiled output specs reused verbatim (decimals +
  drivers, so driven decimals keep working; computed-unit fill rides
  along); input/constant names synthesize `{name,label,unit}` (cards
  read the live symbol table by name, so input cards track). No cards
  node → `outputs: []`.
- Constant mirror: the `valueDriver` compile branch STAYS — legacy
  graphs keep computing.

## Editor (`rm/js/protocol-graph-editor.js` + CSS)

- Palette 📊 Cards / 🔗 References (+ `.pge-node-cards`/`-refs` accent
  bars); display rows via `_boundRow` (role tag "card"/"inline") + an
  open invite dot; config = one label field; plus-menu "Add variable…"
  arms the display slot. Display rows get no pass-through dot (sinks).
- **Mirror retired**: the constant plus-menu item is gone and the value
  row's in-dot renders disabled when no driver exists; an EXISTING
  legacy driver still renders with its removable bound row.

## Reference picker (`rm/js/protocol-editor.js` + CSS)

  `formatSymbolValue` (units attached); search filters within groups;
  no gates anywhere → empty-state row telling the author to add one.
