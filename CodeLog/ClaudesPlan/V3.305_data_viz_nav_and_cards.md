# V3.305 — Data Visualizations: nav item + image-forward gallery cards

## Goal

Two follow-ups to the V3.301 Data Visualizations feature:

1. Put the Data Visualizations page directly in the site navigation, under the
   **Research** heading (previously only reachable from an in-page gateway card
   on the Research stories page).
2. Make the gallery cards image-forward — the card should primarily show the
   actual visualization preview image ("just an image of the visualization
   you're going to get into"), not a text/metadata block.

## Changes

### Nav (`index.html`)
Added `<a href="#/data" data-route="data">Data Visualizations</a>` under the
Research group in all three nav surfaces:
- Desktop Research dropdown (`.nav-group` → `.nav-dropdown`), ordered
  research → projects → **data** → news.
- Mobile Research group sheet (`#group-sheet-research`).
- Legacy drawer fallback (`#site-nav`).

No JS change needed for highlighting: `NAV_GROUPS.data = 'research'` was set in
V3.301, and `setActiveTopNav()` marks the group button `group-active` whenever a
child `a[data-route="data"]` matches the current page — which now exists in the
dropdown. The in-page gateway card on the Research page is kept as a secondary
entry point (harmless, aids discovery).

### Gallery cards (`app.js` `wireVizGallery`, `styles.css`)
- Card face is now the preview image (saved-view poster → manifest `thumb` →
  `🧊` placeholder) with the title in an overlaid `.viz-gallery-caption` over a
  bottom gradient scrim; the "Interactive 3D" badge moved to top-right
  (`.viz-gallery-thumb .viz-embed-badge{ top:10px; bottom:auto }`) so it clears
  the caption.
- Removed the `.viz-gallery-body` text block (description paragraph + tag /
  saved-view-count badges) from the card face. Description is preserved as the
  link's `title` tooltip.
- Thumb aspect ratio 16:10 → 4:3; subtle image hover-zoom.

`sw.js` `CACHE_VERSION` bumped for deploy.

## Verification

Headless Chrome (puppeteer-core + system Chrome):
- **Desktop (1400px)**: `a[data-route="data"]` present in the Research dropdown
  (order research,projects,data,news); navigating to `#/data` sets the link
  `aria-current` and highlights the Research group button.
- **Mobile (390px)**: the Research group sheet contains the `#/data` link.
- **Gallery card**: preview `<img>` present and actually loads
  (`granular-flow-preview.jpg`, naturalWidth>0); title rendered as an
  absolutely-positioned overlaid caption; old text body absent; badge in the
  top half and not overlapping the bottom caption; description present as the
  link tooltip.

All checks pass.
