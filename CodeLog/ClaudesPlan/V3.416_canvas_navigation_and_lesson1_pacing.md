# V3.416 — Canvas navigation pack + demo 1 pacing (add→frame, open-space placement, zoom-to-node)

## Context

Alex's clarification of V3.414: the first lesson step should be
1) input node down, 2) Fit, 3) zoom out then in — THAT completes the
step; naming is the next step. Plus two editor features: new nodes must
land in an open area (they were stacking on the drop point), and a
zoom-to-node affordance — a header button, double-click a node to zoom
to it, double-click empty canvas to Fit — all taught in demo 1.

## Editor (`rm/js/protocol-graph-editor.js`)

- **Open-space placement** — `findFreeSpot(x, y)`: candidate rect
  (224×150 + 26px pad, measured sizes from `sizeCache` when known)
  probes outward from the viewport-centre drop point (right, down,
  diagonal, left, up; 8 rings) and returns the first clear spot;
  pathological density staggers instead of stacking. `addNode` routes
  through it. (Recipes keep their own pre-arranged cluster offsets.)
- **`zoomToNode(n)`** — centres the view on the node at a scale that
  gives it ~room-to-work (clamped 0.3–2.2, cap 1.6).
- **Header ⌖ button** (`.pge-zoomto`, next to collapse) → zoomToNode.
- **Double-click gestures** — empty canvas = `fitView()`; a node card =
  `zoomToNode` (guarded off INPUT/TEXTAREA/SELECT/contentEditable so
  text double-clicks still select words). Dblclick-to-expand is
  retired — the popout keeps its ⤢ button. Cheatsheet rewritten
  (zoom-to-node + fit lines added, expand line updated).
- **View-action counters** — `bumpCounter(key)` stamps
  `viewport.dataset.pgeFits / pgeZooms / pgeZoomtos` on fitView,
  zoomBy, wheel-zoom, and zoomToNode. Graph state can't see view
  gestures; the guided tours read these to VERIFY viewer drills.

## Demo 1 (`rm/js/protocol-graph-tours.js`, 15 → 16 steps)

- Step 1 = **"Add the first Input — then frame it"** (practice): a
  numbered 1-2-3 card — drop the node, ⌖ Fit, zoom out then in —
  completing only when `count(input) ≥ 1 && pgeFits ≥ 1 && pgeZooms ≥ 2`
  (Node-safe DOM guards). Naming is its own next step, exactly as asked.
- "Add the second Input" notes it lands in open canvas; the following
  NEW **"Zoom to the new node"** drill (practice) rings the new card's
  header ⌖ and completes on `pgeZoomtos ≥ 1` — text covers the button,
  double-click-the-card, and double-click-canvas-to-Fit.
- Lesson JSON's gesture block rewritten (open-space placement, ⌖ /
  double-click zoom, double-click-canvas Fit, wire delete/cut).
