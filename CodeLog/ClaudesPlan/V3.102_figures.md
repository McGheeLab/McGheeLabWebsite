# V3.101 — Paper builder: editable figure block

## Goal

The figure block kind already exists in the paper-builder schema
([rm/js/paper-blocks.js:18](../../rm/js/paper-blocks.js)) but renders the
"unsupported in this phase" placeholder. Wire up real figure authoring:
upload an image, write a caption, set LaTeX placement / width / label /
centering, and have all of it round-trip through Yjs and the LaTeX export.

This is the first of four wishlist items tracked in
[rm/wishlist.md](../../rm/wishlist.md):
figures (this version), skeleton outlining + claims (V3.102), body rich
text (V3.103), and equation refs (V3.104). Master plan lives at
`/Users/alexmcghee/.claude/plans/we-need-to-make-expressive-turing.md`.

## Approach

### Data model
The figure block reuses the existing `body: Y.Text` for the caption (so
inline `$math$` and `[@cite]` work the same as paragraphs). The new
`attrs` Y.Map fields:

| Key | Type | Purpose |
|---|---|---|
| `storage_path` | string | `paper-figures/{paperId}/{shortHash}.{ext}` |
| `download_url` | string | Resolved URL, cached so re-renders don't re-hit Storage |
| `hash` | string | First 16 chars of SHA-256 (matches library-upload pattern) |
| `mime` | string | `image/png`, `image/jpeg`, `image/svg+xml`, `application/pdf` |
| `width` | string | LaTeX width spec — `\\linewidth`, `0.8\\linewidth`, etc. |
| `placement` | string | `H` \| `h` \| `t` \| `b` \| `p` |
| `centering` | bool | Default true |
| `label` | string | `fig:cellgrowth` (auto-slugged from caption) |
| `alt` | string | Accessibility text |

Legacy imports keep their existing `attrs.raw_tex` / `attrs.path` /
`attrs.caption` fallback in `figureToTex`.

### Storage path + dedup
Mirrors the existing pattern in
[rm/js/library-upload.js](../../rm/js/library-upload.js): SHA-256 the
blob, check `getMetadata()` first to skip re-uploads, store at
`paper-figures/{paperId}/{shortHash}.{ext}`. Custom metadata stamps
`uploadedBy` and `fullHash`.

### LaTeX export
Replace the `attrs.path` lookup in `figureToTex` with the new attrs
shape. `body` becomes the caption (with paragraph-level token
processing for cite/math). Legacy `attrs.raw_tex` / `attrs.path`
paths still work.

### UI
The figure block toolbar mirrors the equation block toolbar shape:
- handle, kind tag, status pill, delete button
- New: upload button, attrs editor (width / placement / centering /
  label / alt) tucked into a collapsible "Layout" details element
- Image preview below the toolbar; caption contenteditable below the preview
- "Replace image" button next to the preview when one is loaded

`+ Figure` button added to `pe-add-block-row` gated on
`styleFor(section).allowFigures`.

## Verification

```bash
RM_WRITE_ALLOWLIST=mcgheealex@gmail.com python3 rm/server.py
# open http://localhost:8000/rm/pages/paper-builder.html
```

1. Create a new paper (any template), open the editor.
2. In a Methods/Results/Discussion section, click `+ Figure`. Block appears
   with empty preview slot.
3. Click "Upload image", pick a PNG/JPG. Verify the Storage console shows
   the object at `paper-figures/<paperId>/<hash>.<ext>` and the in-page
   preview renders.
4. Type a caption, expand "Layout", set width=`0.8\linewidth`,
   placement=`H`, label=`fig:test`, centering on.
5. Reload — figure persists, image renders from cached download_url, attrs
   intact.
6. Re-upload the same file — confirm `already_existed: true` in the toast
   (no duplicate Storage bytes billed).
7. Click "Export LaTeX". Verify the emitted .tex contains
   `\begin{figure}[H]\centering\includegraphics[width=0.8\linewidth]{...}\caption{...}\label{fig:test}\end{figure}`.
8. Hard reload the browser to evict `mcgheelab-shell-v75`; cache should
   bump to v76.
