# V3.582 — Import Slack Chat History into RM Chat

## Goal

Slack doesn't allow exporting DMs, so lab members copy-paste an entire Slack
conversation into a `.md`/`.txt` file. This feature lets a user open a
conversation in RM chat (a DM like Alex↔Gabriel, or a group channel like the
future "Tritip" group), pick/paste that file, map the detected Slack names to
lab members, preview, and import the whole history. Slack paste carries only
clock times (no dates), so original timestamps are dropped; order is
preserved; every imported message is marked as imported with the import date.
Once imported into a group channel, everyone who joins sees the history.

## Decisions (made with Alex)

- Imported block sorts **before** all existing messages (synthetic backdated
  `createdAt`, 1s apart) + a system divider message
  "History imported from Slack on <date>".
- Unmatched Slack names import **name-only** (`authorUid: null`, Slack
  display name kept).
- Permissions: any DM member can import into that DM; group channels require
  chat admin (or site admin).
- Undo supported: every import gets an `importBatchId`; a "Remove" action
  deletes the whole batch (importer + admins).

## Why a Cloud Function

`firestore.rules` hard-requires `authorUid == request.auth.uid` on
`chatMessages` create — no admin bypass (V3.512 lockdown, deliberate). So
importing Gabriel's messages must go through the Admin SDK:
`chatImportSlackHistory` (onRequest, Bearer ID-token, modeled on
`chatBackfillSubscribers`). No change to the `chatMessages` rules.

**Trigger guard is mandatory:** `onChatMessageCreate` sends an FCM push per
message (NOT gated on `fanout`). A 1,500-message import would push-bomb the
other DM member. Guard: `if (msg.imported) return;` before the channel
lookup. The importer also never touches
`chatChannels.lastMessage/lastActivityAt/messageCount`, so sidebar previews,
unread badges, and the corner alert stay silent.

## Timestamp synthesis

Query the channel's oldest message; anchor below it, spacing 1s
(`anchorMs - (N+1-i)*1000` for message i, divider at `anchorMs - 1000`).
Empty channel → floor at 2000-01-01 UTC. Distinct values are required
because the load-older pagination cursor is a bare Timestamp (ties drop
messages).

## Free win

`rm/js/chat.js` has rendered a dormant "from Slack" badge since the V3.52
port (`msg.importedFromSlack`, CSS `.chat-badge-imported`) with no writer
anywhere. Imported messages set that field and the badge lights up for free.

## Parser format (validated against `slack backup Alex McGhee and Gabriel.md`)

- Header line: `Name␣␣[H:MM AM/PM]` (name, ≥2 spaces, bracketed time, EOL)
- Bare `[H:MM AM/PM]` line = new message, same author (continuation)
- All other lines accumulate verbatim (attachment noise kept — no lossy
  filtering); trim leading/trailing blank lines per message; drop
  empty-after-trim
- Orphan leading body (file starts mid-message) → participant `(unknown)`
- Slack pseudo-authors (`A huddle happened`, `You missed a huddle`) default
  to "Don't import" in the mapping step
