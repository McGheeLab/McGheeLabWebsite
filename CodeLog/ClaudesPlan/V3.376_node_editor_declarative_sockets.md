# V3.376 — Node editor: declaration-driven sockets + "+" modifier menu

## Goal

User feedback: the node editor's bindings were undiscoverable ("I have no
idea how the binding can be made on a node, there's no option for that
anywhere") and sockets only appeared after you already dragged a wire.
Requirements: (R1) creating an input/constant shows an obvious connector
to drag; (R2) bindings are creatable directly on a node before any wire;
(R3) every variable has a LEFT dot to plug into; (R4) every variable has a
RIGHT dot to pass it through elsewhere; (R5) a "+" at the bottom offers
modifiers (like a binding) and wires them to the right feature; (R6) all
node options are visible in the node view.

Designed via a map→design-panel→judge workflow; implemented from the
synthesized spec, then adversarially reviewed.

## Design (engine-safe — no edge-schema change)

The entire fix is editor-side. The edge stays
`{id, from, to, sourceVar?, role?, paramField?}`; `compile()`,
`validateGraph()`, `inferScopes()`, and `paramOverrides` are untouched.
What changed is that sockets are now **declaration-derived** (from
`producedVars()` and a new `inputSlots()`), so they exist before and
after any wire, and the wire's `(role, paramField)` come from the exact
dot it lands on instead of a type-based guess.

**protocol-graph.js**
- `inputSlots(node)` (new, exported): the declared LEFT-dot slots —
  param slots from `paramTargets()` (input min/max/step/default,
  constant value, equation decimals) plus a dynamic `math` slot for
  equations and a dynamic `structural` slot for lists. choices/ordered
  have none.
- `newNode()` auto-seeds type default params (name/field + baseline
  numbers) **only when created with empty params**, so a new node's
  produced variable — and therefore its output dot — exists immediately
  (R1). Import / starter / tests pass explicit params and are untouched.
  Seeded names are id-suffixed to avoid symbol-table collisions.
- Constant-mirror output now honors `p.decimals` (was hardcoded 3).

**protocol-graph-editor.js** (`makeCard` rewrite)
- **Output rows**: one per produced variable — a LEFT in-dot, a
  category swatch + label, and a RIGHT out-dot (fan-out capable = R4).
  The constant's value row's left dot is an active `param:value` slot
  (the mirror); other output rows' left dots are disabled ghosts with an
  explanatory tooltip (visual R3 symmetry without offering an inert
  binding).
- **Setting rows**: each param slot (min/max/step/default, decimals)
  renders a LEFT param dot + an inline number field; a driven field
  disables and shows "↳ driven by X".
- **Operand rows** (equation) / **feed rows** (list): one per bound
  math/structural edge + a trailing OPEN dot that re-spawns after each
  connection (Blender join-geometry style).
- **"+" footer** (`_plusFooter`): a per-type menu whose items arm a
  specific declared dot for click-to-connect (e.g. "Drive max…",
  "Mirror value…", "Add math input…", "Accept a feed…"), add an
  option/member row, or delete the node — so a binding is an explicit
  action on the node with the target field chosen up front (R2/R5).
- **Config fields**: identity + type editors that aren't sockets (name,
  label, unit, formula, widget as a slider|number `<select>`, choices
  options as structured rows + `editable` checkbox, ordered members with
  min/max/step, list dedupe) — all inline (R6).

**Wiring** is bidirectional and deterministic. `onDotDown`/`onDotUp`
drive a module `wiring` state (`originEnd` out|in, plus armed for
click-to-connect). `completeWireAt` reads both endpoints and builds the
edge with no guessing: `from=out.nodeId, to=in.nodeId,
sourceVar=out.sourceVar, role=in.role, paramField=in.paramField`.
`addBinding` guards: self-wire, cycle (`wouldCycle`), categorical→numeric
-param hard refusal, a widened dup-guard
`{from,to,sourceVar,role,paramField}`, and single-arity param
replace-on-redrop. Releasing on empty canvas toasts "no target"; the
temp wire is `pointer-events:none`; the pan handler cancels an armed wire.

**Collapse** keeps every dot + row label visible (so wiring still works
collapsed) and hides only the fields, config, and "+" footer.

**Backward-compat**: no migration. Stored edges dock onto the declared
slot whose `(role, paramField)` they already name; legacy `none`/
unmatched edges render as generic removable rows. Verified the GELS demo
(param/math/structural edges) still compiles to the identical 30-row
list.
