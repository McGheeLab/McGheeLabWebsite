# V3.354 — CV live preview + templates + Word export (FuturePlan 11, Release 2)

**Goal:** the student always sees the document they're producing. One HTML
generator drives the editor's live preview, the print/PDF, the HTML file,
and a new Word export — so they can never disagree.

## What shipped

1. **Template system in `cv-export.js`** — `CVExport.TEMPLATES`:
   `serif` (Classic serif — the previous Georgia layout, still the
   default), `modern` (sans, accent-blue section heads), `compact`
   (Helvetica, tight spacing for long CVs). Shared structure in
   `BASE_CSS`; templates restate only type/color. `toHTML(doc, opts)` /
   `toMarkdown(doc, opts)` accept `opts.template`; back-compat: no opts
   ⇒ old behavior.
2. **Live preview pane in the editor** — "👁 Preview" toolbar toggle
   (persisted in `localStorage['cve-preview']`). Third grid column on wide
   screens (sticky, full-height iframe); stacks full-width ≤1150px.
   `refreshPreview()` (300ms debounce) sets `iframe.srcdoc =
   CVExport.toHTML(state.doc, exportOpts())` after every render and every
   successful save. Iframe (`sandbox="allow-same-origin"`) isolates the
   CV's print CSS from rm/css both ways.
3. **Template picker** in the preview header; choice persisted in
   `cv_meta.template` (new additive top-level object `cv_meta`, ensured by
   `normalizeDoc`).
4. **Word export** — `CVExport.downloadDoc()` wraps the same rendered HTML
   in a Word-HTML shell (`application/msword` blob; the
   grant-biosketch-export pattern). "⇩ Word (.doc)" joins the toolbar; all
   exports + print now pass `exportOpts()`.
5. `applyVariant(doc, variant)` plumbing added to the generator
   (hiddenSections/hiddenEntries filter) — driven by UI in V3.355.
   `downloadBlob` exported.
