# V3.521 — Chat: corner alert for new messages

**Alex request** (chat upgrade follow-up): an in-page corner popup when
a new message arrives, ignorable, click-to-open, and shown ONCE per
burst rather than once per message. Complements (not replaces) FCM push
— push covers closed tabs; this covers "chat is open but you're looking
at another channel/tab/view".

## Design

- **Zero extra Firestore reads** — driven by the existing `chatChannels`
  listener: `processChannelAlerts()` diffs each channel's
  `lastMessage.timestamp` against a per-channel baseline
  (`_lastMsgSeen`). The first snapshot only seeds baselines (no alerts
  on page load).
- **Alert filter**: skip own messages, muted channels, channels I'm not
  in (subscriptions / DM membership), and the channel whose LIVE feed is
  actually on screen (visible tab + active channel + chat view/tab +
  live feed mode).
- **Once per burst**: while the popup is visible, new channels are
  absorbed into it in place ("New messages in #general, Alex +1") — no
  stacking. After it hides (dismissed via ×, clicked, or 8s auto-fade),
  a 3-minute cooldown suppresses re-alerts so a busy conversation
  doesn't nag.
- **Click** → `selectChannel(mostRecentAlertingChannel)` — which lands
  on the newest message thanks to V3.518's open-at-bottom pinning.
- Bottom-right fixed card (`document.body`), slide-in transition,
  raised above the mobile bottom app bar (≤700px), safe-area aware.
  Removed + timers cleared in `destroy()`.

v1 scope: the chat page (including embed popouts / split-view panes,
which run chat.js). An RM-shell-wide listener for other pages is a
possible follow-up.

## Files

- `rm/js/chat.js` — `processChannelAlerts` / `showCornerAlert` /
  `hideCornerAlert`, hook in the channels snapshot, destroy() cleanup.
- `rm/css/chat.css` — `.chat-corner-alert*`.
- `sw.js` — CACHE_VERSION bump.

FTP-only.

## Verification

Two browsers: B posts in a channel A subscribes to while A views a
different channel → corner card slides in; a second message updates the
card (no second card); click → lands in that channel at the newest
message; × dismisses and no new card appears for ~3 min despite more
messages; messages in A's on-screen channel never trigger it; page load
with existing history never triggers it; muted channels stay silent.
Mobile: card sits above the bottom bar.
