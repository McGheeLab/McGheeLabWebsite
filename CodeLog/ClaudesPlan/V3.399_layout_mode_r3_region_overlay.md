# V3.399 — Layout Mode R3: color-coded region overlay + ⬒ Layout toggle

> Release 3 of the Layout Mode program (R1 = V3.395 foundation,
> R2 = V3.397 float engine). Read-only visualization: the page's layout
> REGIONS — Alex's core mental model for the feature — become visible.
> R4 makes them draggable.

## What shipped (rm/js/paper-doc-view.js + rm/css/paper-doc-view.css)

- **⬒ Layout toolbar button** (open to viewers — it writes nothing) →
  `_toggleLayoutViz()` flips `state.layoutViz` and `.pdv-regions-on` on
  `.pdv-scale`; button gets an active state.
- **`_buildRegionLayer(page, geom)`** — one `.pdv-regions` layer per
  sheet (absolute, inset 0, pointer-events none, z 5, `display:none`
  until toggled — mounted on EVERY render so toggling is pure CSS),
  drawn entirely from the R2 `page.rects`: margin frame (dashed gray),
  column guides (dashed blue), text region (neutral tint), footnote
  strip (amber), and one box per float area — **figures blue, tables
  purple** — carrying `data-block-id`.
- **Click-select**: with the overlay on, clicking a figure/table
  (delegated desk handler, before the popover branch, no editable gate)
  sets `state.layoutSelectedId` and rings its region boxes
  (`.pdv-region-selected` glow). Editors still fall through to the
  existing layout popover — selection is viz, the popover is the write
  path until R4's inspector.
- **Survives re-renders**: `_mountSheets` re-appends the layer per sheet
  and calls `_syncLayoutViz()` (class + selection re-applied after
  `scale.innerHTML` replacement).
- **Esc chain** extended: popover → citation panel → deselect region →
  layout off → close overlay.
