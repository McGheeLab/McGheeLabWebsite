# V4.51 — The tab pill centred on the tab

## Goal
Gabe (19 Nov 2026): "The tab pill is not centered on the tabs."

## What was wrong
Each tab's count (`span.tc`, empty unless Review has some) shares its class with the timer card (`20-canvas.css` `.tc{padding:4px 12px 10px}`). So every tab carried 24 px of empty room after its name. V4.46 made the pill the whole tab, so the pill ran about 12 px further right of the name than left of it. The test only checked that the name was inside the pill, not that it was centred.

## Approach
- **`10-base.css`:** `.tab .tc` takes `padding:0`, so the timer card's padding no longer reaches the tab row. With the look off too, the tabs lose that empty room and sit a little closer together.
- **`20d-look.js` `LOOK.tabPill()`:** the pill takes the tab's own top and height as well as its left and width, so the name sits in its middle both ways. With the look off, those inline sizes are let go and the underline is as before.
- **`36-look.css`:** the pill's base box (`top:1px;height:calc(100% - 4px)`) until the script places it.

## Files
- `scientia/src/10-base.css`
- `scientia/src/20d-look.js`
- `scientia/src/36-look.css`
