# V4.16 — Synthesis notes: one per series, their own place in the Portfolio, a note's synthesis in its first block

## Goal
Gabe: "Synthesis notes are for each experiment or experiment iteration batch (e.g., […] Run 2 and […] Run 3 link to the same Synthesis note. Synthesis notes live in their own category in the Portfolio in the same area as Notes and Lit Reviews, but above them." — and: "The synthesis component automatically created in a note is now attached to the initial note component, and appears as legend text underneath its note in the Portfolio view. This synthesis showing can be disabled in the Portfolio tab."

## Approach
A new module, `scientia/src/15e-syntheses.js` (`SYNN`), after the Portfolio's (15, 15d) and the Synthesis's (13zzr) code, wrapping them; nothing of theirs is rewritten.
- **One Synthesis per series** (series from V4.15: `series`, `run`):
  - `CHAIN.nextOf` is wrapped: a run's Analysis leads to the series' Synthesis (`SYNN.noteOf(series)`, the first made) when it has none of its own, so the bottom-right button says "Open Synthesis" and the stage is not made twice.
  - `CHAIN.advance` is wrapped: going there adds the run (its chain id) to the Synthesis's `synthRuns` and gathers it; the first Synthesis of a series made from a run is the series' own (`synthRuns` = that run), titled with the series' name ("… Run 2" → "…", `CHAIN.baseOf`). A lone experiment keeps its own Synthesis, as before.
  - `SYNTH.others` is wrapped: a series' Synthesis gathers from every run it covers (so ⟲ Gather, ☰ The rest and Flag for synthesis reach Run 3's notes).
  - "Notes to synthesize" (`WIDGETS.synthof.body`, wrapped) says which runs it covers and lists the other runs' notes ("Run 3"); each run's stage strip (`CHAIN.strip`, wrapped) ends in "Synthesis", leading there.
- **The Portfolio** (wrapping `PFLIST.split` / `counts` / `group` / `items` / `seg`):
  - `split` takes Synthesis notes out of the experiments' rows into `syns`;
  - each theme: Experiments | **Syntheses** above Notes — one column (`.pf-gcol`), so the two-column grid keeps Experiments beside them (`data-g="syn"`);
  - the switch gains **Syntheses** before Notes (`syn`, with its count), showing only them, theme by theme.
- **A note's synthesis** ("what this note adds up to", 12-doc `synthBox`): `DocView.synthBox` draws nothing on the paper; `DocView.headBox` gets the same box's contents as `.hsynth` at the bottom of the first block, so it moves with it (a drag on its header drags the block: it is not a `.box`). The lab's first block (V3.885) still adds its fields before `.hgrid`.
- **Under each note in the Portfolio** (`PFLIST.note`, wrapped): its synthesis as a muted line (`.pf-leg`, two lines at most). The Portfolio's own switch beside the type switch ("Syntheses under notes", `.pf-legtog`) and Settings both set `FEAT.tune('synthnotes', 'legend')`.
- **Settings → Features → Canvas & notes → Synthesis notes** (`synthnotes`, in Simple too): the switch (off: each run its own Synthesis, a Synthesis back in its experiment's row, the box floating on its own) and the setting for the lines under the notes; a live preview drawn as set.
- The Portfolio's switch now has five choices: in a narrow window it scrolls inside its row instead of widening the pane (`.pf-det .pf-ctl{min-width:0}`).
