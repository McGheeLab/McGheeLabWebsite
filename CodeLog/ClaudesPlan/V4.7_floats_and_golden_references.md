# V4.7 — Floats, and the golden reference tag

## Goal
Gabe (16 Nov 2026): a float is something that belongs to a note not made yet; /float brings a hemisphere dome of floats to drag into the current note; a placed float is assigned, no longer a float, and shows as a bridge from where it was written. On the prototype: not a kind but tracked like one; right-click, or the command on Ctrl-selected components; light purple / sky blue; a cloud; the dome flush with the canvas's bottom, blending into the note through a gradient of its palette, the glass clear and glistening; the reference tag golden.

## Approach
- `b.afloat = { at, t }` (marked), `b.afloat.to = { docId, blockId, at }` (placed). Not `b.float` (CLIP.lift). Like V4.5's references: a flag beside the kind.
- `14h-floats.js` wraps `DocView.box` (cloud + "afloat", "assigned float"; a placed float's bridge band "Float · from … · date" and *Back to the floats*), `DocView.boxMenu` (Make it a float / No longer a float / Make them floats (n) / Back to the floats), `INK.paintSel` (Make floats on the selection's bar), and adds the `/float` command (selected → mark; none → the dome).
- The dome is an overlay in the note's canvas element (`pane.paper.el`): a half disc on its bottom edge (base = edge), a skirt of the note's paper fading up, the glass clear (rim gradient, a fine edge, `BUBBLE.warp(D)` as a backdrop filter where supported, two highlights, a slow sheen). Beads on a hemisphere (golden-angle azimuths, elevation by age, oldest lowest), projected with depth for size and order; a rAF loop turns it only while open, not under reduced motion, never while the pointer is inside or dragging; the bead under the pointer by geometry with hysteresis (as V4.0's Atlas). Rest (setting) or click → preview; drag → `BRIDGE.make(…, { quiet })` at `paper.toWorld(drop)`, `asFloat`; one Undo (`DB.beginGroup('float')`).
- API for the Monthly review (V4.8): `FLOATS.isFloat / waiting / placed / mark / unmark / place / back / open / close / old`.
- Settings → Features → Floats: switch + spin, by, old, rest, place; preview = a mini canvas and dome.
- Golden reference tag: `--gold-grad` on the card's bookmark, the gallery cards' corner, the kindless "Reference" chip and the Atlas's References tab (`data-t` on its tab buttons).
