# V4.94 — a few more settings for numbers the code had hard-coded

## Why
Gabe (20 Nov 2026), after asking for a few settings (edge-pan sensitivity in full screen, pill orientation, customisable keys): "Search for other features like these that could get some easy customization, but currently do not or have very simple customization."

So: an audit of `20a-features.js` (every `D({...})` and the code each feature guards) for hard-coded delays, sizes, counts, thresholds and defaults a person would reasonably want to change, and the best of them built. Each tune is read where the old number was, with the old number as its default, so nothing changes until someone tunes it; each feature's preview follows it.

## What changed
Nine features gained tunes (two of them, Moving around the paper and the Today page, and a third, Messages, are new always-on entries because the code had no feature to hang the numbers on):

| Feature | Tune (default = as before) | Where it is read |

Previews: Hover cards' preview is now interactive (rest on the marked words, the card shows after the chosen wait); Moving around the paper's preview is a real `Paper` (zoom it, drag the box, flick it); Messages' preview has a draining bar over the real time and a button that raises a real message; Focus shows the length chips with the chosen one on; the Today page shows the three lists (and the heatmap's legend in hours); Reminders and Resurfaced claims state and draw their values.

One line in `Paper`'s wheel handler: a paper inside a scrolling page (the Settings preview) may now take the wheel when it is made with `anyWheel: true`; nothing else passes it, so every note keeps scrolling as before.
