# V3.358 — CV lab-overview drill-in + keyboard polish (FuturePlan 11, Release 6)

**Goal:** make the admin Lab Overview actionable, and give power users
keyboard flow in the editor.

## What shipped

1. **Lab Overview drill-in** (`rm/js/cv-overview.js`, admin-only page) —
   member names in the table become links; clicking opens an overlay with
   that member's **rendered read-only CV** (`CVExport.toHTML` in a
   sandboxed iframe — `cv-export.js` added to the lab tab's script list),
   their staleness chip, and a **📧 Nudge** mailto (prefilled CV-refresh
   reminder linking to the editor) — the staleness table now ends in an
   action instead of a dead end. `_cvMap`/`_userMap` retained at module
   scope for the drill-in.
2. **Keyboard shortcuts** in the editor (suppressed while typing in any
   form control; modal-open handled):
   - `n` — new entry in the current section
   - `[` / `]` — previous / next section (cycles the sidebar order)
   - `p` — toggle live preview
   - `Esc` — close the entry modal (via the guarded Cancel path)
   - `?` — TOAST listing the shortcuts

## Files

`rm/js/cv-overview.js`, `rm/js/cv-editor.js`, `rm/pages/cv-editor.html`
(lab-tab script list). FTP-only deploy.
