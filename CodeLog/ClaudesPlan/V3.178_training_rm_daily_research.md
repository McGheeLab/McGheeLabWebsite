# V3.178 — Training: Daily Research Workflow in RM

> Status: **BUILT (2026-05-12).** See [rm/pages/training-rm-daily-research.html](../../rm/pages/training-rm-daily-research.html)
> and [rm/js/training-rm-daily-research.js](../../rm/js/training-rm-daily-research.js).
> Module flipped to `available: true` in [rm/js/training.js](../../rm/js/training.js).

## Goal

The four pages an active researcher uses every working day: activity
tracker, lab notebook, library, protocols. By the end the student can
confidently capture a day's research output into RM in a way that flows
correctly into their next PMR.

## Format

Lecture-style with three light-interactive widgets:

1. **The "Lab Research" workflow walkthrough** — interactive flowchart
   showing how the 5 default workflow pages (activity-tracker → library
   → projects → tasks → lab-notebook → protocols) connect to one
   another. Click each node to read what to do on that page.
2. **Tracker entry confirmer** — simulated pending tracker entry. The
   user fills in hours, confirms or dismisses, and sees the result
   propagate to the (mocked) PMR Activity block.
3. **Lab-notebook entry simulator** — a stripped-down entry form (title
   + date + attachments + PMR-flag toggle on a sample image) that walks
   through the V3.161 PMR-figure-review flow.

## Sections (8)

1. The "Lab Research" daily workflow (5 default-workflow pages).
2. Activity tracker — the auto-pending-entry model, confirmation flow,
   the Coming-up lane.
3. Lab notebook — entries, attachments, the PMR 📌 flag.
4. Library — adding papers, the annotation surface, comments.
5. Protocols — running formula-based protocols, version history.
6. How these four pages talk to each other.
7. How they talk to PMR.
8. Capstone — recover a day's research into RM and verify it shows up
   in your next PMR.
