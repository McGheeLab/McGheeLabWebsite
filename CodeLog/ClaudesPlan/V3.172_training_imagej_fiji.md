# V3.172 — Training: ImageJ / Fiji Deep Dive (full confocal workflow)

> Status: PLANNED — not yet built.

## Goal

A self-contained, **workflow-first** training on processing confocal
data in ImageJ / Fiji — for students who don't want to use the lab's
custom Python software (Cell Tracker, SpheroidSizes, etc.). After this
training, a student can take a raw ND2 / TIFF confocal acquisition,
process it end-to-end in Fiji, and produce publication-quality figures
+ quantification CSVs without leaving the application.

This training is the open-source counterpart to V3.171 (Cell Tracker).
Both produce equivalent end-products (segmented + tracked + quantified
cells); the choice is preference, license, and integration with other
tools.

## Relationship to V3.168 / V3.169 / V3.170

V3.168 / V3.169 / V3.170 (image-analysis basic / intermediate /
advanced) are **concept-focused** — they teach principles (LUTs vs.
data, Otsu thresholding, watershed, deconvolution) using Fiji as one
example tool. This module is **workflow-focused** — given the lab's
typical confocal experiment, here's the exact step-by-step Fiji
pipeline. Expect overlap; cross-link rather than duplicate.

## Format

Full interactive notebook (MODULE_TEMPLATE.md pattern), but heavier on
recipe blocks (literal menu paths + Fiji macro snippets) than the
other interactive modules. 7 tabs.

## Prerequisites

- V3.164 microscope basics
- V3.166 confocal (so the student understands what each acquisition
  parameter means before they post-process)
- V3.168 image-analysis basic (pixels, LUTs, ROI mechanics — this

## Tabs

### Tab 1 — Installation + Bio-Formats import
**Bio context:** opening an AX-R ND2 file with 4 channels + 25 Z-slices
+ 30 timepoints.

- Background: Fiji = ImageJ + Bio-Formats + a curated plugin set; why
  the lab uses Fiji and not vanilla ImageJ
- Install: download from fiji.sc; first-launch update; how to install
  additional update sites (BioVoxxel, CSBDeep, MorphoLibJ — the lab's
  standard kit)
- Bio-Formats import: `Plugins → Bio-Formats → Bio-Formats Importer`;
  the importer dialog (split channels, virtual stack, autoscale, color
  mode); when to use virtual stacks for large files
- Worked example: importing an AX-R 4-channel + Z + T ND2 with split
  channels into a hyperstack

### Tab 2 — Channels, LUTs, and figure-ready merges
- Background: `Image → Color → Channels Tool` for per-channel LUT +
  display range; the **Apply LUT** trap (irreversibly changes data —
  almost always wrong); composite vs. color mode
- The lab's figure conventions (matches V3.168):
  DAPI cyan / cytoplasm green / target magenta / second target far-red
- ROI Manager workflow: `Analyze → Tools → ROI Manager`, mass-add,
  multi-measure, save ROIs as `.zip`
- Interactive: simulated channels tool; drag display ranges and watch
  the histogram clip indicator
- Worked example: building a 3-channel merge with a scale bar
  (`Analyze → Tools → Scale Bar`) ready for a figure panel

### Tab 3 — Preprocessing: background, denoise, flat-field
- Background: rolling-ball (`Process → Subtract Background`); top-hat
  morphological filter (BioVoxxel); paired flat-field correction with
  `BaSiC` plugin for tile-scan illumination correction
- Denoise: 2D / 3D median; Non-Local Means (DenoisE plugin); when each
  is appropriate
- Worked example: a 5-tile spheroid scan with visible illumination
  drop at the edges → BaSiC flat-field → seamless mosaic

### Tab 4 — Segmentation: thresholding, StarDist plugin, Cellpose plugin
- Classical: `Image → Adjust → Threshold` → Otsu / Triangle / Li;
  binary cleanup with `Process → Binary → Open / Close / Fill Holes`
- Watershed: `Process → Binary → Watershed` for touching objects;
  failure modes (over-segmentation rim)
- ML plugins:
  - **StarDist** (`Plugins → StarDist → StarDist 2D`) — for star-convex
    objects like nuclei; lab uses the `2D_versatile_fluo` model
  - **Cellpose** (`Plugins → Cellpose → Cellpose Advanced`) — for whole
    cells; runs the Python Cellpose under the hood via PythonRunner
- Comparison panel: the same field segmented three ways with
  precision / recall / IoU

### Tab 5 — Quantification: per-object + intensity measurements
- `Analyze → Set Measurements...` (what to actually measure: Mean,
  Median, Area, Centroid, Min&Max, Integrated Density)
- `Analyze → Analyze Particles` for binary masks → labelled outputs +
  Results table
- Multi-channel intensity per object: `Image → Stacks → Plot Z-axis
  Profile` for a stack; the ROI Manager `Multi Measure` for per-frame
  measurements
- Background correction: paired ROI in an empty region; the constant
  offset trap

### Tab 6 — Tracking: TrackMate end-to-end
- Background: TrackMate is Fiji's flagship tracking plugin
  (`Plugins → Tracking → TrackMate`); supports many detectors
  (LoG, DoG, Hessian, StarDist, Cellpose, etc.) and the LAP linker
- Walk-through of the TrackMate wizard step-by-step
- Inspecting / editing tracks: TrackScheme view; manual edits;
  filtering by track quality, duration, displacement
- Export: `Tracks statistics`, `Spots in tracks statistics` → CSV;
  saving the TrackMate XML for reproducibility
- Worked example: a 30-frame migration assay analysis end-to-end

### Tab 7 — Macros + batch: scripting the workflow
- Why macro: doing this once is fine; doing this 96 times by hand is a
  reproducibility disaster
- The Macro Recorder (`Plugins → Macros → Record...`)
- Macro syntax basics: variables, `for` loops, conditionals, `getResult`
- Batch mode header (`setBatchMode(true)`) for 10-100× speedups
- A full template macro provided: open folder → for each file →
  bio-formats import → background subtract → segment → quantify → save
  CSV
- **Capstone:** student adapts the template to a provided 12-file dataset
  and runs it end-to-end. The page validates the outputs against
  reference numbers.
