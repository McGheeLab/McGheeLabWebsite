# V3.343 — Embedded-file journal templates (Nature, Science, PLOS, ACS)

**Part of:** [FuturePlan 07 — Paper builder upgrade](../Feature%20requests/FuturePlan_07_paper_builder_upgrade.md) (Release 3 of 7).

## Goal

Complete the journal target set with the four remaining high-value
venues. The V3.341 schema v2 already supports everything needed; this
release is data (four template JSONs) plus one picker registration, with
the journal-specific `.bst`/`.sty` files that TeXLive lacks embedded in
the templates' `extra_files`.

## Tectonic bundle coverage (probed, not assumed)

Compiled a minimal document against each journal's bibliography style
with local Tectonic:

- **Nature** (`naturemag.bst`) — in the bundle. No embed.
- **ACS** (`achemso` class + `achemso.bst`) — in the bundle. No embed.
- **Science** (`scicite.sty`, `Science.bst`) — **not** in the bundle.
- **PLOS** (`plos2015.bst`) — **not** in the bundle.

## Sourced files (embedded via `extra_files`)

Fetched from canonical public repositories, licenses preserved in the
file headers and recorded in each template's `_license` field:

- `scicite.sty` — a modified `cite.sty`, © 1989-2003 Donald Arseneau,
  freely transmittable per its own notice.
- `Science.bst` — the AAAS `scifile` bibliography style, distributed for
  author use.
- `plos2015.bst` — © 2004 Folkert van der Beek, LaTeX Project Public
  License v1.3+.

The V3.341 compile service already writes every bundle file (including
`extra_files`) into the workdir before running Tectonic, so no service
change is needed — the embedded style files compile as local resources.

## Templates shipped

`rm/data/paper-templates/{nature,science,plos,acs}.json`:

- **nature** — `article` 12pt double-spaced, `naturemag.bst`, superscript
  numeric cites, unnumbered sections, defaults line-numbers + double
  spacing; limits abstract 200 / body 4500 / refs 50 / figs 8.
- **science** — `article` 12pt double-spaced, `scicite` + `Science.bst`
  (embedded), Science-style numeric cites, unnumbered sections; abstract
  limit 125.
- **plos** — `article` 10pt, `plos2015.bst` (embedded), numeric-bracket
  cites, unnumbered bold headings, line-numbers default.
- **acs** — `achemso` (JACS defaults), class-managed superscript cites,
  achemso author block via the `{{AUTHOR_BLOCK}}` placeholder + abstract
  environment; `chemformula` in the preamble for `\ch{}`.

Registered in `KNOWN_TEMPLATES` (`rm/js/paper-export-config.js`) under
the "Publishers" group.

## Verification

Extended the headless harness to all nine templates and **compiled each
to a non-empty PDF with local Tectonic**, including the two embedded-file
templates (Science pulls in `scicite.sty` + `Science.bst`; PLOS pulls in
`plos2015.bst` straight from the bundle files) and ACS with its author
block + abstract placeholder. Per-template assertions (cite command,
figure-ref prefix, table-caption citation collection, frontmatter
placeholder routing) pass for all nine.

## Not in this release

Editor-side citation-style rendering (chips as superscript / [1] /
(Author, 2024)) — Release 4. Footnotes + authors panel — Releases 5-6.
Cloud Run figure-fetch stub — Release 7. Nature/Science/PLOS at
acceptance may require the publisher's own document class; these
templates target the *submission* stage, which reviewers accept as
standard `article`-class manuscripts.
