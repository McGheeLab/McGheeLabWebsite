# V4.87 — Scientia: the Data compendium reworked — instruments, experiments' data by itself, Add to a note…, Material → instrument → data

## Why
Gabe, 20 Nov: "Data tab rework for input of instruments related to data and way to visualize material to instrument/data. Make sure that the data present in experiment note canvases is automatically added and tied to the note component, and can be added from the data tree compendium/gallery in Atlas." (The Atlas's Data is the Data compendium since V4.85.)

## What changed (`14ff-dataflow.js`, `DFLOW`; `46-dataflow.css`)
- **Instruments on data.** A data tree (13zzyc) says which instrument made it. An instrument is a material of kind "instrument" (13j), so it has its page, lot and location like the others.
  - A bar under the tree's head shows the instrument's chip (a click opens its page, × takes it off), Change…, or ＋ Instrument: your instruments, a search, or a new one by name (`DFLOW.pick`, `newInst`).
  - **A guess from the files' types** (`DFLOW.guess`, `DATA.INSTR`: .nd2 → Nikon (ND2), .czi → Zeiss (CZI)…): "Looks like Nikon (ND2) — use it", one click.
  - Kept on the tree as `b.dtree.inst = [resource ids]`. An instrument bound to the component (⋯ → Data, materials & code) counts too.
- **An experiment's data joins by itself** (`DFLOW.auto`, `autoComps`; `ADATA.comps` wrapped; the new `ADATA.items` hook in 14fc).
  - In experiment notes, an image panel's images, a table (and the file it came from) and the datasets bound to a component appear in the Data compendium under their note. Each is tied to its component (Open goes to it) and marked "from the canvas".
  - Nothing is copied: they are read from the components each time.
- **Add to a note…** on a note's or a component's row: the move panel (V4.72) picks a note, and the data component goes there as a live reference (`M.pullInto`); the original stays where it is.
  - A note with several data components has the chips and buttons on each component's row, not on the note's.
- **Material → instrument → data**, the Data compendium's third view (`DFLOW.graph`, `flow`): three columns — the materials listed on the notes (or bound to the components) that have data, the instruments, and the data.
  - Curves join them: material → instrument → data, or material → data when no instrument is set.
  - Resting on a node lights its paths upstream and downstream. A click opens it: a material's or instrument's page, or a data component in its note.
- **Settings → Tabs & overview → Data: instruments and flow** (`dataflow`, needs the Data compendium):
  - *Experiments' image panels, tables and datasets join by themselves*, and *Suggest the instrument from the files' types*;
  - a live preview.
  - Off: the bar, the experiments' entries, Add to a note… and the third view go; instruments already chosen stay on their trees.
