> Release 5 of 8. Constraint-based precision (Alex's choice — no absolute

## In-band reorder + pairing (paper-doc-view.js)

- **New drop-target kind `band-slot`** in `_resolveDropTarget`, tested
  BEFORE the strip checks (a band can be taller than STRIP=64; the slot
  is the more specific target): dropping a dragged float onto another
  float's `.pdv-float-slot[data-block-id]` resolves
  `{kind:'band-slot', beforeFloatBlockId, after (pointer half), region
  (from the slot's band), pageIdx}`.
- **`_commitDrop` branch:** adopt the target's band (`{anchor: region}`
  transact) + `moveBlockToPosition` to the target float's live index
  (+1 when `after`) — same index semantics as flow drops, cross-section
  supported.
- **Pairing = source-order adjacency, PERIOD.** The packer's greedy join
  pairs adjacent column floats, and LaTeX places floats in source order
  — reorder is the only portable lever. NO pair_break attr (it would be
  preview-only = dishonest). The drop chip says so: "adjacent floats
  pair up". `_paintDropTarget` paints `.pdv-drop-before` /
  NEW `.pdv-drop-after` accents on the slot.

## Equation span control

- **Attr `span`** on equation blocks ('column' | 'page'); absent =
  legacy = column-bound = byte-identical. Factories (`addEquation` +
  `insertBlockAt`) seed 'column' on NEW blocks only (normalizeTree
  untouched).
- **Export (paper-export-tex.js):** `equationToTex` — span='page' AND
  the template compiles two-column (`compiled_columns === 2`: ieee, and
  PNAS after R7) wraps the display equation (numbered or `\[..\]`) in
  **cuted's `\begin{strip}`**, the only portable spanning-math
  primitive; sets the per-run `_usedCuted` flag → buildBundle appends
  `\usepackage{cuted}` to the preamble ON DEMAND (after section
  rendering, before the `{{PREAMBLE}}` substitution — untouched papers
  byte-identical). One-column classes: emission unchanged (span moot).
  Submission target pushes an advisory ("strip lands where the column
  ends — the journal may reposition"); preprint silent.
- **Preview:** span='page' display equation in a 2-col geometry becomes
  a `'full'` flow item (the title/abstract path — breaks the column run
  and spans the text region); stamps `data-span`.
- **UI:** clicking a display equation (editable users) opens a minimal
  **Equation layout popover** (Span only — reuses the `.pdv-fig-pop`
  shell + `state.popEl` lifecycle, so Esc / outside-click / re-anchor
  across re-renders all behave like the figure popover; `_mountSheets`
  re-anchor extended to `.pdv-eq`). Write origin `eq-span` (added to
  LAYOUT_ORIGINS).
