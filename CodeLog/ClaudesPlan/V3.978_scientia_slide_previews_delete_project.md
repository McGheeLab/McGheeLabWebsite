# V3.978 — Scientia: slide previews and deleting versions; deleting a project; a theme's page as activity

Gabe, 11 Nov 2026: "The slide deck format of the iteration should have a preview in the slides to the left. Versions can be
deleted from an iteration panel. … You should be able to delete a project on the project main page. Project health based on
activity should apply to the internal look of themes as well."

## Approach
1. **Previews** (`13zzq-deck.js`): the versions not on screen are already drawn (hidden, `deck-hid`), so a slide shows a copy of
   its version's own box, scaled — the real look without drawing anything twice. The copy must do nothing: no `data-id` (the app
   finds boxes by it), inert, not editable. Text is laid out at 240 px before scaling so its words are larger.
2. **Delete a version** (`IDECK.drop`): close the line up rather than leave a gap: the next improves on the one before, the second
   becomes the first, numbers again, one left is a component. One undo step. No question asked (Gabe, V3.943: deletes happen at
   once; Ctrl+Z is the way back); the palm guard of V3.977 on ×.
3. **Delete a project** (`13p-edit.js`, `15-portfolio.js`): keep the notes (outside any project) or delete them; themes and aims
   go; one undo step; a backup first with a notebook folder. Not for projects the lab assigns (RM) or that others own; a shared
   project is unshared first, since the hub's handling of a deleted shared project is the lab's to decide.
4. **A theme's page** (`15-portfolio.js`, `15d-pfkit.js`): the same activity as the portfolio — tile, map, each note's.
