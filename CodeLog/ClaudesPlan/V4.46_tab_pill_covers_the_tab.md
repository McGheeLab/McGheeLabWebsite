# V4.46 — The tab pill covers the whole tab, every time

## Goal
Gabe (19 Nov 2026): "Add the gliding tab pill and make sure it covers the entire tab name everytime."

## What was wrong
V4.42 turned the tab underline (`.tink`) into a pill, but kept 11's sizing: `renderTabs` sets it to the width of the name (`.tlab`), at the name's left, and only on navigation. So the pill:
- hugged the letters, with no room around a name that turns bold when it is on;
- left a tab's count (Review 2) outside;
- stayed where it was when a tab changed size without navigating: a font arriving, a count appearing, the window narrowing.

## Approach (look on)
- **`LOOK.tabPill()` (`20d-look.js`)** sizes the pill to the whole tab, its padding, name and count (`on.offsetWidth`, at `on.offsetLeft`). It runs:
  - after every `App.renderTabs`, in the frame after 11's own placement;
  - whenever a tab or the bar changes size (a `ResizeObserver` on the tabs and the bar);
  - when the fonts are ready;
  - on Look and motion's switch.
- **It glides** with the existing transition (`transform` and `width`, the look's curve). Still and reduced motion make it jump.
- **An empty count** gives back its 4 px gap (`margin-left:-4px`), so the name sits in the middle of the pill. The span stays, so the header keeps its height and the Portfolio below is unchanged.
- **Off:** 11's underline under the name, as before. Turning the switch off calls `App.renderTabs()` again.
- **Settings → Look and motion:** the description says so.
