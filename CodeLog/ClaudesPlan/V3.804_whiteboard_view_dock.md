# V3.804 — Whiteboard view dock: zoom + / − / home and "Page + ¼"

**Asked (Alex, 2026-10-07):** "when I do lectures, I often zoom into the white board. I need a
quick settings for zoom for +, -, home. I also want a quick setting for show full new page + 1/4
of the previous page."

## Goal

One tap, without leaving the pen, for the views a lecture actually uses:

| Button | What it does |
|---|---|
| **+** / **−** | zoom the viewer-local lens in / out by 1.25× about the middle of the stage |
| **%** | current zoom (read-out) |
| **⌂** | back to 100% (the whole 1.5-page frame) |
| **Page + ¼** (drawers only) | frame the whole current page with the **last quarter of the page above** it; tap again → the next page framed the same way; on the last page, the tap adds a page first |

## Decisions

1. **A floating dock in the board's top-left corner** (`.wb-viewdock` inside `.wb-board`), not
   the toolbar: always on screen (the toolbar wraps on an iPad and is hidden for viewers), sits
   in the desk margin beside the page at 100%, and the top-left is the corner a writing palm is
   least likely to rest on. Page route only (`chrome:'full'`, lens enabled, never the projector);
   the module panel keeps its existing topbar zoom. Pointer events stop at the dock so a finger on
   a button is never read as a scroll/pinch; `touch-action: manipulation` stops iOS double-tap zoom.
2. **Page + ¼ = scroll + lens together.** Sheet `originY = pageTop(k) − ¼·BOARD_H`, lens scale
   `min(stageH / (1¼ page heights), stageW / page width)` (1.2× on every landscape screen, which
   shows 1½ page heights at 100%), centred horizontally, `ty` placing the quarter at the top. The
   clamp already allows exactly this frame for the first and the last page. One combined tween.
3. **Which page:** the page under the middle of what is visible (lens included). If the view is
   still exactly the frame the last tap produced, the tap advances to the next page (appending one —
   no view jump for anyone else — when it was the last). No hidden mode: any scroll/zoom in
   between makes the next tap re-frame the current page instead.
4. **The room.** The lens stays viewer-local (unchanged). The sheet scroll is shared as usual:
   continuous mode publishes `viewY` (= page k's centre, so followers see ¼ above, the page, ¼
   below — a superset of the drawer's frame); pages mode publishes `activePageId`. A follower
   device using the button pauses following, like any manual move.
5. **Zoomed scrolling (continuous mode):** a pan that runs past the edge of the magnified stage
   spills the remainder into a sheet scroll (two-finger drag, one-finger viewer pan, wheel), so a
   zoomed lecture can keep moving down the sheet. Pages mode unchanged.
