# V3.505 — Chat: incremental rendering foundation

**Release 1 of 7** in the chat upgrade program (foundation/security,
typing+presence, search+history, UX polish — approved plan in
`~/.claude/plans/the-chat-page-needs-squishy-cat.md`).

## Goal

Kill the whole-app `innerHTML` rebuild + ~40-loop re-wiring cascade in
`rm/js/chat.js` without changing any visible behavior, so later releases
(presence dots, typing row, history mode) can update regions in place.

## Problem

`render()` rebuilt `appEl.innerHTML` wholesale and `wireAll()` re-attached
every handler via `querySelectorAll` loops on nearly every state change
(modal open, tab switch, thread open/close…). Side effects: composer text
lost on any full render, thread open/close needed feed-scroll save/restore
hacks, rotating a phone across the 700px breakpoint left a stale layout.

## Approach

1. **One delegated click listener** on `#chat-root` with an ordered
   `CLICK_ROUTES` table (`[selector, handler]`, first `closest()` match
   wins). Specific/inner elements rank above containers (reactions above
   `[data-msg-select]`, modal buttons above `[data-close-modal]`).
   - The modals' inline `onclick="event.stopPropagation()"` (7 sites) had
     to go — it would have swallowed bubbling clicks before they reached
     the delegate. Backdrop-close is now guarded in the
     `[data-close-modal]` route: overlays only close when the click is
     NOT inside `.chat-modal`.
   - Delegation also fixes two latent bugs for free: dynamically added
     settings rows' remove buttons now work without manual re-wiring, and
     search-result clicks survive result-list rebuilds.
2. **`renderShell()`** mounts a stable skeleton once per layout mode:
   desktop `#chat-sidebar` | `#chat-header-slot` / `#chat-view-tabs-slot`
   / `#chat-content-slot` | `#chat-thread-slot` + `#chat-modal-root`;
   mobile topbar/tabbar/`#chat-mobile-content`/bottombar/hamburger slots.
   Slot wrappers use `.chat-slot { display: contents }` so the CSS layout
   tree is byte-identical to the pre-shell markup.
3. **`render()` is now an orchestrator** calling region updaters:
   `renderSidebar`, `updateHeader`, `updateViewTabs`, `updateMainContent`
   (keyed on `view:channelId` — same key refreshes messages/input in
   place, keeping scroll + composer focus), `updateThread`,
   `updateModals`; mobile: `updateMobileTopBar/TabBar/Content/BottomBar`,
   `updateHamburger`. All ~60 existing `render()` call sites work
   unchanged.
4. **Non-click wiring stays region-scoped**: `wireInput` (composer),
   `wireThreadInput`, `wireSidebarNonClick` (drag-drop + contenteditable
   group names), `wireModalsNonClick` (search filters, role selects,
   contact drag-drop), `wireFeedScroll`, `wireFileDrop`.
5. **Behavior upgrades that fall out of the design** (all strictly
   better, none regressions):
   - Composer text + focus + caret survive any `render()` (previously
     lost on modal open etc.).
   - Thread open/close is a targeted `#chat-thread-slot` update on
     desktop — the feed DOM is untouched, so the old scroll save/restore
     hacks are deleted.
   - A debounced `resize` listener rebuilds the shell when crossing
     700px (rotate no longer leaves a stale layout).
   - Read-only / announcement-locked input areas now carry
     `id="chat-input-area"` so in-place refresh can swap them back to a
     live composer when the state flips.
6. Copy fix: `Uploading to Google Drive...` → `Uploading…` (uploads have
   been Firebase Storage since V3.52).

## Not in this release

Zero Firestore/rules/functions changes. FTP-only deploy. Server-side
fan-out + destroy() lifecycle is next (V3.5xx R2).

## Verification

Manual matrix, zero intended visual diffs: desktop 3-pane (messages /
pinned / files tabs, thread open/close preserves feed scroll, modals,
settings add/remove category, contacts drag), mobile ≤700px (4 tabs +
swipe, overview collapse, hamburger), embed popout (`?embed=1` — no
top/bottom bars, lands on chat tab), composer (send, @mention popup,
paste-image, drag-drop file, drafts restore per channel), reactions +
emoji picker, edit/delete own message, rotate across 700px.
