# V3.569 — Lab Chat UX for the Ourlab app

> Alex feedback (2026-07-26): the chat page needs a top nav for the chat
> section, drop the bottom cross-app links, give a proper docked input
> surface, kill the iOS keyboard accessory bar, make emoji + text-format
> fold-up surfaces, and fix the buggy search. All web-repo, app-gated
> (`body.ourlab-app` / `isOurlabApp()`); desktop chat is untouched. Plus
> one mobile-repo plugin (@capacitor/keyboard).

## Changes — `rm/css/chat.css` (app-gated) + `rm/js/chat.js`

1. **Top nav for the chat section.** chat.js's legacy full-screen mobile
   chrome (`.mobile-top-bar` / `.mobile-bottom-bar`) has NO stylesheet on
   this page, so it rendered as raw stacked links. In the app we hide it
   (and the generic RM `.top-nav` + `.page-header`, which is safe because
   chat.css only loads on the chat page) and pin the chat-section tab bar
   (Overview · Chat · Files · Search) as a fixed top bar below the status
   bar (`padding-top: env(safe-area-inset-top)` as a longhand — env() in
   the `padding` shorthand mis-parses in WebKit).
2. **Bottom cross-app links removed** — `.mobile-bottom-bar`
   (Chat/Meetings/Equipment/Activity/Huddle → dead `../x/index.html`
   paths) is `display:none` in the app; the app tab bar already navigates.
3. **Docked input surface.** The composer (`.chat-input-area`, already
   fixed `bottom:0`) was hidden behind the app tab bar (z-index 9000). In
   the app it's lifted to `bottom: calc(52px + safe-area)` (z-index 40)
   with the message list padded to clear it. It already carries the
   standard options (message field, Aa, emoji, 📎 attach + file input,
   send, mention popup, formatting).
4. **Emoji → fold-up sheet.** The `#chat-composer-emoji` handler, in the
   app, opens `APP_SHEET` with an 8-col `EMOJI_SET` grid; picks insert at
   the cursor without stealing focus (sheet stays open). New helpers
   `insertIntoComposer`, `openComposerEmojiSheet`.
5. **Text format (Aa) → fold-up sheet.** `#chat-md-hint-toggle`, in the
   app, opens `APP_SHEET` with Bold / Italic / Strikethrough / Inline
   code / Code block / Mention / Notify-channel, each wrapping the
   selection or inserting (`wrapComposerSelection`, `openComposerFormatSheet`).
   (Desktop keeps the inline `Aa` hint toggle.)
6. **Search fixed.** The mobile Search tab rendered only a placeholder
   ("Use the search modal…") while a separate `position:fixed` modal
   popped — mispositioned behind the app's fixed top bar. Now the Search
   **tab** renders the search UI inline (same `#chat-search-input` /
   `-status` / `-results` ids the search logic binds), and the modal is
   gated to `!isMobile()`. Mobile search-open buttons switch to the tab.
7. **iOS keyboard accessory bar hidden** — `mobile-shell.js` calls
   `Capacitor.Plugins.Keyboard.setAccessoryBarVisible({isVisible:false})`
   (the ⌃⌄✓ toolbar); we provide composer controls instead.

## Verified (iOS Simulator)

Top nav pinned below the Dynamic Island; bottom links gone; composer
docked above the app tab bar with attach/emoji/Aa/send; the Format
fold-up sheet (Bold…@channel); the Search tab inline (input + scope, no
modal). Emoji sheet shares the verified `APP_SHEET` path.

## Rollback

Web changes are app-gated and revert cleanly; the keyboard plugin is
additive (guarded call). No Firestore/rules/functions change.
