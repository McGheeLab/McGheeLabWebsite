# V3.115 — Tabbed right pane + Figures tab (with subfigures)

## Goal

Refactor V3.109's standalone `📐 Equations` slide-out pane into a
unified four-tab pane (📐 Equations / 🖼 Figures / 📋 Tables / 📚
References) and ship the **Figures** tab with subfigure-aware
references. Tables and References tabs land as placeholder empty
states in this version; filled in V3.114 / V3.115.

This is the first of three sequential versions tracked in
`/Users/alexmcghee/.claude/plans/we-need-to-make-expressive-turing.md`.

## Approach

### Tabbed pane refactor
- `.pe-equations-pane` becomes `.pe-tabbed-pane` with a `.pe-tab-nav`
  row of four tab buttons. Active tab persists in
  `localStorage.rm_paper_active_tab`.
- Topbar button becomes `📐 Panel`. Module symbol stays `window.PaperEquations`
  for back-compat (no need to touch every reference).
- Each tab content lives in its own container; inactive tabs use
  `display: none` so subscriptions don't churn on switches.

### Figure schema additions
```
attrs (Y.Map, V3.115 additions):
  numbered: bool              // default true
  subfigures: Y.Array<Y.Map>  // each item: {id, label}
                              // label is free-text, e.g. 'A', 'B', 'i', 'ii'
```

### Doc-order numbering walker
New `getNumberedFigures()` traverses `sections → children`, filters
`kind === 'figure' && attrs.numbered !== false`, returns
`[{blockId, label, num, downloadUrl, captionPreview, subfigures}]`.

### New paragraph tokens
| Source | Renders as | LaTeX |
|---|---|---|
| `[!fig:<label>]` | `Fig. <n>` chip | `\ref{fig:<label>}` |
| `[!fig:<label>:<panel>]` | `Fig. <n> (A)` chip | `\ref{fig:<label>}\,(A)` |
| `[!fig:<label>:<a>-<b>]` | `Fig. <n> (B-C)` chip | `\ref{fig:<label>}\,(B--C)` |

### Right-click context menu — extended in place
[rm/js/paper-equations.js](../../rm/js/paper-equations.js)'s
`_showContextMenu` adds:
- 🖼 Insert figure reference (V3.115)
- 📚 Insert citation (V3.115 — wraps `openCitationPopover`)

### Event rename
`paper-equations-changed` → `paper-panel-changed`. Back-compat alias
listener kept for one release so older bindings still get notified.

## Verification

```bash
RM_WRITE_ALLOWLIST=mcgheealex@gmail.com python3 rm/server.py
# open http://localhost:8000/rm/pages/paper-builder.html?paper=<some-paper>
```

1. Open the panel via `📐 Panel` button. Four tabs visible: Equations / Figures / Tables / References. Tables and References show "(coming in V3.114/V3.115)" empty states.
2. Switch to Figures tab. Add a figure block in any section, set Numbered, label `fig:cellgrowth`, upload an image.
3. Add subfigure panels A, B, C from the Figures tab row's chip editor (or from the figure block's Layout pane).
4. Right-click in a paragraph body → `🖼 Insert figure reference` → picker shows the figure thumbnail + caption preview. Click → choose `(A)` → `[!fig:cellgrowth:A]` inserts at caret.
5. Blur paragraph → renders as `Fig. 1 (A)` chip.
6. Add a second numbered figure. References stay correct as numbers shift.
7. Click figure-row "Open block" → editor scrolls + flashes the figure block.
8. Right-click → `📚 Insert citation` → existing Cmd+K popover opens.
9. Export LaTeX → `\ref{fig:cellgrowth}\,(A)` for the panel ref; `\subcaptionbox{A}{...}\subcaptionbox{B}{...}` for multi-panel figures.
10. Hard reload — SW cache rolls forward.
