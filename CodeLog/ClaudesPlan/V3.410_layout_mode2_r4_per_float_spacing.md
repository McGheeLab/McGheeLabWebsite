## The model

- **One attr does both spacing and nudge: `spacing`** — a SIGNED integer
  mm on the float's **text-facing side**. LaTeX has exactly one per-float
  vertical lever (`\vspace` inside the env; the float-sep lengths are
  document-global), and the anchor identifies which side faces text:
  top float → text below → `\vspace` AFTER the content; bottom → BEFORE;
  flow/[H] → after; float-page → nothing (no adjacent text). Additive on
  top of the R3 document preset. 0/absent → nothing (byte-identical);
  UI clamps to [−6, +18] mm.
- Emitted in BOTH build targets (authors hand-tune `\vspace` routinely);
  in the submission target resolveFloat pushes an advisory ("the journal
  may reset float spacing in production") — the lock-warning philosophy.

## What shipped

1. **paper-layout-rules.js** — `resolveFloat` return gains
   `spacingTex: {before, after} | null` (+ the submission advisory).
2. **paper-export-tex.js** — `figureToTex` injects `before` right after
   `\begin{env}[place]` and `after` just before `\end{env}` (outside any
   V3.405 minipage box — float-level space); `tableToTex` mirrors it
   (independent of IEEE caption-above). Anchored path only.
3. **paper-doc-view.js** — float classification carries
   `spacing` into `f.float` (figure + table branches), which R3's
   `gapForFloat` already consumes → the band row's stamped `row.gap`
   moves in the preview. Popover gains a **Spacing stepper**
   (`[−] +3 mm [+] · reset`, tables included) between Span and Lock:
   each click = ONE transact carrying the full intent (legacy opt-in
   rule) + `spacing` (0 → key DELETED via the null→delete path), origins
   `fig-spacing`/`tab-spacing` (added to LAYOUT_ORIGINS). Hint text
   states the preview honors it for top/bottom bands; in-flow blocks
   carry it to the PDF only (flow gap = CSS margins, out of preview
   scope v1 — documented).
4. **CSS** — `.pdv-fig-pop-spacing` / `.pdv-fig-pop-step` stepper styles.
