# V3.169 — Training: Image Analysis (Intermediate)

> Status: PLANNED — not yet built.

## Goal

From "I can measure one cell" to "I can quantify a whole field" — the
student finishes able to background-subtract, threshold, segment,
count nuclei or cells, and quantify intensity in a reproducible
(scripted) way.

## Format

Full interactive notebook (MODULE_TEMPLATE.md pattern). 5 tabs.

## Tabs

### Tab 1 — Background Subtraction
**Bio context:** uneven illumination across a tiled spheroid scan.

- Background: rolling-ball, top-hat morphological, paired blank field;
  when each is appropriate
- Interactive: the student picks a method + radius; canvas shows the
  flattened image + the residual; verdict flags over-subtraction (rim
  artifacts) and under-subtraction (residual gradient)

### Tab 2 — Thresholding & Otsu
- Background: histogram-based thresholding; Otsu's automatic threshold
  vs. manual; the curse of bimodal-not-quite-bimodal histograms in real
  fluorescence data
- Interactive: histogram panel + threshold slider + binary mask preview;
  toggle between manual, Otsu, Triangle, Li
- Worked example: DAPI segmentation in a packed spheroid edge — Otsu
  fails (single-mode), Triangle wins

### Tab 3 — Watershed & Touching-Object Splitting
- Background: distance transform → seed markers → watershed; over-
  segmentation as the main failure mode; size + circularity filters
- Interactive: input mask (touching nuclei) → live watershed preview;
  the student tunes the minimum distance between seeds and watches the
  count stabilize

### Tab 4 — Per-Object Quantification & Batch Processing
- Background: per-object measurement table (label, area, mean intensity,
  centroid); exporting to CSV; the workflow shift from "click measure"
  to "run a macro on a folder"
- Interactive: Fiji macro snippets with comments; the student modifies
  thresholds and re-runs over a small sample set
- Worked example: count GFP+ nuclei in a multi-position spheroid
  acquisition; output one CSV per well

### Tab 5 — Capstone: end-to-end pipeline on a real dataset
A folder of confocal images of spheroids (provided). The student writes
(or adapts) a Fiji macro to: load → background-subtract → threshold →
watershed → measure → output CSV. The page validates the output against
a reference count.

## Tools referenced
- **Fiji / ImageJ** macros (primary)
- Brief sidebar mention of **CellProfiler** as an alternative GUI for
  the same workflow
