# V3.389 — Demo lessons are interactive guided BUILDS (not pre-populated)

## Context

The demo lessons (V3.382) shipped pre-built node workflows — clicking one
just loaded a finished graph. Alex wants the opposite: clicking a demo
should run a **full interactive walkthrough of how to build that
workflow**, using the V3.385 tour engine (pulsing ring + top-right card
that advances as you actually do each step), starting from an **empty
canvas**.

## Design

### Build tours (`rm/js/protocol-graph-tours.js`)
Four new tours in a new **"Guided builds (lessons)"** group, one per
lesson (`build-lesson-1..4`), each reconstructing that lesson's exact
workflow step by step. Conditions are **name-anchored** (not
tour-freshness): a step that asks you to name a node
`total_volume` / `conditions` / etc. is satisfied by
`H.some(type, _named(name))`, and "add a node" steps use absolute
`H.count(type) >= k` — so the same build re-run on an already-built copy
**auto-skips every done step** (idempotent) instead of waiting for a
delta that won't come. New helper `edgesInto(g, name, role, paramField,
fromType)` counts wires into a named target, so wiring steps verify the
right connection (e.g. two math edges into `total_volume`, a
`param`/`max` edge into `dose`, a `structural` edge from a `choices`
node into `conditions`).

The names the tours teach are **exactly** the names each lesson's prose
`[!var:]` tokens and plate-planner attrs are wired to — enforced by a
test (below), because a mismatch would leave the document showing `?`
forever.

### Auto-start on demo open
- `ProtocolGraphEditor.mount` now returns `startTour(id)` on its handle
  (factored out of the 🎓 menu click).
- `protocol-editor.js`: on init, `?tour=<id>` → force the Nodes view +
  stash `state._pendingTour` + strip the param from the URL
  (`replaceState`, so a reload doesn't restart it); `renderNodesView`
  fires `handle.startTour(pendingTour)` once the canvas mounts (one-shot,
  cleared).
- `protocols.js`: each `DEMOS` entry gains a `tour` id; the loader
  navigates to `…?protocol=<id>&tour=<tourId>` (both the create path and
  the reuse-existing path — reopening resumes, with done steps skipped).

### Content (`rm/data/protocol-demos/*.json`)
All four lessons' `design` blocks now ship **empty** (`nodes:[], edges:[]`),
and the prose was rewritten from "here's the finished thing" to "you'll
build X, here's how to think about it" (docHeader tag "· guided build",
a "How this lesson works" callout). Lesson 3 keeps its `layoutMap` plate
planner (wired to `conditions` / `reps` / `excess`) — it lights up once
the learner builds the list the tour walks them through. The prose
`[!var:]` tokens stay; they resolve as the learner builds the matching
names.
