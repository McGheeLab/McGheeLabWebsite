## 1. What was actually wrong

The scraper was fine: run headlessly against the live VWR page it returned the three priced pack rows. The message had
no reason in parentheses, which only happens when the background worker answers `{ ok: false }` with no `why` — i.e.
an **old worker** that has no `get-items` handler ("unknown type: get-items"). Chrome's own record for the unpacked
extension (`Profile 1/Secure Preferences`) confirmed it: `service_worker_registration_info.version = "0.1.0"`, granted
API permissions without `alarms`, last update time **2026-04-29**. Chrome reads the popup's files from disk every time
the popup opens, but keeps the manifest, the service worker and the content scripts from the last **reload**. So every
version since April showed the newest popup over the oldest worker, and the 0.3.0 "injection fallback" never ran.

The screenshot-and-OCR idea would read the same text the extension already reads straight from the page (what a
screenshot shows IS the page text, which `fromText()` reads as printed), at the cost of a 5+ MB offline OCR bundle and
a `wasm-unsafe-eval` CSP. Not built; noted as the one remaining route for prices rendered as images.

## 2. Fix

- **popup.js** `checkStale(reason)` — on every open, fetch `manifest.json` from disk (`chrome.runtime.getURL`) and compare
  with `chrome.runtime.getManifest().version`; a mismatch, or any stale-shaped reply (`isStaleReply`: "unknown type",
  "Receiving end does not exist", "no reply", "message port closed"), renders a yellow **Reload needed** bar above the
  sections with **Reload now** → `chrome.runtime.reload()`. `send()` keeps `chrome.runtime.lastError` as the error. The
  items message shows `r.error` as well as `r.why`; a partial read lists `d.errors`.
- **background.js** `get-items`: the injected function wraps itself in try/catch and returns `{ ok, data, error }` —
  proven in the E2E: an UNCAUGHT throw inside `executeScript(func)` resolves with `result: null` and no error, so the
  old code could never have reported it. A content-script `{ error }` becomes `why`. New `ping` → `{ version, handlers }`.
- **content.js** `_itemsNow()` returns `{ error }` instead of `null` on a throw.
- **scrape-items.js** `scrapeItems()`: each source runs under `safe(name, fn)`; the result carries `errors: []`.
- **README** — Updating paragraph in "Lab member install", troubleshooting entry.
