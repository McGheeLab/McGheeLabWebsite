# V3.382 — Demo lesson protocols (guided node tutorials)

## Goal

Four bundled, editable demo protocols that teach the node workflow like a
tutorial, loadable in one click from the protocols list — so a new user
learns by opening a real, working protocol instead of a blank canvas.

## Design

### Content — `rm/data/protocol-demos/*.json` (format `protocol-import-v1`, each with `protocol.id`)
1. **lesson-1-variables-and-wires** — nodes, dots, wires; live values;
   prose `[!var:]` tokens. Two inputs → equation, fully wired.
2. **lesson-2-bindings-and-modifiers** — param bindings (a constant
   drives a slider's max), constant live-mirror, the "+ add modifier"
   menu, the four binding roles.
3. **lesson-3-sets-lists-plates** — choices × ordered → list → a
   `layoutMap` plate planner (`assign:true`) with `reps`/`excess`
   master-batch totals.
4. **lesson-4-code-node** — the code node: wired inputs as arguments,
   returned keys as outputs, error surfacing, when to use it.

Each lesson is guided prose (docHeader + steps + callouts) around a
pre-seeded, working `design` block, so the learner reads the concept then
pokes the live canvas.

### Loader
- `protocols.html`: a "🎓 Demos" button in `.pr-list-actions` + a
  `#pr-demo-modal` chooser.
- `protocols.js`: a hardcoded `DEMOS` registry (slug/title/desc/file —
  same pattern as paper-templates' `KNOWN_TEMPLATES`). Picking one
  requires sign-in, computes a collision-free slug from the loaded list
  (`_uniqueSlug` → `-2`, `-3`…), `fetch()`es the bundled JSON (the
  layout-audit static-fetch precedent), and calls
  `PROTOCOL_IMPORT.createFromJson(obj, {slug, onProgress})` — the same
  pipeline the Import button uses — then navigates to the new protocol.
  Errors surface in the modal; a demo never overwrites an existing doc.
- `protocol-graph-editor.js` empty node canvas gains a one-line pointer:
  "New to nodes? Load a 🎓 demo lesson … or try ✨ Recipes."

### CSS
`protocol-editor.css`: `.pr-demo-list`, `.pr-demo-item/-title/-desc`.
`protocol-graph-editor.css`: `.pge-empty-demo`.

## Verification
- `scratchpad/test-demos.js` (31 asserts): each lesson passes
  `PROTOCOL_IMPORT.validate`, `protocol.id` matches its filename,
  `summarize` counts a design block, every design compiles error-free and
  builds a symbol table; lesson-specific computes (l1 total_volume=300; l2
  two param overrides + mirror=10; l3 six rows + numeric `dose_value` +
  reps/excess present + layoutMap→dataset match; l4 total_cells=10M,
  millions=10, import warns about the script node).
- `createFromJson` itself needs Firestore, so the browser step covers it.
- Pending (browser): 🎓 Demos → Lesson 1 imports + opens; Nodes view
  shows the workflow; doc view of Lesson 3 shows the plate planner.
