# V3.440 — T2 of Paper Builder III: multi-page tables (longtable) + table notes + lints

> Completes the Tables II workstream (T0 V3.435 round-trip fix → T1 V3.439 merges/widths →
> this). Tables can now break across pages with repeating headers, and carry footnote-style
> notes under the table.

## Model

- `attrs.longtable` (bool, scalar) — multi-page table. **Not a float**: anchor/span/lock and
  the spacing nudge don't apply; the caption lives INSIDE the longtable's first head.
  **Invalid in two-column classes** (ieee, pnas-new `compiled_columns===2`) — the export
  degrades it to a regular float table there and pushes a layout warning.
- `attrs.notes` (scalar string, one note per line) — table footnotes.

## Changes

- **Export (`rm/js/paper-export-tex.js` tableToTex):**
  - longtable branch: `\begin{longtable}{colspec}` → `\caption{…}\label{…} \\` (or
    `\caption*`), booktabs `\toprule`, header row, `\midrule`, `\endfirsthead`, then the
    same head repeated + `\endhead`, body rows (merge-aware — same cover-map emission as
    T1), `\bottomrule`; notes emit as full-width `\multicolumn{N}{l}{\footnotesize …}` rows
    (threeparttable does not pair with longtable).
  - Regular tables with notes wrap the tabular in `\begin{threeparttable}` +
    `\begin{tablenotes}\footnotesize` with one `\item` per line.
  - New on-demand preamble flags `_usedLongtable` → `\usepackage{longtable}` and
    `_usedThreeparttable` → `\usepackage{threeparttable}` (full `_usedCuted` lifecycle).
- **Lint (`rm/js/paper-export-lints.js`):** `checkLongtable` — warns when a
  `\begin{longtable}` appears in a bundle compiled on a two-column class (covers raw_tex
  imports; authored longtables already degrade in tableToTex).
- **Tables page (`rm/js/paper-equations.js`):** "multi-page (longtable)" checkbox in the
  style bar (title documents the two-column caveat) + a **Notes** textarea under the
  caption (one per line; blur-write; deletes the attr when emptied).
- **Previews:** Document view renders notes as `.pdv-tabnotes` rows under the caption
  (threeparttable look). Longtables render as a normal atomic table in the preview
  (page-spanning preview out of scope — documented).
- **CSS:** `.pdv-tabnotes` (doc view), `.pe-table-notes` (panel).
