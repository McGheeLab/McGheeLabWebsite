## Goal

A self-contained training module that walks a new lab member from
"blank page" to "submitted manuscript". Lab-internal; lives at
`rm/pages/training-paper-writing.html`. Format: lecture-style (same
lighter pattern as the PhD triangle), no full interactive notebook.

## Format

Lecture-style HTML, similar shell to `training-phd-triangle.html`:
single-scroll page, no tab bar, prose + worked-example callouts.
Anchor links jump between sections so the page acts as both a tutorial
on first read and a reference on the tenth.

## Sections (target ~600-900 lines incl. examples)

1. **Why we write papers** — claims as the unit of scientific exchange;
   peer review as quality control; reproducibility expectations.
2. **Before you start — figure-first drafting** — pick the 4-6 figures
   that *are* the story; if you cannot draw them you do not yet have a
   paper. Worked example using one of the lab's recent figures (TFM or
   spheroid panel).
3. **IMRaD anatomy** — Introduction (funnel: field → gap → claim),
   Methods (reproducible recipe), Results (figure-anchored prose),
   Discussion (interpret, situate, limit, project). Each subsection
   gets a "what good looks like / what mediocre looks like" pair.
4. **Citation discipline** — when to cite (every non-obvious claim),
   when not to (your own well-known result, common-knowledge), how to
   cite (anchor at the end of the sentence carrying the claim). Link
   to the Library + paper-builder citation tools that already exist.
5. **Authorship + contribution statements** — what earns authorship
   here, what doesn't (the long ICMJE-adjacent answer); contribution
   statement template; corresponding author duties.
6. **The lab's draft workflow** — write in [paper-builder](/rm/pages/paper-builder.html)
   not Word; check in nightly; PMR paper-writing block tracks status;
   Alex reads every draft section as it lands (don't wait until "done").
7. **The revision letter** — point-by-point format; when to disagree
   (and how); the rebuttal as its own piece of scientific writing.
8. **Sub-journal selection** — match scope, audience, prestige, OA
   policy, lab budget; the lab's preferred journal list per topic area.
9. **Common failure modes** — buried lede; cite-and-move-on Methods;
   Discussion that re-summarizes Results; over-claiming generalization.
10. **Checklist for "ready to submit"** — figures final, references
    parsed, supplementary checked, co-authors signed off, cover letter
    drafted, suggested reviewers picked.
