# V4.114 — Scientia: the notebook kept on any device — each device's own install steps, tested on eight

## Why
Gabe, 24 Nov: "It should be universal across devices. It should work on an iPad, a computer, an iPhone, etc..."

V4.113's mechanism was already the same everywhere: the website build installed as an app, its files kept by the site's service worker. Its words were not:
- the card spoke of "the iPad, a phone, a laptop";
- the card showed install steps for iPad/iPhone Safari, Android Chrome, and one Chrome/Edge line written for Windows; nothing for a Mac (Safari's Add to Dock), a Chromebook, Linux or Firefox;
- the card sent a Windows computer to the desktop app;
- the lab banner's *How* opened the standalone's steps, which speak of pairing with a computer.

## What changed (`13zob-offline.js`)
- **`OFFLINE.kind()`:** what this device is (iPhone, iPad, Android phone or tablet, Mac, Windows PC, Chromebook, other) and its browser (Safari, Chrome, Edge, Samsung Internet, Firefox).
- **`OFFLINE.how()`:** this device's own install steps.
  - **iPad / iPhone:** Share → Add to Home Screen (in Safari, or from the menu in Chrome and Edge), then sign in inside the installed app, which keeps its own storage.
  - **Android:** Chrome ⋮ → Install app; Samsung Internet ≡ → Add page to → Home screen; Firefox ⋮ → Install.
  - **Mac:** Safari File → Add to Dock (sign in again there), or Chrome/Edge's install icon.
  - **Windows / Chromebook / Linux:** Chrome or Edge's install icon, then the Start menu, taskbar or launcher.
  - **Firefox on a computer** cannot install a site as an app; kept, the notebook still opens offline in Firefox.
- **The card:**
  - it says "the same on an iPad, an iPhone, an Android phone or tablet, a Mac, a Windows PC or a Chromebook" and names this device ("Install it on this iPhone, too");
  - it shows the browser's Install button where there is one, and the steps;
  - "Safari may clear it after 7 days" now shows on a Mac in Safari too;
  - the line sending a Windows computer to the desktop app is gone.
- **The lab banner's *How*** opens the same steps (`OFFLINE.howModal`).
- **On the lab site:** the status under the card says "Paired with the lab cloud" (13zd's words are for a device of your computer).
- **While the card is on screen** the install banner steps aside; on a phone it lay over the card.
- **Settings → Features** description and **MANUAL §21:** the steps for every kind of device.
