# V3.408 — Layout Mode II R3: document-wide float-spacing preset

> Release 3 of 8. Alex: "control how tight the spacing between the figure
> and the text wrap is" — this is the DOCUMENT default; the per-figure
> nudge is R4.

## The model

- `paperExports.floatSpacing` ∈ `'tight' | 'normal' | 'loose'`; absent ≡
  `'normal'` ≡ **emit nothing** (byte-identical sentinel for untouched
  papers). Top-level scalar like `buildTarget` — no Firestore rules
  change (doc-level `isLabContributor()` gate).
- LaTeX float-separation lengths are DOCUMENT-GLOBAL — the only honest
  home for a document preset is a preamble `\setlength` block:
  - tight: `\textfloatsep 10pt±2`, `\floatsep`/`\intextsep 8pt±2`
  - loose: `\textfloatsep 28pt+4−2`, `\floatsep`/`\intextsep 18pt±2`
  - `\dbltextfloatsep`/`\dblfloatsep` lines ONLY when the template
    compiles two-column (`figure_environment.compiled_columns === 2` —
    IEEE today, PNAS after R7); kernel `\setlength` only, never
    `\captionsetup` (ACS has no caption package).

## What shipped

1. **paper-export-tex.js** — `buildFloatSpacingPreamble(preset, twoCol)`
   (module fn, harness-exposed) appended addon-style to
   `effectiveTemplate.preamble` in buildBundle right after applyAddons;
   `opts.floatSpacing` threaded.
2. **paper-export.js** — `floatSpacing` in `_defaultConfig`/`_loadConfig`
   /`_saveConfigNow`/build opts; NEW `_bindFloatSpacing()` on the
   Export-page select `#px-float-spacing` (paper-export.html row under
   Build target).
3. **paper-doc-view.js preview** — `FLOAT_GAP_PRESETS {tight:7,
   normal:10, loose:16}` px (normal == BLOCK_GAP → untouched papers
   pixel-identical); `baseGapPx()` reads `state.config.floatSpacing`;
   NEW `gapForFloat(f)` = base + per-float mm nudge (R4's `f.float.
   spacing`, absent = 0; floored at 2px). **Every band row is stamped
   `row.gap` ONCE at pack time** and every consumer reads the stamp —
   rects↔DOM alignment by construction: tryPlaceFloat delta (join delta
   covers height AND gap growth; paired row gap = max), flushFloatPages,
   trailing-drain safety net, `_recordRects` y-advance + bottom
   reservation, `_mountBand` marginBottom. `openRunH` uses `baseGapPx()`
   (text-run gap — never per-float). Toolbar "Spacing" select next to
   Build target (disabled until config loads, editable-gated),
   `_onFloatSpacingChange` mirrors `_onBuildTargetChange` (paperExports
   set-merge → forced re-render); `loadConfig` reads the field.
