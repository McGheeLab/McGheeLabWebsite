# V4.74 — going to a component centres the canvas on it at 50% zoom

## Why
Gabe, 20 Nov 2026: "Clicking open on a task brings you to where it was created and centers the canvas view around it in
50% zoom. This should become the standard for every 'click to navigate to a component' workflow."

Before, a jump to a component only moved the canvas when the component was off the screen, and then to at least 80% zoom
(`DocView.reveal`). Many places called `App.openBlock`, several others wrote `pendingFocus = { reveal }` themselves.

## What changed
- `App.openComponent(id, e)` (11-shell.js) is the one function: the component's note (or the pane already showing it),
  then `DocView.landOn(id)`. `e` carries the modifiers exactly as `App.jump` did: Alt+click opens beside
  (`openSide`), Ctrl/Cmd+click in a split view replaces the pane clicked in (`replacePane`).
- `App.openBlock(id)` stays as a name (the lab layer calls it: lab-mode.js is untouched) and is the same function;
  `App.jump(id, e)` for a component calls it; every `App.openBlock(` in `src/` was renamed `App.openComponent(`
  (tasks, calendar items, reminders, links and chips, search results, term cards, the Atlas, the Portfolio, the
  review, the day views, the reader, bridges...).
- `DocView.landOn(id, arrive)` (12-doc.js): centres the component's box at the zoom set in Settings (50%), glides
  there (a note just opened takes the view at once, `arrive`); the box keeps its brief highlight (`.flash`). Used by
  `focusPending` for every `{ reveal }` (so Alt+click panes and split routes with a component too), and by the story arc's
  dots and "Go to what they are editing" in the presence menu. Keyboard moves between components still use `reveal`.
- Settings -> Open a component (`opencomp`, 20a-features.js): a switch (off: the old behaviour, move only if off screen), "Zoom on
  arrival" 50% / 75% / 100% / Keep mine, and a live preview (the screen frame over a small note, narrower as the zoom grows).
- Test `opencomp_t.mjs`: a real click on a task's Open, a real search result, the older names, Settings, Alt+click
  and Ctrl+click.

## Files
`scientia/src/11-shell.js`, `12-doc.js`, `13-docpanels.js`, `13zzl-story.js`, `13zzk-presence.js`, `20a-features.js`,
