# V3.435 — T0 of Paper Builder III: deep-attr round-trip fix (section-move data loss) + one table seeder

> First release of the approved Paper Builder III program (17 releases, 7 workstreams —
> plan: `~/.claude/plans/the-papers-page-the-optimized-dongarra.md`). This is the
> foundation bugfix the Tables II work builds on.

## The bug (real data loss, pre-existing)

Moving a SECTION snapshots every block via `blockMapToTree` and rehydrates via
`appendBlockFromTree` (paper-editor.js) — and both handled only **scalar** attrs. Deep Y
values were silently dropped:
- table `cells` (Y.Map of Y.Text) — **all cell text destroyed**
- table `caption` (Y.Text) — destroyed
- figure `subfigures` (Y.Array of Y.Map) — panel labels destroyed (breaks `[!fig:x:A]` refs)

Within-section moves were already safe (they use the deep helpers `_snapshotYValue` /
`_writeAttrValue`, paper-editor.js:1159-1264). The fix routes the section-move path through
the same helpers.

## Changes (rm/js/paper-editor.js)

- `blockMapToTree` — snapshots ALL attrs: scalars as-is, deep Y types via `_snapshotYValue`
  (the `{__ytype: text|array|map}` shapes).
- `appendBlockFromTree` — rehydrates: scalars fast-path; `__ytype` snapshots via
  `_writeAttrValue`; **plain JS arrays** from schema-factory trees (e.g. `newFigure`'s
  `subfigures: []`) now convert to their live Y shapes (previously skipped — template-seeded
  figures gain a real `subfigures` Y.Array like `insertBlockAt` ones); unknown plain objects
  still stored as JSON values (import behavior unchanged).
- **`_seedTableAttrs(attrs)`** — ONE table-attr seeder replacing three drifted inline copies
  (`addTable`, `createUnplacedTable`, `insertBlockAt`'s table branch). Fixes the drift:
  `addTable` was missing `numbered/label/booktabs/header_row/align` — tables created from
  that path now get the full default set. (Plan deviation note: the plan named this
  `newTable()` in paper-schemas.js, but the seeder needs `state.Y` for Y.Map/Y.Text
  construction — schemas is deliberately Y-free — so it lives in paper-editor.js. Same
  dedup goal.)
