# V3.360 — Lab notebook seamless input (FuturePlan 10, Phase 2)

## Goal

Kill every `prompt()` in the entry-editing path and stop the
focus-destroying full re-renders, so recording bench work feels
instant on phone and desktop.

## What shipped

- **Inline observation mini-form** — the V3.138 three-`prompt()` chain
  (`onAddObservation`) is replaced by an inline form inside the
  Observations panel (`openObservationForm` / `commitObservationForm`):
  free-text textarea + metric/value/unit row + Log/Cancel. Enter
  commits; the form re-opens after save for rapid-fire logging.
- **🎙 Voice dictation** — `wireVoiceMic` ports the activity-tracker
  SpeechRecognition pattern (single-shot, feature-detected, recording
  pulse, cleanup on end/error) onto the observation textarea; the phone
  action bar's 🎙 opens the form and starts dictation.
- **Tag chip input with autocomplete** — the tag `prompt()` is replaced
  by an inline chip input + `<datalist>` seeded from
  `NOTEBOOK_DEFAULT_TAGS` ∪ tags harvested from the user's index rows
  (`knownTags`). Enter/comma commits, blur commits, Backspace on empty
  removes the last chip.
- **Surgical re-renders** — new `renderAttachmentsPanel`/
  `wireAttachments` and `renderRefsPanel`/`wireRefs` extractions;
  `uploadAndAttach` and `togglePmrFlagOnFigure` now refresh only the
  attachments strip (previously a full `renderEditor()` — pasting a
  screenshot mid-sentence dumped the caret). Reference add/delete
  refreshes only the refs section and focuses the new row. The rail
  preserves `scrollTop` across re-renders.
- **“/” slash-command menu** — typing `/` at line start (or after
  whitespace) in the body pops an anchored menu: Observation, 🧪
  Inventory, 📋 Protocol, 📷 Photo, 📎 Attach, 🧮 DOE, H2, Quote, Code.
  Letters filter, ↑/↓/Enter navigate, Escape/blur dismisses; picking
  deletes the typed `/query` and delegates to the existing toolbar
  handlers (`SLASH_ITEMS`).
- **Dialog hygiene** — `ln-add-link` uses `RM_DIALOG.prompt`
  (`lnPrompt` wrapper with `window.prompt` fallback); upload failures
  toast via `lnNotify` (TOAST wrapper, alert fallback for errors).

## Verification

`node --check`. Browser: log observations via form + mic, tag
autocomplete commit paths (Enter/comma/blur/datalist-change), paste an
image mid-typing (caret survives), slash menu filter + insert on
desktop and phone.

## Rollback

git revert + re-FTP + CACHE_VERSION bump. Client-only.
