# V3.362 — Lab notebook connection & adoption (FuturePlan 10, Phase 4)

## Goal

Turn isolated entries into a connected record: link entries into
chains, search entry content (not just metadata), filter the rail by
lifecycle stage, and show a light weekly pulse.

## What shipped

- **Cross-entry picker** — “🔗 link another entry” in the References
  section opens a popover (inventory-picker chrome) over index rows
  with search; picking writes `reference_links kind:'notebook'`
  **reciprocally** (`linkSiblingEntry`: current doc via normal save,
  the sibling via direct entry save + index-row refresh; one-way link
  survives a failed reciprocal write).
- **Backlinks** — `notebookIndexRow` projects `linked_entry_ids[]`
  (parsed from notebook reference URLs by `notebookLinkedEntryIds`);
  a “Linked from” section renders rows whose ids point at the open
  entry — computed from the `_index` alone, zero extra reads.
- **Excerpt search** — index rows carry a 300-char `excerpt` of
  `body_text`; `filteredIndexRows` matches it, so rail search now
  covers entry content.
- **Rail phase chips** — All · 📝 Plan · ▶ Running · ✅ Complete above
  the rail (`state.filters.phase`), rendered even when the filtered
  list is empty so an active chip can be un-clicked.
- **Weekly pulse** — toolbar line “N this week · M-day streak”
  (`weeklyPulse` over index dates; streak may end yesterday).
  Refreshed via `refreshPulse` on index save — never a toolbar
  re-render (which would eat search focus). Hidden at ≤640px in favor
  of search width.

## Files

`rm/js/notebook-schemas.js` (excerpt + linked_entry_ids projection),
`rm/js/lab-notebook.js`, `rm/css/lab-notebook.css`.

## Deliberately not done

Real entry delete (still the `save({}, )` wipe stub — needs an adapter
delete verb first); full-body search beyond the 300-char excerpt (the
`_index` doc must stay well under the 1 MB cap).

## Verification

Node harness: linked-id extraction (dedupe, kind gating, absolute +
relative URLs), excerpt cap — passed. Browser: link two entries →
backlink chip appears on both; phase chips filter; search hits body
text; pulse line updates after a save.

old rows without `excerpt`/`linked_entry_ids` render fine.
