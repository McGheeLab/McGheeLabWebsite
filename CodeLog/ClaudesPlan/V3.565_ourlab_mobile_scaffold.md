# V3.565 — Ourlab mobile m-v0.1: Capacitor scaffold + web shell seams

> Kickoff of the Ourlab phone app (FuturePlan 05 Workstream D, reconciling
> the older V3.244 plan). This version covers BOTH sides of the seam:
> the new sibling repo `~/Documents/GitHub/OurlabMobile` (its own m-v
> version line, own CodeLog) and the small web-repo patches that make the
> bundled `rm/` tree app-aware. First surfaces, per Alex 2026-07-26:
> **Chat, My Day, Tasks.**

## Goal

Lab members open **Ourlab** on iPhone/Android and land on My Day with a
bottom tab bar `[My Day] [Chat] [Tasks] [More]`. Sign-in is native Google
(one tap, no browser popup); every rm/ page then works signed-in inside
the app. m-v0.1 is scaffold + shell + native auth only — push is m-v0.2
(blocked on the notify.js platform-aware payload fix), store release is
m-v1.0.

## Locked architecture (from FuturePlan 05 / memory, confirmed 2026-07-26)

- **Capacitor**, sibling repo `github.com/McGheeLab/OurlabMobile`, app id
  `app.ourlab.mobile`, display name **Ourlab**. Both platforms from day
  one (Xcode ready; Android Studio + JDK 21 installed as part of this).
- **Bundle `rm/` into `www/`** via a build-time sync script — NOT a
  remote-URL wrapper (offline in basement BSL-2; Apple 4.2).
- **Injected web tab bar** (decision 2026-07-26): `rm/js/mobile-shell.js`
  renders the bottom tabs only when `Capacitor.isNativePlatform()`.
  Native capabilities (push/camera/haptics/…) come through Capacitor
  plugins either way — the bar choice is chrome only; a native UITabBar
  swap later would be cosmetic. OTA-updatable via the bundle.
- **Native auth** via `@capacitor-firebase/authentication` → hand the
  Google idToken to the web Firebase SDK with `signInWithCredential`.
  Web sign-in flow untouched.
- Push (m-v0.2) will reuse `users/{uid}/pushTokens` + `notify.js` — no
  `devices` collection fork. Live Updates + Remote Config wiring also
  deferred to m-v0.2 (needs a Capgo-vs-self-hosted decision).

## Mobile repo (`~/Documents/GitHub/OurlabMobile`, m-v0.1)

```
OurlabMobile/
├── package.json                # @capacitor/{core,cli,ios,android}, @capacitor-firebase/authentication
├── capacitor.config.json       # appId app.ourlab.mobile, appName Ourlab, webDir www
├── scripts/sync-rm.mjs         # copies ../McGheeLabWebsite/rm → www/rm (+ injects mobile-shell tag
│                               #   into every page, writes www/index.html → redirect to my-day)
├── www/                        # generated — gitignored
├── ios/  android/              # Capacitor native projects (committed)
└── CodeLog/                    # m-v plans + CHANGELOG + ARCHITECTURE (mirrors web repo ritual)
```

`sync-rm.mjs` responsibilities: rsync `rm/` → `www/rm/`; inject
`<script src="/rm/js/mobile-shell.js" defer></script>` before `</body>`
in every `www/rm/**/*.html`; write `www/index.html` that redirects to
`/rm/pages/my-day.html`. Run via `npm run sync && npx cap sync`.

## Firebase console/CLI work

- `firebase apps:create ios app.ourlab.mobile` + `apps:create android` on
  `mcgheelab-f56cc`; pull `GoogleService-Info.plist` / `google-services.json`
  via `apps:sdkconfig`; register the Android debug-keystore SHA-1
  (`apps:android:sha:create`) so Google sign-in works in dev.
- No Firestore/Storage rules change — the app reads the same collections
  as the web with the same auth.

## Out of scope (m-v0.2+)
