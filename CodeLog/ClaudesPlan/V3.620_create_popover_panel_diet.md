# V3.620 — One-popover highlight create + panel diet + consistent colors

**Release 2 of 4** in the paper-reader highlight→comment overhaul (after
V3.619's data-loop fix). This is the visible simplification: the happy
path becomes **drag → (optionally type) → click a color — done**, with the
highlight filed to the right drafts and the panel scrolled to the new card.

## Problems this fixes (from the 2026-08-12 investigation)

- The create toolbar was a bare swatch bubble: no comment, no category
  label, no draft control at creation — the full flow took ~7 interactions
  across 3 inline panels.
- The bubble was `position:fixed`, computed once: it stranded itself on
  scroll, died if you clicked ANY control outside the viewer (selection
  lost, no Escape, no retry), and survived plain viewer clicks with stale
  anchors (swatch click highlighted text that no longer looked selected).
- Create/comment failures alerted AFTER the work was discarded.
- A teammate's snapshot arriving mid-comment wiped the textarea
  (`_root.innerHTML` full re-render).
- Five drifting color definitions (3 DEFAULT_COLORS copies + 2 hardcoded
  fallbacks) and panel/type-pill colors that disagreed with the highlight
  palette.
- Six overlapping categorization taxonomies; `group` was write-only and
  "+ New group" was broken for everyone (serverTimestamp-in-arrayUnion).

## Changes

### Create popover (rm/js/annotation-overlay.js — replaces _showToolbar)
- Anchored `position:absolute` INSIDE `.pv-page-wrap` below the last
  selection rect (clamped; flips above when short) — scrolls with the
  selection by construction. z-index 8 (above cite-flash 6 / hotspots 4).
- Contents: 6 labeled color swatches (color IS the category), autofocused
  optional comment textarea, "File to:" draft chips pre-checked from
  active overlays + `+ draft…` (opens the link picker; chips refresh via
  `ANNOTATION_OVERLAY.refreshPopoverDrafts()` wired to
  PAPER_OVERLAYS.onChange), ƒ / 🖼 / × footer.
- **Swatch click = save** (busy state). Failure keeps the popover open
  with an inline error — selection, comment, chips intact for retry
  (library-paper's onCreate no longer catches/alerts; it rethrows and
  focusCards the new card on success).
- Dismissal: Escape (capture-phase keydown); mousedown anywhere outside
  the popover (viewer included). Guards: `.app-sheet-back` (mobile sheet),
  `#lp-overlays-linkmodal` (the + draft picker).
- Zoom/refit dismisses (stored `_popoverZoom` vs live zoom in `redraw()`);
  same-zoom snapshot redraws leave it alone.

### Gesture safety (rm/js/geom-selection.js)
- `clearCommitted()` — clears only a COMMITTED selection; safe from
  document-mousedown handlers because `_beginGesture` resets
  `_hasCommitted` first (pointer events precede mouse events), so a
  mousedown that starts a new drag is never harmed.
- `_pageOfNode` returns null for nodes inside `.ann-popover` — the popover
  is a child of the page wrap, so without this a textarea drag would start
  a page selection gesture and destroy the popover mid-typing.

### Palette single-sourcing (NEW rm/js/annotation-colors.js)
- `window.ANNOTATION_COLORS = {DEFAULT, COLOR_TO_TYPE, byId, typeFor,
  hexFor}` — loaded by library-paper.html, library.html (comments tab
  loader), library-mobile-paper.html. The three DEFAULT_COLORS duplicates
  and the dead per-user palette loads (`library/highlight_colors.json`,
  no writer — V3.608's root cause) are deleted; overlay + panel fallbacks
  now resolve through the module.
- Panel cards show a category badge (the color's NAME in the color's hue)
  next to the author; card left-border accent unchanged (same hex).

### Panel diet (rm/js/annotation-panel.js)
- Card = head (with category badge) → capture block → quote → comment →
  **inline Drafts row** (always visible; was buried in "Tag as
  information") → footer (`Jump to →` · `+ Comment`/`Edit comment` · `⋯`).
- Deleted: "Tag as information" + `_renderInfoPanel`; group row +
  "+ New group…" prompt flow (`getGroups`/`onCreateGroup`/`allowNewGroup`
  init options); orphan bucket-chip wiring (`getBuckets`/`onBucketToggle`/
  `getBucketColor`, `.ann-bucket-chip` handler — chips were never
  rendered); dead `onReply` option.
- "Tag as evidence" moved from the footer into the `⋯` panel as
  "⚖ Evidence for a claim…" (interim home until V3.622 moves triage to
  the comments page). `⋯` also holds owner controls (color/vis/⚑/🗑).
- **`canWrite` init option** (host passes `_canAnnotate`): mutating
  controls only render when the rules will accept the write.
- **Comment durability**: `_commentForm` Map (annId → {text,busy,err})
  survives snapshot re-renders (same pattern as `_evidenceForm`); save
  disables the editor, awaits the write, closes only on success; failure
  shows an inline error with the text intact. Fire-and-forget updates
  (color/vis/⚑/draft chips) go through `_updateOrAlert`.

### Host rewiring (rm/js/library-paper.js)
- onCreate rethrows (popover owns failure UX) + `focusCard(newId)` after
  create; onUpdate rethrows (panel owns failure UX) and still re-stamps
  `annotation_type` on color change.
- ANNOTATION_GROUPS wiring removed (ensureSeed/subscribe/_unsubGroups,
  `_allowNewGroup` + `_emailOnContributorAllowlists`). The annotation
  `group` field is retired from the reader — the real intent ("save this
  PAPER to a library group") is a paper-level feature (V3.622).
- `_loadColors`/`_colorsLoaded` deleted; `_colors` = ANNOTATION_COLORS.
- PAPER_OVERLAYS.onChange also refreshes the popover's draft chips.

### Mobile parity (rm/js/library-mobile-paper.js)
- Create sheet stamps `annotation_type` (COLOR_TO_TYPE) and
  `cite_in_drafts: []` (PAPER_OVERLAYS is desktop-only); group select
  removed; consumes ANNOTATION_COLORS; passes `canWrite`; groups wiring
  removed. onUpdate rethrows + re-stamps type on color change.

### Comments feed (rm/js/library-comments.js)
- Consumes ANNOTATION_COLORS (duplicate palette + dead per-user load
  deleted); group dropdown + "+ New group" prompt + ANNOTATION_GROUPS
  subscription removed (that subscription also leaked a callback per auth
  event).

### Pages
- library-paper.html: + annotation-colors.js; − annotation-groups.js;
  − evidence-tag-dialog.js (zero callers; file deletion lands in V3.621).
- library-mobile-paper.html: annotation-groups.js → annotation-colors.js.
- library.html comments loader: annotation-groups.js → annotation-colors.js.
- rm/css/style.css: `.ann-popover` family + `.ann-cat` badge +
  `.ann-drafts-inline`.
