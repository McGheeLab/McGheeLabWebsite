# V1.1 — Solid Mechanics Foundations (interactive learning modules)

## Goal
Build a 5-module learning series on solid mechanics foundations. Each module
opens at a **high-school** level and ends at a **sophomore-undergraduate**
level, with interactive canvas simulations of every core concept. Modules live
in a new `modules/solids/` course folder and follow the established McGhee Lab
interactive-module pattern (self-contained HTML, tab bar, scenario presets,
`<canvas>` sims driven by the shared `Chart` helper library, MathJax, worked
examples, key takeaways, "Try this" tasks, sources).

## The five modules
1. **Atoms as springs** (`01-atoms-as-springs.html`) — bond potential → why two
   atoms behave like a spring (repulsion when close, attraction when far), the
   parabolic minimum = Hooke's law, a lattice of atomic springs = a macroscopic
   spring, anharmonicity/bond breaking. UG end: Lennard-Jones potential,
   `F=-dU/dr`, `k=U''(r0)`, Young's modulus from bond stiffness.
2. **Grains & fracture** (`02-grains-and-fracture.html`) — polycrystalline metal
   is a mosaic of grains; grain boundaries, dislocations glide → bending
   (plasticity); cracks → breaking; grain size vs strength. UG end: Hall–Petch
   `σ_y = σ0 + k/√d`, ductile vs brittle, slip planes.
3. **Force vs displacement across materials** (`03-force-displacement.html`) —
   pull honey, cheese, rubber, metal, diamond; springs (elastic) + dashpots
   (viscous) and their series/parallel combinations (Maxwell, Kelvin–Voigt,
   SLS). Surface reading (shape of the curve) AND deep reading (element
   models). UG end: viscoelasticity, creep/relaxation, `τ=η/E`.
4. **Stress & strain — why raw force/displacement isn't enough**
   (`04-stress-and-strain.html`) — same material, different sample size/contact
   gives different force–displacement, so normalize: stress `σ=F/A`, strain
   `ε=ΔL/L0`. Contact geometry & stress distribution sims. UG end: engineering
   vs true stress, stress concentration, Young's modulus as the material-
   intrinsic slope.
5. **Stress modes & beams** (`05-stress-modes-beams.html`) — tension,
   compression, shear, torsion, bending, and combinations; how geometry
   channels them; beam bending (top compression / bottom tension / neutral
   axis) and shaft torsion (shear). UG end: bending stress `σ=My/I`, torsion
   `τ=Tr/J`, superposition of modes.

## Approach
- Extract the proven CSS + JS helper library from
  `modules/tfm/01-hydrogels-and-cell-forces.html` into a shared kit so all five
  modules are consistent; each file stays fully self-contained (no build step).
- Each module: 4–6 tabs, escalating difficulty; last tab is the sophomore-UG
  "level up". Every tab has a working canvas sim + scenario presets.
- Register the folder + files in `modules/manifest.json`.
