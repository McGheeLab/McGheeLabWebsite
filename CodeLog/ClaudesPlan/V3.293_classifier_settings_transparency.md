# V3.293 — Classifier Settings & Transparency page

## Request
"We should have a settings page that helps with the weights used in the
classification. I want the most transparency in the classification as possible."

## What "weights" + "transparency" mean here
The classifier is the V3.292 in-browser Naive Bayes. Its tunable "weights":
- per-feature-group multipliers (sender / domain / subject / body)
- activation gate (min examples), confidence gate, Laplace α, min examples/class
And the deterministic fallback (`CATEGORY_RULES`) has explicit numeric weights
on each domain/subject hint.

"Most transparency" → for any email, show the ranked probabilities AND which
feature voted for which category and why, plus the live effect of weight changes
on accuracy, plus the fallback rule weights.

## Build
### Engine (`rm/js/email-classifier.js`)
- `CONFIG` (from `DEFAULTS`) with `minExamples`, `minPerClass`, `minConfidence`,
  `alpha`, `weights{from,dom,s,b}`. `configure(patch)` / `getConfig()` (clamps;
  `getConfig().defaults` for the Reset button).
- `_classLogScore(k, tokens, wantContrib)` — single weighted scoring path:
  `Σ weight(group) · log P(token|class)`. Used by `_scores` and `explain`.
- `explain(email)` → `{ tokens, ranked:[{category,confidence}], classes:[{category,
  logScore, prior, confidence, contrib:[{token,group,weight,count,value}]}],
  ready, config }`.
- α / gates now read from CONFIG (no retrain needed to change α or gates — only
  re-scoring; weights too).

### Rules transparency (`rm/js/category-rules.js`)
- `describe()` returns the rule tables (domainHints/subjectHints with
  pattern+category+weight; noiseSubjects/noiseSenders) read-only.

### Persistence + apply
- Route `email_archive/classifier_settings.json` →
  `userData/{uid}/emailArchive/classifierSettings` (covered by the existing
  `userData/{uid}/{document=**}` rule — no rules change).
- `email-review.js` `boot()`: `loadClassifierSettings()` →
  `EMAIL_CLASSIFIER.configure(...)` BEFORE training, so the Email page uses the
  user's weights.

### Page (`classifier-settings.html` + `classifier-settings.js`)
- Model status: examples, active/warming, live resubstitution accuracy (overall +
  per-class), vocabulary. Accuracy uses `explain()` so it isn't blanked by a high
  minExamples gate, and it recomputes (debounced) on every slider move.
- Feature-weight sliders (0–3×) for sender/domain/subject/body.
- Threshold sliders: min examples, min confidence, α, min/class.
- Explain panel: pick a training example or type sender/subject/snippet → ranked
  probability bars + gate verdict + a per-feature table (feature, group, weight,
  favored category, per-category training counts).
- Fallback rules tables (read-only, collapsible).
- Save (persist) / Reset (defaults).
- Nav: `Settings → Classifier Settings` (lab-member); API page card links to it.
