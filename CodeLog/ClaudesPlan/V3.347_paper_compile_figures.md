# V3.347 — Compile-service completion: figure fetch end-to-end

**Part of:** [FuturePlan 07 — Paper builder upgrade](../Feature%20requests/FuturePlan_07_paper_builder_upgrade.md) (Release 7 of 7 — final).

## What shipped

The Cloud Run compile service's figure fetch had been stubbed since
V3.231 ("TODO Phase 1.1") — journal PDFs compiled with missing-figure
boxes. Now:

- **Client** (`rm/js/paper-export-tex.js` `buildBundle`): collects
  `figureAssets: [{relpath: 'figures/<basename>', storagePath}]` from
  every figure block's `attrs.storage_path`, deduped by relpath, and
  returns it on the bundle. `rm/js/paper-export.js` includes it in the
  compile POST (the `paperCompile` proxy forwards `req.body` verbatim —
  no proxy change).
- **Service** (`functions/paper-compile/server.js`): downloads each
  asset from the Storage bucket into the workdir before Tectonic runs.
  Guards: 60-asset cap, `figures/<basename>`-only relpaths, the same
  path-traversal check as bundle files, `..`-free storagePaths, 30 MB
  per-file size cap (checked via metadata before download). A missing
  or oversized blob is a **warning** (missing-figure box in the PDF),
  never a hard failure; warnings ride back on the response and the
  export page shows them above the compile log.

## Scope correction (recorded for the roadmap)

The FuturePlan draft scoped "subfigure export via subcaption blocks"
here. That was wrong for the data model: `attrs.subfigures` are PANEL
LABELS (A/B/C) on a single composed image, not separate image files —
`[!fig:label:A]` already exports as `Fig.~\ref{label}\,(A)` and
resolves correctly. Composed single-image figures with panel letters in
the caption are what journals ask for anyway. No subcaption work needed.

## Deploy

The service change requires a Cloud Run redeploy (see
`functions/paper-compile/README.md`); the `paperCompile` Firebase
Function is untouched. Client changes ride the normal FTP deploy.

## Verification

Headless: figureAssets collection + dedup (two blocks sharing one
Storage blob → one asset). Server syntax-checked; the download loop can
only be exercised against the live bucket after redeploy — first real
compile with figures is the acceptance test. Full 9-template Tectonic
regression suite: 51/51 assertions pass.
