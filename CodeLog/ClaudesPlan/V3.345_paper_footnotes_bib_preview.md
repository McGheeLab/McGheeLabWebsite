# V3.345 — Footnotes, LaTeX add-ons, bibliography preview

**Part of:** [FuturePlan 07 — Paper builder upgrade](../Feature%20requests/FuturePlan_07_paper_builder_upgrade.md) (Release 5 of 7).

## What shipped

### Footnotes — inline `[^text]` token

Dialect-consistent with the other bracket tokens; no Yjs schema change.

- **Editor** (`paper-editor.js`): both scanners (full render +
  chips-only) render `[^text]` as a superscript **†** chip
  (`.pe-footnote-chip`, tooltip = note text, atomic `data-src`
  round-trip). `findFootnoteEnd` depth-tracks brackets so ONE level of
  nested tokens works — `[^see [@smith2024]]` is a footnote containing a
  citation. Click a chip → prompt-based editor over the chip's source
  byte range (`replaceParagraphRange`, same mechanism as citation
  chips); `_sanitizeFootnoteText` strips newlines and only strips
  brackets when unbalanced.
- **Toolbar** (`paper-equations.js`): "+ Note" button (prompt → insert
  at saved caret); `isBracketToken` accepts `^` so the token chips
  immediately.
- **Export** (`paper-export-tex.js`): `[^…]` runs FIRST of the token
  passes — the note text is processed by a recursive
  `paragraphTextToTex` call (own placeholder scope; running first keeps
  other passes' placeholders out of the note, where they would survive
  reinsert as garbage) and the resulting `\footnote{…}` is protected
  from the markdown passes. Nested-bracket regex
  `\[\^((?:[^\[\]\n]|\[[^\]\n]*\])+)\]`.

### New LaTeX add-ons (`ADDON_REGISTRY`)

`siunitx` (units; marked already-included for mebp-journal), `mhchem`
(`\ce{}` chemistry), `endfloat` (floats moved to end — classic
submission requirement; incompatible with ieee/ieeetran).

**Bug fix found here:** `window.PaperExportTex.ADDON_REGISTRY` had been
`undefined` since V3.231 — the public-surface object captured the
hoisted-but-unassigned `var` — so the export page's add-on toggle list
silently rendered empty. The registry is now attached after the var
initializes.

### Bibliography preview (References pill tab)

Third collapsible "Bibliography preview" in the References tab: cited
entries as numbered reference rows (`[1] Smith, Lee, et al. (2024).
Title. *Journal*`), ordered by first appearance via
`PaperCiteStyle.getNumber` (alphabetical fallback). Unresolved keys
render red with "add it to the lab library before export" — the export
lint's signal, live. `loadCitationIndex` entries now carry `authors[]`
(capped 6) + `authorCount` for the row formatting.
