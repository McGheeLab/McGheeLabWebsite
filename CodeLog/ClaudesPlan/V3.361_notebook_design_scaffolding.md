# V3.361 — Lab notebook experimental-design scaffolding (FuturePlan 10, Phase 3)

## Goal

Help students design better experiments: a plan scaffold on every
entry, templates so entries never start blank, an iteration loop for
experiment chains, and DOE runs that capture results.

## What shipped

- **🧭 Plan panel** — new always-present `plan` field
  (`notebookEmptyPlan`/`notebookHydratePlan` in `notebook-schemas.js`):
  hypothesis, independent/dependent variables (comma inputs → arrays),
  controls, success criteria. Renders as a `<details>` above the body —
  open + emphasized in `phase:plan`, collapsed summary chip once
  running. Index rows project `has_plan`. **Gentle nudge, no gate**:
  `onStartRun` with an empty hypothesis shows one hint toast.
- **Templates** — `New` becomes a split button (`openNewEntryMenu`):
  Blank · 5 built-ins (`NOTEBOOK_BUILTIN_TEMPLATES`: cell-culture day,
  imaging session, synthesis/prep, analysis day, meeting notes) ·
  personal templates (stored in a `_templates` doc in the existing
  `userData/{uid}/notebook` subcollection — zero rules impact) ·
  🧬 Clone last entry · 💾 Save current as template · 📥 Import.
  Sharing = export/import `.notebook-template.json`
  (`{kind:'notebook-template', template:{name, glyph, seed}}`). Seed
  `body_html` is sanitized at apply time (`applySeedToDoc` →
  `sanitizeHtml`) so imports can't smuggle markup. `onNewEntry(opts)`
  gains `{seed, slug}`.
- **↻ Next iteration** (`spawnNextIteration`, complete-phase footer) —
  new plan-phase entry carrying project, tags, plan, and the DOE design
  (factors + runs, results cleared); titles auto-increment
  (“… — run N”); `reference_links kind:'notebook'` written BOTH ways
  (the finished entry gets its forward link via a direct entry save).
  `?entry=<id>` deep-link handling added in `boot` so these links
  resolve.
- **DOE loop closure** — `design.run_results[]` (parallel array keyed by
  run index — immune to a factor literally named “result”), hydrated/
  padded/truncated in `notebookHydrate`. The in-entry design table
  gains editable result + note columns (`renderDesignRunsTable`), the
  header shows an n/N results progress chip, and ⬇ CSV export appends
  both columns.
