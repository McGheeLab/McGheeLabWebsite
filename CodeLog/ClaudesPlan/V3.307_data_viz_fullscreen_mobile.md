# V3.307 — Data Visualizations full-viewer: clean full-screen mobile layout

## Problems reported (phone)

1. The viewer's bottom-left flow-speed legend ("colorbar") was in the way — the
   bottom should be just the preset quick-links.
2. The viewer's bottom preset links were hidden because the SPA's persistent
   bottom tab bar (global nav) sat on top of them.

Measured on 390×844 inside the SPA before the fix: the iframe ran 48px under the
fixed `.bottom-tabs`; the `.viz-viewer-bar` was 148px tall and started at y=24
(partly behind the fixed banner).

## Fixes

### viewer3d.html (`max-width:820px`)
- `#legend{display:none}` — hide the flow-speed colorbar on mobile.
- `#presets` full-width at the bottom (`left:10px; right:10px; bottom:calc(10px +
  env(safe-area-inset-bottom,0))`), replacing the earlier bottom-right-beside-
  legend placement. The bottom row is now purely the preset quick-links.

### SPA (`app.js` + `styles.css`, `max-width:767px`)
- `app.js` sets `document.body.classList.toggle('data-viewer-env', isDataViewer)`
  on the `#/data/{vizId}` route (mirrors `apps-env`).
- `body.data-viewer-env .bottom-tabs`/`.group-sheet{ display:none }` — the
  full-screen viewer hides the SPA bottom nav so it can't cover the viewer's
  own bottom links. Escape routes remain: the "← All visualizations" back link
  and the top banner. The `#/data` gallery keeps its tabs (it doesn't get the
  class); leaving the route clears it.
- `.viz-viewer-section` becomes `position:fixed; top:var(--banner-height);
  inset-inline:0; bottom:0; display:flex; flex-direction:column` so it fills
  exactly from the banner bottom to the screen bottom regardless of the
  saved-views strip's presence. `.viz-viewer-bar` and `.viz-views-strip` are
  `flex:0 0 auto`; `.viz-frame-wrap` is `flex:1 1 auto; min-height:0` and the
  iframe fills it. Replaces the fragile `height: calc(100vh - banner - 150px)`.
- **`hidden`-attribute bug fix** (affected all widths): `.viz-save-controls`
  (`display:inline-flex`) and `.viz-views-strip` (`display:flex`) out-specified
  the UA `[hidden]{display:none}`, so the Save box and an empty strip rendered
  for logged-out visitors — this was what inflated the mobile bar to 148px.
  Added `.viz-save-controls[hidden], .viz-views-strip[hidden]{ display:none
  !important }`.
- Mobile viewer bar kept to one row: `.viz-back-link{flex:0 0 auto}` +
  `.viz-viewer-title{flex:1 1 0; min-width:0; overflow:hidden;
  text-overflow:ellipsis; white-space:nowrap}`. `flex-basis:0` (not `auto`)
  stops the title's content width from forcing a wrap. Bar 148px → 47px.

## Verification (headless Chrome, puppeteer-core)

- **Standalone viewer @390px**: legend `display:none`; presets full-width and at
  the bottom.
- **Full-viewer page @390/375px**: `body.data-viewer-env` set; `.bottom-tabs`
  hidden; bar flush under the banner (t=64), one row (47px); iframe fills from
  the bar bottom to the screen bottom (111→844 / 111→667); save controls hidden
  when logged out.
- **Gallery `#/data` @390px**: tabs still visible; no `data-viewer-env`. Leaving
  the viewer route clears the class and restores the tabs.
- **Desktop @1400px**: iframe 716px tall; save controls hidden when logged out —
  no regression.
