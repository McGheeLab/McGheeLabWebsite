## What was proven (and how)

A live browser can't run in this environment, so the acceptance test is a
representation-layer proof: the harness `test-grant-import.js` reconstructs the real
document's **exact structure** as a `PaperSchemas` tree and runs it through
`normalizeTree` + the tex section exporter. 26 assertions, all green:

- **Structure** — all 10 top-level sections present, in order, mapping to `custom`
  narrative sections with no coercion loss; all **41** real `N.M` / `N.M.K` subheadings
  survive as subheading blocks at their true depth (L2 subsections + L3
  sub-subsections); all **11** figures present as figure blocks with their real
  captions.
- **Export fidelity** — every section emits a heading; subheadings emit
  `\subsection`/`\subsubsection`; figures emit `figure` environments; `[@key]` citation
  clusters emit `\cite`; section order is preserved through export.
- **Manuscript exclusion** — biosketch / facilities / budget / budget_justification /
  data_management_plan / current_pending / mentoring_plan / synergistic_activities all
  skip on the manuscript template (compiled as separate attachments); `references` is
  correctly the manuscript's own bibliography, not an attachment.
- **Template alignment** — the shipped `nsf-career` starter (R1) seeds exactly these 10
  narrative sections, in order — so "New grant → NSF CAREER" gives the real skeleton on
  the first click.

The document's real outline is captured in the harness fixture (`DOC`) as an inspectable
reference: sections 1–10, every subheading (3.1.1 … 7.3.2), and Figures 1–11.

## The manual live check (Alex)

The representation is proven; putting the actual prose in the editor is normal
authoring, not something software can do headlessly. To confirm end-to-end in the
browser:

1. Papers → **+ New grant** (or Grants → + New grant) → type **Grant**, mechanism
   **NSF CAREER** → Create. The editor seeds the 10-section outline above.
2. Paste each section's prose; add subheadings (levels 2/3) matching the `N.M`/`N.M.K`
   structure; drop in Figures 1–11 with captions; cite with `[@key]` (numeric-bracket
   family resolves them to `[1]`, `[3, 6]`, …).
3. **📎 Grant Docs** pill → the NSF-CAREER checklist tracks every required document;
   Facilities/Biosketch pull from the reusable library or attach the final PDF.
4. Document view renders the full hierarchy + figures + resolved citations; compile
   produces the PDF. (Exact NSF PAPPG margins/fonts are a later, per-target refinement —
   content fidelity, not pixel layout, is this round's bar.)
