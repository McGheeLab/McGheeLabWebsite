# V3.870 — The app crashed at launch on iOS 27: adopt the UIScene lifecycle

**Date:** 2026-10-23
**Alex:** *"here is gabes crash log"* (after "on gabes phone, the app doesnt even open")

## The cause (from Gabe's crash log)
- iPhone 16 Plus (`iPhone17,4`), **iOS 27.0.1**, build 18. The app dies 66 ms after launch on the main thread:
  `EXC_BREAKPOINT (SIGTRAP)` in `___UIApplicationEvaluateRuntimeIssueForNoSceneLifecycleAdoption_block_invoke`, called from
  `-[UIApplication workspace:didCreateScene:withTransitionContext:completion:]`. No app frame — UIKit itself stops the app.
- Apple announced at WWDC25 that, in the release after iOS 26, apps built with the latest SDK must adopt the **UIScene
  lifecycle** or they will not launch. Ourlab still uses the app-delegate lifecycle (`UIMainStoryboardFile = Main`, no
  `UIApplicationSceneManifest`), and it is built with Xcode 27.1 (iOS 27.1 SDK). So every build made with the iOS 27 SDK
  crashes at launch on every iOS 27 device. Alex's and Cason's phones (iOS 26) only log a warning, and the simulator runtime
  here is iOS 26.5, so nothing reproduced. Build 16 (an older SDK, presumably) was exempt — that is why "the last update"
  broke it.
- None of the V3.865 / V3.867 crash reporting can see this: the app dies before any page loads. The iPhone's own Analytics
  log was the only witness. (The "page dies on his data" theory of V3.867 was wrong.)

## Fix
- `ios/App/App/SceneDelegate.swift` (new, added to the App target): a `UIWindowSceneDelegate` whose window comes from
  `Main.storyboard` (so `TabShellViewController` stays the root exactly as before). URL and universal-link opens — which iOS
  now delivers to the scene, not the app delegate — are forwarded to Capacitor's `ApplicationDelegateProxy`, as
  `AppDelegate` did (cold-launch ones too, from the connection options).
- `Info.plist`: `UIApplicationSceneManifest` (one scene, `UISceneDelegateClassName = $(PRODUCT_MODULE_NAME).SceneDelegate`,
  `UISceneStoryboardFile = Main`); `UIMainStoryboardFile` removed (the scene's storyboard replaces it).
- `AppDelegate`: `application(_:configurationForConnecting:options:)` returns the "Default Configuration".
- `OurlabDiagnostics` also listens for the scene notifications (`UIScene.didActivate` / `willDeactivate` /
  `didEnterBackground`) next to the application ones, so the unclean-exit marker keeps working under scenes.

## Testing

- iOS 26.5 simulator: the fixed build opens to the sign-in screen, the tabs load, the marker reads `foreground`.
- Then TestFlight build 21 (`--minor`, native change).
