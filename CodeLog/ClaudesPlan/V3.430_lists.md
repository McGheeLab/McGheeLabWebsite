# V3.430 — Lists (itemize / enumerate) — R1 of the Lists/Appendices/Section-refs program

> Alex asked what the paper builder is missing; picked Lists, Appendices, and Section
> cross-references. This is release 1: **lists**. The `list` block kind was declared in the
> schema but unimplemented — the editor showed "List blocks ship in a later phase" and
> `listToTex` emitted a `% TODO` comment. Now you can author bullet/numbered lists.

## Model

The `list` block's `body` Y.Text holds **one item per line**; **2 leading spaces per level**
nest; `attrs.list_type` ∈ `bullet` (itemize) | `number` (enumerate). Rides the existing
block machinery (body + scalar attrs, round-tripped since V3.429) with no new persistence.
An imported block's `attrs.raw_tex` is still honored when the body is empty.

## Changes

- **`rm/js/paper-schemas.js`** — `newList({list_type,text})` factory (exported); `list`
  already in `PAPER_BLOCK_KINDS`.
- **`rm/js/paper-editor.js`** — `insertBlockAt` `case 'list'` seeds `attrs.list_type`;
  inserter-menu **"List"** item; `'list'` added to the cite scan (`getCitedKeysInPaper`).
- **`rm/js/paper-blocks.js`** — `renderList` (registered in `renderYBlock`): toolbar with
  drag/reorder/delete + a **Bulleted/Numbered** toggle, and a `body`-bound contenteditable
  that shows raw one-item-per-line text while focused and a rendered `<ul>`/`<ol>` on blur
  (via the `renderHtml` callback). Helpers `parseListItems` + `listItemsToHtml`.
- **`rm/js/paper-doc-view.js`** — block-walk `blk.kind==='list'` branch → `_listHtml(body,
  list_type)` builds a nested `<ul>`/`<ol>` (`.pdv-list`), pushed as one `col` flow item;
  `'.pdv-list'` added to `SPLIT_GUARD_SEL` so a list never splits mid-item across a page.
- **`rm/js/paper-export-tex.js`** — real `listToTex(block, template)`: parses the body into
  nested `\begin{itemize|enumerate}` … `\item` … (each item through `paragraphTextToTex` for
  cites/math/markdown); empty body → `raw_tex` passthrough or `''`. Dispatch passes the
  template; `'list'` added to the export cite scan (`_collectCitedKeys`).
- **CSS** — `.pe-block-list`/`.pe-list-body` (editor; `white-space:pre-wrap` for raw editing,
  rendered `<ul>/<ol>` on blur); `.pdv-list`/`.pdv-list-block` + paragraph-slate Layout tint
  (doc view).
