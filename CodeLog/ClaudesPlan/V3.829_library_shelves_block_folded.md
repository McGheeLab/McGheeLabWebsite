Alex: *"the shelves block should be collapsed by default"*.

## 1. A default for a registered section

`LIBRARY_COLLAPSE.register(el, { …, defaultCollapsed: true })` marks the id as folded-by-default; `isCollapsed(id)`
returns the stored choice when there is one, else that default. The header toggle now stores an explicit
`true`/`false` (it used to delete the key on open, which would re-fold a default-folded section on the next visit).
The Shelves registration in `library.js` passes `defaultCollapsed: true`. Everything else registered (Add papers,
All papers) keeps its open default.

## 2. Nothing asked for is hidden by the fold

The folded header carries what is inside: `library-groups.js` `render()` sets the `lib-shelf` count to
"3 to read · 5 new in 30 days" (readings `toRead` from `LIBRARY_READINGS.shelves()`, `LIBRARY_RECENT.count30()`),
so the counts Alex asked for in V3.827 read from the closed block.
