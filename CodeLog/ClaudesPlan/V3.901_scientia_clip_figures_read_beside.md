# V3.901 — Scientia: read a paper beside the note, and clip its figures onto the canvas

## Goal

On a Scientia note (desktop, iPad and web) a PDF card can be **read beside the note**: the paper takes exactly half the
screen, full height, untouched by the canvas's pan and zoom, while the note stays live in the other half. Reading,
highlighting and **clipping figures** all happen there (and on the card and in the maximised view too): point at a
figure and a "＋ Figure 2" badge appears — one click and the figure lands on the canvas beside the paper as an image
component, re-rendered from the PDF, titled with its label, its caption from the paper below it, and a "from …, p. 4"
line that takes you back to the page.

Alex (2026-10-24): "we need to be able to clip out figures from a paper into an image item on the canvas" … "we should
be able to hold a paper in a split view within the card still, but it is locked into half the page. this is for reading
the paper, making highlights, and clipping figures when necessary so we need the reader to look and feel very nice."

Defaults taken from the code, not asked: the image item is Gabe's figure component (`FIG`, 1×1); detection is RM's
`PAGE_LAYOUT.figureRegions` (V3.828/831, 99 % on Alex's labels) because V3.616 showed nobody finds a snip button that
isn't on the page; the image is re-rendered from the PDF (~1600 px wide) as RM's canvases do; "Add as text" is left out
(Scientia's quotes do it); clipping works in the maximised view too (same page slots).

## The constraint that shapes it

- **RM already has this** (notebook-canvas.js / notebook-board.js / figure-board-canvas.js: dashed figure boxes +
  marquee → "Add as figure"). The detector is the reusable part; it is pure geometry (`rm/js/page-layout.js`, no DOM,
  only `window.PAGE_LAYOUT`), so it can run inside Scientia. It is **copied by the build**, never forked:
  `scripts/scientia_build.py` refreshes `scientia/vendor/page-layout.js` from `rm/js/page-layout.js` (Gabe's
  `build.py` inlines `vendor/*.js` into both apps) and `--check` fails when the copy drifts.
- **Scientia runs pdf.js 3.11.174, RM 4.10.38.** `collectGraphics` reads `constructPath`'s bounding box as
  `[minX, minY, maxX, maxY]` (4.x); 3.11 writes `[minX, maxX, minY, maxY]`. Scientia passes an adapted operator list
  (indices 1 and 2 swapped when `pdfjsLib.version` is 3.x) — RM's file stays unchanged. Text items are built from
  `getTextContent` exactly as the offline extractor (`ResearchManagement/data/figure-training/extract-feat.mjs`) does,
  `segmentPage` stamps columns, then `figureRegions(items, {pageWidth, pageHeight, graphics, inkProbe, pageNum})` with
  an ink probe from a small render of the page.
- **The maximised view's keys belong to it** (Esc closes, ← → page, captured on `document`). Docked, the note is being
  typed in, so the reader beside is its own overlay with its own keys (← → only while the pointer is over it, Esc only
  ends clip mode), built the way `DOCS.max` builds one and handed to `MXHL.open` for the highlight panel.
- `PDFW.full` (the maximised view and the phone) draws every page once and never gives one back: a long paper read
  beside the note would hold hundreds of MB. It gains the card's release (pages far off screen are given back and
  redrawn on return) and a zoom factor (`pane.zoom`, default 1, so the phone is unchanged).

## Approach, file by file

**`scientia/src/13zza-clip.js`** (new, Gabe's side) — `CLIP`
- `regions(m, n)` → cached `Promise<[{x, y, w, h, label}]>` in the page's natural coordinates (scale 1, top-left
  origin), per media id + page; empty when `PAGE_LAYOUT` is missing (a build without the copy: the drag box still works).
- Hover: one delegated `pointermove` (rAF) on `.pdfw .pdf-slot`; the region under the pointer gets a dashed outline and
  a "＋ Figure 2" badge in a `.clip-layer` laid over the page canvas (percent units, so zoom-proof; `pointer-events`
  only on the badge, so text selection is untouched). Read-only panes (`travel`) show nothing.
- Clip mode: a scissors button added to every PDF bar (`PDFW.bar` wrapped; not read-only); `.pdfw.clipping` on the
  card / the reader. All figures badged, the layer takes the pointer (crosshair), a drag draws a box, release clips it.
  Esc (captured first) or the button ends it.
- `render(m, n, r)`: one viewport offset to the region (`getViewport({scale, offsetX, offsetY})`), white background,
  4 pt padding, scale 1.5–4 for ~1600 px wide (≤ 4096 px), WebP 0.92 (PNG where the browser can't).
- `take(srcId, n, r, label, caption)`: `DB.beginGroup('clip')`, `MEDIA.add(file)`, `FIG.create` 1×1 with the media,
  `label` ("Figure 2" / "Clip"), `body` = the paper's caption text, `clip { src, media, page, rect (0–1), label, file }`;
  placed in the column right of the card (`x + w + 56`), below whatever is already there; revealed in the note.
- The source line: `DocView.box` wrapped (as 13zw does for quotes) — `button.q-from` "from <b>paper</b>, p. 4" →
  `CLIP.show(...)`: the reader beside / maximised view if it holds the paper, else the card; scrolls to the page and
  flashes an outline of the region.

**`scientia/src/13zzb-reader.js`** (new, Gabe's side) — `RDOCK`, "Read beside"
- A book button on the card's bar and "◧ Beside" on the maximised bar. The overlay (`.embed-max.dk-max.rd-docked`) is
  placed in `#app`'s grid (`body.rd-on` → two columns, header across both, `#view` in the other half) and canvases are
  re-applied; `MXHL.open` gives it the highlight panel (a drawer in the half width, toggled from the bar).
- Bar: title · page "3 / 18" with ‹ › · zoom − % + and Fit · scissors (from `PDFW.bar`) · Highlights · ⇄ side ·
  ⤢ full screen · Close. Ctrl/⌘-wheel zooms; ← → page while the pointer is over it; Esc ends clip mode only.
- Stays with its note: `_ls rdock:<docId>` = `{id, side, zoom}` — leaving the note closes it, coming back reopens it;
  Close forgets it. The card on the canvas draws "Reading beside" (no pages: one rendering of the file at a time).
- Quotes made in it land beside the card as before (13zw) and are revealed in the note half.
- Not on the phone layout.

**`scientia/src/13zk-docs.js`** (Gabe's) — `PDFW.full`: page width × `pane.zoom`; one observer draws pages within
1200 px and gives back the ones beyond (`PDFW.releaseSlot`), redrawn when they return.

**`scientia/src/21-sync.css`** — sections for 13zza (layer, outline, badge, marquee, clipping cursor, source line) and
13zzb (the docked grid, the reader's page column — tinted desk, white pages with soft shadow, page numbers, the drawer,
the "Reading beside" card).

**`scientia/src/12b-wires.js`** (Gabe's) — each wire's path, end dot and lifted copy carry `data-w` (its id), so one wire
can be faded or raised. **`scientia/src/04-model.js`** (Gabe's) — `M.wire` reads `b.stamp && b.stamp.sessionId`.

**`rm/scientia/lab-mode.js` §16** (ours) — `CLIP.read` → the lab's `equationOcr` (probe on first use, the signed-in
user's token, `{ image }` → `{ latex }`), as `rm/js/equation-capture.js` calls it. `LAB.version` V3.901.

**`scientia/src/01-util.js`** — `BUILD` '2026-10-24 · Read beside the note, clip figures and equations'.

**`scripts/scientia_build.py`** — `VENDOR_COPY` = `rm/js/page-layout.js` and `rm/js/page-regions.js` →
`scientia/vendor/`, refreshed before `build.py` runs; `--check` reports a stale copy.

**`CodeLog/features.json`** — `scientia.pdf` (13zk-docs, 13zz-maxhl, 13zza-clip, 13zzb-reader, the vendor copy):
`related` rm.paper-reader (the detector), scientia.media (the figure component); `distinct_from` rm.paper-reader /
rm.figure-board with the reason (a PDF that lives on a note; its highlights are the note's quote components and its clips
land on that note's canvas).

**Tests** — `scripts/tests/fixtures/pdf-figure.pdf` (generated: two-column prose, a drawn plot with "Figure 1." and a
full-width "Figure 2." with its caption); the lab-mode harness §19 (badge on hover, one click → a figure component with
page / label / caption / source line, clip mode + drag box, Esc, source line scrolls back) and §20 (reader beside: half
the width, note still usable, page indicator, zoom, highlight from it, card says "Reading beside", reopen after leaving
the note, close). Detection under Scientia's pdf.js checked against Alex's labelled set (a scratch page running the same
code on the set-1 PDFs, scored like `score-figs.mjs`).

## Data

Nothing new in Firestore, rules, indexes or functions. A clip is a `figure` block (existing kind) with a `clip` field
(ignored by older builds: they show a plain image panel) and one `media` record through `MEDIA.add` — the notebook
folder on the desktop, the cloud hub on the web (`api/media`, unchanged).

## Out of scope

"Add as text" (quotes do it) · saving clips into RM's reader annotations or figure board · the phone layout · a reader
for HTML pages · removing the retired lab-mode §14 (its own small change).

## Release

One branch `scientia/clip-figures`, one PR, Gabe reviews and merges. The web picks it up on the next end-of-turn
deploy from main (rebuild of `rm/scientia/scientia.html`); `/rm/` is network-first in `sw.js`, so no cache bump is
needed for freshness (bump it with the merge anyway, per the ritual). No Firebase deploys.

## Rollback

Revert the merge commit; the next deploy rebuilds the web app without it. Clips already made stay as ordinary image
panels (their `clip` field is ignored).

## Found while building

- **pdf.js 3.11's path bounds** (`[minX, maxX, minY, maxY]`) fed to `collectGraphics` (written for 4.10's `[minX, minY,
  maxX, maxY]`): on Alex's labels, **63/79 found, 90 % precise, IoU 0.90** without the reorder; **78/79, 99 %, 0.94** with
  it — identical to RM's own 4.10 run (same miss: brassard p5 duplicate truth; same false +: bennett p3 merged truth).
- **Equations** on the same labels (150 boxes, IoU ≥ 0.5): 65 found, 50 % precise, IoU 0.69 — RM's equation classes were
  scored as blocks, not boxes. Badges are a convenience; the drawn box → Equation covers the rest.
- **Gabe's failed-card fix, completed**: a card whose file can't open yet (the web build before its file list arrives:
  `MEDIA.url` is unmapped) now tries again at 1.5 s / 3 s / 4.5 s, and a successful retry puts the page slots back in place of
  the error (before, they stayed detached and nothing drew).
- **`M.wire` and blocks without `stamp`**: it read `b.stamp.sessionId`; a block written straight to the store (the lab's
  project builder, test fixtures) has none and the wire threw after saving. Guarded.

## Verification

1. Open a note with a PDF card. Point at a figure → "＋ Figure N" appears; click → an image panel appears beside the
   card titled "Figure N" with the paper's caption, "from …, p. N" under it; clicking that scrolls the card to the page.
2. Scissors → every figure outlined; drag a box over a table → "Clip" panel; Esc ends clip mode.
3. Book button → the paper fills the left half, full height; the note works in the right half; zoom, page through,
   highlight a sentence (it appears in the Highlights drawer and as a quote beside the card); clip a figure from the
   reader → it appears beside the card and the note pans to it. ⇄ moves the paper right. Leave the note and come back →
   the paper is beside it again. Close → the card draws its pages again.
4. Maximise a PDF → badges and scissors work there too; ◧ Beside docks it.
