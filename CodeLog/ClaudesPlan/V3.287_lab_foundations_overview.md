# V3.287 — Lab Foundations overview module

## Goal

Create a beginner-facing **overview** for a series of topic-organized, lab-based
learning tracks ("Lab Foundations"). It's the one-stop entry point that orients
a new student: what's available, how the series works, and a direct jump into
the modules for the track their project needs. The first live track is
**Hydrogel Mechanics** (the four TFM modules); other tracks are scaffolded as
"coming soon".

## Context / why this shape

- Modules live as standalone HTML pages under `modules/{folder}/` and are listed
  in `modules/manifest.json` (grouped by folder). The class-builder admin UI
  reads the manifest so an admin can attach any module file to a Firestore class
  (`schedules/{id}.modules[]`).
- The SPA module viewer (`renderModuleViewer` / `wireModuleViewer` in
  `class-builder.js`) loads a module in a sandboxed iframe and derives prev/next
  from the class's `modules[]` array.
- The user already created the Firestore class for this series and named it
  **Lab Foundations**. So the deliverable is the overview content itself — a
  self-contained module they attach as the first lesson.

Decision: ship the overview as a normal learning module (`modules/foundations/overview.html`)
rather than a new SPA route. This reuses the existing module/manifest/class
plumbing, needs no router or nav changes, and drops straight into the class the
user already built.

## Files

- **`modules/foundations/overview.html`** (new) — the overview landing. Dark-theme
  page matching `modules/_template.html` conventions: shared `module-header.css` +
  `module-header.js` + Firebase so it renders class prev/next when opened with
  `?class=`. Sections: hero (one-stop-shop framing), "How to use this series"
  (3 steps), "Topic tracks" grid (Hydrogel Mechanics = Available with 4 linked
  modules; Microscopy Basics / Cell Culture & Sample Prep / Data Analysis &
  Modeling = Coming soon), closing note.
- **`modules/manifest.json`** — new `foundations` folder section (placed first),
  one file `overview.html`.

## Key decisions

- **Class-aware module links.** A small inline script rewrites each track link so
  the student stays in their class flow:
  - Resolve `classId` from the page's own `?class=` param, else (inside the SPA
    iframe) from the parent hash `#/classes/{id}/...`.
  - In the iframe, top-navigation is sandboxed off, so links open in a new tab
    carrying `?class=` (the target module then renders its own correct
    prev/next header). Opened standalone, links navigate in place with `?class=`
    preserved. With no class context, links fall back to the bare standalone
    module path (`../tfm/<file>`).
- **Coming-soon tracks are placeholders** — named to sketch the intended series
  shape; rename/repopulate as content lands. Only Hydrogel Mechanics links to
  real files today.
