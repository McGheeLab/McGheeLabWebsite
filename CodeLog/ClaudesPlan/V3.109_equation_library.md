# V3.109 — Paper builder: equation library + right-click insert + numbering

## Goal

Fourth and final wishlist item from `rm/wishlist.md` "paper builder".
Two coupled needs:

1. **Build equations once, use them anywhere.** The user wants a
   dedicated *Equations* panel where they author and manage all the
   equations the paper uses. Numbered (display) equations get inserted
   between paragraphs as block sections; inline equations get inserted
   into paragraph text via right-click → pick → done.
2. **Numbering + cross-references.** Display-mode equations that the
   user marks "numbered" get sequential numbers in document order.
   Anywhere in the prose, a token can reference a numbered equation by
   its label and render as `Eq. <n>` (with the number tracking the
   document order live as the user reorders blocks).

The current state (after V3.107) has equation BLOCKS that can be
display or inline, but no central library, no right-click affordance,
no numbering, and no references. V3.109 adds all four.

## Approach

### Two equation surfaces, intentionally separate

- **Inline equations** live in a paper-level **library**
  (`paperMap.get('equation_library')`, a `Y.Array<Y.Map>` of small
  reusable equations). They are *not* paragraph children. They are
  inserted into prose via a `[!eqi:<id>]` token; the renderer expands
  the token to inline KaTeX.
- **Display/numbered equations** stay as the existing equation
  **block** kind in `sections.children` (no schema migration). New
  attrs: `numbered: bool` and `label: string`. Numbering is a
  doc-order traversal computed lazily.

The split is deliberate: inline equations are usually short and reused
across the paper (`E = mc^2`, `\sigma = F/A`); they make sense as a
library. Numbered equations are document-anchored and ordering-aware;
they belong in the document tree.

### Schema

```
paperMap (Y.Map):
  meta: { title: Y.Text }
  sections: Y.Array<Y.Map> (existing)
  equation_library: Y.Array<Y.Map>           NEW (V3.109)
    each item: {
      id: string,            // 'eq-' shortId
      name: Y.Text,           // human label, e.g. "Hooke's law"
      latex: Y.Text,          // source, e.g. "F = kx"
    }
```

Existing equation block `attrs` extended:

```
attrs: Y.Map {
  display: bool,   // existing
  numbered: bool,   // NEW (V3.109) — when true && display, gets number
  label: string,    // NEW (V3.109) — e.g. "eq:hookeslaw"
}
```

### Doc-order numbering

A small walker `getNumberedEquations(paperMap)` traverses
`sections → children` and returns an array of numbered equation
blocks in document order with their assigned 1-based number. The
walker is called at:
- Paragraph render time (resolving `[!eqr:<label>]` tokens to `Eq. <n>`)
- Equation block render time (rendering the number badge on the block
  itself)
- Equations panel refresh (showing the list with numbers)

Cache: paperMap subscribes once to `observeDeep` and bumps a counter
on any change; renderers compare counters to avoid recomputing.

### Equations panel

New topbar button `📐 Equations` toggles a slide-out panel anchored
at the right edge (mirrors the comments pane shape). Two sections:

- **Inline library** — full CRUD on `equation_library` entries.
  + New, edit name, edit LaTeX, delete. KaTeX preview per entry.
- **Numbered equations** — read-only list of every block where
  `attrs.numbered === true && attrs.display === true`, in document
  order, with their assigned number. Click → scrolls editor to the
  block and flashes it.

### Right-click context menu

`contextmenu` event on paragraph body opens a custom menu:

- **Insert inline equation** → picker over inline-library entries.
  Pick → inserts `[!eqi:<id>]` at the caret position.
- **Insert equation reference** → picker over numbered equations.
  Pick → inserts `[!eqr:<label>]` at the caret position.
- "Cancel" returns the user to the native menu via Escape (the custom
  menu autocloses on Escape / outside-click).

The picker is a small popover anchored at the click point; KaTeX
preview per row, type-to-filter input.

### New paragraph tokens

| Source | Renders as | LaTeX |
|---|---|---|
| `[!eqi:<id>]` | inline KaTeX of `equation_library[<id>].latex` | `\(<latex>\)` |
| `[!eqr:<label>]` | `Eq. <n>` chip (n = doc-order number) | `\eqref{<label>}` |

Both are added to the existing scanner in `renderParagraphHtml`.
Unknown ids / labels render as a faded `[?eq]` chip so the writer
notices broken references.

### LaTeX export

`paragraphTextToTex` resolves `[!eqi:<id>]` → `\(<latex>\)` and
`[!eqr:<label>]` → `\eqref{<label>}`. `equationToTex` emits:

| Block state | LaTeX |
|---|---|
| `display=true && numbered=true` | `\begin{equation}\label{<label>}<src>\end{equation}` |
| `display=true && numbered=false` | `\[<src>\]` |
| `display=false` | `\(<src>\)` |
| `body` empty + legacy `attrs.raw_tex` | `attrs.raw_tex` (unchanged) |

The label defaults to `eq:<block.id>` when `attrs.label` is empty so
the LaTeX still compiles.

```bash

# open http://localhost:8000/rm/pages/paper-builder.html?paper=<some-paper>
```

2. In Inline library section, click `+ New inline`. Type name "alpha", LaTeX `\alpha = 1/137`. KaTeX preview renders.
3. In a paragraph body, right-click → "Insert inline equation" → pick `alpha`. Token `[!eqi:eq-…]` inserts at caret. Blur → renders as inline KaTeX α = 1/137.
4. Add a `+ Equation` block in any section. Set Display mode, toggle "Numbered" on, label = "hookeslaw", LaTeX `F = kx`. Block shows `Eq. 1` badge.
5. In a paragraph, right-click → "Insert equation reference" → pick "hookeslaw". Token `[!eqr:hookeslaw]` inserts. Blur → renders as `Eq. 1` chip.
6. Add a SECOND numbered equation. The `[!eqr:hookeslaw]` reference still says `Eq. 1`; the new one says `Eq. 2`.
7. Reorder sections so the second numbered equation appears first → numbers swap, references update live.
8. Click an Equations-panel "Numbered equations" row → editor scrolls to that block and flashes it.
9. Edit a library entry's LaTeX from the panel → all `[!eqi:<id>]` references in the document update on next blur.
10. Click Export LaTeX. Verify:
    - `\begin{equation}\label{eq:hookeslaw}F = kx\end{equation}` for the numbered block.
    - `\eqref{eq:hookeslaw}` where the user inserted a reference token.
    - `\(\alpha = 1/137\)` where the user inserted an inline-library token.
11. Verify the Y.Text wire format is unchanged for regular paragraphs (no `[!eqi:]` tokens are written for non-equation prose).
12. Hard reload to evict `mcgheelab-shell-v82`; SW upgrades to v83.

## Out of scope

- **Drag-to-insert from panel.** User can't drag a library entry into a paragraph; right-click is enough. Adding drag is purely additive and lands in a later minor.
- **Equation editor with WYSIWYG.** LaTeX source remains the input format. No mathlive / mathquill integration.
- **Per-equation comments.** Library entries don't get the comments thread that block kinds do (comments live on blocks).
- **Inline-library type filter.** Library entries are simple inline equations; if the user wants a numbered-but-also-reusable equation, they author a numbered block in the doc and reference it. The library is the *inline-only* surface.
