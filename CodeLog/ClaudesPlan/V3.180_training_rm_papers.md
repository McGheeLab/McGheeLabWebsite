# V3.180 — Training: Papers in RM

> Status: PLANNED — not yet built. Infrastructure landed in V3.177.

## Goal

The library + paper-builder + PMR-paper-writing-block flow as one
training. Where V3.163 (paper writing) covers <em>how to write a paper</em>
in the abstract, V3.180 covers <em>how to do it specifically in the lab's
infrastructure</em>.

## Format

Lecture-style with two interactive widgets:

1. **Library annotation walkthrough** — a stripped-down paper viewer
   with a few sample highlights + comments. The user practices adding
   a highlight, replying to a comment, and the V3.158 multi-pick
   citation popover.
2. **Paper-builder citation drop simulator** — the user types text
   into a mock editor; pressing Cmd+K opens the citation picker (same
   layout as the real paper-builder); pick 1+ citations and they land
   inline as `[@key]` tokens.

## Sections (10)

1. The library as the lab's reading list + annotation surface.
2. Adding a paper (DOI / PDF / manual entry).
3. Annotations — highlights, threaded comments, sync across readers.
4. Linking a paper to a project or draft.
5. The paper builder — drafts vs library entries, schemas, Y.text
   real-time collaboration.
6. Adding citations from the library (Cmd+K, multi-pick V3.157,
   click-an-existing-chip-to-edit V3.157).
7. Figures + uploads + paste-image.
8. The PMR paper-writing block (V3.159) — how drafts surface in your
   PMR automatically.
9. Status pills (drafting / review / submitted / in_revision /
   published).
10. Capstone — start a draft, drop two citations, attach a figure.
