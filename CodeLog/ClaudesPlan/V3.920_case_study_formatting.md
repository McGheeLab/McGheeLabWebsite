# V3.920 — Case study: every construct a paper uses, set cleanly in the page view and the PDF

**Asked (Alex, 2026-10-26):** "there still seems to be issues on some of the pages, use this paper as a case study to
make sure all possible things we do in a paper are well formatted. add figures and equations and anything you want
here and there and of different size to ensure the results are really clean always. basically we need to ensure we
can still quickly reproduce journal paper quality drafts."

## The case study

`PaperLab-corpus/_examples/casestudy[-TPL]` (built by the scratchpad script `tools/make_casestudy.py [template]`; the
manuscript is unpublished, so it lives outside every repo): the ME3B HardwareX manuscript (all nine sections from
`MEBP-Paper/hardwarex`, converted to builder blocks: run-in heads, nested lists, quote-lists, the specification
table, the design-files table, the 33-row longtable BOM) plus everything a paper uses, placed where it belongs:
six figures (a page-wide three-panel figure, a two-panel page-wide figure, a column figure, a two-panel column
figure, a 0.6 and a 0.7 `\linewidth` figure), panel references (`[!fig:system:C]`), numbered displays (a fraction,
a long multi-term flow equation, an `aligned` pair), an unnumbered display, inline math, footnotes with math,
citations in groups and ranges, two built tables (one with math in headers), equation / table / figure
cross-references, a nested list, Discussion / Conclusions / Acknowledgements and 24 references. Compiled and
previewed under ACS (spec look, two columns), PLOS (spec look, one column) and IEEE (the journal's own class).

## Defects found and fixed

| What | Where it showed | Fix |
|---|---|---|
| Display equations drawn 1.5 lines too high, over the text above | every look with displays | `_setDisplays` measured KaTeX's baseline with a marker appended after `.katex-html` (a block in display mode: the marker fell to a new line). Marker now inside the first `.base`, measured after `.pdv-eq-tex` applies. |
| A long display ran into its number | Eq. (3) | amsmath's rule: shift the display left toward the number, or set the number on its own line when it still does not fit. |
| "(Fig. ??)" for a panel reference | `[!fig:system:C]` | `paragraphTextToTex` only split a panel off a `fig:`-prefixed label; the bundle format's unprefixed label compiled to `\ref{system:C}`. |
| "Plunger seat (0)" — math inside the paper's own `\textbf{…}` lost | design-files run-in heads | placeholders nested inside a protected command were reinserted in one pass; now until none remain. |
| A list item opening with "[DATA: …]" hung into the margin as its label | build-instruction lists | `\item {}[…`. |
| Lists moved whole to the next column, leaving the foot empty; numbering restarted | every long list | `_splitList`: break between items or between typeset lines of an item; `start` carries the numbering; a cut item continues without a second marker. |
| Lists looked loose and the PDF and page view disagreed | all spec looks | `\@listi`/`\@listii` compact (\topsep 3bp, \itemsep 1bp, no \partopsep), and the page view's CSS reads the same numbers (`look.list` overrides). IEEE: its class's 2pt / 0 and "1)" labels. |
| Footnote mark in one column, note across the page foot; the note's height not reserved | two-column looks | `\footnote` in a two-column class goes to the foot of the mark's column: per-column notes in the packer (`c.notes`), reserved when the item is placed (or its first part when split), mounted above a bottom float; notes measured in a footnote box at column width; `\footnotesize`, 9pt `\skip\footins`, 40% rule. |
| Footnote text showed "(click to edit)" and raw `$…$` | footnotes | read the note from the chip's `[^…]` source and set it as prose. |
| A waiting page-wide table held back Figure 1 (and the reverse) | page 1 | the float queue keeps order per type (figures, tables), as LaTeX does. |
| A run-in heading stood alone above a float | "3.1 Overview" | a float does not start a paragraph: the run-in waits for the paragraph after it. |
| A four-column numeric table went page-wide because its header set on one line | Table 2 | natural width measured on the body rows (a header wraps, as journals set one) — both `\rmTnat` and `_tableNaturalW`. |
| "(µ m)" broke inside table cells | header cells | a formula and the text touching it are one unbreakable unit in cells. |
| A `p{}` column ragged in the page view, justified in the PDF | imported tables | `parseTabular().justify`; such cells are typeset by Knuth–Plass. |
| A source newline in a table cell | imported cells | a space, as in prose (V3.917). |
| Reference numbers in the page view disagreed with the PDF; `\cite{}` in the paper's own LaTeX never cited | References | `PaperCiteStyle` and `getCitedKeysInPaper` read `\cite{…}` too, and list blocks and imported tables. |
| References "1." / "[1]" where the look prints "(1)"; ACS entries in the generic format | References | the look's label; achemso's format for ACS. |
| A missing reference printed "% @misc … data/items.json …" in the PDF | References | a real entry with "Reference not in the lab library: KEY — add it before submission", same words in the page view. |
| An imported table outside `table` floated in the page view, but sits in the text in the PDF | PLOS | in one column, an imported `tabular` / `longtable` is in-flow; a longtable breaks between rows across pages (`_splitTableRows`, also when it is taller than a fresh page). |
| A page of floats stacked them in the middle | float pages | `\@fpsep` 2fil vs 1fil: spread (`space-around`). |
| IEEE tables at body size in the page view (`\footnotesize` in the PDF), "TABLE 2." instead of "TABLE II" + small-caps caption | IEEE | `look.table` (font + size), `caption.table_style: 'ieee'`, `table_numbering: 'Roman'` (captions, "(continued)", reference chips); `\rmTable` measures at the class's table size. |

## Results

Page counts, page view vs PDF: ACS 14 vs 14 at the start → 13 / 13; PLOS 26 / 25 → 25 / 25; IEEE 15 / 15. No overlaps,
no hanging text, every reference resolves. The 8 reference papers: page counts unchanged, NSF 16/16 page starts.

Known, not changed: TeX's page builder sometimes ends a column a line earlier than the page view to avoid a column
ending on a hyphen (`\brokenpenalty`) and stretches the column instead, so later columns can start a line or two
apart; IEEE (the journal's own class) is approximated a few lines either way.
