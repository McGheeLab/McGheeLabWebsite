# V3.365 — Association pills + status selector + derived active/inactive lifecycle

**FuturePlan 13, Release 1** (see `CodeLog/Feature requests/FuturePlan_13_associations_lab_themes.md`).

## Goal

Make `meta.library.linked_drafts` (the journal-paper ↔ draft association,
V3.352) a first-class, manageable UI everywhere, with a lifecycle: pills
on the reader sidebar and the library list, quick add/remove, a `draft:`
search token + association sort, and a builder status selector whose
`published` transition derives every pill for that draft **inactive**.

## Key decisions

- **Active/inactive is DERIVED from draft status, never stored.** Paper
  drafts: active while `projects/papers.json` status ≠ `published`.
  Grants: active while status ∈ {drafting, submitted, under_review,
  revising, rejected} (paper-overlays' GRANT_DRAFT_STATUSES). No
  migration, no publish-time sweep, reversible by un-publishing.
- **Status selector is admin-only** — the `projects` collection write
  rule is `isAdmin()` (firestore.rules `match /projects`), so enabling it
  for author students would die on permission-denied. Authors see the
  current status disabled with an "ask the PI" tooltip. (Same latent
  restriction applies to the existing title sync / authors panel.)
- The add-picker lists **active drafts only** — inactive drafts can't
  gain new associations; existing inactive pills stay visible (collapsed
  behind "+N inactive") and removable.
- Unknown/deleted draft ids render as inactive removable pills (cleanup
  affordance), never break.

## Edge cases

- Resolver cache cold → badges fall back to raw counts +
  `_draftTitleById`; `_load`'s `.then(_render)` upgrades them.
- `library/papers.json` fast path has no grants — resolver reads
  items.json + grantDrafts directly (mirrors `_loadAllDrafts`).
- Concurrent toggles safe by construction (LIBRARY_LINKS atomic ops).
- Reader popover-preservation: picker-save flow still re-opens the
  overlays popover (it was open behind the modal); auto-link doesn't.

## Verification

1. Reader: pills block renders between Categories and share widget; add
   paper + grant via ＋ picker; overlays widget count updates without
   reload; remove via pill ×; remove via overlays picker re-renders pills.
2. Library: badge "→ N active"; popover add/remove repaints rows; ghost
   "+ draft" on zero-assoc rows incl. chunk-tail (>50 rows); `draft:gels`
   filters; "Draft associations" sort; smart group on a `draft:` query.
3. Status: admin flips to published → pills go inactive everywhere
   (collapse behind "+N inactive"); flip back reactivates. Non-admin
   author sees disabled select with tooltip.
4. `node --check` all touched JS. No Firebase deploy (items writes ride
   the V3.309 rule).
