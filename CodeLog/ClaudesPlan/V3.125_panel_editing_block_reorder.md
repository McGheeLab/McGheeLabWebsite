# V3.125 — Panel-side editing for figures/tables + block reorder + inline add buttons

## Goal

Three coupled requests:

1. **All non-text content built in the side panel.** Tables and
   figures move their builder UI from the document inline blocks into
   the right slide-out panel. Document-side blocks become read-only
   rendered previews with an "Edit in panel" button that opens the
   panel + scrolls to the matching row.
2. **Inline block insertion.** Replace the per-section bottom toolbar
   (`+ Paragraph` / `+ Figure` / `+ Table`) with a small `+ Add` button
   between every pair of blocks (and at the start / end of each
   section). Clicking opens a menu — Paragraph / Equation / Figure /
   Table. Pick → block inserted at exactly that position.
3. **Block reorder.** Each block toolbar gets up / down arrow buttons
   that swap with the adjacent block in the same section. The drag
   handle (`⋮⋮`) becomes a real HTML5 draggable that supports drop on
   another block to reorder within a section.

## Approach

### Inline `+ Add` buttons
- Render a small `<button class="pe-block-inserter">` between every
  pair of blocks in a section, at the top of the section's children
  area, and at the bottom (replacing the existing add-row).
- On click: anchor a small popover offering four choices (Paragraph,
  Equation, Figure, Table). Choices are grayed when the section's
  `styleFor` policy disallows the kind (e.g., abstract → no figures).
- Picking calls `insertBlockAt(sectionId, idx, kind)` which creates
  the block at that position via Y.Array `insert`.
- Equation choice opens the V3.124 creation modal pre-targeted to
  insert at this position (instead of "end of last-focused section").
- Figure / Table choices create a blank block AND auto-open the side
  panel on the corresponding tab so the user can fill in details.

### Block reorder
- Per-block toolbar gains `↑` and `↓` buttons that swap the block
  with its neighbor in the same section's `Y.Array<Y.Map>` children.
  The Yjs Array.delete + insert pattern (used by V3.115's section
  reorder) is the canonical move.
- Drag handle becomes draggable: `dragstart` stamps the block id;
  `dragover` on another block highlights drop zone; `drop` calls
  `moveBlockBefore(sectionId, srcId, targetId)`. Cross-section drag is
  out of scope.
- Both arrow + drag route through a shared `moveBlockWithinSection`
  helper.

### Figure editor moves to panel
- Document-side `renderFigure` becomes a thin preview: image only +
  caption rendered (read-only) + an `Edit in panel` link that opens
  the side panel on the Figures tab + flashes the matching row.
- Figures tab row gets the upload control, layout details
  (width/placement/centering/alt), caption Y.Text contenteditable,
  subfigures editor (already there), Numbered/label inputs (already
  there). The row becomes a full editor.

### Table editor moves to panel
- Document-side `renderTable` becomes a read-only rendered HTML table
  (using the same alignment/booktabs styling, but no contenteditable
  cells, no toolbars, no controls). Plus an `Edit in panel` link.
- Tables tab row gets the full grid editor (cells = contenteditables
  bound to per-cell Y.Texts), the booktabs/header/alignment toolbar,
  caption editor, +Row/+Col buttons. The row becomes a full editor.

### Section-bottom toolbar retired
- The V3.40-era `+ Paragraph` / `+ Equation` / `+ Figure` / `+ Table`
  / `+ Reagent` row at the bottom of each section is replaced by a
  single `+ Add block` button (the same component as the between-block
  inserter). This keeps add-block UX consistent throughout the doc.
  Inventory quick-insert moves into the menu as a fifth choice.

    `Edit in panel` link). All editing UI moves to paper-equations.js.

## Verification

```bash
RM_WRITE_ALLOWLIST=mcgheealex@gmail.com python3 rm/server.py
# open http://localhost:8000/rm/pages/paper-builder.html?paper=<id>
```

1. Open a section. Verify there's a small `+ Add` button at the top, between every pair of blocks, and at the end. No more `+ Paragraph` / `+ Figure` / `+ Table` row at section bottom.
2. Click `+ Add` between two paragraphs. Menu appears with Paragraph / Equation / Figure / Table. Pick Paragraph → blank paragraph inserts at that exact position.
3. Click `+ Add` → Equation → V3.124 creation modal opens. Save → equation block lands at the inserter position (not at end of section).
4. Click `+ Add` → Figure → blank figure block lands; Figures tab opens; row scrolls into view + flashes. Upload an image from the panel row's Upload button. Verify the doc-side block updates with the image.
5. Click `+ Add` → Table → blank table block lands; Tables tab opens; row scrolls into view + flashes. Edit cells from the panel-side grid editor. Verify the doc-side block re-renders read-only with the new content.
6. Verify the doc-side figure block has only the image + caption (rendered) + an `Edit in panel` link. Click the link → panel opens, Figures tab active, matching row flashes.
7. Verify the doc-side table block is read-only — clicking a cell does NOT focus it; an `Edit in panel` link is the only interaction.
8. Click `↑` arrow on the second block in a section → it swaps with the first.
9. Drag a block by its `⋮⋮` handle and drop on another block in the same section → src moves before target.
10. Hard-reload — SW cache rolls forward.
