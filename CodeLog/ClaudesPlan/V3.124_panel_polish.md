# V3.124 — Side panel polish: resizable, unified equation creation, References UX

## Goal

Three coupled tweaks to the V3.115/V3.120/V3.122 right slide-out:

1. **Resizable pane.** The slide-out is currently a fixed 380 px. Add
   a left-edge drag handle so the user can widen/narrow it. Width
   persists in `localStorage.rm_paper_pane_width`.
2. **Unified equation creation in the panel.** Replace the V3.109
   "+ New inline" button with a single **"+ Equation"** button that
   opens a creation modal (name + LaTeX + type radio: `inline` /
   `main`). All equation creation flows through the panel — the
   section-level "+ Equation" button is retired. `main` library
   entries get an "Insert as block" action that creates a numbered
   display equation block in the section of the last-focused
   paragraph (auto-numbered via the existing doc-order walker).
3. **References tab UX.**
   - Wrap **Cited in this draft** and **Linked but not cited**
     sections in collapsible `<details>` elements. Default open.
   - Cited keys without a matching library entry render a red
     **"Add to library"** pill (replaces the V3.122 read-only
     `unknown` badge). Click → small modal with Title / First author /
     Year / DOI; Save creates a stub entry in `items.json` with
     `meta.library.is_library_entry: true` and the user's typed
     citation key, then the row flips to `cited` (green) live.

## Approach

### Resizable pane
- New `.pe-pane-resize-handle` div pinned to the left edge of
  `.pe-tabbed-pane`, 4 px wide, `cursor: ew-resize`.
- `mousedown` on handle → `mousemove` on document moves the pane's
  width to `window.innerWidth - clientX`, clamped to `[280, 800]`.
- On `mouseup` save to `localStorage.rm_paper_pane_width`.
- On panel build read `localStorage` and apply width to `style.width`.

### Equation library type field
- Each library entry gains `type: 'inline' | 'main'`. Defaults to
  `'inline'` for back-compat (existing V3.109 entries).
- `getInlineEquationLibrary()` projection includes `type`. Existing
  consumers that don't read it remain unaffected.
- The right-click "Insert inline equation" picker shows ALL entries
  regardless of type (any equation can be inserted inline). Type is
  primarily an organizational marker for the panel.

### Equation creation modal
- "+ Equation" button at top of Equations tab opens
  `_openEquationCreateModal()` — same modal pattern as the V3.104
  flag-claim modal (overlay + card). Fields: Name (text input,
  required-ish), LaTeX (textarea, required), Type radio (inline /
  main). Save → calls `_createEquationLibraryEntry({name, latex, type})`
  which creates the Y.Map in `equation_library`.

### Main equations section
- New section between Inline library and Numbered equations:
  **Main equations (library)** — shows entries with `type === 'main'`.
  Per-row UI: name + KaTeX preview + "Insert as block" button +
  delete.
- "Insert as block" calls `_insertMainAsBlock(libEntryId)`:
  - Find the section containing the last-focused paragraph (walk up
    from `_state.savedEl`).
  - Create a new equation block at the end of that section's children
    (or after the focused paragraph index — the latter is harder; use
    end-of-section for V3.124).
  - Block attrs: `display: true`, `numbered: true`, `label` auto-slugged
    from the entry name (e.g., "Hooke's law" → `eq:hookeslaw`),
    `body: <library entry latex>`.
  - Numbering badge appears via the existing walker.
- If no section can be resolved (no saved focus), alert: "Place the
  cursor in a paragraph first."

### Section-level "+ Equation" retirement
- In [paper-editor.js](rm/js/paper-editor.js)'s `pe-add-block-row` build,
  remove the `+ Equation` button. The panel is now the only equation
  creation surface.

### Collapsible References sections
- Replace the V3.122 `.pe-equations-section` divs for Cited and
  Linked with `<details open>` elements. The section title goes inside
  `<summary>`. The list goes inside the `<details>` body.
- Search section stays as-is (always-on input).

### Add-to-library flow
- V3.122 already emits a `pe-ref-row-unknown` row for unknown keys.
  Add a button to that row labeled "Add to library" with red styling.
- Click → `_openAddToLibraryModal({key})` — modal with the key
  pre-filled and read-only, plus Title / First author / Year / DOI
  inputs. Save calls `_createLibraryStub({key, title, firstAuthor, year, doi})`:
  - Loads `items.json`
  - Builds new item: `{id: 'lib-' + shortId(), type: 'paper', title, meta: {library: {is_library_entry: true, citation_key, title, authors: [{family: firstAuthor}], year, doi, date_added}}}`
  - Pushes + saves
  - Invalidates + reloads citation index
  - Re-renders References tab → row flips from `unknown` to `cited`

6. Type `[@unknown_key]` in a paragraph. Verify the References tab row shows a red **"Add to library"** pill (not just `unknown` badge).
7. Click the pill → modal with cite key pre-filled. Fill in title + author + year + DOI. Save → new library entry appears in items.json; row flips to `cited` (green) within ~1 s.
