# V3.885 — Scientia: a note's details live in its first block; templates swap in place

**Ask (Alex, 2026-10-23):** "for any note set, all of the information you would input for the note like project
connection, title, etc should be in the block that comes with the note page, this block is always editable. when a
user adds a note page never ask for this information up front, instead it is just in this initial block. including
templates, where the user can change the template and it auto populates the correct items and if the template changes
then it deletes all of them and changes the template so the user can keep trying until they decide on the right one.
Once the user edits any item, changing template will require the user to say they are sure and warn them that this
will delete existing items, or they can say to keep items they edited and delete the rest and load in the new template
next to the items they already used."

Supersedes V3.882's *Save to a project…* form and V3.880's blank-page template bar: one place, the note's first block.
Web build only (`rm/scientia/lab-mode.js`); `scientia/src` untouched.

## The first block (Gabe's head box, always on the note)

Title · Type · Template · Project · Theme — and *Seen by* when the project is assigned work from RM — added above his
header fields, always editable (change events, so a re-render never interrupts typing). His ✎ note dialog stays for the
date and delete.

## Making a note asks nothing

`App.newDoc` (+ Note, Ctrl+Alt+N, a link to a new note, a project's or theme's + Note), `CHAIN.start` (+ Experiment) and
＋ Quick note make the note at once — the type's template applied, no project unless the place it was made from has one
— and open it. Running a registered protocol (`pre.runDef`) keeps Gabe's dialog, which picks the run.

## Templates swap in place

Items a template brings carry `tpl { id, label0, text0 }`; an item is *edited* when its label, text or marks differ, or
it is no longer a plain component.

| Situation | What a template change does |
|---|---|
| nothing edited | swaps at once — all of the template's items go, the new template's come; the type follows the template; a default title follows the type |
| something edited | asks (Gabe's modal): **Keep the items I edited** (they stay and become the person's own — no `tpl` — the untouched ones go, the new items are placed beside the kept ones) · **Replace everything** (all of the template's items go, edits too) · Cancel |
| items the person added | never touched |

Changing the **Type** of an untouched note brings that type's template; of an edited one it changes only the type.
