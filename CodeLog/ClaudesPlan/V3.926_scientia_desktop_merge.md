# V3.926 — Scientia: the desktop's features join the lab's copy

## Goal

Gabe's desktop Scientia had moved ahead of `scientia/` in this repo (his private `Scientia-In-Situ` repo, commit 5e47916
on 867d3dd, reconciled against the lab's V3.901 and carrying V3.903 / V3.905). He decided on 26 Oct 2026 to retire the
app's own Firebase sync (the lab hub is the one cloud, via `scientia-cloud.py`) and to make this repo's `scientia/` the
single source for the desktop. This version brings every desktop-only change into the repo so the website's Scientia
gets the same features: moving a component by dragging its name or date (double-click edits the name / the time), tables
and plots from Excel / CSV, library themes and groups, saved ink, dashed lines, canvas export.

## Approach

A real three-way merge, base = the lab's `scientia/` at V3.901 (ff8acea), ours = `main` (V3.925), theirs = the desktop:

- 18 files changed only on the desktop, 10 are new there: copied in (nothing changed only on the lab side, so nothing of
  the lab's was overwritten).
- 4 files changed on both sides: `12-doc.js`, `13-docpanels.js` and `21-sync.css` are the lab's version plus the desktop's
  additions (no overlap); `01-util.js` differs only in the `BUILD` label — the desktop's label wins (Gabe, 26 Oct).
- Not copied: `scientia-cloud.py` (the lab's copy in `rm/scientia/` is the bridge), built files, notebook data.
- `scientia/README.md`: the Firebase section is gone, "one cloud" says the lab hub is the only one.
- `CodeLog/features.json`: `scientia.tables` and `scientia.canvas-export` are new; `scientia.canvas`, `scientia.library`
  and `scientia.settings` list the new modules (13zz2-pen3, 13zz3-dash, 13zz4-inksplit, 17d-libgroups, 21c-labexport).
- `rm/scientia/lab-mode.js`: `INS_PICS` gives the four new + Insert rows an icon (`table`, `table-empty`, `plot`,
  `inklib`), as the lab harness requires of every row (V3.898).
- `scripts/gen-icons.mjs`: on Windows the emoji gate built paths with backslashes, so its skip patterns (icons.js,
  `vendor/`, `rm/scientia/`) never matched and the gate failed — 432 hits on clean main, which HELD every push from a
  Windows computer. Paths are normalised to `/` first.

## Key decisions

- The library groups and reader additions are new work in features the lab is folding into RM (`scientia.library` →
  `rm.library`, `scientia.reader` → `rm.paper-reader`). The push gate warns; Gabe asked to keep every new feature, so
  they ship and the PR says so.
- Not in this version (lab follow-ups): spreadsheet extensions in `functions/scientia-hub-core.js` `MEDIA_EXTS` and the
  bridge's `IMG_EXTS` (needs a functions deploy); a read-only guard for shared copies in the app (`sharedFrom.role ===
  'read'`).
