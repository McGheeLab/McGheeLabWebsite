# V3.120 — Pill tabs + global toolbar + Tables tab

## Goal

Two coupled changes the user asked for in the same breath:

1. **Layout refactor.** Replace the V3.115 "📐 Panel" topbar button +
   right-slide-out trigger with a **pill bar always visible at the top
   of the editor** (no icons — text-only pills): `Equations` /
   `Figures` / `Tables` / `References`. Below the pills, a
   **persistent global toolbar** with rich-text buttons (B / I / X₂ /
   X² / `<>`) and reference-insert buttons (`+ Eq` / `+ Fig` / `+ Table` /
   `+ Cite`). Toolbar buttons act at the **current caret** (last-focused
   contenteditable). The V3.107 per-paragraph rich-text toolbar is
   retired in favor of the single global one.

2. **Tables tab.** Build out the placeholder Tables tab from V3.115
   with: caption Y.Text (idempotent migration from the legacy string),
   numbered + label attrs, per-column alignment, booktabs / header-row
   styling toggles. New `[!tab:<label>]` paragraph token renders as a
   `Tab. N` chip and exports to `\ref{<label>}`. Extends the
   right-click context menu with `+ Table — Insert table reference`.

This is the second of three sequential versions tracked at
`/Users/alexmcghee/.claude/plans/we-need-to-make-expressive-turing.md`.

## Approach

### Layout

```
.pe-page
  .pe-topbar                     (existing: back link + title + save state)
  .pe-pillbar                    NEW (always visible)
    .pe-pill[data-tab=equations] "Equations"
    .pe-pill[data-tab=figures]   "Figures"
    .pe-pill[data-tab=tables]    "Tables"
    .pe-pill[data-tab=references] "References"
  .pe-global-toolbar             NEW (always visible)
    .pe-rt-group: B / I / X₂ / X² / <code>
    .pe-ref-group: + Eq / + Fig / + Table / + Cite
  .pe-readonly-banner            (existing)
  .pe-layout                     (existing: sidebar + main + comments)
```

The right-side **slide-out pane** survives but loses its head + close
button. Active pill controls which tab content is visible inside the
pane; clicking the active pill again hides the pane.

The legacy V3.107 per-paragraph rich-text toolbar (`buildRichToolbar`
in [paper-blocks.js](rm/js/paper-blocks.js)) is removed. Its keybinds
(`Cmd+B/I/E`) survive because they're bound on the body contenteditable
itself in `richTextKeydownHandler`.

### Global toolbar mechanics

The toolbar buttons reuse `wrapSelectionInTokens(lhs, rhs)` and
`_insertAtSavedCaret(text)`. Each button's `mousedown` listener calls
`e.preventDefault()` so the focused contenteditable keeps its
selection across the click. The reference-insert buttons open the
existing pickers (eq / fig / table / citation).

The insert-reference buttons act as a *trigger* for the picker rather
than directly inserting — same UX as the right-click menu.

### Table block schema additions
```
attrs (Y.Map, V3.120 additions):
  caption: Y.Text       // migrated from legacy string in one Y transact
  numbered: bool        // default true
  label: string         // auto-prefix 'tab:'
  align: string         // per-column 'lcr' (length === cols when present)
  booktabs: bool        // default true
  header_row: bool      // default true
```

Migration: on first `renderTable` post-V3.120, if `attrs.caption` is a
plain string, convert to `Y.Text(caption)`. Idempotent.

### Tables tab UI

Each row in the Tables tab:
- `Tab. N` badge if numbered
- Caption preview (first line of `attrs.caption` Y.Text)
- Label input (auto-prefix `tab:`)
- Mini schema readout: `3 × 4 · booktabs · header`
- Numbered checkbox
- Insert reference button + Open block link

### `[!tab:<label>]` paragraph token

| Source | Renders as | LaTeX |
|---|---|---|
| `[!tab:<label>]` | `Tab. N` chip | `\ref{<label>}` |

### Right-click context menu

5th item: `Insert table reference` — same picker pattern as figures,
no sub-panels.

### LaTeX export

`tableToTex` rewritten to read block-level attrs:
- `\begin{table}[<placement>]\centering\begin{tabular}{<colSpec>}…\end{tabular}\caption{…}\label{…}\end{table}` when numbered.
- `\caption*{…}` (no number, no \label) when unnumbered.
- `colSpec` = `attrs.align` when length matches cols, else fall back
  to `'l'.repeat(cols)`.
- `\toprule` / `\midrule` / `\bottomrule` only when `attrs.booktabs`.
- `\midrule` after row 0 only when `attrs.header_row`.
