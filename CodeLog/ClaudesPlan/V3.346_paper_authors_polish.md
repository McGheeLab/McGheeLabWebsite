# V3.346 — Authors & affiliations panel + workflow polish

**Part of:** [FuturePlan 07 — Paper builder upgrade](../Feature%20requests/FuturePlan_07_paper_builder_upgrade.md) (Release 6 of 7).

## What shipped

### Authors & affiliations panel (export workspace)

- Storage: `paperExports/{paperId}.authors[] = {name, affiliationIdx[]
  (0-based), corresponding, email}` + `.affiliations[]` — loaded/saved
  with the existing debounced config persistence in `paper-export.js`.
- UI: new "Authors & affiliations" section in `pages/paper-export.html`,
  rendered by `PaperExportConfig.bindAuthors` (affiliation rows with
  numbering, author rows with name / affiliation-numbers / ✉
  corresponding toggle / email, add-remove; read-only for non-editors).
- Export: `renderAuthorBlock(template, leadAuthor, authorsCfg)` — when
  structured authors exist, `renderStructuredAuthors` emits per-format
  multi-author LaTeX: elsarticle (`\author[n]{}+\corref/\ead/\cortext
  +\affiliation`), ieee (`\author{A, B, and C\thanks{…}}`), achemso
  (`\author+\affiliation+\email` per author), superscript
  (article-class default with numbered affiliations + * corresponding).
  No structured authors → the legacy lead-author block (no regression).

### Workflow polish

- **Auto-label numbered floats** — the "Numbered" toggles in
  `paper-blocks.js` (equation/figure/table) auto-assign a
  `eq:`/`fig:`/`tab:` label slugged from the caption when the label is
  empty, and all four ref-picker dead-ends in `paper-equations.js`
  (`_autoAssignFloatLabel`) now assign-and-insert instead of alerting
  "This figure has no label yet."
- **Word-count badges** — every section header shows a live `~N w`
  badge (red `N / max w` when over the kind's advisory `maxWords`);
  filled on first paint, refreshed on throttled `paper-panel-changed`.
- **⌨ shortcuts card** — toolbar button opens a static shortcuts &
  tips popover (Cmd+K, chip click-to-edit, formatting dialect, footnote
  token, view modes, Guide pill).

## Verification

Tectonic-compiled elsevier / ieee / acs / preprint-numeric with 3
structured authors across 2 affiliations (ieee + acs need ≥1 citation —
empty-bibliography LaTeX quirk, not an authors bug). Syntax checks on
all edited files.
