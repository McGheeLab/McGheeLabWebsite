# V3.534 — My Day R9: retire tracker manual entry + task-add CTA (flagged)

Part of the **My Day program** — see `V3.526_my_day_program.md`.

## Goal
Second retirement pair: the activity tracker becomes a review/confirm/
analytics surface; the tasks "Add" workspace points new-task composition
at My Day.

## Approach
- `labConfig/featureFlags.myday_retire_tracker_manual` — when true,
  activity-tracker.js hides the Single/Bulk input areas and shows
  "☀️ Log today in My Day →" instead. Historical manual entries keep
  rendering everywhere (analytics, year-review, PMR).
- `labConfig/featureFlags.myday_retire_task_add` — when true, the tasks
  `?tab=add` workspace shows a "New tasks are composed in My Day →"
  banner (`my-day.html?compose=1&type=task`). task-quick-builder.js
  itself is untouched — email-review/calendar still embed it.
- Both flags default false (dark); both read through
  `DAY_DISTRIBUTE.getFeatureFlags()`.

## Deploy
FTP only; flip flags per-surface when ready. Rollback = flip back.

## Verify
Flags off → zero visible change. Tracker flag on → input areas gone, CTA
shown, existing entries + suggestions still render. Task flag on → banner
on the add tab only.
