# V3.911 – V3.914 — Grant formats, starting with NSF CAREER

**Asked (Alex, 2026-10-25):** "Grants need some help. Each type has a set of rules we
need to follow for formatting … replicate the NSF CAREER grant such that I can easily
format it and ensure it follows guidelines and that I can easily adjust things to make a
page count without too much trials and tribulations."

## Ground truth

Alex's submitted CAREER package (`GELS CAREER/Final package/FINAL/`, July 2026), measured:

| Document | Pages | Made in | Type |
|---|---|---|---|
| Project Description | 15 (the limit) | Word | Aptos 11 pt, 12.66 pt line pitch, no indent, no paragraph space, captions Arial 10 / 11.5 |
| Project Summary | 1 | Word | Arial 11 |
| References Cited | 10 | LaTeX | Latin Modern 10.9 |
| Data Management & Sharing Plan | 2 | LaTeX (pandoc) | Latin Modern 10.9 |
| Mentoring Plan | 1 | Word | Arial 11 |
| Facilities | 2 | LaTeX (pandoc) | Latin Modern 10.9 |

The Project Description's house style: bold 11 pt headings at the body pitch with no extra
space ("1. Overview and objectives", "3.1.1 …"), bold run-in aim labels, justified text,
seven of eleven figures wrapped at ~3 in with text beside them, the rest full width.

It already exists as an RM grant paper (`GELS-CAREER.paperbundle`, V3.472), but every
figure is stored full width, so the bundle in the Paper Lab corpus
(`PaperLab-corpus/gt-nsf-career-gels/`, outside every repo) is corrected to the
submitted layout (wrap side and width per figure, run-in aim labels).

Note found while measuring: **Aptos is not a PAPPG typeface.** PAPPG 24-1 §II.C.2 lists
Arial / Courier New / Palatino Linotype (≥ 10 pt), Times New Roman (≥ 11 pt) and Computer
Modern (≥ 11 pt). The new rules check would have flagged it.

## Rules (PAPPG 24-1, current base edition; supplements 26-200 / 26-202 change no format rule)

- Letter paper, margins ≥ 1 in all sides, nothing in the margins, no page numbers (II.C.1).
- Typefaces above; smaller type allowed for equations, figures, table and diagram captions,
  Symbol-font characters, if readable.
- ≤ 6 lines of text per vertical inch → line pitch ≥ 12 bp.
- Project Summary ≤ 1 page, three parts: Overview / Intellectual Merit / Broader Impacts.
- Project Description ≤ 15 pages incl. visuals; a "Broader Impacts" heading on its own
  line; Results from Prior NSF Support ≤ 5 of the 15 pages; no URLs.
- References Cited: separate upload, no limit.
- DMSP ≤ 2, Mentoring Plan ≤ 1, Synergistic Activities ≤ 1, Budget Justification ≤ 5;
  CAREER Departmental Letter ≤ 2 (department head, separate upload).
- Biosketch / Current & Pending / COA: SciENcv or NSF forms (upload only, unchanged).

## Approaches considered for "make a page count without trials and tribulations"

1. **Estimate** (lines ÷ lines-per-page). Cheap, wrong by a page whenever figures, headings
   or wraps move — exactly the trial-and-error Alex wants gone.
2. **Compile in a loop** (edit → PDF → count). Exact but each loop is a 20–60 s round trip.
3. **A preview that IS the PDF page** (the V3.907–910 journal-look machinery: same fonts,
   TeX line breaking, TeX page rules), with the page count read off the preview live and
   knobs that re-lay out the document in a second. Chosen. It needs one new piece of TeX
   modelled in the preview: wrapfig.
4. Constraint solver over every knob. Kept as the last step of option 3: "Fit" tries the
   compliant knobs in order of least visible change and stops at the first that fits.

## Releases

### V3.911 — the NSF look, the PAPPG rules, References Cited as its own PDF

- `nsf-career.json` gets a **spec look** reproducing the submitted page: Letter, 1 in
  margins, one column, no page numbers; Arial-metric sans (TeX Gyre Heros — Helvetica's
  outlines, Arial's widths, so a line breaks where Word-with-Arial breaks it) 11 / 12.65;
  no indent, no paragraph space; headings bold 11 at the body pitch with zero space;
  captions sans 10 / 11.5 with a bold "Figure N." label; numeric [1] citations sorted and
  compressed.
- Typeface choice per paper among PAPPG faces (Arial-metric, Times, Palatino, Computer
  Modern), each with its PAPPG minimum size. Per-paper overrides live in
  `paperExports.lookOverrides` (a whitelist: face, size, line pitch, paragraph space,
  heading space, caption size, wrap gap), merged after the template's look by
  `PaperLook.resolve` — the PDF and the preview read the same object.
- `look.bib.where = 'separate'`: the Project Description reads the bibliography (so [12]
  resolves) but prints none; References Cited compiles as its own document with
  `\nocite{…}` in first-citation order (= the Project Description's numbering, since
  unsrtnat numbers in `\citation` order and a caption's `\cite` is written when the float
  box is built, i.e. in source order). No server change: it is another bundle through the
  same compile endpoint.
- `rm/js/paper-grant-rules.js` (pure, Node-tested): the PAPPG checks above, from the look
  and the laid-out document (pages, headings, text).
- `nsf-career` registered in the export template picker for grants.

### V3.912 — wrap figures exactly as wrapfig sets them

Measured with Tectonic and read from wrapfig.sty v3.6:
- the box's reserved height is `depth + 1.5\baselineskip + 2\intextsep` (−`\intextsep` at
  the top of a page), the wrapped line count `⌊(size + 1.1\baselineskip)/\baselineskip⌋ − 1`;
- narrow lines are `\linewidth − width − \columnsep`, carried across paragraphs and headings
  until the count is used up, and every paragraph that starts while wrapping is set at
  `\tolerance 9999`;
- at the next paragraph start, if the room left on the page is less than the size: the
  floating form (`R`/`L`) holds the figure (text runs full width) and retries at each later
  paragraph start, unless less than one line is left, in which case it breaks the page and
  places the figure at the top of the next.

The export writes `\begin{wrapfigure}{R|L}{width}` (floating form, count left to wrapfig)
under a look; the preview's paginator runs the same rules and re-sets the affected
paragraphs with per-line widths (Knuth–Plass already takes a width per line).

### V3.913 — page budget and Fit

- A page meter on grant documents: "14 pages + 31 lines of 15", lines each section uses.
- The Check panel gains the PAPPG rules and a Fit section: each knob with its compliant
  range and the lines it saves (measured by re-laying out, not estimated), and **Fit to N
  pages**, which applies, in order, paragraph tightening (`\looseness=-1` where the last line
  is short), heading and paragraph space, line pitch down to 12 bp, caption size, figure
  scale — stopping at the first combination that fits, all undoable in one step.

## What was built

**V3.911.** The NSF look and `grant` block in `nsf-career.json`; `paper-grant-rules.js` + 18 tests; per-paper
`lookOverrides`; `bib.where:'separate'`; TeX Gyre Pagella; References Cited by `\nocite` in citation order (105 of
105 numbers identical to the Project Description's).

**V3.912.** wrapfig modelled in the paginator. Getting the GELS proposal from 3/16 to 16/16 identical page starts took
these findings, each measured against Tectonic's output and wrapfig's own `\WF@info` log:

| Finding | Effect before the fix |
|---|---|
| titlesec headings break wrapfig (narrowing never ends after a figure placed at one) | whole pages set narrow, 19 pages |
| wrapfig's non-floating form overhangs the bottom margin | figures in the margin |
| headings are not placement points once they hang by 1sp; numbered `\@startsection` headings never were | figure placed a paragraph early |
| a waiting figure is dumped (`\WFclear`) when the next wrapped figure begins | Figure 2 set alone, 28-line page |
| wrapfig's `\pagebreak` overrides keep-with-next | heading moved to the wrong page |
| captions sit between struts (0.7 / 0.3 × lead) | every figure 1.4 bp tall, wrapped line counts flip |
| a whole-pixel ceiling per measured item | the line TeX fits exactly at a page foot lost |
| headings set by Knuth–Plass like body text, line by line beside a figure | a 3-line heading taking 4 lines |
| a heading keeps a whole chain of headings with it | heading stranded at a page foot |
| XeTeX gives every line the face's ascender/descender | dumped figure 2 bp off |

Result: 16 / 16 pages, 16 / 16 page starts, 87 % line ends.

**V3.913.** Page budget, rules, page settings and Fit in the Check panel; `\looseness` everywhere via LaTeX's
paragraph hook; `breakLines` follows tex.web §873/§875 for looseness. Fit on GELS: 16 → 15 pages (tighten, captions 9 pt,
pitch 12 pt); the compiled PDF is 15 pages, 12 / 15 page starts identical.

**V3.914.** The Document picker (Project Summary 1/1, DMSP 2/2, Mentoring Plan 1/1 pages on the GELS texts) and the
Export page's Grant documents card.

**Found on the way:** the submitted Project Description is set in Aptos, which the PAPPG does not list.

**Journal looks, found with the same side-by-side tools** (a regression run after V3.912 moved bioRxiv to 12 preview
pages against 13 compiled; the exact-height fix had removed an over-count that was cancelling two real errors):
adjoining vertical spaces count once, the larger (CSS margin collapsing = LaTeX's `\addvspace`), and TeX discards the
space before an item at the top of a page or column; display equations were spaced by KaTeX's 1em margins instead of
TeX's display rules; the preview bibliography did not follow unsrtnat. All three fixed in V3.914.
