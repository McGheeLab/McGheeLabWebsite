# V3.381 — Recipes (one-click pre-wired node patterns)

## Goal

Lower the blank-canvas barrier: a **✨ Recipes** dropdown that inserts a
common, already-wired cluster of nodes so the author starts from a
working pattern and edits from there.

## Design

### `rm/js/protocol-graph.js`
- `RECIPES` (exported): five templates, each
  `{key, icon, label, hint, nodes:[{ref,type,params,dx,dy}], edges:[{from,to,role?,paramField?,sourceVar?}]}`
  with template-local refs:
  1. **Dilute a stock** — C1/C2/V2 inputs → `V1=C2*V2/C1` → `Vdiluent=V2-V1`.
  2. **Percent of a total** — total + pct slider → `part`.
  3. **Two sets → experiment list** — choices × ordered → list (structural).
  4. **Drive a setting** — a constant param-binds an input's `max`.
  5. **Script transform** — an input feeds a code node `return {y:x*x}`.
- `instantiateRecipe(recipe, graph, at) → {nodes, edges}` (pure, never
  mutates the graph or template): clones params, mints fresh ids via
  `newNode`/`newEdge`, remaps `from`/`to` by ref. **Collision-safe
  renaming** — collects every produced name in the target graph; if any
  template name collides, picks the smallest `_k` suffix that frees ALL
  of the recipe's names at once, then rewrites consistently:
  `params.name/field`, `items[].name`, `outputs[].name`, edge
  `sourceVar`s, and identifier occurrences inside `expr`/`body`/
  `dedupe.when` (via `\b`-anchored regex).

### `rm/js/protocol-graph-editor.js`
A "✨ Recipes ▾" palette button right after the node-type buttons opens a
`.pge-recipes-menu` (label + hint per item) with **outside-click-to-close**
(listener removed on teardown). Picking one calls
`instantiateRecipe(recipe, graph, viewportCentreWorld)`, appends the
nodes/edges, `persist(); render()`, and confirms via the strip.

### CSS
`rm/css/protocol-graph-editor.css`: `.pge-recipes`, `.pge-recipes-menu`,
`.pge-recipes-item/-label/-hint`.

## Verification
- `scratchpad/test-recipes.js` (32 asserts): every recipe instantiates
  into an empty graph, `normalizeGraph` drops no edges, compiles
  error-free; dilution computes (V1=50, Vdiluent=450); collision applies
  one consistent `_2` suffix (exprs + body + sourceVars rewritten), the
  combined graph compiles and both instances compute independently, a
  third insert → `_3`; drive-setting emits the `max` paramOverride;
  code-transform emits a code entry + collision rewrites the body;
  sets-list assembles 6 rows; template + source graph untouched.
- Pending (browser): ✨ Recipes → "Dilute a stock" → sliders + outputs
  appear pre-wired and compute; insert it twice → second copy names
  suffixed, no duplicate-name error.
