# V3.567 — Ourlab app UX round: pop-up composer, curated More, trimmed Tasks

> Three app-facing UX changes from Alex (2026-07-26). All web-repo edits,
> FTP-only; two are app-gated (no change to desktop RM), one (the pop-up
> composer) is a universal My Day improvement.

## 1. My Day — composer is a pop-up sheet, folded by default

The always-on "What does this step accomplish?" composer at the bottom is
now folded away behind a floating **＋ FAB** (bottom-right). Tapping it —
or "＋ Plan a step" in the empty state, or a focus/task "plan" action, or
`?compose=1` — pops the composer up as a sheet with a **▾ fold** control
in its header. Editing an item (✎) also opens it. `rm/js/my-day.js`:
`state.composerOpen` (default false); `render()` shows `renderFab()` when
closed, `renderComposer()` (with a header + slide-up animation) when open;
`open-composer`/`fold-composer` actions; `?compose=1` deep-link opens it
(also useful for a future push "quick add"). CSS: `.md-fab`,
`.md-comp-header`, `.md-empty-add`, `@keyframes md-comp-slideup`
(`rm/css/my-day.css`). Universal — a good change on desktop too; the FAB
clears the app tab bar via `body.ourlab-app` offset.

## 2. "More" tab — curated app sheet, not the rest of RM

The More tab no longer navigates to `/rm/index.html` (the full RM portal).
It opens an in-app bottom sheet listing ONLY the pages the app ships,
plus the signed-in user and a Sign-out. `rm/js/mobile-shell.js`:
`MORE_LINKS` allowlist (Team Focus, Lab Notebook, Scheduler, Research,
Settings — edit this array to add/remove), the More tab renders as a
`<button>` that calls `openMoreSheet()`, sign-out via `firebridge.signOut`.
Self-injecting sheet CSS. App-only (mobile-shell is a no-op in browsers).

## 3. Tasks — trimmed to Dashboard / Completed / Task Market (app only)

Inside the app the Tasks hub drops the "Add Task" and "Task List" tabs.
`rm/pages/tasks.html`: a `window.__isOurlabApp()` guard + an
`__OURLAB_TASK_TABS = ['dashboard','archive','market']` allowlist filters
the `HUB` tab list and folds a deep-linked `add`/`inbox` tab back to the
dashboard. Desktop web (guard false) is unchanged — all five tabs remain.

## Files

- `rm/js/my-day.js`, `rm/css/my-day.css` — pop-up composer + FAB.
- `rm/js/mobile-shell.js` — More sheet + MORE_LINKS allowlist + sheet CSS.
- `rm/pages/tasks.html` — app-gated tab trim.
- `sw.js` — 540 → 541.

No mobile-repo source change (its sync-rm already bundles these files);
`npm run build` re-picks them up. No Firestore/rules/functions change.

## Verified (iOS Simulator, this session)

- My Day opens folded with the ＋ FAB; `?compose=1` pops the composer up
  with the ▾ fold header.
- Tasks shows only Dashboard · Completed · Task Market.
- (More sheet: code complete; tap-confirm pending — no headless tap tool.)

## Rollback

All four files revert cleanly. The composer change is universal but
additive; the More/Tasks changes are behind the app guard, so reverting
mobile-shell.js / the tasks guard restores the prior behavior with zero
desktop impact.
