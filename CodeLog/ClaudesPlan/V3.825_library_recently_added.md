# V3.825 — Library: filter by how recently a paper was added, and a persistent "Recently added" section

**Date:** 2026-10-22 · **Builds on:** V3.824 · **Backend:** none · **Site files:** `rm/pages/library.html`,
`rm/js/library.js`, new `rm/js/library-recent.js`, new `rm/css/library-recent.css`, `sw.js` 805 → 806 (auto-uploads
at turn end)

Alex: *"in the library, i want to be able to filter papers by how recent we added them. also keep a persistent
section that says recently downloaded papers"*.

## 1. When was a paper added?

`meta.library.captured_at_iso` (extension captures, to the second) → `meta.library.date_added` (the day; every item
built by `LIBRARY_METADATA.buildPaperItem` stamps it) → `meta.library.pdf.uploaded_at`. None of them: "unknown" — such
a paper never matches a recency window, counts as older than everything, and is left out of the strip.

## 2. The filter — two surfaces, one core (`library-recent.js`)

- **Toolbar select** `#library-added` next to the search box: any time / today / 7 / 30 / 90 days / this year / older
  than 90 days. A per-browser convenience (`localStorage lib_added_filter`), restored on load. While it is on the
  list sorts **newest first** (whatever the sort preference), the count line says so, the select turns indigo, and
  the groups shelf hides as it does for any filter.
- **Query token** `added:` in the search box — `added:today`, `added:7d`, `added:2w`, `added:3m`, `added:30d`,
  `added:year`, `added:2026`, `added:2026-10`, `added:older`, `added:older-30d` — the saveable form: a smart group's
  definition is its query string, so "papers added this month" can be a group. `_parseQuery` gains the field,
  `_matches` asks `LIBRARY_RECENT_CORE.withinWindow`.

## 3. The persistent section

`#lib-recent` sits between the shelves and the toolbar, registered with `LIBRARY_COLLAPSE` (id `lib-recent`, folds and
remembers like the other sections; `mirrorHidden` so an empty library hides the header too). It renders from the
**visible pool** on every `_render` — a search or filter never hides it ("persistent"). Eight newest first (title →
paper page, first authors, journal · year, "added 3 days ago · who · extension", Read or "no PDF"); **Show 24 ↓** /
fewer; **See all added in the last 30 days (n) ↓** sets the select and scrolls to the table; the header counts "n in
30 days"; with a filter on, the strip names it with a clear link.
