# V3.341 — Journal-formatting infrastructure + pure-TeXLive templates

**Part of:** [FuturePlan 07 — Paper builder upgrade](../Feature%20requests/FuturePlan_07_paper_builder_upgrade.md) (Release 2 of 7).

## Goal

Let students write content only while the export infrastructure produces
correct formatting for any major journal. This release generalizes the
template system (schema v2), fixes two production-blocking bugs it
uncovered, and ships four new journal targets that compile on Tectonic's
default TeXLive bundle with no embedded files.

## What shipped

### Template infrastructure (schema v2, backward compatible)

`rm/data/paper-templates/*.json` — static files FTP-deployed with the
site. New optional keys (absent → pre-v2 behavior, so the migrated
`mebp-journal` is byte-for-byte equivalent in output):

- `citation: { command, narrative_command, render_family, bibliography_style }`
  — drives the LaTeX cite command (previously hardcoded `\cite`).
- `refs: { figure|table|equation: { prefix, command } }` — the
  "Fig.~/Table~/Eq.~" word emitted before `\ref`/`\eqref` (export used
  to drop it, so PDFs read "as shown in 3").
- `extra_files: [{ relpath, content }]` — journal `.bst`/`.sty`/`.cls`
  text files shipped verbatim in the compile bundle (used by Release 3's
  embedded-file journals; the Cloud Run service already writes them).
- `author_block: { format }` + `main_template` placeholders
  `{{ABSTRACT}}`, `{{KEYWORDS}}`, `{{AUTHOR_BLOCK}}` — for classes whose
  frontmatter owns those positions (elsarticle, IEEEtran).
- `limits: { abstract_words, body_words, references, figures, title_chars }`
  — drives the new `checkLimits` lint and the export-page facts row.
- `addon_defaults`, `incompatible_addons` — picker hints.

### New templates (all compile on Tectonic default bundle)

`preprint-numeric` (unsrtnat numeric), `preprint-authoryear` (plainnat
`\citep`/`\citet`), `ieee` (IEEEtran two-column, IEEEkeywords), `elsevier`
(elsarticle frontmatter with placeholders). Plus migrated `mebp-journal`.

### Bugs fixed (uncovered during verification)

1. **Broken template fetch in production** — `fetchTemplate` used
   `api.load('paper-templates/…')` which had no api-routes entry and fell
   through to a dev-only fetch (404 on godaddy). Now fetches the static
   `/rm/data/paper-templates/<id>.json` first, legacy path as fallback;
   `id` validated against `/^[\w-]+$/`.
2. **Figure cross-refs mis-parsed** — labels are stored *with* their
   `fig:` prefix, so a real token is double-prefixed (`[!fig:fig:setup]`).
   The old regex split the no-panel case into `label="fig", panel="setup"`
   → `\ref{fig}(setup)`. Rewritten to treat a trailing `:PANEL` as a
   panel only when stripping it leaves a valid `prefix:slug` label.
3. **Markdown/LaTeX collision** — the new `~` ref prefixes were eaten by
   the markdown subscript pass (`~x~`) whenever a paragraph had 2+ refs.
   Fixed structurally: `paragraphTextToTex` now stashes every injected
   LaTeX fragment (inline equations, refs, cites, code) behind
   private-use-codepoint placeholders and runs the markdown passes only
   on user prose, reinserting fragments afterward. This also fixes the
   pre-existing fragility with multiple `[!eqi:]` equations in one
   paragraph.
4. **Table-caption citations dropped from the .bib** — `collectCitationKeys`
   scanned paragraphs and figure captions but not table captions (the
   editor-side counter already included them). Now scanned.
5. **`$&` corruption** — `main_template` placeholder substitution switched
   to function-form `.replace()` so `$&`/`$'` in a preamble can't corrupt
   output.

### Export workspace UX

Grouped `<optgroup>` template picker; template description block now shows
submission-limit facts and a one-click "apply suggested add-ons" hint
(never auto-applied — the user's saved add-ons win). `checkLimits` lint
added to the pre-flight run.

## Verification

Headless harness (`buildBundle` per template with a mock Yjs doc) +
**local Tectonic compile of all five templates to non-empty PDFs**.
Asserted per-template: correct cite command (`\cite` vs `\citep`), figure
ref prefix present, 3 citation keys collected including the table caption,
abstract routed into frontmatter for placeholder templates, no unreplaced
`{{…}}`. Regression-tested a single paragraph with `H~2~O`, `x^2^`, four
ref tokens, bold, a cite, and a code span → all render correctly in both
default and cleveref modes. Legacy `mebp-journal` output unchanged.

## Not in this release

Embedded-file journals (Nature/Science/PLOS/ACS) — Release 3, needs the
journals' `.bst`/`.sty` kits in `extra_files`. Editor-side citation-style
rendering — Release 4. The Cloud Run figure-fetch stub — Release 7.
