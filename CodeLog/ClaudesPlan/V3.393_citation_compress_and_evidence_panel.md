# V3.393 — Citation sort & compress, packed superscripts, click-for-evidence panel

## Goal

Three refinements Alex requested right after V3.392 made citation
families render at all (Nature/superscript screenshot):

1. **Sort & compress**: `[1,2,3,9]` should render `[1–3,9]` — same for
   superscripts — the way natbib `sort&compress` / the `cite` package
   typeset multi-citations.
2. **Packing**: superscripts scattered — `²², ²³, ²⁴ …` with huge gaps
   (justified 2-col text stretched the `", "` separators) and groups
   even split across lines (`²⁷,` / `²⁸`). A multi-citation must be ONE
   packed, unbreakable token.
3. **Hover + click → evidence**: every numbered citation gets a hover
   affordance; clicking opens a **left panel** with the citation's
   metadata and all evidence attached to that citation's use.

## What was done

### 1+2 — `renderCitationChip` (rm/js/paper-editor.js)

For numeric families (superscript / numeric-bracket / numeric-paren):

- Resolve every key → `{key, hit, n=getNumber(key)}`, dedupe keys.
- Sort numbered entries ascending; consecutive runs of **3+** collapse
  to `a–b` (en dash); runs of two stay `a,b` (natbib semantics).
- Un-numbered keys (index still loading) trail as bare keys.
- **Display-only**: `data-src` keeps the author's original key order, so
  the serializer round-trips the exact source token. Range chips carry
  all covered keys `;`-joined in `data-key` (verified: nothing else
  consumes `data-key`) + a multi-line `n. Title` tooltip.
- Separator `", "` → packed `","` (no space → nothing to justify-stretch).
- Author-year / narrative paths unchanged (share the new `chipHtml`).

CSS: `.pe-cite-family-{superscript,numeric-bracket,numeric-paren}` get
`white-space: nowrap` in paper-editor.css; paper-doc-view.css re-asserts
it with `!important` for `.pdv-sheet` **and `.pdv-probe`** (the flatten
block sets `white-space: normal !important`; probe must match the sheet
or pagination measurement drifts).

### 3 — Citation details panel (rm/js/paper-doc-view.js + css)

- Desk click delegation now checks `.pe-cite-group` FIRST and is **not**
  editable-gated (viewers can inspect). Keys come from the group's
  `data-cite-keys` (full original list — a collapsed range still opens
  every key).
- `_openCitePanel(keys)` → `.pdv-cite-panel` appended to the overlay
  (absolute, left, under the toolbar via measured offset, z 30, slide-in
  animation). Per key:
  - number in the family's wrapper (`[n]` / `(n)`; `@` when unnumbered),
  - metadata from `PaperEditor.getCitationByKey()`: title, authors via
    the existing `_authorList` (escaped), journal · year;
    volume(issue):pages, DOI link, monospace `@key`; unknown key → "not
    in the lab library",
  - **Evidence in this draft**: `_loadCiteEvidence` walks
    `PaperBulletClaims.getAllClaims()` (whole draft, not one paragraph),
    maps claim evidence `{paperId, annId}` → citation key via
    `getCitationList()` `itemId`, groups one card per (claim, key), and
    fetches highlight text from `papers/{paperId}/annotations/{annId}`
    (`target.pages[].selectors.textQuote.exact` + `comment`) — the exact
    chain the editor's V3.192 citation-popover claim context uses.
    Cards: Claim badge + status pill + statement + per-highlight stance
    (✓ supports green / ✗ counters red) + quote + comment. Empty state
    explains how to attach evidence.
- Seq-guarded async (`state.citePanelSeq`); Esc order popover → cite
  panel → close; `close()` tears the panel down; panel is a sibling of
  the desk so re-renders don't destroy it.
- `_mountSheets` rewrites cite-group tooltips ("Click to edit citation"
  → "Click for citation details & evidence").
- Hover CSS: pointer cursor + blue tint on `.pe-cite-group[data-cite-keys]`
  (must `!important`-override the flatten block's `cursor: text` /
  `background: none`).

## Deliberate choices

- Compression happens **within one `[@a; @b; …]` token**. Adjacent
  separate tokens (`[@a] [@b]`) do NOT merge — LaTeX wouldn't either
  (separate `\cite` commands don't compress); authors who want ranges
  put keys in one citation.
- The editor keeps click-to-edit on chips (its existing popover); the
  panel is a Document-view affordance — edit vs inspect stay separate.
- Bibliography entries don't open the panel (inline citations only, as
  asked); cheap follow-up if wanted.
- Claim-detail slide-out (`PaperBulletClaims.openClaimDetail`) is not
  linked from the panel — it would open BEHIND the z-4200 overlay.
