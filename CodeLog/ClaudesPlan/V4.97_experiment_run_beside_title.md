# V4.97 — Scientia: an experiment's run number beside its title, never in it

## Why
Gabe, 20 Nov: "Each experiment should not have Run x in their note title, but rather have it as information next to their placement in Portfolio. The run number also appears when you are in the note canvas."

## What changed (`13c-chain.js`, `CHAIN.runNo` / `runChip` / `migrateRuns`)
- **A new run of a series** (+ Experiment → Continue a series) is named with the series' name alone. V4.15 named it "… Run 3"; `CHAIN.nextRun` no longer adds the number. The number stays where it was already kept, `run` on each of the run's notes. The dialog's hint still says "Run 3 of “…”".
- **Once:** a title that ends in "Run N" (an experiment's name, as V4.15 made them) loses it on every note of that run, and `run` takes N where it was not set (`settings().expRunTitles497`).
- **The run beside the title:**
  - in the Portfolio, beside the experiment's name (`15-portfolio.js`: the experiment's row, or the note's row for a one-note experiment);
  - in the note: beside the title in its header (`12-doc.js`), and in the note's first box beside its stage, on the canvas.
  - It shows for a run of a series, or any run past the first; the tooltip names the series.
- **Settings → Experiment series** (`expseries`): *Show the run number* (on by default). The preview shows the names without "Run N", with the chip when it is on.
