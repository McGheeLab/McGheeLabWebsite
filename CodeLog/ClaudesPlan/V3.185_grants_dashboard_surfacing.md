# V3.185 — Grant Drafts on the RM Home Dashboard

## Goal

Surface the V3.179 grant drafts on the RM home page so users see open
drafts and upcoming submission deadlines at a glance. Without this, the
grant writer is one nav-click off from the dashboard and a user has no
quick signal that they have a draft sitting at "needs-review" or a
deadline approaching.

Two-line change scope:

1. **Grant Drafts card** on the dashboard cards grid, slotted between
   Calendar and Proposals (logical pipeline: Drafts → Proposals →
   Awards). Shows count of `status` ∈ {draft, internal-review} drafts +
   the soonest `deadlineISO` among them. Click-through to
   `/rm/pages/grant-builder.html`.
2. **Grant deadlines injected into the deadlines table.** Each open
   draft with a non-`TBD` `deadlineISO` within the last week or future
   appears as a row with `category: 'grant'` alongside calendar
   deadlines.

## Approach

Read `grantDrafts` collection directly via `firebridge.db()` (same
pattern as the Protocols card lines 166–177 of [rm/js/dashboard.js](../../rm/js/dashboard.js)).
Gate on `firebridge.isLabMember()` so a guest signin doesn't 403; wrap
in try/catch so a rules denial or transient failure silently skips the
card rather than crashing the dashboard.

The `grantDrafts` variable is hoisted to the outer scope of
`_runDashboard()` so the deadlines-table injection (~250 lines later)
can iterate the same array without a second collection read.

## Out of scope

- "Open drafts assigned to me" filter (would need a `pi.uid` index +
  query). The current card shows lab-wide drafts because `grantDrafts`
  is a lab-shared collection — same semantics as Proposals/Papers cards.
- Drag-reorder of dashboard cards.
- Grant draft deadline notifications via push (lives in the Mobile
  app wishlist item).
