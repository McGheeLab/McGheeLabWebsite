# V3.570 — App chrome + chat composer refinements

> Alex feedback (2026-07-26), continuing the app UX pass. Web-repo
> FTP-only + one OurlabMobile config change.

## Changes

1. **Hide the Workflows / All Pages / Split / My Workflows nav buttons in
   the app.** `rm/js/nav.js` adds `.nav-app-hide` to the three top links
   (via `makeTopLink`) and the My Workflows dropdown; `rm/js/mobile-shell.js`
   hides `.nav-app-hide` under `body.ourlab-app`. The RM nav keeps the
   brand + account avatar; each page's own tab bar is the nav in the app
   (My Day Day/Week/Month, Team Focus Week/Month, Tasks Dashboard/
   Completed/Market, Chat Overview/Chat/Files/Search) — the "same top tab
   nav concept" as chat. Desktop web unchanged.

2. **Chat format (Aa) → compact horizontal toolbar under the input.**
   Small icon buttons (B / I / S / `<>` / `</>` / @) on their own
   full-width row beneath the textarea, shown only when Aa is tapped.
   `rm/js/chat.js` `renderFormatBarHTML` + `_formatBarOpen` + `applyFormat`
   (`wrapComposerSelection`); rendered after `.chat-input-wrapper` with
   `.chat-format-bar { flex: 0 0 100% }` so it wraps to its own row in the
   flex-wrap `.chat-input-area`. Replaces the V3.569 fold-up sheet.

3. **Keyboard raises from the bottom for every input.** OurlabMobile
   `capacitor.config.json` sets `Keyboard.resize: "native"` (with
   `@capacitor/keyboard`, added V3.569) so focusing any text field pushes
   the WebView up and keeps the field — and fixed-bottom composers /
   `APP_SHEET` fold-ups (My Day, etc.) — visible above the keyboard.

## Files

- `rm/js/nav.js`, `rm/js/mobile-shell.js` — nav-button hide.
