# V3.936 — Scientia: eight changes from Gabe's list

## Goal

Gabe (27 Oct 2026), for the Scientia lab notebook:

1. Pills left untouched for 3 s roll into their bar (not 10 s).
2. Notes written in an HTML page (maximised), ported out of the page like quotes, and still shown in the page.
3. An HTML page stays as it was left (a slider at the value it was moved to) across reloads and revisits.
4. Regions and components fold with a small arrow left of their title; a region can be copied (embedded) into a note
   like a component; regions nest; a region connects like a component.
5. Tab in a protocol step goes to the next step (a new one after the last); Shift+Tab to the previous.
6. Pen strokes go on top of images, and ink written on an image is glued to it when the image moves.
7. An empty image of an image panel can be a whiteboard, opened full-window for the pen — "the whiteboard should come
   directly from the whiteboard in the lab": the Lab Notebook's own whiteboard.
8. A protocol step can be tied to another protocol (step 1 "synthesize a 2D hydrogel" → that protocol).

The shared lab layer (`lab-mode.js`, `cloud-sync.js`, `scientia-cloud.py`) is not edited.

## Approach

- **Pills (1)**: the lab layer exposes its pill state as `SIS_LAB.pills` (`dockMs: 10000`). The app sets
  `SIS_LAB.pills.dockMs = 3000` at `DOMContentLoaded` (`99-boot.js`), after the lab layer has run (web and desktop).
  The lab's own default and its comments still say 10 s; if Alex prefers, the default can move into `lab-mode.js`.
- **HTML state (3)** — `13zze-html.js`: the page's copy already carries the quote reporter (`13zw` `QUOTE.SCRIPT`); a second
  script (`QUOTE.more`) reports trusted `input` / `change` / `toggle` of form fields and `<details>` (by id, else by
  index) as `{sis:'state'}`; the app keeps it on the block (`htmlState = {media, v}`, saved quietly — not an undo step)
  and writes it into the copy, so every new frame (the note redrawn — which happens on every change in it —, the page
  maximised, the app restarted) starts as it was left; the frame applies it after `load` (and once more after 800 ms for
  late controls), dispatching `input` + `change` so the page's own handlers redraw. A reloaded frame (⟳) asks
  (`hello`) and gets the latest. The card and the maximised view stay in step (`restore`). ⋯ → *Back to how the page
  starts*. Not kept: controls a page draws itself (Plotly zoom, SVG sliders).
- **HTML notes (2)** — same module: ✎ Note in the maximised page's bar → the next click in the page reports a spot
  (`{path, fx, fy, px, py}`: the element under it by child indices, the place inside it as fractions, page coordinates
  as a fallback) → a small editor → a note component beside the page (`quote: {src, note: true, at | exact…}`, wired
  `comments` to the page), so it is a quote-like component on the paper, listed (as a note) in the maximised page's side
  panel. The page draws every note as a pinned sticky (in the card too), re-placed on resize; clicking a pin edits /
  removes it. Selecting text offers ✎ Note too: a note on a passage (highlighted, the pin at its end). Quotes without a
  passage are no longer sent to the highlighter (`13zw` `paintMarks`).
- **Regions (4)** — `13v-region.js` rewritten around nesting: `members` may hold region ids; `blocksOf`, `subRegions`,
  `ancestors`, `hider`, `tidy` (empty regions and dangling ids go). A region drawn around members of a region (or around
  whole regions) sits inside the closest region holding them all; a component or region dropped in a deeper region joins
  it, Alt takes it out into the region around (as before for components). Deleting a region leaves its contents in the
  region around it and drops its connections. **Fold**: `r.collapsed` + `r.at` (where it was): only its title shows (a
  card, above the paper's components); its contents (and ink glued to its images) are hidden; connections to anything
  inside end on it (`REGION.shown`, `12b-wires` `w.f / w.t`). **Connections**: a region id is a wire end — `M.end(id)`
  / `M.endName(id)` (`04-model.js`), `rectOf` finds a region, `drawWires` / names / the inspector / chips / chain-drop
  use them; a ● on the region starts one; dropping on a region's title ends one (`LINKS.regionAt`, `13zp`); a timer's
  wire still tags the region (13za). **Embed in another note…** (region ⋯) and a plain drag of its title into another
  pane (`13zb`; Alt still moves): text components are embedded live (refs), ink / images / files / tables / plots /
  equations / calculators / plates / views are copied, the regions re-made around them (nested), the connections
  between them drawn again. **Components fold** too: ▾ left of the title (`b.collapsed`, `12-doc.js`).
- **Protocols (5, 8)** — `13b-protocol.js`: Tab / Shift+Tab in a step editor (`tabFrom`, after saving the step — an
  iteration of a used registered step behaves as with Enter) and in a run's temporary steps (`tabRun`). A step can be
  tied to another protocol (`step.sub`, step ⋯ → *Tie to another protocol…*; protocols that lead back are not offered,
  `reaches`); the tie is kept by a new wording or a split. Under the step: ↳ name · n steps (▸ shows its steps, three
  levels deep), and where the protocol is run, ▶ *Run it here* — a run of it below, `parentStep = {runId, stepId}`,
  wired `needs`; finishing that run checks the step (and the note's timer keeps running for the parent run).
- **Ink on images (6)** — `13zf-ink.js`: the pen may start on an image panel's images (`INK.onImage`); a stroke written
  on a panel makes or extends ink glued to it (`ink.glue = {to, dx, dy}`; ink on and off the image no longer gather
  into one). `13zzc-glue.js`: glued ink is drawn over the image (z-index 5, only its strokes take the pointer), follows
  the image in every drag (it hooks `drawWires`, which every drag calls), on every redraw (undo, sync) and into another
  note (`MOVE.expand`); its new place is saved quietly. Dragging the ink itself re-glues it to the image it lands on.
- **Whiteboards (7)** — `13zzd-board.js`: ✎ Whiteboard in an empty cell makes `cell.board = {lab: 'nb…_<uid>', owner,
  title}` — a board of the Lab Notebook's whiteboard (`/rm/pages/notebook-board.html`, the `whiteboard.js` engine,
  `userData/{uid}/notebookBoards/{board}`), the same id rule as the notebook's whiteboard block. The cell shows the
  board (a frame, not interactive); a click opens it full-window (Done / Remove whiteboard / Open in a new tab). It needs
  the lab sign-in, so boards are made where Scientia runs on the website (`window.__sisCloud.user`); the desktop app
  shows a board's card and opens it on mcgheelab.com in the browser.
