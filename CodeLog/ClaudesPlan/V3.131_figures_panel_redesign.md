# V3.131 — Figures panel redesign (streamline + visual polish)

## Goal

Reported: "the figure pannel creator is hard to use, we need to stream
line it all and make it look much better." The V3.115 → V3.127 Figures
tab row stacks 7+ small sections vertically (caption preview, label
row, Numbered checkbox, subfigures, actions, then a `<details>` editor
body with upload + caption editor + 4-field layout grid). The result
is busy and the user has to hunt for what they want.

V3.131 collapses the row into 4 clearly-grouped sections with cleaner
typography:

1. **Header** — large thumbnail (140×100) + label input + Numbered
   toggle + actions (Insert reference / Scroll to block / Delete).
   `Fig. N` badge overlays the thumbnail.
2. **Caption** — single full-width Y.Text editor. The pre-existing
   redundant caption preview line is dropped (the editor *is* the
   caption).
3. **Sub-panels** — bigger chip row + clearer "+ Add panel" affordance.
4. **Layout** — collapsed `<details>` (width / placement / centering /
   alt) so it's out of the way until needed. Upload control sits at
   the top of this section as a single-button row, since it's the
   first thing the user does when starting a figure.

## Approach

### Section ordering reflects user task flow
- Header (identity + key actions): always visible
- Caption (the most-edited field): always visible, full-width
- Sub-panels (panel labels for `Fig. 3 (B-C)` references): always visible
- Layout / upload (rare edits + initial upload): collapsed `<details>`

### Visual polish
- Thumbnail bumped from 96×72 → 140×100 with a subtle shadow.
- `Fig. N` badge now overlays the bottom-left of the thumbnail.
- Label input becomes the primary identity field (monospace, prominent).
- Numbered checkbox sits inline with the label row.
- Chip styling for sub-panels gets larger touch targets.
- Section labels use uppercase 10px gray + 4px margin-bottom for clean
  hierarchy.
- "Insert reference" + "Scroll to block" become primary / secondary
  buttons with proper visual weight.
- "Delete figure" added (was missing — only available via doc-side
  block toolbar before).

### Caption preview retired
The duplicate caption preview line (rendered first-line of the caption
Y.Text) is removed from the row. The caption editor is the only
caption surface in the panel — fewer DOM nodes, no sync-state bug, no
"which one is the source of truth" confusion.

### Upload row simplified
Currently the upload row has a `<button>Upload image</button>` + status
text. V3.131 moves it inside the Layout `<details>` (since it's a
once-per-figure action) and tightens the styling. The button shows
"Upload image" when no `storage_path` and "Replace image" when one
exists.
