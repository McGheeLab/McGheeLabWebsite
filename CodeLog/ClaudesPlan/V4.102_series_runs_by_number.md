# V4.102 — Scientia: fixes the demonstration takes turned up — a series' runs named by number; Open a component lands in a note opened for the first time

## Why
V4.97 took "Run N" out of an experiment's title, so every run of a series now has the series' name. Three places still named the runs by their titles, and the series' Synthesis took its first run's chip. The takes for the demonstrations (V4.103) showed them:
- the hint of + Experiment → Continue a series read "Run 3 of “30 kPa series” — after 30 kPa series, 30 kPa series";
- the series' Synthesis read "it covers 30 kPa series, 30 kPa series and 30 kPa series";
- a run joining it was announced as "“30 kPa series” joins the series' synthesis";
- the series' Synthesis showed "Run 1" beside its title, though it covers every run.

## What changed
- `13c-chain.js`:
  - the hint lists the runs by number ("— after Run 1, Run 2");
  - `CHAIN.runNo` returns nothing for the series' own Synthesis (a note with `synthRuns`), so it carries no chip. A run's own notes keep theirs.
- `15e-syntheses.js`:
  - the line in the Synthesis reads "it covers Run 1, Run 2 and Run 3", each a link to that run;
  - the message reads "Run 3 joins the series' synthesis".

## Open a component, in a note never opened before (`12-doc.js`)
The take of *Open a component* (V4.67) showed it: a task's Open, in a note with no saved view, centred the task at 50% and then lost it, ending at the whole-note view (76% here) with the task off-centre.
- **Cause:** `fill()` asks for the focus before `render` asks for the first-open fit, so the fit ran after `landOn` and replaced its view.
- **Fix:** `landOn` marks the pane (`_arrived`), and the first-open fit stands aside for a note opened to land on a component. `render` clears the mark.
