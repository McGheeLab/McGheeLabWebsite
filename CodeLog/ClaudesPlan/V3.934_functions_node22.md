# V3.934 — Cloud Functions on Node.js 22

## Goal
The 27 Oct deploy warned: "Runtime Node.js 20 was deprecated on 2026-04-30 and will be decommissioned on 2026-10-30, after
which you will not be able to deploy without upgrading." Alex: "do it".

## Approach
- `functions/package.json` `engines.node` → "22" (the Firebase CLI reads the runtime from here; `firebase.json` sets none).
- Keep `firebase-functions` 5.x / `firebase-admin` 12.x. The CLI's "outdated firebase-functions" warning is about v6+,
  which changes what `require('firebase-functions')` exports. That is a separate, larger change.
- Verify on a real Node 22 (`npx -p node@22`): load `index.js`, run every unit test.

## Deploy (Alex)
`firebase deploy --only functions` (all 60, so each moves to Node 22). Before 30 Oct.

## Not changed
`functions/paper-compile` is a Cloud Run container (`FROM node:20-bookworm-slim`). It isn't covered by the Cloud Functions
deadline, so it stays on its image until it is rebuilt deliberately.
