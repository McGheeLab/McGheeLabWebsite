# V3.400 — Typed units: Type → Unit dropdown pair + type_XX auto-naming

## Context

Alex: "the nodes should be changed so that units inherit from a type —
type: volume, length, temperature, etc picked from dropdown; unit is a
subset in a dropdown as well. doing this prevents the user from making
errors. other things should also follow this same structure, and
variables should be named by type_XX."

## Design

### No schema change — type is DERIVED
`params.unit` remains the single stored value everywhere (import/export,
compile, doc view, notebook untouched). The TYPE is derived via the
existing `categoryOfUnit()` dimension system (case-sensitive UNIT_MAP,
V3.369). Legacy free-text units keep working: a non-catalog spelling
(`uL`, `hr`) presents as **Custom** with the exact string preserved.

### Kernel (`rm/js/protocol-graph.js`)
- `UNITS_BY_CATEGORY` — curated canonical subsets (µ over u, ² over 2),
  every entry a UNIT_MAP key: volume nL/µL/mL/L; mass pg→kg; amount
  pM→M + nmol→mol + mg/mL + g/L; length nm→m; area µm²→m²; temperature
  °C/K/°F; time s/min/h/d; ratio %/×/AU/fraction.
- `unitTypeOptions()` → ordered `{key, label, units}` list;
  `unitsForCategory(cat)`.
- `isAutoName(name, nodeId)` — true only for THIS node's seeded
  placeholder (`value_<idtail>`, `k_`, `calc_`, `out_`, `seq_`, `opt_`,
  `list_` + the node id's last 4 chars), a previous auto-name
  (`volume_01`-shape), or empty. Hand names (`volume_each`, `k_on`)
  are never touched.
- `autoNameForCategory(graph, cat)` → next free `<type>_NN` (01, 02, …)
  across every produced var in the graph; null for non-dimensions.

### Editor (`rm/js/protocol-graph-editor.js`)
- `unitField(label, autoRename)` in `_configFields` replaces the
  free-text Unit input on **input / constant / equation** (autoRename
  on) and **ordered**'s node-level default unit (autoRename off — its
  `field` is a semantic axis name). Two selects: **Type** (Unitless,
  the 8 dimensions, Custom…) and **Unit** (that type's subset); Custom
  swaps in a text input. Picking a type sets the unit to the current
  one if it fits, else the subset's first; picking Unitless clears.
- **type_XX auto-naming**: when a type is picked and
  `isAutoName(p.name, n.id)`, the variable renames to
  `autoNameForCategory` (e.g. `volume_01`) and outgoing edges re-point
  (same single-produced-var logic as manual rename).
- `_unitCellSelect(cur, onCommit)` — grid-row variant: one `<select>`
  with an optgroup per dimension + "— " (unitless) + preserved
  "(custom)" option + "custom…" (swaps to text input). Used by the
  **code outputs** grid and the **ordered members** grid unit cells.

### Tours (`rm/js/protocol-graph-tours.js`)
Six step texts updated to the new mechanics (pick Type Volume → µL;
µM from the Amount group; M from the Amount group; the input node tour
now teaches the `volume_01` auto-name convention). No condition changes.

### CSS
`.pge-unit-pair` flex row inside `.pge-field`; `.pge-unit-cell` styled
like grid inputs.
