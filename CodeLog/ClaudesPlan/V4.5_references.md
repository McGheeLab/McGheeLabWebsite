# V4.5 — References

## Goal
Gabe (16 Nov 2026): "Add a new component kind called reference, which registers whatever is in that component for the user to quickly lookup or reference in another note. References are unique in which it can coexist with another kind. A reference list should become available. Add /reference as a command which brings a gallery popup for you to search your references. References should live as a separate inner tab of Atlas. Reports from HTMLs or PDFs should as well (in an additional tab in Atlas). Make the gallery view modern and almost like a clean display of each with ease of navigation and search capabilities. Bring forth some examples in an artifact."

## Approach
- **A flag, not a kind.** `b.ckind` holds one kind; a reference has to sit beside it, so it is `b.isRef` (+ `b.refAt`) on any block (a component, an image panel, a table, an equation, a PDF or page). The kind picker gains "Also a reference" under the kinds (`CKINDS.pick` wrapped: one more row in its menu); the component's menu gains "Make it a reference" / "No longer a reference" (`DocView.boxMenu` wrapped); `/reference-mark`. The card carries a bookmark (`DocView.box` wrapped; `.rf-mark`).
- **The gallery** (`REFS.gallery`, `/reference [words]`): an overlay with one search box (words over name, text, table cells, TeX, note, project, terms; `type:` `kind:` `note:` `project:` `tag:` — the terms it uses are its tags), chips for type, kind and project, a grid of cards each drawn as what it holds, and a preview pane. Keys: arrows, Enter, Alt+Enter, Esc. The note's project first (Settings).
- **Putting one in a note reuses the bridge** (13zzu `BRIDGE.make`, at the view centre `CLIPX.spot`): it stays live and points back; `asRef` makes it quiet (`.ref-use`: dashed, "Reference · from", no empty "why").
- **The Atlas's inner tabs** (`ATLAS.render` wrapped in 14g, after 14f): Room (the three-axis room, unchanged), References (`REFS.page`: groups by note / project / kind / date, gallery or rows), Reports (`REFS.reportsPage`: blocks with `ckind: 'report'`, the figures with `clip.src` = the report under each).
- **Settings → Features → References**: switch, four settings, live preview; `FEAT.audit()` empty.
