## Key decisions

- **Pen mode on the web.** Gabe's "pen mode off → the pen pans" keyed on `INK.shown` (the ink bar). On the web the ✎ cog
  uses `INK.shown` for pen *settings* and the pen hand sets `INK.mouse`. The app now asks `INK.writing()` =
  `INK.shown || INK.mouse`, so the desktop is unchanged and the web's pen hand writes with the settings bar hidden.
  Nothing in `src/` branches on the target.
- **Canvas export on the web** removes the target flag, the cloud shim and lab mode from the copy it writes (the regex
  is built so the desktop build never contains the shim's file name — `scientia_build.py` refuses that).
- **Export for the lab website** is hidden when `SIS_TARGET === 'web'`.
- **+ Insert icons**: four new rows get Heroicons (`view-columns`, `squares-plus`, `chart-bar`, `star`) in `INS_PICS`;
  path data copied from `rm/js/icons.js`, caps stripped like the others.
- **Library groups vs RM collections**: on the web the Library tab is RM's, so groups show on the desktop only.
  `scientia.library` is folding into `rm.library`; when it does, groups map to RM collections (a later, shared PR).
- **Hub**: `MEDIA_EXTS` does not take spreadsheets yet; a table's cells travel in the record, so nothing is lost. Adding
  `xlsx xlsm xls ods csv tsv txt` to `functions/scientia-hub-core.js` (and the bridge's `IMG_EXTS`) is a lab follow-up.
