# V3.839 — Canvas controls: a sheet that grows and zooms out, coloured + scalable cards, movable pills, custom pens and highlighters

**Alex (2026-10-22):** *"the canvas is not scaling with the items placed in it. we should be able to color the
items. the items can be scaled up or down by the user. the tool radial selection buttons can be moved around on
the page wherever the user wants them. the color pen selection should get custom colors. there should be a
highlighter option as well. the user can add custom amount of pens and highlighters as they please."*

Follows V3.837/V3.838 (Scientia frame on both canvases: `CodeLog/ClaudesPlan/V3.832_scientia_integration_plan.md`).
Everything here is in the ENGINE (`whiteboard.js` + `whiteboard-board.css`), so the lab notebook and the paper
figure board get it together; the hosts are untouched.

## 1. The canvas scales with its items

What Alex saw: cards pile up at the foot of the last page and there is no more canvas (the rail with ＋ page is
folded on host boards), the lens cannot zoom OUT (MIN_SCALE 1), and on a landscape screen with `fitWidth` the top
~6 % of page 1 is unreachable (`clampOriginY` centred a page taller than the stage).

- **The sheet grows.** `growSheetIfNeeded()` (debounced from `renderItems` and `finishStroke`): when a card's foot
  or a stroke on the LAST page reaches its lower 8 %, `appendPageNoMove()` adds a page — in continuous mode the
  canvas simply gets longer. Owner only, host boards only, never in replay, ≤ 60 pages.
- **Zoom out.** `minScale()` = 0.3 on host boards (1 on class boards, whose followers mirror a 100 % stage).
  `clampView` centres the page horizontally below 100 %; `sheetViewH()` is the visible sheet height AT the current
  scale when below 100 %, so scrolling and page tracking see what is on screen. `clampOriginY` lets a page taller
  than the view scroll from its top edge to its bottom edge (fixes the hidden strip).
- **⊡ Fit everything** on the View pill: `fitAll()` frames the content extent (cards + ink) at ≤ 100 %.
- Bug found on the way: `strokesInRect` iterated flat point arrays as triplets (production strokes are flat
  `[x,y,p,…]`; the V3.837 harness seeded triplets) → a region never found its strokes. Fixed for both shapes.

## 2. Colour the items

`item.color` (hex or '') on widget docs. A colour dot in the card header (owner, host boards) opens a palette of
soft tints + "none"; `updateItem(id, { color })`. Rendered as `--wb-card` on the node (`.wb-tinted`: header fill,
body wash, border), in the export (`drawWidgetItem` header band) and in replays (`itemEventPayload` carries it;
`whiteboard-replay.js` copies it back).

## 3. Items scale up or down

A corner grip (`.wb-wgrip`) on every widget card, always available to the owner (not only in Arrange). Dragging it
changes `w`; the card's text scales with its width — `widgetScale(it) = clamp(√(w / 0.42), .75, 1.6)` on the font
size — so a card grows or shrinks as a whole. Same factor in the export. Arrange mode keeps its own handle.

## 4. Movable pills

Drag a pill button (> 8 px) to move it; drop position stored per pill as fractions of the board
(`localStorage wb_pillpos_v1`), re-applied at every size; the fan direction follows the quadrant (left/right,
up/down) and the caption flips with it. Double-tap a pill → default position. The click after a drag is swallowed.

## 5. Custom pens + highlighters

The **pen set** replaces the fixed four colours on host boards: `[{ id, kind:'pen'|'hl', color, w }]`, kept on the
device (`localStorage wb_pens_v1`, shared by every board; defaults = the four pens + one yellow highlighter).
Pens fan: the pens, eraser, three widths (applied to the current pen), ＋ pen, ＋ highlighter, undo, clear.
Tap the selected pen again → the **pen editor** (in the pill box, no browser popup): Pen / Highlighter, 18 swatches,
a native colour input for any colour, a width slider with live preview, Remove (two taps), Done.
A highlighter stroke is stored with `hl: true`, constant pressure, and painted with `globalAlpha .4` +
`multiply` so ink stays legible under it — same path for the live layer, the committed ink, thumbnails, exports and
replays (`paintStroke`). Class boards keep their toolbar (`S.hl` is cleared by its colour/width buttons).

## Decisions
- Pen set + pill positions live on the device, not in Firestore: no rules, instant, and a tablet's pens are the
  tablet's. A synced set is a later step if Alex asks.
- Resizing scales text with √(width): wider cards read bigger, but a narrow migrated figure card never drops
  below 75 %.
- Highlighter never varies with pressure (uniform band), always under the cards (ink layer).
