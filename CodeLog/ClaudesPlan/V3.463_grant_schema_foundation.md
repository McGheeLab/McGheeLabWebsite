# V3.463 — Grant unification R1: schema/registry foundation

> First release of the grant-writing unification program (plan:
> `~/.claude/plans/the-papers-page-the-optimized-dongarra.md`). Folds the standalone
> grant/biosketch/facilities pages into the paper editor as a `paper_type: 'grant'`
> variant. Success bar for the whole program: faithfully reconstruct the real
> `GELS CAREER/Final package/FINAL/NSF_CAREER_ProjectDescription2.pdf` in the editor.
> This release is the pure data layer — no UI yet.

## What shipped (rm/js/paper-schemas.js only)

- **18 grant "attached-document" section kinds** registered in `PAPER_SECTION_KINDS`
  + `SECTION_KIND_LABELS` + `SECTION_STYLE`: `project_summary`, `specific_aims`,
  `research_strategy`, `biosketch`, `facilities`, `budget`, `budget_justification`,
  `current_pending`, `collaborators_coa`, `synergistic_activities`,
  `data_management_plan`, `mentoring_plan`, `resource_sharing`, `vertebrate_animals`,
  `human_subjects`, `select_agents`, `letters_of_support`, `pecase_statement`.
  Registration is the hard prerequisite — `normalizeTree` coerces any unregistered
  kind to `custom` on every load.
- **Zero new narrative kinds, zero new block kinds.** Reading the real Project
  Description showed the narrative (Overview, Significance, Background, Research
  Plan/Aims, Education Plan, Broader Impacts, Timetable) is flowing prose with a
  3-level heading hierarchy — already handled by `custom` sections + the shipped
  subheading blocks (levels 2/3). Equipment folds into `facilities` (matches how NSF
  actually requires it).
- **`SECTION_STYLE` gains an advisory `pageBudget` field** alongside the existing
  `maxWords` (nothing enforces either — surfaced in the UI in a later release).
  `research_strategy`/`specific_aims`/`facilities` allow subsections; the rest are
  prose-only, matching real document structure.
- **New export `GRANT_ATTACHED_KINDS`** (the 18 kinds) — the single source of truth
  R3's export skip-guard and R4's Grant-Docs page will consume. `references`,
  `cover_letter`, `suggested_reviewers` are deliberately NOT in it (already handled by
  the existing submission-doc guards / auto-generation).
- **Grant starter templates** in `PAPER_TEMPLATES`, each tagged with a new `types`
  field (existing journal entries → `['journal']`; `blank` → all types): `nih-r01`
  (replaces the old thin stub), `nih-r21`, `nsf-standard`, `nsf-career`. `nsf-career`
  mirrors the real submitted outline — ten `custom` narrative sections
  (Overview and Objectives … Timetable) + `project_summary`, then the attached kinds.
  The `types` field is what R2's creation-flow picker filters on.
