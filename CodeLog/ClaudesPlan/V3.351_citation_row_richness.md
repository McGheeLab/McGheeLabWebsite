# V3.351 — Richer citation rows + add-by-DOI + live library sync

**Part of:** [FuturePlan 09 — Builder ↔ library ↔ reader bridge](../Feature%20requests/FuturePlan_12_builder_library_bridge.md) (Release 2 of 3).

## What shipped

- **Citation-index projection** (`paper-editor.js` `loadCitationIndex`)
  gains `hasPdf` (from `meta.library.pdf`) and `tags` (first 3) — light
  fields already on the items doc, no extra reads.
- **Popover rows** show 📄 (PDF in the library) + tag chips on the meta
  line. **References-tab rows** (`_buildRefRow`) show the same, plus an
  **"Abstract ▸"** action that lazily loads the abstract from the extras
  subdoc via new memoized `PaperEditor.fetchAbstract(itemId)`
  (LIBRARY_EXTRAS.load → `items/{id}/details/main`; read rule is
  isLabMember — no rules change).
- **Add-to-library upgrade** — the unknown-`[@key]` modal gains
  **"🔍 Look up metadata"** (needs a DOI or a ≥4-word title): calls
  `LIBRARY_METADATA.lookup` (same Cloud Function path as the library
  page), prefills the fields, and on Save builds a REAL entry via
  `LIBRARY_METADATA.buildPaperItem` (authors/journal/ids), keeping the
  builder's citation key; the abstract goes to the extras subdoc via
  `LIBRARY_EXTRAS.savePatch`. Without a lookup, the legacy stub path is
  unchanged.
- **Live library sync** — new
  `PaperEditor.ensureFreshCitationIndex(maxAgeMs=5min)`: invalidates +
  reloads a stale index. Fired (fire-and-forget) when the References tab
  is on screen (`_refreshPanel`) and when the citation popover opens;
  rows and the Evidence Inbox re-render on `paper-citations-loaded`.
  Papers added to the library mid-session now appear without a reload.
- Builder page now loads `library-extras.js` + `library-metadata.js`
  (both verified standalone/light).

## Verification

Popover + References rows show 📄/tags only for papers that have them;
Abstract ▸ loads once (single details/main get, second toggle instant),
empty-state message for papers without one. Unknown key → Look up with a
DOI → fields fill → Save → full entry (not stub) appears with the
builder's key; abstract lands in the extras subdoc. Add a paper on the
library page in tab A → builder tab B References reopen after staleness
window → paper appears. Non-admin: abstract fetch + lookup both pass
rules.
