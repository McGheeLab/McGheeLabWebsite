# V3.379 — Smart wire routing + shift-drag cut + interaction cheatsheet

## Goal

Make the `design` node canvas readable and quick to edit: wires that
**route around node cards** and **fan out** at shared dots instead of
stacking; **hold Shift + drag** a line through wires to **cut** them;
and a **? cheatsheet** so the canvas gestures are discoverable.

## Design

### New pure module `rm/js/wire-router.js` (`window.WireRouter`, DOM-free)
Waypoint-detour routing smoothed with Catmull-Rom → cubic beziers. Per
edge: classify forward/backward; forward edges insert a fan waypoint
when several wires leave the same out-dot (`computeFanGroups`, ordered by
target y/x/edge-id → stable, no flicker), then iteratively insert **flat
detour pairs** around inflated obstacle rects the sampled curve passes
through (side = where the straight chord passes the rect; per-`(rect,
side)` lane counters spread parallel detours; re-offense escalates
clearance, then accepts). Backward edges loop around both endpoint cards
(cheaper of above/below), long run pushed clear of corridor cards. A
clear straight edge reproduces the **exact** pre-V3.379 bezier
(`M a C a+dx,a … b`, `dx=max(30,|Δx|/2)`) — regression-stable. Every
route returns `{edgeId, d, points}`; `points` (10 analytic samples per
segment) doubles as the cut-test polyline. Cut geometry:
`segIntersect` (orientation test) + `hitsForSegment` + `polylineHits`.

### `rm/js/protocol-graph-editor.js`
- `render()`'s rAF now caches `sizeCache[nodeId]={w,h}` so a node drag
  reroutes with **no per-move layout reads** (positions are world coords
  already).
- `drawWires()` builds `edgeInputs` (a/b via `socketCenter`, obstacle
  rects from `n.x/n.y`+sizeCache), calls `WireRouter.routeAll`, writes one
  multi-segment `<path>` per edge (class/stroke/title/click-delete
  unchanged), stamps `data-edge-id`, and stashes `routesByEdgeId`. Falls
  back to the legacy simple bezier if the router is unavailable.
- **Shift-cut** (`startCut`): a Shift-pointerdown on bare canvas **or a
  wire** starts cut mode instead of pan — a dashed `.pge-cutline`
  follows the pointer, crossed wires highlight live (`.pge-wire-cut-hit`,
  incremental `hitsForSegment` on each new segment), pointerup deletes
  every hit edge (`filter + persist + render`) with a "✂ Cut N wires"
  strip message. Wire click-delete ignores `shiftKey` so the gesture
  never double-fires.
- **Cheatsheet** (`toggleCheat`): a `?` palette button toggles a small
  `.pge-cheat` overlay listing every gesture (pan / zoom / move / wire /
  delete / **shift-cut** / recipes / expand).

### Loading + CSS
`protocols.html` editor scripts load `/rm/js/wire-router.js` before
`protocol-graph-editor.js`. `protocol-graph-editor.css` adds
`.pge-cutline`, `.pge-wire-cut-hit`, `body.pge-cutting` (crosshair),
`.pge-cheat*`.

  loop chooses the cheaper side, clears both cards, arrives in +x;
