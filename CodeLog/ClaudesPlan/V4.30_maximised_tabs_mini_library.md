# V4.30 — The maximised reader keeps its tabs; the mini library from the left; shelves assigned to projects

## Goal
Gabe (18 Nov 2026): "When in maximized view, the multi tabs remain, but dragging the interface on the left of your screen brings up a mini library view of the current active shelves in your reader, which become the new system to navigate between PDFs or HTMLs. Shelves in libraries are assigned to projects."

(The end of the same message as V4.29's reading sets.)

## Approach
- **A new module again:** `scientia/src/17j-minilib.js` (`RLIB`) + `35-minilib.css`, wrapping `MXHL.open`, `RDOCK.open / switchTo / closeTab / full`, `RSET.pick / paintRow` (17i) and `LGROUP.side`. No direct edit to `13zzb-reader.js`, `13zz-maxhl.js` or `17d-libgroups.js`.
- **The maximised view keeps the tab row** (Settings → Reading sets by project → *The tab row stays in the maximised view*):
  - **a pane in full screen (⤢):** the reader's own row is fixed across the top of the window (`body.rs-maxrow`, CSS only) and the pane starts under it (`--rs-th`, measured after each `RDOCK.full`). What is opened from the row, + or the mini library is read in that pane and stays full screen (`RDOCK.open` gets `pane` = the full pane and is put back to full; `RDOCK.switchTo` → `RLIB.read`); × on the tab read there reads the next one, still full screen; a chip opens that set's paper full screen (17i's `RSET.use` re-fulls). Close on the pane's bar still goes back beside (V4.29).
  - **a maximised card** (a PDF's or a page's ⤢ / ⛶ on a note): it is a visit — the card becomes a tab of the set shown, or of the note's project's set when the reader is closed (`RLIB.visit`), read now — and the set's row (`.rs-maxrow`: the band, the chips) sits over it. A tab or a chip clicked there reads that paper in the reader, full screen (the card gives way, as 13zzb's `RDOCK.open` already does).
- **The mini library** (`RLIB.grip / pull / push / open / close / fill / pick`):
  - a thin grip (12 px; 22 px on touch screens) on the left edge of every maximised view, inside its `.mx-row` (below its bar), so it is inside `.embed-max`, which the edge pan (13zzh) never acts on, and left of the pills (which keep 12 px from the edges);
  - a drag to the right (mouse, finger or pen: pointer events, `touch-action: none`) pulls the panel out under the pointer; let go past a third of its width — or a plain click — and it stays open; a short pull springs back;
  - **content:** the tabs open in this set (click: read it here), then the shelves assigned to this project (each with its foci and their papers that have a PDF or a page here — `RLIB.openable`), with *All shelves (N more)* and a *This project | All shelves* switch; All shelves lists this project's first, then the rest, then the foci on no shelf. A paper in the set has a dot; the one being read is lit;
  - **a paper clicked:** `RDX.embedFor(lib)` (an embed on its literature note, made if needed — what 17e's + does), then read in the maximised view as a tab of this set;
  - **it closes** by dragging it back (past a third), Esc, a click outside, or ×. Esc must not also leave full screen: while it is open a hidden `.ovl` marker (`.rs-libguard`) makes 13zzb's key handler wait, and the panel's own Esc handler (window, capture) stops the event before a maximised card's.
- **Shelves assigned to projects:** `projectIds` on a shelf (`libsets`, kind `theme`), saved with `LGROUP.save` (synced like every libsets row). A project button (briefcase icon, the count) on each shelf of the Library's tree (`LGROUP.side` wrapped — both builds draw the tree through it) opens a popover of the projects to tick. Settings → Mini library lists every shelf with its projects and the same button.
- **Settings:**
  - *Reading sets by project* gains *The tab row stays in the maximised view* (on);
  - **Mini library** (`rlib`, needs Reading tabs; the code also needs the Library): the switch (off: no grip, no project buttons; assignments stay), *It opens on* (this project's shelves / all shelves, this project's first), *After a paper is picked, it* (closes / stays open), *Shelves and their projects*; a live preview of the panel pulled out of a maximised page.

## Decisions where the brief was silent
- A maximised card becomes a tab of the set (so the row over it has its tab lit, and the Reader button's "most recent visit" includes it).
- Tabs and chips clicked over a maximised card read in the reader's full screen rather than swapping the card's overlay, so there is one maximised reader to keep in step with the beside panes (another builder's work).
- The mini library lists only papers that can be read here (a PDF in this notebook, or a page embedded in a note); for the no-project set, "this project's shelves" is empty and All shelves is offered.
- After a pick the panel closes by default (the page gets its width back); Settings can keep it open.
