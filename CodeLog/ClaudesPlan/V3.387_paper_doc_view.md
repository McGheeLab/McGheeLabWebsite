# V3.387 — Document view: journal-styled page preview + template switcher

## Goal

An in-browser **Document view** for the paper builder: the paper renders
as **discrete journal-styled page sheets** (8.5×11 / A4 on a gray desk)
closely resembling the eventual compiled PDF — title/author block,
abstract, numbered/unnumbered sections per journal, resolved prose
(typeset citations, KaTeX, cross-refs), figures at their configured
LaTeX widths with "Figure N." captions, booktabs tables, (N)-numbered
display equations, formatted bibliography — **without building a PDF**.
It is (a) the surface for designing figure layout (click a figure →
width / placement / centering popover writing the block attrs) and
(b) THE way to change the target journal (template select writing
`paperExports/{paperId}.templateId`).

User decisions: discrete sheets (block-atomic greedy pagination, page
count shown as "≈ N") · live debounced ~1.5 s updates · interactive
figure popover.

## Architecture

**NEW `rm/js/paper-doc-view.js`** (`window.PaperDocView = {open, close,
isOpen}`) + **NEW `rm/css/paper-doc-view.css`** (all `.pdv-*`, scoped).

Reuses (all already on the builder page):
- `PaperExportTex.paperTreeFromYDoc` (plain tree, Yjs array order) +
  `fetchTemplate` (local cache w/ in-flight dedupe + offline fallback
  template).
- `PaperEditor.renderParagraphHtml` / `renderEquationHtml` (the editor's
  resolved-prose renderers — chips flattened to plain text by scoped
  CSS), numbering walkers, `getCitedKeysInPaper`/`getCitationByKey`,
  and TWO NEW exports: `ensureKatex` (math must load BEFORE measurement)
  and `getPaperMeta` (default templateId fallback =
  `meta.template_id || 'mebp-journal'`, mirroring paper-export.js).
- `PaperCiteStyle` for citation family + global first-appearance
  numbers; `PaperExportConfig.populateTemplateSelect` (paper-export-
  config.js newly loaded on the builder — pure registry, no DOM at
  parse).
- `paperExports/{paperId}` set-merge write (mirrors paper-export.js
  `_saveConfigNow`; `write: isLabContributor()` — students may switch,
  NO rules deploy).

**DOC_HINTS** — columns/margins/fonts are baked into LaTeX preambles,
not template JSON fields, so the module carries per-template render
hints (only `ieee` is 2-col: 0.75in margins, 0.17in gutter, run-in
abstract; `mebp-journal` is A4; future template JSONs may add
`render_hints` which override the map).

## Render pipeline

open → overlay shell (toolbar: journal select · zoom Fit/75/100/125 ·
"≈ N pages" · Compile PDF → link · ✕; gray desk; hidden measurement
probe) → parallel: paperExports get + `ensureKatex()` (failure → math
renders raw + status note) → fetchTemplate → render + attach listeners
(`yDoc.on('update')` ALL origins + `paper-panel-changed` → shared
debounce timer 1.5 s; detach on close; `renderSeq` guard abandons stale
async renders).

renderDocument: tree snapshot → flow items (title block full-width;
abstract per `section_kind_to_command` [`abstract_env`/`_placeholder` →
styled Abstract, ieee run-in "*Abstract*—"; `keywords_placeholder` →
"Keywords: …"; `skip` → omit; `section` → "N. Label" JS counter;
`section_star` → unnumbered]; paragraphs via renderParagraphHtml (empty
body + skeleton → "· unwritten block ·" marker); display equations with
right-aligned (N); figures at translated widths (`width` spec regex →
frac × column, `\textwidth` → full page body = spans both columns in
2-col — net-new visual, the exporter never emits `figure*`); tables from
cells map with booktabs rules (1.5px top/bottom, 1px under header, no
verticals) + caption below; bibliography last [numeric families ordered
by PaperCiteStyle numbers with `[n]`/`n.` prefixes; author-year
alphabetical unnumbered; unknown keys muted]) → footnote chips →
sequential `<sup>` + page-bottom strips → cross-ref prefixes rewritten
per `template.refs` → **measure** in the probe (batch append per width
class, one forced reflow, batch read; first render awaits
`img.decode()` w/ 8 s timeouts then caches natural sizes as
`aspect-ratio` so re-renders measure synchronously) → **greedy pack**:
letter 816×1056 / A4 794×1123 px (96 dpi exact), fill factor 0.97,
2-col column runs at 2× column capacity rendered as fixed-height CSS
multicol segments (`column-fill:auto; overflow:hidden`) with full-width
items BETWEEN segments (no `column-span`), footnote strip heights count
against the page, oversized blocks get their own page + overflow badge,
80-sheet cap → **mount** sheets (inline size/margins/font per hints,
page numbers "k / ≈N") → re-apply zoom → re-anchor open popover.

## Interactivity

- **Figure popover** (editable users; hover outline): width presets
  (\linewidth, 0.9/0.8/0.5, \textwidth, \columnwidth + current-if-custom),
  placement H/h/t/b/p (+ current-if-other, e.g. ieee `!t`), centering.
  Writes via the EXACT paper-blocks transacts (`attrs.set('width',v)`,
  origins 'fig-width'/'fig-placement'/'fig-center') so the Figures panel
  + LaTeX export pick them up; the write's own yDoc event re-arms the
  SAME shared timer the popover sets to 150 ms → exactly one re-render.
  Popover survives re-renders (re-anchor by data-block-id).
- **Template switcher**: set-merge {templateId, updatedAt ISO,
  updatedBy} (preserves authors/affiliations/addons/overrides) →
  `PaperCiteStyle.init(paperId)` → dispatch `paper-panel-changed`
  (editor chips restyle live behind the overlay) → re-render. Failure →
  status message + select revert. Export page auto-syncs (reads the doc
  on load). Read-only members see the select disabled.

## Known estimates / limitations (by design)

- Pagination is block-atomic and approximate ("≈ N pages"); LaTeX float
  placement (t/b/p) is NOT simulated — figures render where they sit in
  the source flow; placement is still editable here because the export
  uses it.
- Author block is the generic scholarly format for all templates v1
  (per-format ieee/elsarticle/achemso variants = future polish).
- Bibliography entries are the builder's index format (authors ≤6 + et
  al., year, title, journal) — not the .bst's exact punctuation.

## Verification

1. mebp-journal: A4 sheets, title+abstract p.1, numbered sections,
   superscript citations, "n." bibliography in first-appearance order.
2. ieee: 0.75in margins, 2 columns, full-width title strip,
   `\columnwidth` figures; a `\textwidth` figure spans both columns.
3. Switch mebp → ieee: paperExports merge preserves authors; editor
   chips flip superscript → [n] live; view reflows 2-col; export page
   shows IEEE on next load; switch back clean.
4. Figure popover: 0.5\linewidth → reflow; Figures panel shows the same
   value; exported .tex contains `width=0.5\linewidth`; placement +
   centering round-trip; popover survives the re-render.
5. Live: coauthor edit re-renders ≤ 2 s; close → no further renders.
6. Read-only member: opens, select disabled, figures inert.
7. preprint-authoryear: (Author Year) chips + alphabetical bibliography.
8. Edge: no paperExports doc, oversize figure (own page + badge),
   unknown cite key, footnote strip, Esc/reopen, zoom Fit/125.
