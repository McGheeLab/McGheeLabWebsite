# V3.171 — Training: Cell Tracker (lab software)

> Status: PLANNED — not yet built.
> Source repo: [`/Users/alexmcghee/Documents/GitHub/Cell Tracker/`](../../../Cell%20Tracker/)
> README of record: `Cell Tracker/README.md` (PySide6 GUI, 11 sequential pages, StarDist segmentation, three tracking backends including SerialTrack).

## Goal

Operational fluency on the lab's flagship custom confocal-image analysis
application. Cell Tracker handles the full pipeline — load → preprocess
→ segment → track → quantify → export — for ND2 / TIFF fluorescence
time-series. By the end of this training a student should be able to
run a full analysis without needing to ask Alex for any step.

## Format

Full interactive notebook (MODULE_TEMPLATE.md pattern), but with one
non-standard element: each tab corresponds to a contiguous chunk of
the Cell Tracker sidebar so the student has a 1:1 mapping between the
training and the actual GUI. 6 tabs.

## Prerequisites

- V3.164 microscope basics (foundational concepts)
- V3.166 confocal (the data this software was designed for)
- V3.168 image analysis basics (pixels, channels, LUTs — Cell Tracker
  assumes you understand them)

## Tabs

### Tab 1 — Install + launch, the .cta session file
**Bio context:** a fresh ND2 of a 24-hour live-cell time-series of a
GFP-Lifeact tumor spheroid on the AX-R.

- Background: the install flow from `Cell Tracker/README.md` —
  Python 3.10-3.12 venv, `pip install -r CellTracker/requirements.txt`,
  StarDist model auto-download, the macOS SSL gotcha
- The 4 sidebar session controls: New / Save / Load / Recover; the
  `.cta` zipped-JSON session format; when auto-save fires (every page
  change after detection has completed)
- Interactive: walk-through of the 11 sidebar pages with locked / unlocked
  state visualized — students see why "Tracking" can't be opened before
  "Detection" runs
- Worked example: load an example ND2; save a `.cta`; close the app;
  recover from auto-save

### Tab 2 — Pages 1-2: Import + Process & Crop
- Page 1 (Import): per-channel color assignment, channel enable/disable,
  Z-projection (max / mean / min); the practical decision rule for which
  projection to use given the experiment
- Page 2 (Process & Crop):
  - **Crop tab** — rectangle / ellipse / freeform ROI; entering pixel
    coordinates; cropping to remove edge artifacts from tile scans
  - **Process tab** — the trial / accept / reject loop on enhancement
    steps; the **Set as Raw** button as the lock for the measurement
    baseline
- The **two-stage processing discipline** (verbatim from README):
  truthful corrections → Set as Raw → aggressive enhancement → detection
  → Use raw data on analysis pages. Worked example showing why mixing
  the two destroys measurement fidelity.

### Tab 3 — Pages 3-4: Detection (Tune + Run)
- Page 3 (Detection Tune): pick the segmentation channel (typically
  nuclei marker like DAPI / H2B-mCherry); the StarDist parameter set
  (probability threshold, NMS threshold); single-frame tuning loop
- Page 4 (Detection Run): batch StarDist across all frames; what the
  automatic per-cell intensity measurement gives you for free
- Failure mode: bad tuning leads to under- or over-segmentation; the
  visual cue (touching nuclei merged, or one nucleus split into multiple
  blobs)

### Tab 4 — Pages 5-6: Tracking (Config + Run)
- Page 5 (Tracking Config): the three tracker backends:
  - **Spatial Fingerprint** — the default; good when cells don't move
    much per frame
  - **Topology (Hungarian)** — global optimum per pair; better for
    crowded fields
  - **SerialTrack** — for complex deformations (TFM-style); requires
    the SerialTrack_Python install (V3.174 training covers this)
- Page 6 (Tracking Run): run + visual inspection of color-by-track-ID
  output
- Decision rule: which tracker for which experiment

### Tab 5 — Pages 7-10: Results, Synthesis, Spatial Maps
- Page 7 (Results — Cells): Lagrangian view; the keyboard / mouse
  combinatorics (`+` / `-` / Fit zoom; Select vs. Pan; `<` / `>` step;
  click-on-plot-line selects cell); the valid / invalid track flag and
  why this matters for downstream stats
- Page 8 (Synthesis — Cells): multi-variable scatter + isoline plots
  with binned means ± SEM
- Page 9 (Spatial Maps): Eulerian gridded heatmaps over the image
  (density / intensity / fold-change / speed / divergence / curl);
  quiver arrows; scale bar
- Page 10 (Synthesis — Spatial): conditional spatial analysis — show
  one field filtered by the range of another
- Worked example: a single dataset taken through Lagrangian + Eulerian
  views; the student learns to read both representations of the same
  data

### Tab 6 — Page 11: Export + capstone session
- Page 11 (Export): tracked CSV, track-labeled RGB TIFF, summary plots,
  `.cta` session
- **Capstone:** a guided full-pipeline run on a provided ND2 sample.
  The student loads, processes, detects, tracks, generates results +
  spatial maps, and exports. Page validates outputs against a reference.
