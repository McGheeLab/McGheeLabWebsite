# V3.280 — BME 295C Admin Gradebook

## Context

User asked for an admin gradebook in the BME 295C dashboard that:
- Aggregates per-student × per-speaker participation
- Lets the admin rate alertness/engagement per student per talk
- Lets the admin grade the actual discussion response (group-level, not duplicated per student)
- Surfaces a composite % per student

Plan synthesized by a 4-phase Workflow run (explore × 3 → design × 3 → adversarial critique → final synthesis). Base = HYBRID design; folded in CSV export from SIMPLE + free-rider helper from COMPREHENSIVE + critique fixes (TEST_* filter, ungraded-neutral, explicit-present requirement for grading, alertness weight only counts when rated).

**In scope:** admin-only gradebook panel, manual ratings, weighted composite, CSV export, free-rider protection, per-day excused absences.

**Out of scope:** student-facing grade view, letter grades, publish workflow, multi-admin realtime sync of grades.

## Data model

Single new field on `_classData` (schedule doc `schedules/bme295c`):

```js
grades: {
  weights: { attendance: 40, discussion: 30, alertness: 30 },  // sum = 100
  alertness: {                                                  // per-student, per-talk
    [speakerSlug]: { [rosterId]: { rating: 1|2|3, ratedBy, ratedAt } }
  },
  discussionQuality: {                                          // GROUP-level (shared)
    [`${campus}-${groupNum}-${speakerSlug}`]: { stars: 1|2|3, gradedBy, gradedAt }
  },
  comments: { [rosterId]: { text, updatedBy, updatedAt } },
  excused: { [rosterId]: { [day]: true } }                      // forgives attendance
}
```

Reused, unchanged: `_classData.dailyAttendance`, `groupResponses/{...}.attendance.presentIds` (V3.252).

Defaults:
- Missing alertness rating = unrated (excluded from denominator)
- Missing quality stars = ungraded = neutral (full credit, NOT a multiplier penalty)
- Missing attendance record = NOT present for grading (overrides `bmeIsPresentOnDay`'s default-present semantics)

## Composite formula

```
w = bmeGradeWeights()                        // normalized to sum 100
hasAnyAlertness = ...
if (!hasAnyAlertness) {
  redistribute alertness weight to att+disc proportionally
  total = att*100*attW + disc*100*discW
} else {
  alert = mean(rated values) / 3
  total = att*w.attendance + disc*w.discussion + alert*w.alertness
}
total = round(clamp(total, 0, 100))
```

Defaults: 40 / 30 / 30. Configurable via 3 number inputs in the panel header.

## Render

- `renderBmeGradebookPanel()` — table of (Name · Att% · Disc% · Alert% · Total · Comment · Open) rows, sorted by total desc. Weight inputs + "Export CSV" button in the header. Inline alertness matrix in a `<details>` block.
- `openBmeStudentGradeModal(rosterId)` — per-day excused checkboxes, per-talk rows with attendance pill + response status + group stars + alertness 3-button picker, comment textarea. Autosave on change.

## Verification

1. Empty `grades` → migration runs → gradebook appears with all non-TEST rows.
2. Mark a student absent for Monday → Att% drops to 80%.
3. Mark same student excused for Monday → Att% returns to 100%.
4. Submit a group response with only 2 of 3 group members' ids in `attendance.presentIds` → those 2 get Disc% credit; 3rd stays at 0%.
5. Open detail modal, rate alertness 1/2/3 on three talks → Alert% = 67%; Total uses 40/30/30.
6. Click 2-star quality on a talk → all groupmates get 2/3 multiplier for that talk's discussion fraction.
7. Edit weights to 50/25/25 → sum stays 100, Total recomputes.
8. Edit weights to 50/25/30 → sum indicator red; bmeGradeWeights normalizes on read.
9. Inline matrix lets admin enter 10 ratings for one student in seconds.
10. Export CSV → file downloads with one row per non-test student.
