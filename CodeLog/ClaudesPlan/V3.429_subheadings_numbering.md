# V3.429 — Subheadings as first-class blocks + section-numbering options

> Alex: "in the paper editor page, i want to be able to make subsections.
> currently we have subsections as blocks of text, but they should get special
> treatment in the document viewer as well as the editor just like sections do.
> various styles should have section numbering options."
>
> (Numbered V3.429 — parallel node-editor sessions took V3.425–V3.428.)

## Design

A **subheading is a lightweight block kind** (`kind: 'subheading'`), not a nested
container — matching LaTeX's `\subsection`/`\subsubsection` model (a heading in
the section flow, positioned between paragraphs, reorderable like any block).
`body` holds the heading text; `attrs.level` (2 = subsection, 3 =
subsubsection) picks the depth. This slots into the existing 2-level tree with
minimal surface area.

Section **numbering** becomes a per-paper preset (`sectionNumbering`:
`auto`|`on`|`off`) that drives BOTH the preview and the compiled PDF.

## Changes

**Schema — `rm/js/paper-schemas.js`**
- `'subheading'` added to `PAPER_BLOCK_KINDS` (so `normalizeTree` preserves it);
  `MAX_SUBHEADING_LEVEL = 3`; `newSubheading({level,text})` factory (exported).

**Block round-trip — `rm/js/paper-editor.js`** (also fixes a latent bug)
- `blockMapToTree`/`appendBlockFromTree` now snapshot & restore **scalar attrs**
  so a subheading's `level` survives `moveSection` (snapshot→delete→rehydrate).
  Bonus: figure/equation/table scalar attrs (numbered, display, span, width,
  placement, anchor, lock, size_key, download_url, …) now survive a section
  move too — previously they were blanked. Deep Y types (table cells,
  subfigures) are unchanged (still not snapshotted).
- `insertBlockAt` handles `'subheading'` → `attrs.level` (2, or 3 via opts).
- Inserter menu: **"Subheading"** item, gated by the section style's
  `allowSubsections` (off for abstract/keywords/references/conclusions).
- Cite scan (`getCitedKeysInPaper`) includes subheading bodies.

**Editor rendering — `rm/js/paper-blocks.js`**
- `renderSubheading`: heading-styled contenteditable bound to `body` (inline
  math/markdown via the paragraph contract), a toolbar **H2/H3 level toggle**,
  reorder controls, drag handle, delete. Registered in `renderYBlock`.

**Doc view — `rm/js/paper-doc-view.js`**
- Subheading blocks render as `.pdv-subheading` (`-l2`/`-l3`) in the flow with a
  computed number; stamped `data-block-id`.
- **Numbering engine**: `secCounter`/`subCounter`/`subsubCounter`; a section is
  numbered per `sectionGetsNumber(cmd)` — `off` never; `auto` only the numbered
  `\section`; `on` any body `\section`/`\section*`. Sub-counters reset per
  numbered section. Number **format** by `geom.numbering`: `arabic` (1 / 1.1 /
  1.1.1) default, `ieee` (I. / A. / 1)) — `fmtSectionNum`/`fmtSubNum`/
  `fmtSubsubNum` + `_romanUpper`/`_alphaUpper`; IEEE hint added to `DOC_HINTS`.
- `sectionNumbering` in `loadConfig` (default `auto`) + the render signature;
  ⬒-toolbar **Numbering** select (`#pdv-numbering`, Auto/Numbered/Unnumbered) +
  `_onNumberingChange` (paperExports set-merge + forced re-render).

**Export — `rm/js/paper-export-tex.js`**
- `blockToTex` → `subheadingToTex`: level 2 `\subsection`, level 3
  `\subsubsection`; starred in `auto` mode when the template's body sections are
  starred (Nature etc.), non-starred under `on`/`off` (secnumdepth does the
  work).
- `resolveSectionCommand`: `_sectionNumbering === 'on'` promotes a body
  `section_star` → `section`.
- `buildBundle`: sets `effectiveTemplate._sectionNumbering` from
  `opts.sectionNumbering` and appends `\setcounter{secnumdepth}{3}` (`on`) /
  `{-1}` (`off`); `auto` emits nothing (byte-identical).
- Cite scan (`_collectCitedKeys`) includes subheading bodies.

**Export panel — `rm/js/paper-export.js` + `rm/pages/paper-export.html`**
- `sectionNumbering` in default/load/save + `_bindSectionNumbering()` on the new
  `#px-section-numbering` row; `sectionNumbering` added to the `buildBundle` call.

**CSS** — `.pdv-subheading`/`-l2`/`-l3` + `.pdv-heading-num` + Layout-mode amber
tint (doc view); `.pe-block-subheading`/`.pe-subheading-text` (editor).

## Numbering matrix (preview ↔ export)

| Mode | Preview | Compiled PDF |
|---|---|---|
| auto | number where template uses `\section` | template as-is (byte-identical) |
| on | number all body sections + subheadings | `secnumdepth 3` + star→non-star |
| off | no numbers | `secnumdepth -1` |
