# V3.826 — "Recently added" moves into the Shelves; every shelf starts folded

**Date:** 2026-10-22 · **Builds on:** V3.825 · **Backend:** none · **Site files:** `rm/js/library-groups.js`,
`rm/js/library-recent.js`, `rm/js/library.js`, `rm/js/library-prefs.js`, `rm/pages/library.html`,
`rm/css/library-recent.css`, `sw.js` 806 → 807 (auto-uploads at turn end)

Alex: *"the recently added block should be in the shelves and all shelves should be collapsed by default."*

## 1. A shelf, not a section

The V3.825 block was its own collapsible section above the toolbar. It is now the first shelf inside the 📚 Shelves
block, rendered by `library-groups.js` alongside 📖 Open in reader, 📌 Pinned and 📁 Groups: `<section data-sec=
"recent">` with the shelf's own header (🆕 Recently added · "n in 30 days" · *newest first* hint) and a body
`#lib-recent` that `LIBRARY_RECENT.render()` fills right after the shelf is in the DOM. `library.js` hands the
visible pool to `LIBRARY_RECENT.setPool()` on every render; the shelf omits the section when nothing is dated
(`hasAny()`), and Customize → "Shelf: recently added" (`widgets_enabled.shelf_recent`) hides just that shelf. Like
every shelf it hides while a search or filter is active (results are the focus) — "See all added in the last 30
days" therefore hands over to the table with the Added filter on. The static `#lib-recent` div, the
`LIBRARY_COLLAPSE` registration and the "lib-recent" section id are gone.

## 2. Folded by default

`library-groups.js` `_isSecCollapsed(id)`: a shelf with no stored choice is **folded**; a stored `true`/`false`
(the person's own click) wins. The toggle now stores an explicit value (`_collapsed[sec] = !_isSecCollapsed(sec)`)
instead of deleting the key, and "reveal Groups after saving a group" sets `false` instead of deleting. Existing
users: the old code deleted the key on open, so nobody has a stored `false` — every shelf folds for everyone until
they open it, which is what Alex asked. Group rows inside Groups keep their old open default.

CSS: `#lib-recent.lg-sec-body { display:block }` (rows, not chips) needed `.lg-collapsed > #lib-recent.lg-sec-body
{ display:none }` beside it — the id selector would otherwise have outranked the fold rule and shown the body of a
folded shelf (caught by the selftest's `getComputedStyle` check).
