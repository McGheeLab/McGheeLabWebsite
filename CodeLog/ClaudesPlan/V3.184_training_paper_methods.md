## Goal

Teach a student to write the Methods section the way reviewers want
it: as a recipe, not a narrative. The single most-edited section of
any paper, because students reliably want to put biological
storytelling into it.

## Format

Lecture-style. Two interactive widgets:

1. **Methods-vs-Intro toggle** — same content rendered as Methods
   prose (Technician voice) vs. as Introduction prose (Storyteller).
   The student sees the difference and learns to migrate sentences to
   the right section.
2. **Methods completeness checker** — checkbox grid covering the
   lab's standard Methods anatomy (cells / reagents / equipment /
   parameters / analysis pipeline / statistics / data availability).
   Progress bar fills as the student ticks confirmed coverage.

## Sections (8)

1. The Methods' job — reproducibility, not storytelling.
2. The anatomy: cells, reagents, equipment, parameters, analysis,
   statistics, data + code availability.
3. Catalog numbers + named versions (everything cited).
4. Voice: Technician (per V3.182) — terse, factual, no interpretation.
5. Active vs passive — the one section where passive is sometimes
   correct.
6. The "but everyone knows..." trap.
7. What belongs in Methods vs. Supplementary Methods.
8. Capstone — Methods completeness checker.
