# V3.426 — Derived dimensions get canonical names (mass/volume = density)

## Context

Alex: "fundamental units get various colors. we should name the mixed
fundamental units without displaying them in the legend. i.e.
mass/volume = density." I.e. the legend stays fundamental-categories-
only (the pie colors already decode to it), and a recognizable derived
quantity is CALLED what it is wherever its dimension is described.

## Kernel (`rm/js/protocol-graph.js`)

- **`DERIVED_DIM_NAMES`** — exact-match exponent-map → name table, lab-
  centric: density (mass/volume), concentration (amount/volume), molar
  mass, molar volume, speed, acceleration, flow rate, mass flow, molar
  flow, reaction rate (amount/volume/time), diffusivity (area/time),
  surface density, surface concentration, linear density, specific
  volume, surface-to-volume, heating rate (temperature/time),
  frequency (1/time), per volume (1/volume). Fundamental positive dims
  are deliberately absent (volume stays "volume").
- **`dimName(d)`** (exported) → name or ''; **`dimDisplay(d)`**
  (exported) → name, else the spelled-out `dimLabel`.
- All checker warnings speak the names: "adding density to
  concentration", "sqrt of a non-square dimension (density)",
  log/exp/exponent messages likewise (single-cat fundamentals
  unchanged — the table has no entry for them, so existing pinned
  texts hold).

## Editor (`rm/js/protocol-graph-editor.js`)

- `_dimNameOf(name)` — canonical name for a COMPUTED variable via
  qtysCache ('' for declared/unnamed).
- Output-row label: `rho (density · mg / µL)`; swatch + out-dot +
  bound-chip tooltips lead with the name (`rho · density (mass·volume)`);
  pad variable buttons and strip chips carry it in titles.
- Pad info line: "computes to density (mg / µL)" — and now shows for
  NAMED single-category dims too (frequency), not just multi-cat.
- Declared-vs-computed message uses dimDisplay ("declared unit µL is
  volume, but the math computes density").
- **Legend untouched** — `.pge-legend` keeps only the fundamental
  categories, per Alex's instruction; derived quantities are named
  inline where the variable appears.
- Exploratory equation tour "Units travel — and cancel" step gains the
  naming clause.

## Verification

- Suite **672 ok / 0 FAIL** (+12): table hits (density, concentration,
  molar mass, diffusivity, frequency), fundamental/unnamed → '',
  dimDisplay fallback, warning texts ("adding density to

- Pending (browser, sw 399): the repro graph's result1 row reads
