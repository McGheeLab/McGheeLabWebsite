# V3.419 — Document view: continuous text flow, citation panel displacement + hover, paper type

> Alex's post-Layout-Mode-II test feedback, three items in one release.

## 1. Continuous text flow (the white-space bug)

The packer was BLOCK-ATOMIC: a paragraph that didn't fit deferred whole
to the next page, stranding white space at every page end. Now
paragraphs SPLIT AT LINE BOUNDARIES (LaTeX's own page-break model):

- `_packPages` walks an indexed WORK QUEUE (was forEach) — a split's
  remainder splices in as the next item and re-enters the normal flow,
  including splitting again across multiple pages.
- NEW `_splitColItem(item, availPx, geom)`: clones the paragraph into
  the probe at column width, finds the last character whose LINE bottom
  fits the budget (binary search over Range client rects), backs up to a
  word boundary, then `Range.extractContents()` — nested inline
  formatting bisects correctly while ATOMIC inlines (citation chips,
  KaTeX, ref chips — SPLIT_GUARD_SEL) stay whole on one side because the
  split point is always a bare text node outside them. Guards: ≥2 lines
  in part A (orphans), real content in part B, availPx re-check, any
  exception → atomic fallback (old behavior). Part B gets
  `.pdv-para-cont` (no first-line indent, no top margin). Parts carry
  the same data-block-id (+ data-block-part) so click/drag targeting
  still resolves the block.
- Node packer harness untouched-green (fake nodes take the atomic
  fallback via the probe/cloneNode guards) — the split path is
  browser-verified.

## 2. Citation panel: displace + set/hover

- The panel now DISPLACES the paper: `.pdv-cite-open` on the overlay →
  `.pdv-desk { margin-left: 400px }` (transitioned; ≤900px falls back
  to overlay). Persists until ✕/Esc.
- CLICK sets (`state.citeSetKeys`); HOVER over any cite group previews
  it over the set (130 ms debounce, "hover preview — click to set" tag
  in the head) and mouse-out reverts to the set (200 ms). Group hovers
  load ALL the group's keys — the panel already separates notes per
  citation by its displayed number (V3.393). Panel swaps bump
  `citePanelSeq` so stale evidence loads never paint.

## 3. Paper type (journal | grant | editorial | book-chapter)

- New-paper modal gains a Document type select; `createPaper` stamps
  `paper_type` on the papers row.
- The EDITABLE truth lives on contributor-writable
  `paperExports.paperType` (the papers row is admin-write): Export page
  "Document type" select (`#px-paper-type`, `_bindPaperType`) seeds from
  the row, saves with the config, and re-filters the template picker.
- `PaperExportConfig.KNOWN_TEMPLATES` rows gained `types` tags;
  `populateTemplateSelect(selectEl, currentId, paperType)` filters by
  type with a full-list fallback (grant has no formats yet — hint says
  they're coming; preprints also tagged editorial/book-chapter). The
  Document view passes the type to its journal select too.
