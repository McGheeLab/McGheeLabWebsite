# V3.334 — Paper Writing Guide tab

**Part of:** [FuturePlan 07 — Paper builder upgrade](../Feature%20requests/FuturePlan_07_paper_builder_upgrade.md) (Release 1 of 7).

## Goal

Give students, inside the paper editor, section-aware guidance on **what
to write** — so they can focus on content while the infrastructure
handles formatting. A new leftmost "✍️ Guide" pill tab shows, for the
section the writer is currently in: a one-line purpose, the 3–5
rhetorical moves of that section kind, live self-checks computed from the
paper tree, and (collapsed) common pitfalls + a good-vs-weak example.
Guidance is **curated static content** (no AI); full lessons stay in the
`training-paper-*.html` pages, which the tab links out to.

## Approach

New self-contained module `rm/js/paper-writing-guide.js` exposing
`window.PaperWritingGuide` (`buildTabContent`, `refresh`, `getContext`).
It reads only public accessors (`PaperEditor.getPaperMap()`,
`PaperSchemas`), holds no editor state, and mutates nothing.

**Content** — `GUIDE_CONTENT` keyed by `PaperSchemas` section kind
(abstract, keywords, introduction, background, methods, results,
discussion, conclusions, acknowledgements, references), plus
`BLOCK_GUIDE.figure` for a focused figure caption and a `GENERIC`
fallback for `custom`/unknown kinds. Each entry:
`{ icon, purpose, moves:[{id,label,hint}], checks:[id], pitfalls:[],
example:{good,bad,note}, training:url }`.

**Live self-checks** — a `CHECKS` registry of pure functions over a
plain-JS snapshot built by walking the Yjs paper map each refresh (same
traversal shape as `getCitedKeysInPaper`). No new state. Checks:
word-count vs `SECTION_STYLE.maxWords` (advisory), uncited substantial
paragraphs in intro/background/discussion, skeleton-without-body,
results-figure-first, results paragraphs without a figure ref, unlabeled
numbered floats, disallowed content (figures in abstract/conclusions),
empty figure caption, plus paper-wide unreferenced-floats and status
roll-up in the no-focus view.

**Focus tracking** — `paper-editor.js`'s `renderSection` now stamps
`dataset.sectionKind`; `rememberFocus` resolves the focused
section/block via `closest()` and dispatches a `paper-focus-changed`
CustomEvent, but only when the resolved ids change (it fires on every
keystroke otherwise). The Guide follows focus by default; a 📌 pin
toggle (persisted at `localStorage rm_paper_guide_follow`) freezes it.
It also listens to `paper-panel-changed` to refresh checks, throttled
≥1.5 s and skipped when the tab is not visible.

## Files

- **New** `rm/js/paper-writing-guide.js` — content data, checks, renderer.
- `rm/js/paper-equations.js` — `TABS` gains a leftmost `guide` entry;
  `_buildPanel` adds `#pe-guide-root`; `_refreshPanel` delegates the
  `guide` tab to `PaperWritingGuide.buildTabContent`.
- `rm/js/paper-editor.js` — `renderSection` stamps `dataset.sectionKind`;
  `rememberFocus` dispatches `paper-focus-changed` via new
  `_notifyFocusChanged`.
- `rm/pages/paper-builder.html` — load `paper-writing-guide.js` before
  `paper-equations.js` in `editorScripts`.
- `rm/css/paper-editor.css` — `.pe-guide-*` styles.
- `sw.js` — `CACHE_VERSION` 305 → 306.

## Key decisions

- **One TABS entry + one render function** — the pill-tab panel was built
  (V3.120) so a new tab is a data addition; the Guide follows that
  contract rather than introducing a parallel panel.
- **Snapshot-per-refresh, no editor state** — checks read a fresh
  plain-JS projection so the module never holds Y refs or goes stale.
- **maxWords stays advisory** — `SECTION_STYLE` notes enforcement is a
  separate phase; the check displays counts, never blocks.
- **Link out, don't duplicate** — the eight `training-paper-*.html`
  lessons (V3.330) are the long-form content; the tab is a focused
  in-context tool per the "focused tool, not encyclopedia" principle.
