# V3.413 — Layout Mode II R6: section styles — data model + export core

> Release 6 of 8 (invisible release — no UI writes the new fields yet;
> R8 ships the authoring surface). Alex: "a mode where I can add custom
> sections… Many journals like PNAS have these custom section blocks…
> I want to be able to drop in these section styles or make custom ones."

## The model

- **Per-section fields** (never new section kinds — normalizeTree:254
  coerces unknown kinds to 'custom' on every load, which would erase
  identity; with fields, that coercion is a guaranteed no-op):
  - `special` — a style key into the template's `special_sections`
    catalog (e.g. 'significance').
  - `special_render` — 'box' | 'heading', the CROSS-JOURNAL fallback
    captured at creation, so dropping PNAS's Significance into any other
    journal keeps its boxed look with zero warnings.
- **Resolution chain** (`resolveSectionCommand`): special → current
  template's catalog entry (authentic journal command) → else
  special_render ('box' → generic rmcallout, 'heading' → `\section*`,
  both silent — a deliberate drop-in, not an error) → else `\section*`
  + exactly one warning through the existing `_layoutWarnings` channel.
- **Command objects**: every legacy string normalizes to an object with
  byte-identical emission (`skip` / `abstract_placeholder` →
  `{placeholder, token:'{{ABSTRACT}}'}` / `keywords_placeholder` →
  `{keywords}` / `abstract_env` → `{env:'abstract'}` / `section_star` /
  `section`); new types `{env, name}`, `{macro, name}`,
  `{placeholder, token}`, `{box}`.
- **`{type:'box'}` → `\begin{rmcallout}{<label>}…`** — an mdframed-based
  definition (stock TeX Live; compiles on all 9 templates) injected into
  the preamble ON DEMAND only (`_usedCallout` flag, the `_usedCuted`
  lifecycle).
- **Token-map stash**: `_placeholderStash.tokens` seeds
  `{{ABSTRACT}}`/`{{KEYWORDS}}` (legacy) + every catalog-declared
  placeholder token to '' — the leftover-token sweep: no literal
  `{{FOO}}` can survive into main.tex; one substitution loop replaces
  the two explicit subs.

## What shipped

1. **paper-schemas.js** — `newSection(kind, label, order, opts)` sets
   `special`/`special_render` only when provided (legacy serialization
   byte-identical). normalizeTree UNTOUCHED (preserves unknown keys —
   verified).
2. **paper-editor.js** — the round-trip ×3 (the V3.369 `completed_at`
   precedent: miss one and a section REORDER silently drops the field):
   `appendSectionFromTree`, `sectionMapToTree`, `hydrateSectionFromTree`.
3. **paper-export-tex.js** — `paperTreeFromYDoc` reads the two fields
   (ONE reader feeds export AND the Document view); `normalizeCommand` +
   `resolveSectionCommand` + generalized `sectionToTex`; `_usedCallout`
   + rmcallout preamble injection in the capture block; token-map stash
   + seeded catalog tokens + substitution loop.
4. **All 9 template JSONs** gain `special_sections` catalogs (key, label,
   command, singleton, default_position, preview, hint): acs ships the
   REAL achemso `acknowledgement`/`suppinfo` environments; elsevier
   CRediT/declaration/data-availability; nature/science full end-matter
   sets (hints note the class approximation); ieee/plos/mebp/preprints
   generic star sets.
