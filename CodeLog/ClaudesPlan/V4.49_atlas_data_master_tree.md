# V4.49 — The Atlas's Data: every data tree in one master tree

## Goal
Gabe (19 Nov 2026): "… and create data tab in Atlas, which organizes all trees recorded there for a master tree."

## Approach (`14fc-atlasdata.js`, new; CSS in `37-atlashub.css`)
- **A Data section in the Atlas** (`ATHUB.add`, after Map and Materials; the row shows how many notes have data).
- **What is in it:** every component with a data tree (13zzyc `b.dtree`, live, in a live note), drawn by the data tree itself. `DTREE.el` runs read-only on a tree made for it (`_adata`), so folders fold, and sizes, counts and dates read the same as on a note. A wrapper on `DTREE.el` dresses the rows after each draw (a fold draws again), through an `o.decorate` hook only this section passes.
- **By project** (where it starts):
  - the projects in the Portfolio's order, then No project, each with its hue's dot;
  - each project's notes with data, newest first, each with its kind's label in the Portfolio's section colour and Open (`App.jump` to the component);
  - then the note's folders and files;
  - a note with data on several components has one branch per component, each with Open.
- **One merged tree:** every note's folders merged by name, level by level, so a folder logged in several notes is one. Each row carries the notes it came from ("in 2 notes", or the note's title); a click lists them to go to one.
- **The sum line:** folders · files · size, in how many notes of how many projects. **Search** keeps what matches and what is above it, and opens those folders.
- **Nothing is copied or changed**; the trees stay on their components.
- **`NOTEKIND`:** a note's kind for its label, using the Portfolio's own rules (`SYNTH.is` / `'reflection'`, `PFLIST.isLit`, `PFLIST.isExp`, else Note), with its section symbol and colour. Hot notes (V4.50) reuse it.
- **Settings → Tabs & overview → Data (in the Atlas)** (`atlasdata`, on in every preset): its description and a preview (the row with Data lit, a small master tree). With it off, or the data tree off, the section leaves the Atlas.
