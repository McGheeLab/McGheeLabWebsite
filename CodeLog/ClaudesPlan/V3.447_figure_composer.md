# V3.447 — F1 of Paper Builder III: multi-panel figure composer (bake-to-one-image) on the Figure editor page

> Alex's chosen model (vs real LaTeX subfigures): compose panels client-side and BAKE one
> image through the existing single-image pipeline. Export / compile / doc view / reader
> are untouched; panel letters sync to the `[!fig:label:A]` reference system; panels stay
> stored so the composite is always re-editable. Matches the earlier "panels are labels,
> never subcaption" decision.

## Model (scalar attrs — survive all moves per V3.435)

- `attrs.panels_json` — ordered `[{storage_path, download_url, hash, mime, label, span}]`
  (`span` 1 = one column, 0 = full row). Labels are auto A, B, C… by order.
- `attrs.compose_json` — `{cols (1-4), gapPx, labelSize, bg}`.
- On bake, the block's single `storage_path/download_url/hash/mime` become the composite
  and `attrs.subfigures` is rebuilt to match the panel letters.

## Changes

- **NEW `rm/js/paper-fig-compose.js`** (`PAPER_FIG_COMPOSE.open({paperId, blockId, attrs,
  yBlock})`):
  - Modal: columns / gap / label-size controls; multi-file "+ Add panels…" (each panel
    uploads through `PAPER_FIGURES.uploadImage` — content-hash dedup, same Storage
    folder); panel cards with thumbnail, letter, column↔full-row toggle, ◀▶ reorder,
    remove; **live preview canvas** (300px columns).
  - Layout: rows of `cols` panels; `span:0` panels take a full row; each panel scales to
    its cell width; row height = tallest panel (vertically centered); letters drawn bold
    with a white halo.
  - **Bake**: full-res compose (column width = widest panel's natural width, ≤1800px; the
    composite's long edge capped at 4000px) → PNG blob → `uploadImage` → ONE transact:
    composite pointers + `panels_json`/`compose_json` + `subfigures` rebuilt (Y.Array of
    {id, label}) — origin `fig-compose-bake`. EXIF orientation honored via
    `createImageBitmap(…, {imageOrientation:'from-image'})` (Image fallback).
  - Re-opening rehydrates from `panels_json` — panels are never lost.
- **Launcher** — "🧩 Compose panels…" in each figure's Panels row
  (`_buildSubfiguresEditor`, `rm/js/paper-equations.js`; resolves the live block via
  `_findFigureBlock`).
- **"🏗 Figure builder" placeholder card** at the top of the Figure editor page — reserves
  the surface for Alex's later guided-workspace concept (explicitly not designed now).
- **`rm/pages/paper-builder.html`** — loads `paper-fig-compose.js` in the editor script
  set. **CSS** — `.pfc-*` modal + `.pe-figbuilder-card`.

## Limitations (documented in-UI)

Raster panels only (SVG/PDF can't canvas-compose); per-panel captions live in the main
caption text ("(A) … (B) …"), not typeset under each panel — the trade Alex accepted for
an untouched compile pipeline.
