# V3.436 — Plate planner: drag-and-drop + plate presets (Release 1 of 2)

## Context

Alex: "we need to update how the users move experiments to a plate. I want
easy functionality like drag and drop and drag off the plate to delete …
This feature is very important for the users experimental design, and if we
dont get it right they wont use it." Release 1 = the direct-manipulation
interaction; Release 2 (next) = multi-strategy auto-arrange.

Today `renderGridAssignment` (`rm/js/protocol-widgets.js`) is click-select-a-
chip-then-click-a-well only. This adds drag while keeping the click path as
the touch tap fallback.

## Interaction (`rm/js/protocol-widgets.js` `renderGridAssignment`)

- **Drag** a palette chip onto a well → place; **drag a filled well** onto
  another → move (empty target) or swap (filled target); **drag a well off
  the plate** (or onto the revealed 🗑 trash zone) → remove.
- **Tap** (pointer moved < 5px) falls through to the legacy behaviour: chip
  tap selects, empty-well tap places the selection, filled-well tap clears —
  so touch tap-to-place is unchanged.
- Pointer capture is on the assign root `el` (survives the refresher's
  re-render); drop targets resolve via `document.elementFromPoint` walking to
  a `.prd-well` carrying `data-gid`/`data-slot` — the touch/pen-safe house
  pattern (mirrors protocol-graph-editor + huddle). A `pointer-events:none`
  ghost follows the pointer; the hovered well rings; the source dims. A
  mid-drag recompute is deferred (`if (dragging) return`) so it can't yank
  the DOM; the commit re-renders anyway.
- `touch-action:none` + `preventDefault` on wells/chips so touch-drag doesn't
  scroll the page. State shape is unchanged (`{grids, assignment}`), so the
  notebook run's persistence, freeze snapshot, totals, and the legacy
  dual-path all keep working untouched.

## Plate presets + A1 (`rm/js/protocol-widgets.js`)

- "+ Add grid" → **"+ Add plate ▾"** dropdown: `PLATE_PRESETS` = 96 (8×12),
  384 (16×24), 24 (4×6), 12 (3×4), 6 (2×3), + Custom… (block defaults). The
  choice sets the new grid's rows×cols and names it; the per-grid rows/cols
  inputs remain for tweaks. Outside-click closes the menu.
- Each well gets a `title`/canonical A1 address
  (`PLATE_ROWLETTERS[r] + (c+1)`) for hover + accessibility.
