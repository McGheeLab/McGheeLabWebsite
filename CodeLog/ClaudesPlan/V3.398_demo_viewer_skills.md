# V3.398 — Demo tours teach the viewer: zoom/fit/collapse after node 1, Tidy last, features spread across lessons 2–4

## Context

Alex: "on demo 1, after we place the first node, it should tell the user
about magnification and fit and collapse expand. after all the things
are placed it should tell the user about tidy as a last step. demo 2, 3
and 4 can do other features of the viewer too."

## Design

### New step flag: `practice: true`
Viewer-skill drills that VERIFY a real action (collapse, expand, tidy)
are `when`-steps like build steps — but they must not count toward the
prebuilt "already built" gate (a legacy pre-populated copy satisfies
every build condition yet has never collapsed/tidied anything, and the
gate would stop triggering). `start()`'s gate now filters
`s.when && !s.practice`. Zoom/fit/pan/popout/cheatsheet aren't visible
in the graph, so those are `next:true` info steps with ring targets
("try it, then press Next").

### Lesson 1 (+5 steps → 15)
After "Name it volume_each":
- **Viewer skill: zoom** (info; rings `.pge-view-btn[title="Zoom in"]`)
- **Viewer skill: ⌖ Fit** (info; rings the Fit button)
- **Viewer skill: collapse the node** (practice do-step —
  `H.some('input', n => !!n.collapsed)`; rings the node's `.pge-collapse`)
- **…and expand it back** (practice do-step — `some(input, !collapsed)`)

After "Write the formula" (everything placed), before the document step:
- **Everything placed — now Tidy** (practice do-step — any node position
  changed vs the step-activation snapshot; rings
  `.pge-view-btn[title^="Auto-arrange"]`)

### Lesson 2 (+2 steps → 12) — after the cap→max binding lands
- **Go full screen** (info; rings `.pge-expand-btn` popout)
- **The ? cheatsheet** (info; rings `.pge-view-btn[title^="Canvas how-to"]`)

### Lesson 3 (+2 steps → 13)
- **Pan** (info; rings the whole `.pge-viewport`) after the dose axis
- **Read the colored outlines** (info; rings `.pge-scope-list`) after
  both feeds — scope shading = scalar vs per-experiment

### Lesson 4 (+2 steps → 10) — after the script works
- **Wire surgery** (info; rings `.pge-wire`) — click-delete + shift-cut
- **✨ Recipes** (info; rings `.pge-recipes-btn`)

All new steps carry `why` strips. Build-step conditions and their
relative ORDER are unchanged — only indices shifted.
