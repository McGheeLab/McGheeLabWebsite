# V3.468 — Grant unification R6: submission checklist

> Sixth release. Bakes the standalone `submission_checklist.html` tool into the Grant
> Docs page as a per-mechanism, reusable feature — the "helpful tools like the
> submission checklist" the user asked for, one per grant type.

## Data file (rm/data/grant-checklists/nsf-career.json)

Ported faithfully from the real `GELS CAREER/Working docs/admin/submission_checklist.html`
(NSF 22-586), with proposal-specific status/file-link hardcoding stripped (the
guidance, page limits, channels, and category structure are solicitation facts and
carry over verbatim). Two arrays:

- **`manifest`** — 17 documents (`{key, label, req: req|cond|opt, limit, channel, note,
  sectionKind}`). `sectionKind` maps each document to a paper section kind (facilities →
  `facilities`), to `"__narrative__"` (Project Description → the aggregate of the custom
  narrative sections), or to `null` (portal/form artifacts — Cover Sheet, Letters of
  Collaboration — status shown neutrally).
- **`process`** — the 8 categories (Accounts, Eligibility, Core documents, CAREER
  supplementary, Budget, Single-copy/compliance, Formatting, Submission), each with
  items carrying the `?` plain-language `hint:{t,b}` popovers verbatim.

Fetched as a static file (`fetch('/rm/data/grant-checklists/{id}.json')`, the
`fetchTemplate` pattern). Add `nih-r01.json` etc. as more grants are prepared.

## Rendering module (rm/js/paper-grant-checklist.js)

`window.PaperGrantChecklist.mount(host)` — mounted into `#pgd-checklist-host` (the slot
R5's paper-grant-docs.js already reserves). Keyed off the paper's `grant_subtype`
(no subtype → an explanatory empty state; unknown id → "checklist can be added later").

- **Document manifest** with **live** status computed from the paper's Yjs sections
  (`getPaperMap` scan): a `sectionKind` row reads "Drafted" when that section has block
  text, "Uploaded" when its R3 upload slot is filled, "Empty"/"Not added" otherwise;
  `__narrative__` reads off any custom section having content; clicking a row jumps to
  that section on the Write page (`PaperEquations.gotoPage('write', {focus})`).
- **Process checklist** — the 8 categories as checkboxes with the `?` hint popover, a
  progress bar, and a deadline date picker + countdown.
- **State persists on `paperExports/{paperId}.checklist`**
  (`{mechanismId, deadline, checkedProcess}`, merge-write, debounced) — Firestore, so
  it's shared across devices/collaborators (the source tool used localStorage). No new
  rules: `paperExports` is already lab-contributor-writable, and this only adds a field.

## CSS (rm/css/paper-editor.css)

`.pgc-*` (header/deadline/manifest table/status badges/progress bar/category items/hint
popover). Loaded before paper-grant-docs.js in `paper-builder.html`.
