# V3.443 — E1 of Paper Builder III: MathLive visual equation editor (vendored) + Visual ⇄ LaTeX toggles

> The first real WYSIWYG math editing in the paper builder. MathLive (MIT) is vendored —
> no CDN dependency — and every equation-library surface gains a Visual ⇄ LaTeX toggle.
> LaTeX stays the source of truth: the visual field writes LaTeX back through the same
> persistence paths, and an untouched visual open/close writes NOTHING.

## Vendored dependency (new)

`rm/vendor/mathlive/` pinned **mathlive@0.110.0** (fetched from jsdelivr; note the files
live at the package ROOT, not `dist/`):
- `mathlive.min.mjs` (843 KB) — the web component (registers `<math-field>`)
- `mathlive-static.css` (13 KB) + `mathlive-fonts.css` (3 KB) — static-markup rendering
  (used by the reader in E3)
- `fonts/KaTeX_*.woff2` (20 files, ~280 KB)
Sounds intentionally not vendored (`soundsDirectory = null`). Total ~1.1 MB, loaded ONLY
on first visual-editor use (viewers never pay it).

## Changes

- **NEW `rm/js/mathlive-loader.js`** — `window.ensureMathlive()`: memoized dynamic
  `import('/rm/vendor/mathlive/mathlive.min.mjs')` (single registration; retry after
  transient failure); sets ABSOLUTE `MathfieldElement.fontsDirectory =
  '/rm/vendor/mathlive/fonts'` (a relative default 404s → tofu glyphs). Its own module —
  not paper-editor.js — because the library READER needs it too (E3). Loaded by
  paper-builder.html's editor script set.
- **`rm/js/paper-equations.js`** — `_mountVisualToggle(srcInput)`: a LaTeX/Visual toggle
  inserted before a LaTeX `<textarea>`; Visual swaps in a `<math-field>` seeded from the
  textarea; edits mark a `dirty` flag; commit (on field blur or toggling back) writes
  `getValue('latex')` INTO the textarea and dispatches synthetic `change`+`blur` — so the
  existing persistence (`_updateLibraryEntry` clobber, create-modal read, preview
  re-render) runs untouched. **Fidelity guard:** MathLive normalizes macros it doesn't
  model, so `dirty === false` writes nothing — stored LaTeX stays byte-identical unless
  the user actually edits. Attached at the three seams: main-equation row, create modal,
  inline-library row (all now living on the Equations page after P1).
- **CSS (`rm/css/paper-editor.css`)** — `.pe-visual-toggle`, `math-field.pe-mathfield`,
  and `:root { --keyboard-zindex: 5000 }` so the virtual keyboard clears the RM stack
  (panels ~3500 / modals 4000 / doc-view 4200).
