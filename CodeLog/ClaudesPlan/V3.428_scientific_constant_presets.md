# V3.428 — ⚛ Preset scientific constants on the 📌 Constant node

## Context

Alex: "on the constants panel, lets add in predefined common scientific
constants like pi, avogadros number, boltzmans constant, etc."

## Kernel (`rm/js/protocol-graph.js`)

- **`SCIENTIFIC_CONSTANTS`** (exported, 14 entries):
  {key, label, value, display, unit, note} — π, Avogadro N_A,
  Boltzmann k_B, gas constant R, molar gas volume V_molar (STP), speed
  of light, Planck h, elementary charge q_e, Faraday, standard gravity
  g_std, water density ρ (25 °C), room temperature T_room (298.15 K),
  ion product of water K_w, ln(10). Keys are valid expression
  identifiers (they become the variable name).
- **Unit-safety rules** (comment-documented): units use catalog
  spellings wherever the dimension system can represent them —
  `m/s` (speed), `L/mol` (molar volume), `g/mL` (density), and NEW
  `1/mol` (per amount) all decompose and name themselves. Energy-based
  units (J/K, J·s, J/(mol·K), M²) aren't representable in the category
  system and ride as custom atoms — numerically fine, dimension-
  silent. Coulomb-per-mole is written **C·mol⁻¹, never C/mol** (a '/'
  split would misread C as Celsius); q_e says 'coulomb', never bare
  'C', for the same reason. A test sweep asserts nothing but T_room
  parses as temperature.
- **`1/X` decomposition** in `quantityOfUnit`: numerator literal '1'
  with a dimensional denominator → negative dim ({amount:-1}, units
  {mol:-1}, scale 1/s(X)). N_A × mol → dimensionless count.

## Editor (`rm/js/protocol-graph-editor.js`)

- `constPreset()` inside `_configFields`: a "Preset" select at the top
  of the constant panel ("⚛ common constants…" placeholder; options
  read "Boltzmann constant — 1.381e-23 J/K", note as tooltip). Picking
  one fills label/value/unit and persists; the select snaps back to
  the placeholder (action, not state).
- **Name policy**: a hand-typed name is KEPT; seeded (k_xxxx), auto
  (type_XX), or previously-preset names (key or key_N) are replaced by
  the preset key, collision-suffixed (_2, _3 …) against all produced
  vars, with outgoing edge sourceVars rewritten — same convention as
  the name field and V3.400 auto-naming.
- Constants tour "Set its value + unit" step now mentions the ⚛
  Preset dropdown.
