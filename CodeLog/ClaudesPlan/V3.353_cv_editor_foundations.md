# V3.353 — CV editor foundations (FuturePlan 11, Release 1)

**Goal:** make the RM CV editor safe and reachable — responsive on phones,
live-synced across tabs, undo-able deletes, and no more silent divergence
between the CV and the public Team page.

Roadmap doc: [`FuturePlan_11_cv_builder_upgrade.md`](../Feature%20requests/FuturePlan_11_cv_builder_upgrade.md).

## What shipped

1. **Responsive shell** — `rm-desktop-only` + `desktop-only-guard.js`
   removed from `cv-editor.html`. ≤900px: the section sidebar becomes a
   sticky horizontal rail; ≤640px: full-screen entry modal, single-column
   form, `--tap-min` targets.
2. **Live doc listener** — `subscribeDoc()` replaces the one-shot
   `loadDoc()`: `firebridge.db().collection('cvData').doc(uid).onSnapshot`.
   Echo guard copied from lab-notebook (`savePending` +
   `suppressUntil = now+2500` + `hasPendingWrites`). Remote changes landing
   mid-edit (`editingInProgress()`: modal open or focus in a form control)
   are queued (`remoteQueued`) and applied after the edit — saves upsert by
   `_id` into the fresh arrays, so concurrent edits to other entries survive.
3. **Unified `savePayload()`** — all five former direct
   `firebridge.setDoc('cvData', …)` sites route through one path: status
   chip, `TOAST.error(retry)` on failure (rethrows), echo-guard arming, and
   the profile-sync hook.
4. **Soft delete + Undo** — `confirm()` dropped. Deletes move the entry to
   an additive `trash[]` top-level array ({section, entry, deleted_at};
   pruned to 50 items / 30 days), save atomically with the section, and
   offer an 8s `TOAST` Undo (restores at the original index). A
   "🗑 Recently deleted" sidebar link opens a restore dialog for anything
   the toast outlived. Additive-key safety verified: the parent app
   round-trips unknown top-level keys; biosketch/exports read only named
   sections.
5. **Profile-sync gap fix** — NEW [`rm/js/cv-profile-sync.js`](../../rm/js/cv-profile-sync.js)
   mirrors `user-system.js syncCVToProfile` (journals→papers,
   conferences→posters, presentations→presentations, patents→patents;
   verbatim mapping, cross-referenced header). Debounced 800ms, writes via
   `firebridge.updateDoc('users', uid, …)` — allowed by firestore.rules
   L170-172 (owner update, role unchanged), **no rules deploy**.
   Fire-and-forget; never blocks a CV save.
6. **Lab tab honesty** — `nav.js` CV Overview gains `gate:'admin'`;
   `cv-editor.html` renders the Lab tab only for admins (onAuth);
   `cv-overview.js` shows an "admin view" notice to non-admins instead of
   the silent all-zeros table (rules restrict cross-user cvData reads to
   admins).
7. **Extras** — "⇩ Backup (JSON)" toolbar button; stale
   `window.CVEditor.appendEntry` header claim corrected (real API is
   `CVStore.appendEntry`); bare "Not signed in" `alert()`s → `TOAST.warn`;
   `toast.js` gains additive `opts.actionLabel` (button text, default
   'Retry').
