## 1. Readings → shelves with counts

`library-readings.js` `shelves()` returns the three groups for `library-groups.js`: **📥 Assigned to me** (always,
once anything was ever sent; count may be 0 with its "Nothing assigned right now." note), **💡 Suggested for me** and
**✓ Read** (when non-empty), each with `count` = number of papers and the row HTML it already rendered. The groups
block puts them first (before 🆕 Recently added), folded by default like every shelf (V3.826), header count = the
number to read. The readings' mark-as-done click handler is now delegated on the document (rows live in the shelf);
`render()` in shelf mode hides the old `#lib-readings` mount and asks the groups block to repaint. Customize →
"Shelf: papers sent to me" (`widgets_enabled.shelf_readings`). The old mount remains a fallback when the groups
module is absent.

## 2. Download the PDF from All papers

A ⤓ button on every row with a PDF (`data-act="download-pdf"`): `LIBRARY_UPLOAD.downloadUrl(storage_path)` →
`fetch` → blob → `<a download="<paper-id>.pdf">` click, so the file lands in Downloads instead of opening a viewer
tab (a cross-origin `download` attribute is ignored, hence the blob URL). If the fetch is refused the Storage URL
opens in a new tab with a note to use its download button.

## 3. Popovers fully on screen

New `rm/js/popover-place.js`: `POPOVER_PLACE.compute({ w, h, anchor, viewport, preferLeft, gap, margin })` (pure,
node-tested) → below the anchor when it fits, above when below does not, otherwise as high as needed, never past an
edge, `maxHeight` = window − margins; `fit(pop, anchorRect, opts)` applies it after the popover is in the DOM with
`box-sizing: border-box` (the padding and border had put the box 22 px past the edge before the selftest caught it).
Both `la-popover` sites in `library.js` (Organize, associations) call it right after `appendChild`. CSS max-height
`60vh` → `calc(100vh − 16px)`, plus `max-width: calc(100vw − 16px)`.
