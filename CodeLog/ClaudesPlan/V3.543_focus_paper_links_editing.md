# V3.543 — Focus↔paper links + in-place focus/task editing

Follow-up to the Weekly Focus program (`V3.536_weekly_focus_program.md`),
Alex test feedback 2026-07-25.

## Goal

1. A focus area should relate to the research/papers being written — so
   the week's why is visibly connected to a manuscript.
2. Focus titles/descriptions AND the tasks under a focus must be
   editable in place (task text was previously read-only).

## Changes

- **`rm/js/focus-areas.js`** — focus docs gain `paper_refs: [{id, title}]`
  (hydrated for old docs). New API: `listDrafts(studentUid)` (the exact
  PMR paper_writing query — `papers` where `authorUids array-contains`
  the student, excluding `is_library_entry`; papers are lab-readable so
  mentors pick from a mentee's drafts with no rules change),
  `addPaperRef` / `removePaperRef`, and `updateTaskText`.
- **`rm/js/team-focus.js`** — each focus card gains a papers row:
  📝 chips linking to `paper-builder.html?id=…` with ✕ unlink + a
  "＋ link a paper…" select of the person's unlinked drafts. Task rows'
  text is now an editable input (saves on blur, toast confirms); title/
  description edits now always toast "Saved" (previously silent unless
  the status flipped), and hover reveals the edit borders so
  editability is discoverable. All editing locked once `reported`.
- **`rm/js/my-day.js`** — focus panel cards show the linked paper chips.
- **`rm/js/pmr.js`** — the focus_review block includes 📝 paper links
  per focus card.
- CSS in `rm/css/team-focus.css` / `rm/css/my-day.css`.

## Deploy

FTP only. `sw.js` 516 → 517.

## Verify

- Mentor links "MEBP paper" to a focus → chip on Team Focus, My Day
  panel, and the PMR focus review; chip opens the paper builder.
- Edit a task's text on Team Focus → blur saves, toast; mentee sees the
  new text; checking it off still works.
- Edit title/description as mentee → toast + status flips to
  "Edited — needs sign-off" as before.
- Reported focus: everything read-only including task text and paper
  links.
