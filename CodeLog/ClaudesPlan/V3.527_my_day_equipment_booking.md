# V3.527 — My Day R2: equipment sessions + inline availability + booking fan-out

Part of the **My Day program** — see `V3.526_my_day_program.md` for the full roadmap.

## Goal
The canonical flow: pick "🔬 Equipment" in the My Day composer, choose the
confocal + 2–4pm, see the device's calendar inline (existing bookings +
posted availability window), and on Add the booking is created as part of
the distribution alongside the huddle post / notebook stub / tracker event.

## Approach
- **`rm/js/equipment-availability.js`** (new) — `window.EQUIP_AVAIL`:
  `listEquipment` (catalog, cached), `listForDay(equipmentId, date)`,
  `checkSlot(equipmentId, date, start, end, ignoreId)` →
  `{ok, reason, needsApproval, bookings, restrictions}`. A COPY of the
  pure logic in equipment.js (availabilityRestrictions V3.336, overlap
  check) so equipment.js stays untouched. Student-path differences:
  no admin bypass, conflicts BLOCK (never displace), duration >
  maxDurationMin → `needsApproval` → booking lands `pending-approval`.
- **`rm/js/day-distribute.js` equipment adapter** — writes
  `equipmentBookings/{itemId}` with exactly the rules-whitelisted keys +
  `source_ref: {kind:'dayplan', id}`. Cascade edit = date/time/notes via
  the owner-edit clause; cascade delete = **cancel** (`status:'cancelled'`,
  owner-cancel clause — hard delete is admin-only).
- **`rm/js/my-day.js`** — equipment type row (device dropdown + protocol
  picker) and the 07:00–21:00 availability strip (gray blocks = existing
  bookings, hatch = outside posted window, green/red = your proposed slot).
  Submit disabled with the reason while the slot is bad.
- **`firestore.rules`** — additive: `source_ref` (must be a map) added to
  the equipmentBookings create whitelist + the owner-edit `bkChanged()`
  whitelist. Everything else unchanged.

## Deploy — ORDER MATTERS
1. `firebase deploy --only firestore:rules`  (old rules reject source_ref)
2. FTP.

## Rollback
Rules change is additive/optional — redeploy the previous rules file from
git; bookings simply lose the backref key. FTP previous tree for the UI.

## Verify
- Conflicting slot → red overlay + submit disabled with "Taken 2–3pm by …".
- Clean slot → booking appears on equipment.html calendar immediately.
- Slot > maxDurationMin → item adds, booking status `pending-approval`,
  chip shows "(approval pending)".
- Delete the My Day item → booking flips `cancelled` (not deleted).
