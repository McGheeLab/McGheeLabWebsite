# V3.446 — E4 of Paper Builder III: "From reading library" in the equation picker + paste importers

> Completes the MathLive/equations workstream (E1 V3.443 → E2 V3.444 → E3 V3.445 → this).
> Captured equations made in the paper reader are now insertable into manuscripts, and the
> equation library gains bulk paste import.

## Changes

- **Equation picker source** (`rm/js/paper-equations.js` `_openPickerAt`, kind
  `equation`): a "📚 From reading library…" row opens `_openCaptureBrowser(sectionId,
  idx)`:
  - Step 1: library papers from the builder's citation index
    (`PaperEditor.getCitationList()` — carries `itemId`/`key`/`linkedDrafts`), papers
    **linked to this draft** sorted first (badge), searchable.
  - Step 2: the paper's equation captures — fetched from
    `papers/{itemId}/annotations` with the same visibility model as the reader (two
    equality-only queries: lab + own-private; no composite index needed); KaTeX previews.
  - **Insert as block** → `insertBlockAt(sectionId, idx, 'equation', {body: latex,
    display: true})`; an "also add to this paper's equation library" checkbox (default on)
    copies it via `_createEquationLibraryEntry`; the row shows the source `[@key]` so the
    citation is one paste away. (Plan deviation: the earlier idea of auto-appending
    `[@key]` into an adjacent paragraph was dropped as fragile — the key is displayed
    instead.)
- **⇪ Import** button beside "+ Equation" on the Equations page →
  `_openEquationImportModal`:
  - **Paste LaTeX** — split on blank lines → per-entry KaTeX preview + name input →
    "Add to library" creates main-type entries.
  - **Paste from Word (MathML)** — a `<math-field>` (shared `ensureMathlive`) parses
    MathML on paste natively → named entry. UI documents the caveat: plain Word copies
    often carry OMML/pictures (works from MathType / Google Docs / Word with MathML
    clipboard).
- **CSS (`rm/css/paper-editor.css`)** — `.pe-eqimport-*`, `.pe-eqcap-browse-*`,
  `.pe-eqcap-linked`.

## Verification

- `node --check` clean; CSS balanced; suite 338 green (no export changes).
- **Browser (Alex):** capture an equation in the reader (E3) → builder write page →
  `+ Add → Equation` → "From reading library" → your linked paper sorts first → the
  capture previews → Insert → a display-equation block lands at the position and the
  library copy appears on the Equations page. ⇪ Import: paste two LaTeX blocks separated
  by a blank line → two previews → both entries created; paste a Word/MathType equation in
  the MathML tab → converts and saves.
