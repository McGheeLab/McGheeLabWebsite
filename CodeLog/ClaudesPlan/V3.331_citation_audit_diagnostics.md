# V3.331 — Citation-audit diagnostics + baseline (coverage-expansion R1)

> Plan: citation-style coverage expansion, R1 of 5 (2026-07-12). The V3.310
> harness reports per-paper coverage but not WHY misses miss — this release
> makes failures diagnosable and comparable so R2–R4 are measured, not guessed.

## Changes

- **`PAPER_CITATIONS.analyzeDocument`** gains `debug: true`:
  - `alignedCount` — how many SS ref numbers the printed-list alignment fixed;
  - `fragmentationSuspects` — count of `[ 12` / `12 ]`-style artifacts in the
    joined page text (the unconditional space-join breaking split markers);
  - `missDetails` — for up to 15 unlocated refs, ±60-char page-text contexts
    around the ref's bare number (numeric styles) or first-author surname
    (author-year), capped at 3 contexts each. This is how we SEE the marker
    form we're missing. No behavior change without the flag.
- **`rm/js/citation-audit.js`**: failure-bucket chips per row
  (`no-style-detected`, `low-coverage<50%`, `numbering-drift-fixed`,
  `fragmentation-suspected`); expandable miss-context dump; per-style corpus
  totals; **⬇ Export JSON** + **Load baseline** file input → Δ located column
  for one-click before/after comparison across R2–R4.
