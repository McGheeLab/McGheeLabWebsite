# V3.451 — ★ the ONE server change of Paper Builder III (Alex's manual Cloud Run gate)

> The single deploy that unblocks BOTH marked-up revision diffs (D2) and submission-doc
> service compiles (S-γ). Everything else in the 17-release program is FTP-only; this one
> is `gcloud run deploy` from `functions/paper-compile/`. Client releases are sequenced so
> nothing breaks while this lags (D1 fields are ignored by the old service; the S-γ/D2 UI
> self-detects the new service before enabling).

## Changes (staged in the repo; deploy when ready)

- **`functions/paper-compile/Dockerfile`**
  - `latexdiff` added to the apt line — a Perl script + libalgorithm-diff;
    `--no-install-recommends` is CRITICAL (stops latexdiff's Recommends from dragging in a
    full TeX Live — Tectonic stays the only engine; ~5–10 MB image cost). Build asserts
    `latexdiff --version`.
  - Deploy header: `--timeout 90 → 120` (a diff request = latexdiff + a SECOND tectonic
    pass).
- **`functions/paper-compile/server.js`**
  - **docKind pass-through** — request field validated against
    `main|diff|cover_letter|rebuttal` (default `main`), written on the compiles doc (the
    ONLY way to stamp it: compiles are admin-write; the proxy passes the body through
    unchanged).
  - **Flat-source storage** — non-diff compiles with a `flatSource` string (≤5 MB) store
    it at `paperExports/{paperId}/compiles/{compileId}.tex` (best-effort; a failure only
    warns) and record `flatStoragePath` on the doc. D1 clients already send it, so history
    accumulates from the first post-deploy compile.
  - **`mode:'diff'`** — validates `baseCompileId` (16-hex); downloads the base compile's
    stored `.tex` (clear 400 when absent: "recompile once to enable diffs"); writes the
    current `flatSource` as `new.tex`; runs
    `latexdiff --type=UNDERLINE --math-markup=whole --graphics-markup=none
    --disable-citation-markup base.tex new.tex` (flags = the classic breakage avoidances);
    compiles `diff.tex` in the SAME workdir (figures/refs.bib/extra_files already
    materialized); records `{docKind:'diff', baseCompileId}`.

## Deploy checklist (Alex)

```
cd functions/paper-compile
gcloud run deploy paper-compile --source . --region us-central1 \
  --allow-unauthenticated=false --memory 1Gi --timeout 120 --max-instances 3
```
1. Image builds; logs show `latexdiff --version` during build.
2. A NORMAL compile still succeeds (regression) — its compiles doc now carries
   `docKind: 'main'` + `flatStoragePath`.
3. Compile twice, then use the D2 "Marked-up diff" picker (V3.452) → an
   underline/strikeout PDF.
4. A cover-letter Compile (V3.452 card) returns its own PDF and does NOT disturb the main
   staleness banner.

No proxy / storage.rules / firestore.rules changes (verified: the proxy forwards the body
unchanged; `paperExports/**` already allows Admin-SDK writes + authed reads).

## Client detection

V3.452's S-γ/D2 UI enables itself only when the newest compile doc carries a `docKind`
field — i.e., after the FIRST post-deploy compile — so shipping the client ahead of this
deploy is safe.
