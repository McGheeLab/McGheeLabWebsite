# V3.404 — Demo curriculum ladder: escalating depth, full feature coverage

## Context

Alex: "the demos should go through more and more details as we go from
demo 1 to n. at the end of doing all of the demos the user should have
touched every feature."

## Design

The four lessons become a LADDER — each assumes the previous and digs
deeper — and every remaining untouched feature was assigned to the
lesson where it naturally lives. New hands-on steps are verified drills
where the graph can see them; page-chrome steps use the V3.403
DOM-checked pattern. **Every new `when`-step is `practice: true`** so
the prebuilt "already built" gate (which only counts build conditions)
keeps working on legacy copies.

### Lesson 1 (17 steps, unchanged this release) — the basics
Inputs, equation, wiring, naming, typed units, zoom/fit/collapse/tidy,
✎ Editor switch, 🔗 Reference.

### Lesson 2 (13 → 17) — configuration depth + wire fluency
- **Detail: pick the widget** — flip dose to `number`
  (`widget === 'number'`); why covers slider-vs-number precision + the
  Hint field.
- **Detail: display decimals** — mirror prints 10.0
  (`decimals === 1`).

  (`edgesInto(mirrored_dose,'param','value') < 1`) and watch the mirror
  freeze.
- **Drill: re-bind it** — rebuild the binding from memory (`>= 1`).

### Lesson 3 (13 → 16) — structure depth
- **Detail: lock the set** — untick "editable at run time"

- **Read the unit legend** — info, rings `.pge-legend` (socket colors =

### Lesson 4 (10 → 15) — capstone: power tools + the protocol lifecycle
- **Drill: break it on purpose / fix it** — delete `millions` from the
  return (body has `return` but not `millions`), watch the contained ⚠,
  restore it (build-script condition again). Error contract by
  experience.
- **Drill: drop in a recipe** — insert ✨ Script transform
  (`count('code') >= 2`).
- **Drill: wire surgery + cleanup** — shift-cut + × the scratch pair
  (`code <= 1 && input <= 2`); replaces the two former info-only steps

- **Finish like a pro** — switch to ✎ Editor (DOM `.active` check),
  **Mark the section complete** (rings `.pre-section-donebtn`,
  completes on `.pre-section-complete`), then a lifecycle closer
  ringing 💾 Save version and name-dropping 📜 Versions, 🍴 Fork, and
