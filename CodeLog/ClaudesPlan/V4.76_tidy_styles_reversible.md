# V4.76 — Tidy layout in styles, and a way back to your own layout

## Why
Gabe, 20 Nov 2026: "Tidy layout should be reversible to user manual layout state, and upgrade tidy layout in general to be
various styles: flow of information top down or horizontally, etc..."

## What changed
- **Reversible** (12d-layout.js): before a tidy, `LAYOUT.snap(d)` takes where everything stands (components with a place, the
  head and synthesis boxes, folded regions' places). After it, `LAYOUT.keep` writes `d.layout.tidy = { style, at, from, to }`
  on the note's record (a `documents` row, so it syncs; `d.layout.tidyStyle` is the remembered style). **Undo tidy · back to
  your layout** (`LAYOUT.untidy`, one undo step) restores `from` for every component still in the note, any time later, not
  only by Ctrl+Z; a component made since stays where it is. Tidying again keeps the first `from` while nothing moved since the last
  tidy (several styles in a row still go back to your own layout); a component moved by hand afterwards makes the layout as it is
  the new one to go back to. It is in the note's ⋯ menu, the paper's right-click menu, the style menu, and `/untidy`.
- **Styles** (`LAYOUT.STYLES`, `LAYOUT.arrange`): Packed (the tidy so far: by links, smallest near-square), Top down (each group a stack
  of rows, groups side by side in shelves; the unconnected ones in a grid after them), Left to right (`pack(..., 'across')`: layers become
  columns; groups one under the other in shelves), By kind (a column for each kind, oldest on top: the structure kind, else the
  component kind), Grid (reading order in even rows and columns). Regions stay pieces of their own, laid out in the same direction.
  Ordered notes (protocols, experiments) keep "Flow in order", which is now reversible too.
- **Chosen when tidying**: "Tidy layout" in the menus opens the styles (a monochrome icon, a line each, the note's style ticked);
  `/tidy [style]`; remembered per note; Settings → Tidy layout holds the default style and a switch "Remember the style for each note".
- Settings → Tidy layout (`tidy`): switch (off: Tidy is the one Packed click it was, nothing kept), default style, remember; the live
  preview draws a sample note in the chosen style with `LAYOUT.sample`, which runs the same `LAYOUT.arrange`.
- Test `tidy_t.mjs`: real right-click, the style menu, the undo row; the five styles' geometry; the way back after one and after four
  tidies; a move by hand; Ctrl+Z; the default and `/untidy`; Settings and the preview; the switch off.
