## How a module reaches a teacher (three gates)

1. **The file** under `modules/<folder>/`, FTP'd.
2. **`modules/manifest.json`**, which lists it in the admin catalog and the Add Module picker. Regenerated by
   `scripts/scan_modules.py`.
3. **`teacherCatalog/{folder--basename}.published`**, the per-module "Available" tick on RM → Teachers → Module
   Catalog. `TC_DB.publishedCatalog()` reads only ticked rows into the teacher's `#/teach` picker. It is Firestore
   admin data, written by an admin in the browser; nothing in this repo sets it.

Worksheets need their own tick. `teacher-teach.js` `withWorksheets()` files `worksheet-NN-…` under lesson `NN-…`,
but it groups only among items already published in the catalog. An unticked worksheet is missing without any
warning, not attached. The new filenames match `worksheetNum()`'s pattern.

## Approach

- Copy the 6 lessons + 6 worksheets from the source, byte-identical (`cmp`). `harness_06.mjs` stays in the source
  repo: it is a Node test, not a page.
- Before copying, three small defects found while re-checking the pages were fixed at the source:
  - **"∝" rendered as a near-invisible glyph.** No macOS system font has U+221D, so it fell back to Apple Symbols'
    tiny one. Lesson 1 teaches the sign by name; it appears in 22 places in page text plus 6 canvas captions. Fixed with a one-glyph
    `@font-face 'PropSign'` alias (`unicode-range: U+221D`, local STIX Two Math / Cambria Math / Noto Sans Math /
    Segoe UI Symbol / DejaVu Sans / Menlo) at the head of the body font stack. No text changed. Six canvas captions,
    which cannot rely on a local font face, now say it in words.
  - **Lesson 3 Tab 3:** at the default L = 4 mm, the "halve L → double q" hint sat on the chart ceiling and its label
    was clipped. It now drops below the legend when it would clip.
  - **Worksheet 6:** record row E was one cell short; the column names now match the lesson's stat labels.
- `scan_modules.py` → manifest diff is exactly the six new worksheets.
- `sw.js` 767 → 768 (modules are network-first, so this is ritual).
