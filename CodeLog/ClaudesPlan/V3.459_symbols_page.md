# V3.459 — ∑ Symbols page: reorderable math-symbol palette

> Test feedback on Paper Builder III (fix 7 of 7, second half of issue 1): "I also want
> another page that is just all math symbols sectioned by type, that each section is
> expandable and are cards you can move around, and that order becomes the new default."

## What shipped

A new pill page `paper-builder.html?paper=X&page=symbols` — a focused palette tool
(tiles + copy, no reference prose):

- **NEW rm/js/paper-symbols.js** (`window.PaperSymbols.buildTabContent(root)`, the
  paper-writing-guide contract — idempotent, loaded before paper-equations.js):
  - ~230 KaTeX-safe symbols in 10 section cards: Greek lower/upper, accents &
    decorations, operators, relations, arrows, calculus & big operators, matrices &
    delimiters (pmatrix/bmatrix/vmatrix/Bmatrix/cases samples), sets & logic, misc.
  - Each **tile** = KaTeX-rendered glyph (`PaperEditor.ensureKatex()` +
    `renderEquationHtml`, raw-LaTeX fallback) + monospace caption; **click copies the
    LaTeX** (navigator.clipboard with execCommand fallback) with a ✓ copied flash.
  - Each **card** collapses/expands (header click or ▸/▾) and reorders via the ≡
    pointer-drag handle (drop-line indicator; custom pointer events, no HTML5
    draggable) or ▲▼ buttons.
  - **Persistence:** `userSettings/{uid}` merge-write of
    `paperSymbols: { order, collapsed, updated_at }` — the library-prefs.js debounced
    (500 ms) direct-firebase pattern; rules already allow owner writes (**no
    deploys**). `_orderedSections()` drops stale ids and appends new catalog sections
    in default order, so future symbol additions don't break saved prefs.
- **Plumbing (the six enumerated spots):** paper-builder.html PAGES allowlist +
  PAGE_TITLES ("Math Symbols — Paper Editor") + script list (paper-symbols.js before
  paper-equations.js); paper-equations.js TABS (`∑ Symbols` between Equations and
  Figures — pill bar and tab nav are data-driven), `_buildPanel` symbols tab div
  (`#pe-symbols-root`), `_refreshPanel` symbols branch. Anti-flash CSS and
  `_reflectPillState` needed no changes (generic).
- **rm/css/paper-editor.css** — `.pe-symbols/.pe-symcard*/.pe-symtile*` (cards, grid
  `minmax(96px,1fr)`, drag ghost + drop line, copied flash).
