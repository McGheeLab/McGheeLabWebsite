# V3.905 — Scientia: type /cite to cite a paper

## Goal

Alex (2026-10-24): "when im writing i want to be able to write /cite and the same thing happens, and the citation selected
replaces my /cite text". "The same thing" is Ctrl+I: Gabe's citation picker (`ED.citePicker`, 09-editor), which searches
the library (on the web, the lab's papers mirrored from RM) and puts a citation in the text at the caret.

## Approach (`scientia/src/09-editor.js`, Gabe's)

- `ED.slashCite(el, b, e)` runs on each `input` of a box, before Gabe's `$…$` conversion.
  - It fires when the text just typed ends in `e`, the caret is collapsed in an editable text node (not inside an equation
    or citation atom), and the text before the caret ends with `/cite`.
  - `/cite` must come at the start or after a space or bracket, so `and/cite` or a path does not trigger it.
  - It opens `ED.citePicker(el, b, sel, '/cite')`.
- `citePicker(…, typed)`: the citation's place is the caret minus `typed`. On a pick, the `/cite` there is replaced by the
  citation. If the text moved while the picker was open, the last `/cite` in the box is used. If it is gone, the citation
  is simply inserted. Esc (or clicking away) leaves the `/cite` as typed.
- Hints: the note's bottom line reads "Ctrl+I or /cite cite"; the picker's tip mentions /cite. `BUILD` updated.
- Ctrl+I is unchanged, and so is select-then-Ctrl+I (add the selected text to the library).
