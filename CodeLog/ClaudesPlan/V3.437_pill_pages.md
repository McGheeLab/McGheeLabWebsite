# V3.437 — P1 of Paper Builder III: the pills become PAGES (Guide / Equations / Figures / Tables / References)

> Alex: "I want all of the pills to go to separate pages… for the figure composer, lets
> make that a separate page in the main paper editor called figure editor."
> This is the structural release the Tables II UI (T1/T2), MathLive (E1), and the figure
> composer (F1) land on top of.

## Mechanism

Extends the builder's existing per-mode boot (V3.58/V3.60 `__PAPER_MODE` pattern) with a
`page` URL param — **no new .html files, no module split**:

```
paper-builder.html?paper=<id>                 → write (the doc editor, default)
paper-builder.html?paper=<id>&page=figures    → Figure editor page
                       …&page=guide|equations|tables|references
```

Each is a real URL (bookmarkable, back/forward, own browser tab). Every page keeps the
paper header (title/status/savestate/presence) and the live Yjs connection — an edit on a
tool page appears in the write page's doc live, and vice versa.

## Changes

- **`rm/pages/paper-builder.html`** — boot script parses+validates `page` →
  `window.__PAPER_PAGE` + `data-paper-page` on the root + per-page `document.title`
  ("Figure Editor — McGhee Lab" etc.). Anti-flash style rules: tool pages hide
  `.pe-layout` + `.pe-global-toolbar` + `.pe-mobile-toggle`; the write page hides
  `.pe-toolpage`. New full-width host `#pe-toolpage-root` before `.pe-layout`.
- **`rm/js/paper-equations.js`**
  - `_gotoPage(pageId, {focus})` — canonical navigation (exported as
    `PaperEquations.gotoPage`); `_currentPage()`/`_isToolPage()`.
  - **Pill bar = page nav**: leading **Write** pill + the five tool pills; click
    navigates; active pill = current page (`_reflectPillState` keyed on the page).
    The old open/close toggle (`_togglePill`) is gone.
  - **Tool-page mount**: `attach()` on a tool page calls `_mountToolPage()` — builds the
    SAME pane (`_buildPanel`, all ids intact), classed `pe-toolpage-pane`, appended into
    `#pe-toolpage-root`, pinned to the page's tab; then `_applyFocusParam()` honors
    `&focus=<blockId>` (scroll+flash, retrying up to ~5 s while Yjs lists hydrate).
  - **Legacy-caller shims** (the write page has no slide-out anymore):
    `showPanel()` on write schedules a DEFERRED navigation so the classic
    `showPanel(); setActiveTab(t)` pairs land on the right page; public `setActiveTab`
    records the tab on write / navigates across tool pages;
    `scrollToFigureRow`/`scrollToTableRow` redirect (with `focus`) when called from the
    wrong page; `_focusPanelOnBlock` navigates with focus. `hidePanel` is a no-op on
    tool pages.
- **`rm/js/paper-blocks.js`** — the two "Edit in panel ↗" buttons are now
  "Edit on Figures/Tables page ↗" calling `gotoPage(tab, {focus: blockId})`.
- **`rm/css/paper-editor.css`** — `.pe-toolpage` (max-width 1100px centered) +
  `.pe-toolpage-pane` overrides (static, full-width, no resize handle / pane head /
  internal tab nav — the header pills are the navigation).

## Notes

- The doc editor still initializes on tool pages (hidden via CSS) — it owns the Yjs
  connection, title/status header, and presence; render cost of hidden DOM is accepted
  v1 (noted as a future optimization).
- The write page keeps the block-inserter pickers (popovers) untouched; their "+ New"
  rows now land you on the item's page focused on the new block.
- The Figures page is the future home of the F1 panel composer + the "Figure builder"
  helper card (Alex's later concept).
