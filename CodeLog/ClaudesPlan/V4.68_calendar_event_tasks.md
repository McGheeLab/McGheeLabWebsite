# V4.68 — Scientia Calendar: tasks for an event, kept in its linked note

## Why
Gabe, 20 Nov: "You may add tasks to a calendar event, which associates that task to the linked note."

## What changed
- **The event's card has a Tasks row** (`CAL.taskRow`). Typing a task and pressing Enter makes a task component in the event's linked note (`CAL.addTask` → `TASK.create`). It is due when the event starts, or that day for an all-day event, so it is also a reminder, and it carries `eventId`. The event keeps its tasks in `ev.tasks`.
  - With no note linked, the row says to link one first, since the tasks are kept in it.
  - Each task can be ticked there (`TASK.toggle`), opened where it is in its note, or taken off the event (it stays in its note).
- **The event's card on the calendar counts them:** open / all, with a check icon.
- Settings → Calendar: the description says so.
