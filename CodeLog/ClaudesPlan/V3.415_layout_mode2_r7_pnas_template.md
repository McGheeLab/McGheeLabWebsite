# V3.415 — Layout Mode II R7: the PNAS template (real pnas-new class)

> Release 7 of 8. "Many journals like PNAS have these custom section
> blocks" — this ships PNAS itself: the real class, two-column compile,
> Significance in the blue page-1 box, end-matter macros wired through
> the R6 section-style catalog. **Gate: the Cloud Run compile** (the one
> check that can't run client-side).

## What shipped

1. **rm/data/paper-templates/pnas-new.json** (41 KB) — ships the REAL
   `pnas-new.cls` v1.44 + `pnasresearcharticle.sty` + `pnas-new.bst`
   as `extra_files` (LPPL v1.3+; the science.json scicite.sty
   precedent; every `\RequirePackage` is stock TeX Live → tectonic-safe).
   `\documentclass[9pt,twocolumn,twoside]{pnas-new}` +
   `\templatetype{pnasresearcharticle}`; the class draft watermark is
   `\AtBeginDocument`-gated, so the preamble disables it
   (`\setboolean{displaywatermark}{false}` — this mirror's watermark is
   the mirror author's name). `figure_environment.compiled_columns: 2`
   — the SECOND two-column template: starred floats (`figure*`/`table*`),
   the R3 `\dbl*` spacing lines, and R5's cuted strip all key on
   compiled_columns, not template id, and light up automatically
   (harness-verified). Table captions above; render_hints.layout
   87/114/178 mm, placements t,p; numeric-paren citations on the
   pnas-new bst; author_block format `authblk`.
2. **Wrap placeholders** (paper-export-tex.js) — placeholder/keywords
   commands accept `wrap` ('\\acknow{%s}\n\\showacknow') + `sep`: content
   substitutes into %s, an EMPTY section stashes '' so end-matter macros
   never print bare headings (`\matmethods{}` would render an empty
   "Materials and Methods" otherwise). Token seeding now also walks
   `section_kind_to_command` object commands. PNAS main_template carries
   only bare `{{*_BLOCK}}` tokens — every one pre-seeded (leftover-sweep
   contract, harness-asserted against the real JSON).
3. **PNAS catalog** — significance (`\significancestatement{}` wrap,
   front, box preview), author_contributions (`\authorcontributions{}`),
   matmethods (`\matmethods{}\showmatmethods`, text-only hint — Methods
   default stays an INLINE `\section`: floats can't live in a macro arg),
   acknowledgments (`\acknow{}\showacknow`), data_availability (star).
   Keywords kind-command = object `{keywords, token:{{KEYWORDS_BLOCK}},
   wrap:\keywords{%s}, sep:' | '}` (PNAS pipe separators).
4. **`authblk` author format** (renderAuthorBlock + structured variant)
   — `\author[nums]{Name}` + `\affil[n]{...}` (pnas-new RequirePackages
   authblk).
5. **Preview** (paper-doc-view.js) — DOC_HINTS 'pnas-new' (letter,
   0.75 in, 2 cols, 9.4 pt, 0.16 in gap); `_buildFlowItems` now resolves
   section commands through the SHARED
   `PaperExportTex.resolveSectionCommand` (special-first + object
   vocabulary — newly exported with normalizeCommand) and maps the
   object back onto the walker's dispatch; boxed specials render as a
   `.pdv-significance` callout (blue PNAS-style box; rose R2 tint);
   headings + the callout stamp `data-section-id` (R8's click targets).
6. **Registry** — KNOWN_TEMPLATES row 'PNAS (pnas-new class)'.
