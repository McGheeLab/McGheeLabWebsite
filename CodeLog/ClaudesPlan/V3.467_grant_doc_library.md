# V3.467 — Grant unification R5: reusable document library

> Fifth release. Fills the Grant Docs page with the reusable-document library: pull a
> saved biosketch variant / facilities doc / boilerplate template into an attached-doc
> section, or save a section's prose back as a reusable default. **The one Firestore
> rules deploy of the program** (new `grantDocTemplates` collection).

## New module (rm/js/paper-grant-docs.js)

`window.PaperGrantDocs.buildTabContent(root)` — same lazy-scaffold contract as
PaperWritingGuide / PaperSymbols; `paper-equations._refreshPanel` already calls it on
the grant-docs page (R4). Loaded in `paper-builder.html` editor scripts before
paper-equations.js. Renders (grant papers only) a card per attached-document section
with insert/save actions:

- **Insert sources** (append blocks via `PaperEditor.insertBlockAt`, never destructive):
  - `biosketch` sections → picker of the user's `biosketches/{uid}/variants` → inserts
    the variant's Personal Statement as paragraph blocks.
  - `facilities` sections → picker of `facilitiesDocs` → inserts each present section
    (Facilities / Equipment / Computing / Office / Other Resources) as a subheading +
    HTML→blocks.
  - **any** attached kind → picker of `grantDocTemplates` filtered by kind → inserts
    the saved `body_html` as blocks.
- **💾 Save as template** (any attached section) → serializes the section's
  paragraph/subheading/list blocks to `body_html` and writes a `grantDocTemplates` doc
  (prompt for name; choose lab-shared vs personal). The inverse of insert — the literal
  "save these as defaults I call in and edit" ask.

Reuses already-shipped block kinds (paragraph/subheading/list) via a small
`_htmlToBlocks` walker (DOMParser; `<ul>/<ol>`→list, `<h2-4>`→subheading, else
paragraph) + `_blocksToHtml`. The existing `biosketches`/`facilitiesDocs` collections
are **read-only** here (authored on their own pages, untouched); `grantDocTemplates` is
the new generic read+write store. Direct-firebase (`firebridge.db()`) matching the
sibling facilities/biosketch pattern.

## New collection + rules (firestore.rules) — REQUIRES DEPLOY

`grantDocTemplates/{docId}` — `{kind, label, owner_uid (null = lab-shared),
body_html, created_by, created_at, updated_at}`. Rules mirror `facilitiesDocs`:
lab-read; create by author; update by admin or (lab member && (lab-shared ||
owner)); delete by admin or author. **Validated with `firebase deploy --only
firestore:rules --dry-run` — compiles successfully.**
