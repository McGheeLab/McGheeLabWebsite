# V3.397 — Layout Mode R2: the float engine

> Release 2 of the Layout Mode program (R1 foundation = V3.395). The
> Document view's packer now understands ANCHORED floats: a figure/table
> whose `anchor` is top/bottom/float-page claims a page BAND, and text
> packs into the remainder — LaTeX's own float-area model, in-browser.
> No new UI in this release: anchors are set via the existing figure
> popover (or the Figures panel placement selects); R3 adds the
> color-coded region overlay + ⬒ Layout toggle, R4 the drag interaction.

## What shipped (all in rm/js/paper-doc-view.js + rm/css/paper-doc-view.css)

1. **Flow-item classification** — `_buildFlowItems` items now carry
   `sectionId`, `blockId`, and `float: null | {region, span, lock}`
   (needed by every later release). `_buildBlockNode`: figures with
   `anchor !== 'flow'` classify as floats (span mirrors the measured
   container — page-span figures were already measured at body width);
   tables gained the same classification plus `data-block-id`/
   `data-block-kind` stamps (previously missing) and can now be
   `type:'full'` when span='page' in a 2-col journal. All float nodes
   stamped `data-anchor`/`data-span`.
2. **Band packer** — `_packPages` rewritten. Pages gain
   `topFloats`/`bottomFloats` (rows of `{span, items, h}`), `topH`/
   `bottomH`, `isFloatPage`, `rects`. Deterministic float→page
   assignment = LaTeX's rule (land on the page where the source
   position falls, else the next page with room) via a `pending` queue
   drained after every float push (same-page [t]/[b]) and at each fresh
   page. `openRunH()` projects the OPEN column run so mid-page float
   placement can't overflow already-admitted text. Column-span floats
   pair two-up per row (per-column float areas); `FLOAT_MAX_FRAC = 0.72`
   caps the band share (the \topfraction analogue — prevents text
   starvation AND pack oscillation); **locked floats ignore the budget**;
   a float opening an EMPTY page always places (guaranteed progress).
   `anchor='float-page'` items become dedicated sheets flushed between
   text pages. Trailing floats drain onto fresh pages with a guard.
3. **Region rects** — `_recordRects` stamps every page with page-local
   px rectangles: margin frame, column guides, text region, footnote
   strip, and EXACT per-float rects `{blockId, kind, region, span,
   x, y, w, h}` (top rows stack down from the margin; bottom rows stack
   up from the footnote top; paired columns at both x positions). This
   is the R3 overlay's entire data source — zero re-measurement.
4. **Mount** — sheet body = `[top band][.pdv-textregion (existing
   segments)][bottom band]`; `_mountBand` renders rows → `.pdv-float-row`
   (flex, colGap) → `.pdv-float-slot` (colW px or 100% — the widths the
   items were measured at, so band heights stay truthful). CSS:
   `.pdv-sheet-body` becomes a flex column; the bottom band anchors via
   `margin-top:auto`; `.pdv-textregion` is `flex: 0 0 auto` (an overflow
   page must overflow + clip at the sheet edge like pre-R2 block layout,
   not squeeze).

## Invariants

- **Zero-anchored-float papers render as before** — bands never mount;
  the only DOM delta is the `.pdv-textregion` wrapper (validated by the
  no-float parity tests: identical `usedH` accounting + page breaks).
- Measurement path untouched — floats measure in the existing col/full
  batches by `item.type`.
- The popover/citation-panel delegation and the popover-survives-
  re-render re-anchor keep working (figures keep `.pdv-figure
  [data-block-id]` inside band slots).

## Verification

- `node --check` ✓. **44-case packer harness** (scratchpad
  `test-packer.js`, loads the real module in Node with the export line
  string-replaced to expose `_packPages`): no-float parity, band
  placement (top/bottom, same-page), column pairing + paired rect x
  positions, budget deferral + locked override, float-page dedicated
  sheets, trailing-drain termination + every-float-placed-exactly-once
  conservation, 1-col full-width bands, rects sanity (all inside
  margins), mixed stress. 44/44 ✓. R1 harness still 55/55 ✓.
- Adversarial review: the Opus find phase (3 dimensions) raised 10
  findings; the verify agents hit the org's monthly spend limit, so all
  10 were hand-verified against the code. Five were real and fixed —
  strict source-order float queue, float-page slot span mirroring the
  measured container, band-over-cap overflow flags, MAX_SHEETS float
  leak → truncation notice, band-row BLOCK_GAP mounted so DOM ==
  recorded rects — plus unknown-anchor hardening. Five refuted by
  inspection (pre-existing footnote chrome slack, 1-col consistency,
  duplicates). Harness extended to 51 cases covering each fix.
- Browser (Alex): open the Document view on mebp-paper, click a figure →
  set Anchor "Top of the page" → the figure should jump to the top band
  and text fill below; set "Own floats page" → dedicated sheet; page
  count stays sane; a paper with no anchors renders unchanged.
