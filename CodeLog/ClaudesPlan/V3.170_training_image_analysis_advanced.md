# V3.170 — Training: Image Analysis (Advanced)

> Status: PLANNED — not yet built.

## Goal

The frontier methods a student needs once classical thresholding +
watershed run out: deconvolution, 3D segmentation, colocalization
metrics, ML-assisted segmentation, and time-lapse tracking. By the end
the student can argue for / against each method on a real lab dataset.

## Format

Full interactive notebook (MODULE_TEMPLATE.md pattern). 6 tabs.

## Tabs

### Tab 1 — Deconvolution
**Bio context:** AX-R confocal Z-stack of a 100 μm spheroid where the
out-of-focus blur is still visible because the pinhole was opened to
1.5 AU for SNR.

- Background: image = sample ⊛ PSF; deconvolution as a deblurring
  inverse; theoretical PSF vs. measured PSF; Richardson-Lucy iterations
- Interactive: side-by-side raw vs. deconvolved single XZ slice; slider
  for iteration count → image sharpens then noise blooms; verdict picks
  the sweet spot
- Tools: Hugens (commercial), DeconvolutionLab2 (Fiji plugin), CARE (ML)

### Tab 2 — 3D Segmentation
- Background: 2D-then-stack vs. true 3D (3D watershed, marker-based);
  why nuclei-touching-in-Z is harder than nuclei-touching-in-XY
- Interactive: walk a 3D mask in XY/XZ/YZ — the student sees the same
  cluster from three views and adjusts the 3D distance transform
- Tools: 3D Suite (Fiji), MorphoLibJ, scikit-image, napari

### Tab 3 — Colocalization
- Background: Pearson, Manders, Costes randomization; the "yellow in
  the merge" fallacy; thresholded vs. pixel-by-pixel
- Interactive: two channels with adjustable overlap → Pearson + M1 + M2
  update live; the student tries to fool the metric and sees that
  Costes randomization flags real vs. apparent colocalization
- Worked example: receptor + ligand on the same membrane — what
  Pearson 0.7 actually means here

### Tab 4 — ML-Assisted Segmentation
- Background: Cellpose, StarDist, Mesmer — pre-trained models for
  cells / nuclei / cell-typed segmentation; when to use vs. when to
  fine-tune; common training-set pitfalls
- Interactive: run Cellpose (simulated, with cached results) on a
  spheroid edge; compare against classical Otsu+watershed; verdict
  reports recall, precision, IoU
- Hardware: where on the lab's compute infrastructure to actually run
  this (GPU box vs. CyVerse vs. local CPU)

### Tab 5 — Time-Lapse Tracking
- Background: linking detections frame-to-frame; nearest-neighbor vs.
  global linkage (Munkres / Jonker-Volgenant); track quality metrics
- Interactive: simulated migration data; the student adjusts the
  maximum jump distance and watches tracks form/break
- Tools: TrackMate (Fiji), btrack, ilastik tracking workflow

### Tab 6 — Capstone: choose-the-right-method worksheet
Given three hypothetical analysis problems (one good fit for classical,
one for ML, one for tracking), the student selects the method, defends
the choice, and identifies the validation metric. The page critiques
each answer with the canonical reasoning.
