# V3.357 — CV onboarding & guidance (FuturePlan 11, Release 5)

**Goal:** a first-year student opening the CV editor knows exactly what to
do next — and is steered into the import flows instead of blank forms.

## Design

Persistent **"Get started" checklist rail**, not a modal carousel. Steps
deep-link the *existing* flows; completion is **derived from the document
itself** — the only stored state is `cv_meta.onboarding_dismissed` and
`cv_meta.last_export_at` (both additive).

## What shipped

1. NEW [`rm/js/cv-onboarding.js`](../../rm/js/cv-onboarding.js) —
   `CV_ONBOARDING.render/healthChip/emptyStateFor/steps`.
   Steps: ① profile basics (name + title/institution) → ② import
   publications (→ library pull) → ③ round out ≥2 more sections
   (→ awards) → ④ preview & export (done once `cv_meta.last_export_at`
   is stamped). Rail hides when dismissed or complete.
2. **Health chip** in the toolbar — "CV health k/4" (tooltip lists what's
   missing; "CV ✓" when complete); clicking it un-dismisses the rail.
3. **Guided empty states** — `renderEmptyState` now shows a believable
   example entry line per section (EXAMPLES map) plus the right CTAs:
   journals/conferences get "📚 Pull from library" (primary) + ORCID +
   BibTeX + manual; every other section gets "+ Add your first entry".
4. **Export stamping** — `markExported()` on Markdown/HTML/Word/print
   stamps `cv_meta.last_export_at` (fire-and-forget; first stamp
   re-renders to complete the step).
5. **Schema hints** (display-only, contract-safe): journals.doi ("paste
   and click Fetch from DOI"), presentations.event, service.role examples
   in `cv-schemas.js`.
