# V3.439 — T1 of Paper Builder III: merged table cells + per-column widths

> Tables were a plain l/c/r grid. Now cells merge (\multicolumn/\multirow) and columns
> take fixed widths (p{} colspecs) — authored on the Tables page (P1), previewed in the
> doc-side block and the Document view, compiled faithfully.

## Model (scalar attrs — survive every move path per the T0 fix)

- `attrs.merges_json` — `{"r-c": {"rs": N, "cs": M}}`, anchored at the top-left cell.
  Covered cells keep their Y.Texts (unmerge restores content).
- `attrs.widths_json` — per-column `[{"mode":"auto"|"frac"|"mm","v":N}, …]`.

## Shared helpers — `rm/js/paper-layout-rules.js` (window.PaperLayout + module.exports)

`parseTableMerges(json)` (validated, ints ≥1); `tableCoverMap(merges, rows, cols)` →
`{anchors, skip, cont}` — skip = swallowed cells; cont = rowspan-continuation cells at the
anchor column (LaTeX needs an EMPTY placeholder there, an empty `\multicolumn{cs}` when the
merge also spans columns, to keep the column count right); overlaps: first anchor row-major
wins. `parseTableWidths(json, cols)`. Consumed by all four surfaces + the node harness.

## Changes

- **Export (`rm/js/paper-export-tex.js` tableToTex):** colspec builder — width-set columns
  become `p{0.3\linewidth}` / `p{25mm}` with alignment preserved via array-package
  prefixes (`>{\centering\arraybackslash}` / `>{\raggedleft…}`); auto columns keep l/c/r
  (byte-identical when no widths). Cell loop uses the cover map: anchors emit
  `\multicolumn{cs}{a}{…}` and/or `\multirow{rs}{*}{…}` (combined = multicolumn wrapping
  multirow); continuation rows emit the empty placeholder; swallowed cells are skipped.
  New on-demand preamble flags `_usedMultirow` → `\usepackage{multirow}`, `_usedArray` →
  `\usepackage{array}` (declare/reset/consume/finally — the `_usedCuted` lifecycle).
- **Tables page editor (`rm/js/paper-equations.js` `_buildTableEditorBody`):** click a
  cell / shift-click a corner to select a rectangle (`.pe-cell-selected`); **⧉ Merge**
  (rejects overlap with an existing merge) / **⧉ Unmerge** buttons beside +Row/+Col;
  per-column **width select** (auto / 15–50% / mm…) under each L/C/R triple; the grid
  renders merge-aware (anchors carry row/colSpan, covered cells hidden). Selection state
  `_tblSel` module-level, cleared on merge/rebuild.
- **Doc-side block (`rm/js/paper-blocks.js` renderTable):** read-only mirror — colgroup
  from widths + row/colSpan + `.pe-cell-merged`; the existing attrs observer re-renders on
  merges/widths writes.
- **Document view (`rm/js/paper-doc-view.js` table branch):** same colgroup + spans in the
  journal-page preview (HTML rowspan covers continuation cells — no placeholders needed).
- **CSS (`rm/css/paper-editor.css`):** `.pe-cell-selected` (blue outline),
  `.pe-cell-merged`, `.pe-table-width-sel`.
