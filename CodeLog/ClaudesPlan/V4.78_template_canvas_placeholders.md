# V4.78 — Scientia: a template opens as a note canvas, with placeholder components that wait in the note

## Why
Gabe, 20 Nov: "Templates in settings should bring up a note canvas with placeholder components. For example, you can add a placeholder image panel that waits for you to click on them to add images when you create a note with that template."

Settings → Templates → Edit showed a list: a label box and a default-text box per component. Nothing showed where the components would sit in the note, and a template could hold nothing but text.

## What changed
- **The template as a canvas** (`20c-tplcanvas.js` `TPLC.edit`, `41-tplcanvas.css`). Edit opens a wide window with a small note canvas: a faint header band, then each component as a card where a note made from the template will place it. Drag a card by its title bar (14 px grid); type its label and default text in place; × removes it; the toolbar adds a text component, an image placeholder or a whiteboard placeholder; Tidy lays the cards out as a new note of that type would. A template made before this (no positions) opens laid out as a note would (one column for ordered types such as meetings and protocols, two columns otherwise); Save keeps the positions.
- **Placeholders.** A template row stays `{ label, body, x, y }`; new optional keys: `w` (width), `ph: 'image' | 'board'` and `fig: { rows, cols }`.
  - **Image placeholder** — `M.createDoc` makes an empty image panel with `ph: 'image'`. In the note it shows as a dashed panel of the size the real one will have (`FIG.phBody`), "Image panel · 2 × 3 — click to add images". One click (or dropping files on it) opens the file chooser; the first image added removes `ph` and it is a real panel from then on, the other cells waiting. Its shape is one m×n box on the card with the shape drawn as you type (the same `FIG.parseShape` / `shapeWidget` as the Image panel dialog).
  - **Whiteboard placeholder** — `ph: 'board'`, a 1×1 panel; a click starts the lab's whiteboard in it (`BOARD.make`) and removes `ph`.
- **Old templates keep working.** `createDoc` reads `label`, `body`, `x`, `y` as before; the new keys are only read when present. The plain list editor is still there (below).
- **Save structure as template…** (`M.saveAsTemplate`) now keeps an image panel as an image placeholder of its shape (text components as before).
- Lists of a template's components (Settings, New note's choice) say what waits: `M.templateSummary`.
- **Settings → Features → Template canvas** (new FEAT `templates`, group Canvas & notes): description, the setting "A new image placeholder starts as" (1×1, 1×2, 2×2, 1×3), a preview that is the canvas in small (header, a text component, the placeholder in that shape). Off: Edit shows the old list again (placeholders already in a template stay in the record and are still made); Save structure as template keeps only text components.
