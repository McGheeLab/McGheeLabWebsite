# V3.238 — Tasks inbox phone layout (Phase 3b of mobile compatibility)

> Phase 3b continued. V3.237 fixed `.yr-line` / `.ch-line` (calendar / activity rows). V3.238 fixes the second-worst phone offender: `.inbox-row`, used by the **tasks inbox** (the single highest-frequency phone use case per the user's must-have list: "Check my task inbox / mark done").

## Goal

Make the tasks inbox usable for the daily phone workflow: scan today's assigned subtasks, tap a checkbox to mark done, drill in if more detail is needed. Three concrete fixes:

1. **Larger tap targets.** Desktop checkbox is `14px × 14px`. The open-task link is a 14px arrow with 4px horizontal padding. Both are below Apple's 44px HIG minimum and frustrating to hit on a phone.
2. **Surface the project crumb.** V3.233 hid `.inbox-crumb` (project/bucket name) on phone to save space, but the crumb carries critical context: "Mark done on which task in which project?" Hiding it forced users to drill in to disambiguate similarly-named subtasks.
3. **Wrap the title.** Desktop ellipsis-truncates the title at the row width. On a 390px screen with 30px of chrome on each side, the title shows ~30 characters before truncation. Wrapping to 2 lines is more useful.

## Approach

CSS-only `@media (max-width: 640px)` block targeting `.inbox-row` and its descendants. Converts the desktop flex-row to a 4-column / 2-row `grid-template-areas` layout:

```
| check | dot | main (title + crumb) | open |
|       |     | meta chips           | meta |
```

The original DOM structure is unchanged — every `.inbox-row` still emits checkbox, dot, main, meta, open-link in the same order. Only the grid template changes.

## Changes

### `rm/css/style.css`

Expands the existing 4-line `@media (max-width:640px)` block at line 1810 (which previously did `.inbox-crumb { display: none }` and removed `.inbox-meta { max-width }`). New rule body:

- `.inbox-row` becomes a grid: `auto auto 1fr auto` columns × 2 rows via `grid-template-areas`.
- Checkbox `[type=checkbox]` grows from `14px × 14px` to `20px × 20px`. (Larger would shift the desktop alignment; 20px is the sweet spot — still distinguishable from "decorative" affordances and tappable in the larger 36px+ row.)
- Row padding bumps from `8px 14px` to `var(--sp-3)` (12px all sides). Combined with the 2-row grid this gives ~52px row height — above the 44px tap target.
- `.inbox-title` drops `white-space: nowrap` so it wraps to 2 lines instead of ellipsis.
- `.inbox-crumb` restored to `display: block` (was `display: none` on phone) so users see project/bucket context.
- `.inbox-meta` left-aligned (`justify-content: flex-start`) under main rather than competing for right-edge space.
- `.inbox-open` (the `↗` arrow) gets `min-width: 28px; text-align: center; font-size: 16px; padding: var(--sp-1) var(--sp-2)` — a proper tap area.

No JS changes. The existing click handlers on `.inbox-row` (which open the task detail) and on `[type=checkbox]` (which marks done) keep working unchanged.
