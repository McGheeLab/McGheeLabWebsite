# V4.91 — Scientia: edge pan in full screen, tunable

## Why
Gabe, 20 Nov: "Edge pan in full screen should have its sensitivity tunable."

## What changed
- **Settings → Pen and touch → Edge pan in full screen** (`edgepan`) gets three sliders, read by the edge pan (`13zzh-hands.js`, `HANDS.sens` / `edge` / `dwell`):
  - **Sensitivity**, 25–300% (100% = as before): how fast the note pans for the same push. It scales `HANDS.speed`, so the push still speeds it up the same way.
  - **Rest at the edge before it starts**, 0–800 ms (140 ms before): a flick to the edge, or overshooting a button there, moves nothing if it is shorter.
  - **Reacts within**, 1–24 px of the screen's edge (2 px before): wider is easier to reach.
- **The preview** draws more arrows the faster it is set, and says the three numbers.
- The defaults are the old numbers, so nothing changes until it is set.
