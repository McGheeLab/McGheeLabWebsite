# V3.168 — Training: Image Analysis (Basic)

> Status: PLANNED — not yet built.

## Goal

First-touch image analysis for biological confocal data. The student
finishes able to open a multi-channel stack, set a sensible LUT, draw
ROIs, and read off mean intensity correctly.

## Format

Full interactive notebook (MODULE_TEMPLATE.md pattern). 5 tabs.

## Tabs

### Tab 1 — Pixels, Bit Depth, Dynamic Range
**Bio context:** a single confocal slice of a DAPI / phalloidin / GFP
spheroid acquired at 16-bit on the AX-R.

- Background: 8-bit (0-255) vs 12-bit (AX-R native) vs 16-bit; saturated
  pixels (clipping) and how you recognize them; underexposed acquisitions
- Interactive: a synthetic image rendered at different bit depths; the
  student raises gain past saturation and watches the histogram clip

### Tab 2 — Look-Up Tables (LUTs) & Display vs. Data
- Background: the image data is fixed; the LUT just maps pixel values
  to display colors. Adjusting the LUT does NOT change the data and is
  NOT a measurement
- Interactive: a single image with sliders for display min/max and a
  palette switcher (gray, fire, green, magenta, jet) — verdict warns
  if the student is about to use a non-perceptually-uniform LUT to
  "see structure" that isn't there

### Tab 3 — Channels, Merges, & Pseudo-color Conventions
- Background: 4-color publication conventions (DAPI cyan/blue,
  cytoplasm green, target red, second target far-red as magenta);
  red-green colorblind accessibility argues for magenta over red
- Interactive: drag channels in/out of the merge; the student composes
  a 3-color overlay
- Worked example: how to reproduce a journal-quality merged image
  matching figure conventions

### Tab 4 — ROI & Mean-Intensity Measurement
- Background: drawing an ROI; mean vs. median vs. integrated density;
  background subtraction (paired vs. constant-offset); per-cell vs.
  per-image quantification
- Interactive: the student drags an ROI on a synthetic cell; the panel
  reports mean, median, integrated density; toggle background
  subtraction and watch the number change

### Tab 5 — Capstone: open / inspect / measure a real stack
A small embedded multi-channel TIFF (provided in `rm/img/training/`)
representing a confocal slice of a tumor spheroid. The student is
walked through: open → set LUTs → ID channels → draw ROIs → record
mean intensities → screenshot → save to lab notebook.

## Tools referenced
- **Fiji / ImageJ** — primary; the student is assumed to have it installed
- Worked examples include Fiji macros snippets the student can paste
