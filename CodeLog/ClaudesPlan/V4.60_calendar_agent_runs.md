# V4.60 — Scientia Calendar: agent runs, a layer over the calendar

## Why
Gabe, 19 Nov: "There should also be a second view that can be superposed onto the current calendar, which is agentic workflows. These are supposed to show double dipping work from AI working in the background."

And on 20 Nov: "The AI runs should appear as electrons flowing from the beginning to the end of where it's planned to run as a vertical line, not a block. The title of it should run alongside the line vertically through its length."

## What changed
- **A run is an event of kind `run`**, with `run: {did, done}` and an output note (`docId`). It is never a card, never in the legend, never in the all-day row.
- **The layer:** Agent runs in the bar, or G, lays the runs over the calendar (`CAL.st.agents`, kept on this device).
  - The bar adds up the AI hours shown and how much of them ran while you had something on: "AI 5.2 h · 2× for 1 h alongside you" (`CAL.tally`, `CAL.alongMin`).
- **Each run is a thin vertical line** (`CAL.runEl`) in a lane at the right of its day, from its planned start to its planned end.
  - Runs that overlap take lanes side by side. The day's cards make room: they sit in `.cal-cin`, which stops at the lanes (`--runw`).
  - Its title is written vertically along the line (`writing-mode: vertical-rl`), cut with an ellipsis.
  - **Running** (now between its start and end): three glowing dots, the electrons, flow down the line (`@keyframes cal-electron`, its pace set by the run's length). Under reduced motion they stand still.
  - **Planned:** a dotted line. **Done** (past its end, or marked done): solid and faint.
  - A sort singled out fades the runs that ran alongside none of its cards.
- **Rest on a line** about a second, and its card opens (`CAL.runFill`):
  - title, time and length ±15;
  - **While:** "2× alongside …" and how many minutes were double dipped, or "On its own";
  - **Did:** what it did, kept as you type;
  - its output note, Mark done, Delete.
- **A click** opens its output note, or makes one ("<title> — agent run") and links it.
- **The create window**, with the layer on, starts with Event · Agent run.
- **Agenda** lists the runs, as Agent run, while the layer is on.
- **Settings → Calendar:** "Electrons flow down a running agent run" (on by default). Off, a running run glows without moving; the preview shows a run line either way.
