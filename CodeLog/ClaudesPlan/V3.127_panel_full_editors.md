# V3.127 — Full panel-side editors + deep-clone reorder

## Goal

Three follow-ups to V3.125:

1. **Deep-clone reorder.** V3.125's `moveBlockWithinSection` does a
   primitives-only attrs copy. V3.126 walks attrs recursively and
   re-creates Y.Text / Y.Array / Y.Map sub-attrs so figure subfigures,
   table cells, and table caption Y.Text survive the move.
2. **Full panel-side figure editor.** The Figures tab row gains the
   complete editing surface previously inline: upload control, caption
   Y.Text contenteditable (cite/math/markdown render), layout details
   (width / placement / centering / alt). Subfigures editor + Numbered
   + label were already there from V3.115.
3. **Full panel-side table editor.** The Tables tab row gains the
   grid editor (per-cell Y.Text contenteditables), the styling toolbar
   (booktabs / header / alignment), the +Row / +Col buttons, and the
   caption Y.Text editor.
4. **Doc-side figure / table become read-only previews** — image-only
   for figures, rendered table-only for tables. The `Edit in panel ↗`
   link is the only interaction.

  `.pe-fig-editor-body`, `.pe-tab-editor-body`, `.pe-fig-row-editor`

## Verification

1. Reorder a figure with 3 subfigures (A / B / C) — subfigures
   preserved after move. Reorder a table with content — cells + caption
   preserved.
2. Doc-side figure shows only image + rendered caption + `Edit in
   panel ↗` link. No upload button, no layout pane, no caption editor.
3. Click `Edit in panel ↗` → Figures tab opens, row scrolls into
   view, the row's expanded editor section is visible. Upload, edit
   caption, change width/placement/centering/alt — all from the panel.
4. Doc-side table shows only the rendered table + caption (read-only).
   Edit-in-panel opens the Tables tab, grid + styling + caption editor
