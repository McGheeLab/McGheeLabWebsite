# V3.568 — Team Focus UX + the standard app fold-up sheet

> Alex feedback (2026-07-26). Team Focus people-selector redesign,
> mentor-assign popup, iOS zoom fix, auto-sizing description boxes — plus
> a NEW reusable fold-up input surface (`APP_SHEET`) that becomes the
> app-wide standard, first applied to Team Focus's assign-focus and
> mentor picker. Also a build-time safe-area fix in the mobile repo.

## Team Focus (`rm/js/team-focus.js` + `rm/css/team-focus.css`)

1. **People selector redesign.** The signed-in user is now a full-width
   pill on top (`renderSelfPill`); mentees sit below in a horizontal
   scroll strip (`.tf-mentees-scroll`), replacing the old category-grouped
   sidebar. The `@media(min-width:900px)` sidebar override is removed —
   the strip layout is used at every width.
2. **Assign-a-mentor is a popup**, not an inline `<select>`: a
   `＋ Assign mentor` button opens a chooser (`openMentorPicker`, now via
   `APP_SHEET`). Removed `onMentorChange` (the select handler).
3. **iOS zoom-on-focus fixed.** All editable fields
   (`.tf-title/.tf-desc/.tf-task-text/.tf-task-add/#tf-new-*`) are 16px —
   below 16px iOS auto-zooms the input on focus.
4. **Description boxes auto-grow** to fit their content up to 260px
   (`autosize()` on input + after each render), instead of a fixed 2-row
   scroll.

## The standard app fold-up sheet — NEW `rm/js/app-sheet.js`

`window.APP_SHEET` — a reusable bottom sheet that slides up with a grip +
a ▾ fold-away control, matching the My Day composer. This is now the
app's **standard surface for inputs**; pages open forms/choosers through
it instead of inline blocks so the interaction is consistent everywhere.

- `APP_SHEET.open({ title, build(body, api) | bodyHTML, onClose })` →
  returns `{ close, body, back }`. Backdrop / ▾ / Esc all close it;
  first field auto-focuses. Inputs are 16px (no iOS zoom); textareas
  auto-grow.
- `APP_SHEET.fab({ label, icon, onClick })` → the standard `.app-fab`
  (bottom-right ＋, clears the app tab bar via `body.ourlab-app`).
- Self-injects CSS (icon-picker pattern); framework-free.

**Team Focus adopts it:** the inline "＋ Assign a focus" form is gone —
a `.app-fab` (week view) opens the assign form in an `APP_SHEET`
(`openAssignFocus`); the mentor picker uses it too. Loaded on
`team-focus.html` before `team-focus.js`.

> My Day's composer already implements the same fold-up interaction
> (V3.567, its own `state.composerOpen`/FAB); it's left as-is (its drag
> strip + equipment availability make a generic port risky) but is
> visually consistent with `APP_SHEET`. New input surfaces should use
> `APP_SHEET`.

## Mobile repo (OurlabMobile) — build-time safe-area fix

`scripts/sync-rm.mjs` now injects `viewport-fit=cover` into each page's
viewport meta **at bundle time**, so `env(safe-area-inset-*)` is non-zero
when the nav first lays out. The previous runtime meta-patch in
mobile-shell.js raced initial layout and left the top nav under the
Dynamic Island on some pages. (mobile-shell's runtime patch stays as a
belt-and-suspenders for mobile-Safari preview.)
