## 1. Ctrl+click (13zu)
- Ctrl+click (⌘) a component adds it to the lasso's own selection or takes it out (`LASSO2.toggleBox`); an ink component
  brings its strokes. A drag on any selected component moves them all (`DocView.pointer` → `LASSO2.move`); Delete /
  Backspace removes them all (`INK.deleteSel`); the selection bar copies or duplicates; Esc lets go.
- A Ctrl+click on a link or a term in the text still follows it; a Ctrl+drag over text still holds the text (13z).

## 2. Deleting at once (13p)
- `EDIT.confirmBlock` no longer asks and no longer copies the whole record to the notebook folder first (`DISK.keep` —
  the freeze on a large notebook); Ctrl+Z is the way back. The box leaves the screen at once; the clean-up and the index
  run a frame later; the toast says what went with it. "Delete component…" → "Delete component". Notes still ask (a
  note is many components); Scientia has no project deletion of its own.

## 3. Ink in HTML pages (13zze)
- Pen mode (any hand but pan, the pen / highlighter / eraser) reaches each HTML page (`HTMLX.inkOn`, on every
  `INK.paintBars` and when a page loads). The page's own script (`HTMLX.INKSCRIPT`, added to its copy after the quote
  and notes scripts, on `window` so it comes before the quote script's pen) draws the stroke live, pins it to the element
  it starts on (path + fraction, like a note) and sends it; the app keeps it in `block.htmlInk {media, strokes}` (one
  undo step a stroke, the pressure feel applied) and sends back every stroke drawn the notes' way (`INK.path`). The
  eraser and the pen's back take strokes away. Strokes written within 60 px of each other are one ink label.
- **Export ink labels** (⋯ on the page, or the maximised page's bar): for each label the page sends a frozen copy of
  itself (its HTML now: canvases as pictures, typed values, no scripts, no ink); the app draws it in a hidden frame
  that runs no script, with html2canvas (`vendor/workers/html2canvas.js`, MIT, shipped as text), around the label at 2×.
  A crop step shows it with the ink over it (move, size or redraw the box; Skip / Stop / Export). Out come an image panel
  of the crop ("Ink label", captioned with the page's name) with the ink glued on it where it was (13zzc), connected to
  the page ("cropped from"); the label leaves the page. One undo step.
- A sandboxed page cannot draw itself: html2canvas clones into a frame the page cannot reach. The page keeps its sandbox.
