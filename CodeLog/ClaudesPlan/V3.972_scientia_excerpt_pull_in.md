# V3.972 — Scientia: copied words pulled in as a live excerpt

**Date:** 2026-11-10 · **Branch:** `scientia/web-capture` (after V3.971) · **Gabe:** "text inside a component that is selected, can be
copied and pasted to pull in just that part of the component in whichever note you paste it in."

## What was there

Copying words in a component already put `{ kind: 'text', blockId, from, to, text }` on the clipboard (`CLIPX.copy`, V3.961).
Pasted in another note it pulled in the whole component; in the same note it made a copy.

## What changed

- **An excerpt** is a pulled-in component with `refSpan { from, to, exact, prefix (40 chars before), suffix (40 after) }`. Its card
  shows only the passage, rendered by the editor with the original's marks clipped to it (a citation, an equation or an object cut
  in half is left out), an "excerpt" pill, and "from <note> › <component>".
- **Live, and safe when the original changes** (`EXCERPT.locate`): the passage at its place; else its words found elsewhere (prefix
  and suffix decide between repeats, then nearness); else what lies between the last words before it and the first words after it,
  when those are still there and not far apart (the passage edited inside). When none of these holds, the excerpt shows the words as
  they read when pulled in and says they are no longer in the original.
- **Kept as it was:** the whole text copied still pulls in the whole component; the same note still gets a copy; Ctrl+Shift+V now
  makes a copy in another note too. The Markdown mirror and the read-only HTML export carry the passage.
- **Judgment call:** "whichever note" read as any other note; in the note the words came from, a paste stays a copy, as before
  (an excerpt of a component sitting beside it would only repeat it).
