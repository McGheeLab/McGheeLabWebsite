# V4.105 — Scientia: search says an experiment note's stage and run

## Why
Gabe, 20 Nov: "the search function should show if the experiment note is planning, run, or analysis, and shows the run on it too."

Every note of an experiment carries the experiment's name, and since V4.97 every run of a series carries the series' name too. So a search for "30 kPa" listed six notes all called "30 kPa series":
- the quick list labelled each with its type (Planning, Experiment, Analysis) and never its run;
- the Atlas and the note pickers showed the name alone.

## What changed
- **`13c-chain.js`:**
  - `CHAIN.stageRun(d)` gives the note's stage, with its run where `CHAIN.runNo` shows one: "Planning · Run 3", "Run 3" (the Run note's own), "Analysis · Run 3", "Synthesis". A lone experiment shows its stage alone, and any other note shows nothing.
  - `CHAIN.listTitle(d)` gives "30 kPa series — Analysis · Run 3".
- **The quick search list** (`19-activity.js`): the stage in the right-hand column where the type was, and the run as a chip under the path. The stage and run count as words, so "30 kPa analysis run 2" finds that one note.
- **The Atlas** (the Search button, Ctrl+K):
  - a note's dot is labelled with its list title (`14b-atlas.js`; the nest view, `14d-nest.js`);
  - in the bubble, the note's card and caption say its stage and run (`14f-atlas3.js`);
  - a component's caption names its note the same way.
- **The note pickers** (`/open`, Move to…, a lens's notes, `CMD.KINDS.note`) list notes by their list title. A picked note is passed as the note itself, so commands are unchanged.
- **Settings → Experiment series → *In search, the stage and run*** (on). Off: the name alone, with the note's type, as before. The preview shows a search for "30 kPa" with its three notes, and follows this switch and *Show the run number*.
