## Goal

Three things the instructor needs, in the order they depend on each other:

1. **The module on the site** — `modules/bme466/05-integrins-and-the-motor-clutch.html`, byte-identical
   to the course repo's canonical build (`Interactive-Modules/projects/bme466/build/`), so the
   instructor can FTP it.
2. **In the learning-modules list** — `modules/manifest.json` must list the file so the class-builder's
   Add Module picker offers it; the instructor adds it to the class page themselves.
3. **Embeddable on the whiteboard** — `＋ Simulation` on a class board resolves `5.T.S` through
   `modules/bme466/simulations/index.json` and iframes `05-…html?embed=T.S&sim=1`. That needs the
   module to carry the V3.737 whiteboard head block (`whiteboard.js` refuses a module without
   `whiteboard-panel.js`, and `gen_simulations.py` skips it silently) and one generated wrapper page
   per simulation.

- **Nothing in the website repo is hand-edited except `sw.js`.** The module is a copy, the manifest and
  the simulation pages are generated. If a Week 5 section is added, renumbered or retitled later,
  `gen_simulations.py bme466 --check` is the detector; content edits inside a section need nothing.
- **A parallel course-repo session was editing Week 5 during this work** (engine went 60 → 69
  functions mid-task). The deployed copy is a snapshot of the state that passed the full course
  verification chain at copy time (207 harness assertions, parity, 24/24 call sites, equation
  bookkeeping). Re-run `cmp` against the canonical build before FTP if that session has since written.

  cuts a TestFlight build. This entry goes to `PENDING_RELEASE.md` like any other batched change.

## What the whiteboard QA found that nothing else had

`5.3.1` passed the ink test and showed "— pN" / "NaN" in every readout; the screenshot caught it. Root
cause was in the course build (a derived field read and never assigned), fixed there, re-copied
(484,911 bytes, byte-identical), `--check` clean, page re-read numeric. A text sweep across all 21 pages
found no other instance. **For this pipeline:** the per-page check should read the iframe's `.stats`
and `.val-verdict` text for `NaN|undefined|Infinity|— <unit>` as well as measuring ink — the sweep script
that did it here is a one-screen patchright run and belongs next to `gen_simulations.py --check` before
any FTP of a new module.
