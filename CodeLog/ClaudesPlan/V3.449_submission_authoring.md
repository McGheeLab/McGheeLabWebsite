## Changes

- **NEW subdoc templates (`rm/data/paper-templates/`, NOT in KNOWN_TEMPLATES — never in
  the manuscript picker; fetched by id):**
  - `rm-cover-letter.json` — 11pt article letter: `\today`, `{{AUTHOR_BLOCK}}` letterhead,
    "Re: {{TITLE}}", "Dear Editor," + `{{BODY}}` (cover_letter → placeholder, no heading)
    + `{{REVIEWERS}}` (suggested_reviewers → placeholder with a
    `\subsection*{Suggested reviewers}` wrap — prints only when the section has content)
    + a signature from `{{LEAD_AUTHOR}}`.
  - `rm-rebuttal.json` — "Response to Reviewers" title block + `{{INPUTS}}` (the rebuttal
    section renders `\section*`; `custom: section_star` makes subheadings emit
    `\subsection*` — Reviewer 1 / 2 without broken 0.x numbering) + its own
    natbib/unsrtnat bibliography (rebuttal `[@cite]`s collect via the filtered tree).
- **NEW `rm/js/paper-subdocs.js`** (`window.PaperSubdocs`): `DOCS` registry (cover_letter
  [+ suggested_reviewers folded in], rebuttal), `sectionsPresent(yDoc, docKind)`
  (present/hasContent via `paperTreeFromYDoc`), `buildSubdocBundle({docKind, yDoc, …})` —
  `fetchTemplate` + `buildBundle` with S-α's `sectionFilter`; **addons never forwarded**
  (anonymize must not strip the cover letter's signature).
- **Export page** — "Submission documents" card (`#px-subdocs`, hidden for non-journal
  paper types): per-doc status (no section / empty / ready), **⬇ .zip** (JSZip bundle —
  compile locally), and a **Compile** button present but disabled ("unlocks with the next
  compile-service update"). `_bindSubdocs` + `_downloadSubdocZip` in `rm/js/paper-export.js`;
  script tag + card in `rm/pages/paper-export.html`.
- **Editor** — submission sections show a "📨 Not part of the manuscript — compiles as a
  separate PDF" banner + indigo left edge (`renderSection`, `rm/js/paper-editor.js`);
  creation is via the existing + Add section prompt (the kinds registered in S-α appear
  automatically). CSS in paper-editor.css / paper-export.css.
- **Harness** — the catalog-sanity loop now exempts `rm-*.json` subdoc templates (they
  intentionally carry no special_sections catalog).
