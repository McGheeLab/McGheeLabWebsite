# V3.977 — Scientia: websites from a page saved in the browser; four fixes

Gabe, 11 Nov 2026: "Website capturing is not working. … If an image panel or an image from a panel is pulled in to a note, it
should appear there as well, which it currently doesn't. The Notes to synthesize component does not appear until you exit the
note and re-enter it. The command bar gets hit by my palm when I write, so deactivate it in pen mode, unless the actual pen hits
it."

## Website capture — what was wrong
- The capture route and the installed app were fine; captures of Wikipedia and Nature worked. The sites Gabe reads refuse a
  program: bioRxiv 429; ScienceDirect, Wiley, Cell, Science 403; PubMed and Scholar a check for robots. The lab website has no
  computer to fetch from at all.
- Getting past those checks would be disguising a program as a person, which we do not do. The honest route is the page the
  person already has open: browsers save it whole as "Webpage, Single File" (MHTML).

## Approach
1. `webcap.py`: an honest User-Agent; the page's own title; a robot check recognised; every refusal names the saved-page route.
2. `13zzs-webcap.js`: `fromMhtml` reads the MHTML in the app (no server: the website and every device can), makes it one
   self-contained HTML file the way `webcap.py` does (pictures, stylesheets, fonts as data URLs; scripts and frames out; links to
   the live page; the no-network CSP), and makes the same component (`make`, shared with `capture`). The Website… dialog and a
   refused capture offer it; a saved page dropped on a website component is its next version.
3. `13zu2-bulk.js`: `.mhtml` sorted as a saved page; a general drop of files on a note (there was none: only a figure's cells).
4. `13zzr-synth.js`: make the component when the note is drawn (`fill`), not only when opened.
5. `13zx-refwidget.js`: the picture of a `figCell` / `figPanel` structure in its reference card.
6. `11c-navbar.js`: touches on the bar ignored with a pen hand, the pen near, or a palm-sized contact.

## Decisions
- No bot-check evasion; the saved page is the answer for those sites.
- The MHTML is converted in the browser (DOMParser), not on the server, so the website works without a computer.
- In-page links (`#…`, written out in full by the browser) stay within the copy.
- The bar keeps working for the pen and the mouse in pen mode; only touches are ignored.
