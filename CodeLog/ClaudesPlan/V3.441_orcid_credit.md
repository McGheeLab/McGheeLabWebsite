# V3.441 — M1 of Paper Builder III: ORCID iDs + structured CRediT roles

> Author metadata upgrade. Per-author ORCID renders as the icon link beside the name in the
> compiled PDF; per-author CRediT roles generate the authorship-contribution statement into
> the paper's Author-contributions section with one click.

## Changes

- **Author rows (`rm/js/paper-export-config.js` bindAuthors):**
  - `orcid` input per author (monospace, validated `\d{4}-\d{4}-\d{4}-\d{3}[\dX]`;
    invalid → red outline, not saved). Round-trips through the existing `emit()` →
    `paperExports.authors` (no schema/rules changes).
  - **CRediT button** per author (`CRediT (n)`) toggling a 2-column panel of the 14
    CRediT roles (checkboxes → `a.credit: [role]`; panel stays open across the
    re-render via `openCreditIdx`; count updates live).
  - New exports: `CREDIT_ROLES` (the 14) + `creditStatement(authors)` —
    "A.B.M.: Conceptualization, Methodology; J.D.: Software." (initials from the full
    name; role-less authors skipped; '' when none).
- **Statement writer (`rm/js/paper-export.js`):** "✎ Generate CRediT statement" button
  under the authors card (contributors only). `_writeAuthorContribSection(text)` writes
  into the Yjs doc directly (the export page has the connection + PaperSchemas): finds the
  section by `special` (`author_contributions`/`credit_authorship`) or label, else creates
  it mirroring `appendSectionFromTree`'s shapes (label Y.Text, children Y.Array, paragraph
  {skeleton/body Y.Text, attrs Y.Map}) with the CURRENT template's catalog key (PNAS fact
  box etc.) + `special_render:'heading'`; clobbers the first paragraph's body. The section
  stays the editable source of truth — no export-time magic.
- **Export (`rm/js/paper-export-tex.js`):** `nameTex(a)` appends
  `\,\orcidlink{ID}` beside the name in ALL five `renderStructuredAuthors` formats
  (authblk / elsarticle / ieee name-run / achemso / superscript).
  `\usepackage{orcidlink}` (stock TeX Live) joins the preamble when any author carries an
  iD — checked directly on `opts.authorsCfg` in buildBundle (renderAuthorBlock runs during
  the main.tex substitution AFTER the preamble is finalized, so a render-time flag would
  fire too late).
- **CSS (`rm/css/paper-export.css`):** `.px-author-orcid` (+`.px-invalid`),
  `.px-author-credit-btn`, `.px-credit-panel`/`.px-credit-role`, `.px-credit-generate`.
