# V3.122 — References tab (writer-side citation management)

## Goal

Final tab from the V3.115/V3.120/V3.122 plan. Replace the References
placeholder with a working three-section panel:

1. **Cited in this draft** — every unique `[@key]` token currently in
   the document (paragraph bodies + figure captions + table captions +
   skeleton bullets + equation-library entries). Status badge: `cited`.
2. **Linked but not cited** — library papers where
   `meta.library.linked_drafts` includes this `paperId` AND no
   `[@key]` token uses the citation_key. Status badge: `linked`.
3. **Library search** — text input. Filters the lab's full library
   index (`state.citationByKey`). Status badge: `library`.

Per-row actions: `Insert citation` (restores caret + inserts `[@key]`),
`Link to draft` / `Unlink` (writes `meta.library.linked_drafts` array
on the library paper via `api.save('items.json', …)`), and a row title
link that opens `/rm/pages/library-paper.html?id=<itemId>` in a new tab.

No new schema. The References tab is a writer-side surface over the
same `items.json` + `meta.library.linked_drafts` field that the V3.106
reader-side link picker writes.

## Approach

### New helpers

- **`getCitedKeysInPaper()`** in [rm/js/paper-editor.js](../../rm/js/paper-editor.js):
  walks `paperMap.sections → children` looking for `[@key]` tokens in
  paragraph bodies, paragraph skeleton bullet text, equation block
  bodies (no — equations don't have `[@cite]`; skip), figure block
  bodies (captions), and table block `attrs.caption` (Y.Text). Also
  walks `paperMap.equation_library[*].latex` (also skip — math, not
  prose). Returns a unique-keyed array `[{key, paperId? (resolved from
  state.citationByKey), title?}]` sorted alphabetically by key.

- **`_refreshReferencesSection()`** in
  [rm/js/paper-equations.js](../../rm/js/paper-equations.js): builds
  the three groups + search. Subscribes to `paper-citations-loaded`
  + `paper-panel-changed` so the cited-keys list refreshes live as
  the user types.

### Citation index lazy-load

`state.citationByKey` is loaded by `loadCitationIndex()` on first
Cmd+K. The References tab eagerly triggers the load when first opened
so the user doesn't have to hit Cmd+K to see library results.

### Link toggle write path

- Read: `api.load('items.json')` → find item by `id` → look at
  `meta.library.linked_drafts: []`.
- Write: append/remove `paperId` in `linked_drafts`, then
  `api.save('items.json', {items})`.

This matches the V3.106 link-picker write path exactly.
